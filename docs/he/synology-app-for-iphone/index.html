בתוך האפליקציה

כל מה שאתה בודק ב-NAS

  • מערכת: CPU, RAM, עומס, קלט/פלט של דיסק וטמפרטורה, מצב מאוורר, בדיקת עדכון DSM, הפעלה מחדש וכיבוי.
  • אחסון: נפחים ובריכות עם סוג RAID, בריאות SMART וטמפרטורה לכל כונן, הוצאה בטוחה.
  • יישומים: מרכז החבילות, קונטיינרים וסטאקי Compose של Docker, מכונות וירטואליות.
  • גיבויים: Hyper Backup ו-Active Backup for Business, עם גדלים אמיתיים.
  • קבצים: File Station, העתקה והזזה ב-NAS, תיקיות משותפות. הורדות פותחות את גיליון השיתוף של iOS.
  • הרחק מהבית: QuickConnect, דומיין מותאם אישית או VPN. אין צורך בהעברת יציאות.
