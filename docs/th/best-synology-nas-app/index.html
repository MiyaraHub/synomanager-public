แอปเดียว ดูแลทั้ง NAS

Syno Manager เป็นแอปไคลเอนต์ของ Synology จากผู้พัฒนาภายนอกที่สร้างขึ้นจากคำถามที่ต่างออกไป ไม่ใช่ "แอปมือถือทำอะไรกับไฟล์ได้บ้าง" แต่เป็น "เจ้าของ NAS ต้องตรวจสอบอะไรจริง ๆ และอยากแก้อะไรจากโซฟา"

ผู้ช่วยที่ทำงานบนอุปกรณ์

ถามเรื่อง NAS ของคุณด้วยภาษาธรรมดา และรับคำตอบจากโมเดลบนมือถือของคุณ ใช้งานได้แบบออฟไลน์ ไม่ส่งข้อมูลไปที่ใด และอ่านข้อมูลเท่านั้น

แต่ละเครื่องมือเหมาะกับงานแบบไหน

นี่ไม่ใช่ตัวแทนของ DSM

การบอกขอบเขตให้ชัดมีประโยชน์กว่าการอ้างว่าไม่มีข้อจำกัด

งานควรทำที่ไหนเหตุผล
สร้างหรือขยายวอลุ่มDSMย้อนกลับไม่ได้ และต้องใช้หน้าจอที่เห็นทั้งอาร์เรย์พร้อมกัน
กำหนดงานสำรองข้อมูลDSMการเลือกแหล่งข้อมูล ตารางเวลา และระยะเวลาเก็บรักษาเป็นฟอร์มยาว
สร้างคอนเทนเนอร์DSM หรือ Portainerพอร์ต การเมานต์ และตัวแปรสภาพแวดล้อมต้องการพื้นที่กว้าง
กู้คืนจากข้อมูลสำรองDSMไม่ใช่สิ่งที่ควรเผลอเริ่มบนมือถือ
และบนมือถือ
ตอนนี้มีอะไรผิดปกติไหมSyno Managerหน้าจอเดียว พร้อมบอกสาเหตุ
สำรองข้อมูลทำงานแล้วหรือยังSyno Managerรอบล่าสุด รอบถัดไป และขนาดที่ใช้จริง
รีสตาร์ตคอนเทนเนอร์นั้นSyno Managerแตะสามครั้ง ดูบันทึกอีกหนึ่งครั้ง
ติดตั้งแพ็กเกจSyno Managerค้นหา เลือกวอลุ่ม ติดตั้ง แล้วยืนยันด้วยการอ่านรายการซ้ำ
ดูหน้าประตูบ้านSyno Managerดูภาพสดจากที่ไหนก็ได้ โดยไม่ต้องเปิด RTSP ออกสู่ภายนอก
ปลุกเดสก์ท็อปก่อนถึงบ้านSyno ManagerNAS จะกระจายแพ็กเก็ตปลุกให้คุณ
หลักการออกแบบ

ตัวเลขที่ตีความได้สองแบบ จะถูกระบุชื่อ ไม่ใช่เดา

หลักการนี้ปรากฏอยู่ทั่วทั้งแอป เป็นสิ่งที่เห็นได้ยากที่สุดในภาพหน้าจอ แต่มีค่าที่สุดในการใช้งานทุกวัน

  • การตั้งค่าที่อ่านไม่ได้จะถูกเรียกว่าอ่านไม่ได้ ไม่ใช่แสดงเป็นศูนย์ เพราะใน Download Station ศูนย์หมายถึง "ไม่จำกัด" และการอ่านที่ล้มเหลวแต่แสดงเป็นศูนย์ก็คือการโกหกอย่างมั่นใจ
  • จะไม่อ้างสถานะของโปรไฟล์ VPN เพราะระเบียนของ DSM ไม่มีฟิลด์สถานะให้อ่าน
  • วิดเจ็ตบอกว่าตัวเลขถูกอ่านเมื่อไร เพราะถ้าไม่มี NAS ที่เงียบสงบกับวิดเจ็ตที่ค้างเก่าจะดูเหมือนกันทุกประการ
  • การถอดไดรฟ์จะยืนยันเมื่อไดรฟ์หายไปจริง ไม่ใช่เมื่อคำขอถูกรับไว้
  • การเปลี่ยนโหมดพัดลมจะถูกอ่านกลับมาตรวจ หาก NAS ปฏิเสธโหมดนั้น ก็จะรายงานว่าถูกปฏิเสธ
  • สถานะที่ไม่รู้จักจะแสดงตามที่เป็นจริง เครื่องเสมือนที่ไม่ได้ทำงานและไม่ได้ปิดอยู่ จะแสดงคำที่ NAS ใช้และปุ่มกู้คืน ไม่ใช่ปุ่มเริ่มที่ใช้งานไม่ได้

ป้ายกำกับที่ผิดบนค่าที่อ่านถูกต้อง มาพร้อมความน่าเชื่อถือเท่ากับค่าจริง และไม่มีใครแยกออก เรื่องนี้คุ้มค่ากับความใส่ใจมากกว่ารายการฟีเจอร์

ไม่มีเซิร์ฟเวอร์คั่นกลาง

  • ไม่มีเซิร์ฟเวอร์ของ MiyaraHub มือถือของคุณเชื่อมต่อกับ NAS ของคุณ ไม่มีอะไรอื่นอยู่ระหว่างทาง
  • ข้อมูลรับรองอยู่ใน keychain ของแพลตฟอร์ม ไม่เก็บเป็นข้อความธรรมดา และไม่รวมอยู่ในการสำรองข้อมูลของอุปกรณ์
  • ผู้ช่วยทำงานบนอุปกรณ์ และการบิลด์จะล้มเหลวหากพบ SDK ของคลาวด์หรือ API key อยู่ที่ใดก็ตามในแอป
  • จ่ายครั้งเดียว $9.99 คิดราคาแยกตามแพลตฟอร์ม ไม่มีโฆษณา ไม่มีการสมัครสมาชิก ไม่มีการซื้อในแอป Apple เป็นการซื้อแบบยูนิเวอร์แซลครั้งเดียวสำหรับ iPhone, iPad และ Mac
  • รายงานการขัดข้องคือข้อยกเว้นเพียงอย่างเดียว และระบุไว้อย่างเปิดเผย ไม่ซ่อนไว้
เป็นอิสระ และบอกตรง ๆ Syno Manager สร้างโดย MiyaraHub Technologies และไม่มีส่วนเกี่ยวข้องกับ Synology ใช้ API ของ DSM ที่เปิดเผยเป็นทางการ ซึ่งเป็น API เดียวกับที่หน้าเว็บของ DSM เรียกใช้เอง

ทำไมต้องใช้แอป Synology จากผู้พัฒนาภายนอกด้วย
เพราะ Synology แบ่งฟังก์ชันบนมือถือออกเป็นหลายแอป แต่ละแอปทำได้ดีเพียงอย่างเดียว ส่วน Syno Manager เป็นอีกแนวทางหนึ่ง คือแอปเดียวที่ตรวจสอบ NAS และควบคุมสิ่งที่คุณต้องการจัดการจากมือถือ โดยไม่ต้องสลับไปมาระหว่างแอป
ใช้แทน DSM ได้ไหม
ไม่ได้ และก็ไม่ได้พยายามจะเป็นเช่นนั้น DSM คือที่ที่คุณใช้สร้างสิ่งต่าง ๆ ส่วน Syno Manager คือที่ที่คุณใช้ตรวจดูและสั่งการสิ่งเหล่านั้น
มีค่าใช้จ่ายต่อเนื่องไหม
ไม่มี Syno Manager ซื้อครั้งเดียว $9.99 ไม่มีโฆษณา ไม่มีการสมัครสมาชิก และไม่มีการซื้อในแอป ราคาคิดแยกตามแพลตฟอร์ม ดังนั้น Google Play และ Microsoft Store จึงซื้อแยกกัน ส่วน Apple เป็นการซื้อแบบยูนิเวอร์แซลครั้งเดียว ที่ครอบคลุม iPhone, iPad และ Mac
ข้อมูลของฉันปลอดภัยไหมกับแอปจากผู้พัฒนาภายนอก
Syno Manager เชื่อมต่อกับ NAS ของคุณโดยตรง ไม่มีเซิร์ฟเวอร์ของ MiyaraHub อยู่ระหว่างทาง ข้อมูลรับรองการเข้าสู่ระบบถูกเก็บไว้ใน keychain ของอุปกรณ์ และไม่รวมอยู่ในการสำรองข้อมูลของอุปกรณ์ ส่วนโมเดลของผู้ช่วยทำงานบนมือถือ รายงานการขัดข้องเป็นสิ่งเดียวที่ออกจากอุปกรณ์ และมีเพียง stack trace ไม่มีข้อมูลใด ๆ เกี่ยวกับ NAS ของคุณ ดูความเป็นส่วนตัว
