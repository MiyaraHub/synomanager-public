iPhone과 iPad에서 만나는 Synology NAS

Syno Manager는 Synology NAS를 위한 독립적인 네이티브 iOS 앱입니다. 실시간 시스템, 스토리지, 네트워크 수치, Docker, 카메라, 사진, 백업, 파일을 앱 하나에 담았고, 홈 화면 위젯, Siri, 휴대폰에서 실행되는 어시스턴트를 제공합니다.

$9.99의 유니버설 구매 한 번으로 iPhone, iPad, Mac을 모두 사용할 수 있습니다.

일반 텍스트가 아닌 키체인 ›

DSM 자격 증명은 iOS 키체인에 보관됩니다. 2FA 코드를 지원하며 신뢰하는 기기는 기억합니다.

NAS에서 확인하는 모든 것

  • 시스템: CPU, RAM, 부하, 디스크 I/O, 온도, 팬 모드, DSM 업데이트 확인, 재시작 및 종료.
  • 스토리지: RAID 유형이 표시되는 볼륨과 풀, 드라이브별 SMART 상태와 온도, 안전 제거.
  • 앱: 패키지 센터, Docker 컨테이너와 Compose 스택, 가상 머신.
  • 백업: 실제 용량이 표시되는 Hyper Backup과 Active Backup for Business.
  • 파일: File Station, NAS 안에서 복사 및 이동, 공유 폴더. 다운로드하면 iOS 공유 시트가 열립니다.
  • 외출 중에도: QuickConnect, 사용자 도메인 또는 VPN. 포트 포워딩이 필요 없습니다.
