入門指南

不到一分鐘就連上

NAS 上不需要安裝任何東西。Syno Manager 與 DSM 本來就在運作的 API 溝通 - 你只要告訴它 DiskStation 在哪裡、你是誰就好。

第零步

您需要準備的東西

需求詳細說明
一台 Synology NAS任何執行 DSM 7.0 或更新版本的機型。上面不需要安裝任何東西 - App 使用的是 DSM 網頁介面使用的同一批 API。
一個 DSM 帳號你平常的 DSM 使用者名稱與密碼。管理員帳號看得到所有內容；非管理員則只看得到 DSM 允許的內容，App 會隱藏其餘部分，而不是顯示會被拒絕的控制項。
你的裝置Android 7.0 或更新版本、iOS 16.0 或更新版本、macOS 11.0 或更新版本，或 Windows。四個平台都是同一個 App。
連到 NAS 的路徑同一個區域網路、連入該網路的 VPN、自訂網域，或 QuickConnect。任何一種都夠用。
只是查看並不需要管理員帳號。任何 DSM 使用者都能使用監控功能。控制動作 - 重新啟動容器、執行備份、退出磁碟 - 則需要 DSM 本身對該動作要求的權限，App 會如實回報被拒絕，而不是假裝成功。
它在哪裡

找到你的 NAS 位址

如果你已經用瀏覽器開啟過 DSM，網址列就有你需要的一切：主機與連接埠，就是 App 要求的兩個值。

從 DSM 本身

  • 控制台 › 網路 › 網路介面會顯示 NAS 在每個介面上的 IP 位址。
  • 控制台 › 網路 › DSM 設定會顯示 DSM 監聽的 HTTP 與 HTTPS 連接埠。除非有人更改過，否則是 5000 與 5001。

從瀏覽器

你輸入什麼來連到 DSM，App 就要什麼。在 https://192.168.1.20:5001 中，主機是 192.168.1.20，連接埠是 5001，且 HTTPS 為開啟。

從路由器

多數路由器會依名稱列出已連線的裝置。NAS 會以伺服器名稱出現 - 也就是在控制台 › 資訊中心中設定的那個。

為它指定固定位址。如果路由器在重新開機後給 NAS 不同的 IP，App 就會找不到它。在路由器上設定 DHCP 保留，或在 NAS 上設定固定位址，就能避免這個問題。使用主機名稱或自訂網域也可以，而且不在乎 IP 是什麼。
新增 NAS

表單上的每個欄位

在裝置清單上點選 + 新增 NAS。表單很短，只有三個欄位沒有合理的預設值。

欄位要填什麼
NAS 暱稱任何你喜歡的名稱 - 只有你自己看得到。有多台 NAS 時會很有用。
連線類型輸入位址時選擇直接 IP，使用 QuickConnect ID 時選擇 QuickConnect。請參閱下方說明。
主機 / IP 位址NAS 的本機 IP、主機名稱，或指向它的自訂網域。
連接埠啟用 HTTPS 時為 5001，關閉時為 5000 - 除非 DSM 改用了其他連接埠，那就填那些。
HTTPS預設為開啟，建議保持開啟。手機與 NAS 之間的一切都會加密，包括你的密碼。
驗證 SSL 憑證預設為關閉，因為多數 DiskStation 使用的是自簽憑證，無法對公開機構進行驗證。無論開關，連線仍然是加密的。只有在你安裝了正式憑證時才需開啟。
使用者名稱你的 DSM 帳號名稱。支援含有空格的使用者名稱 - App 會正確處理引號，這是其他用戶端常常失敗的原因。
密碼你的 DSM 密碼。眼睛圖示可在輸入時顯示密碼。密碼會寫入平台鑰匙圈或金鑰儲存區，絕不以純文字儲存。
兩步驟驗證如果你的 DSM 帳號使用驗證器 App，請開啟此項。請參閱下方說明。
透過 DSM 連接埠通道傳輸攝影機即時影像預設為關閉。關閉時，攝影機即時影像會直接連到連接埠 554 上的 RTSP，在自己的網路中速度較快，但無論你身在何處，都必須能連到該連接埠。開啟時，影像串流會透過你已在使用的 DSM HTTPS 連接埠傳輸，因此不必對外開放 554，也能從外部觀看即時影像。請參閱 Surveillance Station。
不必輸入位址

QuickConnect

將連線類型切換為 QuickConnect，輸入你的 QuickConnect ID，取代主機與連接埠。Synology 的中繼服務會找到你的 NAS，不論它在哪裡，也完全不需要設定路由器。

  • 你的 ID 在哪裡。在 DSM 的控制台 › 外部存取 › QuickConnect。必須先在那裡啟用。
  • 代價是什麼。中繼會增加延遲，所以縮圖與即時影像的載入速度會比在自己的網路中慢。一切功能仍可正常使用。
  • 省下了什麼。不必轉送連接埠、不必隨時更新動態 DNS，你這一端也不會有任何東西暴露在網際網路上。
你可以兩種都用。同一台 NAS 新增兩次 - 一次用本機 IP，一次用 QuickConnect - 在家用快速的那筆，外出用穩定的那筆。它們是各自獨立的項目，版面也各自獨立，哪個離你近就用哪個。
2FA

兩步驟驗證

如果你的 DSM 帳號受驗證器 App 保護，請在儲存前開啟兩步驟驗證 (2FA)。密碼通過後，App 會立刻要求你輸入六位數驗證碼。

  1. 在「新增 NAS」表單上開啟切換開關。
  2. 儲存 & 連線。App 會登入，DSM 會要求第二重驗證。
  3. 輸入驗證器中的驗證碼。
  4. 選擇是否記住這台裝置。如果記住，DSM 會發出裝置權杖，這支手機就不會再被要求輸入驗證碼。權杖的儲存方式與密碼相同，都存放在平台鑰匙圈。
如果驗證碼被拒絕，請檢查時鐘。驗證器的驗證碼是依目前時間產生的，所以手機或 NAS 的時鐘若有偏差，就會產生或預期錯誤的數字。NAS 的時間來源會顯示在主畫面的快速統計列。
送出之前

測試連線，然後儲存

測試連線會嘗試位址、連接埠與憑證，並告訴你發生了什麼事，但不會儲存任何內容。這是找出打字錯誤最快的方法，因為它能區分「連不到 NAS」與「連到了，但密碼不對」。

訊息的意思意思
連線逾時沒有任何回應。問題出在位址、連接埠或手機所在的網路 - 不是憑證，因為憑證根本還沒被嘗試。
憑證無效NAS 有回應，但拒絕了登入。位址與連接埠是對的；使用者名稱或密碼不對。
憑證錯誤已啟用 HTTPS，且對自簽憑證同時開啟了驗證 SSL 憑證。請關閉驗證。
需要 2FA此帳號使用兩步驟驗證，但切換開關是關閉的。請開啟後再試一次。

儲存 & 連線會儲存此項目並登入。你會進入主畫面，而你的 NAS 已經在載入中。

你已進入

第一次連線時會發生什麼事

  • App 會詢問你的 NAS 能做什麼。它查詢 DSM 的 API 目錄並保留清單。這就是為什麼沒有 Surveillance Station 的 NAS 永遠不會出現攝影機分頁，也是安裝套件後它的畫面就會出現的原因。
  • 所有支援的卡片都已開啟。新卡片會直接顯示而不是隱藏，所以你的 NAS 支援的功能，你就看得到。自訂是用來關閉項目的地方，不是用來尋找功能的地方。
  • 會擷取 NAS 的 MAC 位址，讓網路喚醒 (Wake-on-LAN) 之後能夠運作，不需要你自己去查。
  • 只會出現一次簡短的歡迎畫面。它會說明 App 的功能，以及在哪裡變更設定。有個核取方塊可以讓它不再出現。
  • 需要說明的畫面會出現說明卡片。長按卡片即可關閉；可在設定中逐一還原。
連線後才安裝了套件？功能清單是在連線時讀取的，所以連線後才安裝的套件還沒有分頁。下拉重新整理，或重新開啟 App，新畫面就會出現。
無法連線時

簡短檢查清單

  1. 在手機瀏覽器中開啟 DSM，位址與連接埠要與你輸入的完全相同。如果瀏覽器也連不上，問題就出在網路或位址，而不是 App。
  2. 確認 HTTPS 與連接埠相符。連接埠 5001 搭配關閉 HTTPS，或連接埠 5000 搭配開啟 HTTPS，都會逾時。它們是不同的監聽服務。
  3. 如果 NAS 使用的是出廠時內建的憑證，請關閉驗證 SSL 憑證。
  4. 檢查手機的網路。使用行動數據時，本機 IP 是連不到的。請連上 Wi-Fi，或改用 QuickConnect、網域或 VPN。
  5. 在 iOS 上，請允許本機網路存取。設定 › App › Syno Manager › 本機網路。沒有開啟的話，iOS 會默默封鎖對你自己網路內位址的連線。
  6. 檢查 DSM 的防火牆。控制台 › 安全性 › 防火牆。若有規則只允許特定位址，就會擋掉不在其中的手機。
  7. 檢查自動封鎖。控制台 › 安全性 › 帳號。多次登入失敗可能會讓你手機的位址被封鎖；它會列在那裡，可以將它移除。

完整疑難排解指南

常見問題

設定常見問題

使用 Syno Manager 需要準備什麼？
一台執行 DSM 7.0 或更新版本的 Synology NAS、該 NAS 上的 DSM 帳號，以及一台執行 Android 7+、iOS 16+、macOS 11+ 或 Windows 的裝置。NAS 上不需要安裝任何東西 - App 使用的是 DSM 本來就有的 API。
要輸入什麼位址和連接埠？
在自己的網路中，輸入 NAS 的本機 IP 位址與 DSM 的連接埠 - 啟用 HTTPS 時為 5001，關閉 HTTPS 時為 5000。你也可以輸入主機名稱或自訂網域。如果你不想處理位址，可以把連線類型切換為 QuickConnect，然後輸入你的 QuickConnect ID。
為什麼「驗證 SSL 憑證」預設是關閉的？
因為多數 DiskStation 使用的是自簽憑證，它不是由公開機構簽發，因此即使連線仍然是加密的，驗證也會失敗。關閉驗證就會接受該憑證。如果你安裝了正式的憑證 - 例如來自 Let's Encrypt - 請開啟驗證。
需要在路由器上開啟連接埠嗎？
不需要。在自己的網路中，不需要轉送任何連接埠。從外部連線時，由 QuickConnect 為你中繼連線，VPN 也可以。只有在你特別想要從網際網路直接連入，或想從網路外部透過 RTSP 觀看攝影機即時影像時，才需要連接埠轉送。
顯示連線逾時，該怎麼辦？
這個訊息代表 App 完全沒有得到回應，幾乎都是位址、連接埠或手機所在的網路有問題。請確認 HTTPS 與連接埠相符、若使用本機 IP 則手機要與 NAS 在同一個網路，並確認手機瀏覽器能以相同的位址與連接埠開啟 DSM 自己的網頁介面。
可以新增多台 NAS 嗎？
可以，想加幾台都行。每一台都有自己的憑證、儀表板版面與設定，你可以從裝置清單切換。請參閱多台 NAS 裝置。
