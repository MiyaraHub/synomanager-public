Syno Manager는 서비스가 아니라 NAS용 클라이언트입니다. 휴대폰이 DiskStation에 연결을 열 뿐이며, 구조의 전부가 이것입니다.

  • MiyaraHub 서버가 없습니다. 데이터가 지나갈 경로가 없으므로 NAS에 대한 어떤 정보도 저희에게 전달되지 않습니다.
  • 자격 증명은 키체인에. 플랫폼의 보안 저장소에 보관되며 일반 텍스트로 저장되지 않고 기기 백업에서도 제외됩니다.
  • 2FA와 기기 신뢰. 일회용 코드를 지원하며, 신뢰하는 기기는 기억하므로 실행할 때마다 묻지 않습니다.
  • 어시스턴트는 기기에서 실행됩니다. 질문, NAS 데이터, 답변이 휴대폰 밖으로 나가지 않습니다.
  • 밖으로 나가는 것은 하나뿐입니다. 충돌을 고칠 수 있도록 보내는 충돌 보고서입니다. 여기에는 스택 트레이스가 담기며 NAS 정보는 담기지 않습니다. 전체 내용 보기.

휴대폰으로 보는 Synology, 궁금증 해결

Syno Manager는 어떤 일을 하나요?
DSM에서 실제로 휴대폰으로 확인하는 기능을 하나의 앱에 담았습니다. 실시간 CPU, RAM, 온도, 네트워크 수치, 스토리지 볼륨과 드라이브별 SMART 상태, Docker 컨테이너, 패키지 센터, Surveillance Station 실시간 보기, Synology Photos와 Drive, Hyper Backup과 Active Backup, Download Station, File Station, 사용자, 예약된 작업, UPS, DDNS, Wake-on-LAN을 지원합니다. DSM이 공개한 자체 API를 사용해 NAS와 직접 통신합니다. 모든 화면은 사용자 가이드에서 다룹니다.
어떤 Synology 모델에서 동작하나요?
DSM 7.0 이상을 실행하는 모든 Synology NAS에서 동작합니다. 앱은 연결할 때 해당 NAS가 보고하는 내용을 읽고 실제로 지원하는 화면만 표시하므로, 2베이 DS223j와 랙마운트 RS1221+ 각각에 맞는 대시보드가 만들어집니다. 호환성을 참고하세요.
외출 중에도 사용할 수 있나요?
네. NAS를 한 번 추가하면 앱이 접속 가능한 경로를 알아서 사용합니다. 집에서는 로컬 IP를, 밖에서는 QuickConnect, 사용자 도메인 또는 VPN을 사용합니다. 사진, 카메라 실시간 보기, File Station과 Drive 다운로드는 모두 QuickConnect 중계를 통해 동작하므로 포트 포워딩이 필요하지 않습니다. 원격 접속을 참고하세요.
내 데이터가 사용자 서버를 거치나요?
NAS 데이터는 거치지 않습니다. Syno Manager는 NAS와 직접 연결되며 그 경로에 MiyaraHub 서버가 없으므로, 파일, 수치, 구성 정보는 저희에게 전달되지 않습니다. 자격 증명은 기기의 키체인 또는 키스토어에 보관되며 기기 백업에서 제외되고, 어시스턴트의 모델은 휴대폰에서 실행됩니다. 기기 밖으로 나가는 것은 Firebase Crashlytics를 통한 충돌 보고서 하나뿐이며, 스택 트레이스, 기기 모델, 앱 버전만 담기고 NAS 데이터는 전혀 포함되지 않습니다. 자세한 내용은 여기에서 확인하세요.
Syno Manager의 가격은 얼마인가요?

가격은 플랫폼별로 책정되므로 Google Play와 Microsoft Store는 각각 별도로 구매해야 합니다. Apple은 하나의 유니버설 구매로 iPhone, iPad, Mac을 모두 포함하며, 한 번 구매하면 세 기기 모두에서 사용할 수 있습니다.

2단계 인증을 지원하나요?
네. DSM 계정에서 2FA를 사용하면 앱이 일회용 코드를 요청하며, 기기를 기억해 두어 그 휴대폰에서는 다시 묻지 않도록 할 수 있습니다. 또한 무언가를 변경하는 모든 클라이언트에 DSM이 요구하는 SynoToken을 모든 제어 동작마다 가져와 함께 전송합니다.
NAS를 여러 대 관리할 수 있나요?
네. 원하는 만큼 추가하고 기기 목록에서 전환할 수 있습니다. 각 NAS는 자격 증명, 대시보드 레이아웃, 설정을 따로 보관합니다. 여러 대의 NAS를 참고하세요.
Syno Manager는 Synology에서 만든 앱인가요?
아니요. Syno Manager는 MiyaraHub Technologies LLC가 만든 독립 앱입니다. Synology Inc.와 제휴, 보증 또는 후원 관계가 없습니다. DSM의 웹 인터페이스가 사용하는 것과 같은 공개된 DSM API로 NAS에 연결합니다. 이 사이트에 언급된 Synology, DSM, 패키지 이름은 Synology Inc.의 상표입니다.
