相容性

只要執行 DSM 7，就能用

不需要對照機型清單，因為 App 根本沒有這種清單。連線時它會詢問你的 NAS 能做什麼，再依照答案自行調整。

規則

只有一項要求，其餘自動調整

需求詳細說明
DSM 版本DSM 7.0 或更新版本。這是唯一的硬性需求。
模型不限。DiskStation、RackStation、FlashStation，不論有無擴充設備。
硬碟槽不限。從一顆硬碟到二十四顆都行；App 列出的是 DSM 回報的內容。
架構不限。App 與 DSM 的 API 溝通，而不是直接面對硬體。
你的裝置Android 7.0、iOS 16.0、macOS 11.0 或 Windows - 四大商店皆有上架。
不支援 DSM 6。它使用不同的 API 版本與不同的驗證機制，若兩者都支援，就得猜測 NAS 說的是哪一種。而猜測，正是這個 App 極力避免的事。
為什麼沒有支援表

靠探索，而不是寫死的清單

依機型列出的支援表，在 Synology 推出新機型的那天就會出錯，而當其中一款新增了某個套件時，又會再錯一次。

  • App 在連線時查詢 DSM 的 API 目錄並保留結果。這份目錄就是你的 NAS 能做什麼的最終依據。
  • 畫面會出現，是因為你的 NAS 回報了背後的 API。安裝 Surveillance Station，就會出現攝影機檢視；解除安裝，該檢視就會消失。
  • 不會從機型名稱去推測任何事。兩台相同機型但安裝的套件不同，得到的 App 也就不同，這才是正確的。
  • NAS 沒有回報的數值會標示為未讀取，絕不會用看似合理的預設值填上去。

實用的說法是：如果你手機瀏覽器能打開 DSM 自己的網頁介面，而你的 DSM 帳號在那裡看得到某項內容，Syno Manager 也看得到。

常見問題

相容性常見問題

Syno Manager 支援哪些 Synology 機型？
任何執行 DSM 7.0 或更新版本的 Synology NAS - DiskStation、RackStation 與 FlashStation，不論有無擴充設備。沒有機型清單，因為 App 在連線時會直接詢問你的 NAS 能做什麼。
DSM 6 可以用嗎？
不行。需要 DSM 7.0 或更新版本。DSM 6 使用不同的 API 版本與驗證機制。
小型雙層 NAS 也能用嗎？
可以。畫面較少是因為它執行的服務較少，而不是因為不受支援。它實際執行的一切都會完整顯示。
支援擴充設備嗎？
支援。擴充設備中的硬碟會與內建硬碟並列顯示。
如果我的 NAS 執行的是 DSM 測試版呢？
通常都能運作，因為 App 讀取的是 API 目錄，而不是預設某個版本。若測試版更動了某個 API，App 可能將某個數值回報為未讀取 - 它會如實告知，而不是顯示錯誤的數字。
