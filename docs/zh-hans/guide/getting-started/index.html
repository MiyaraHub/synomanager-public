入门指南

不到一分钟即可连接

第零步

您需要准备

要求详情
一台 Synology NAS任何运行 DSM 7.0 或更高版本的型号。NAS 上无需安装任何东西，应用使用的 API 与 DSM 网页界面相同。
一个 DSM 账户你平常使用的 DSM 用户名和密码。管理员账户可以看到一切，非管理员账户能看到 DSM 允许它看到的内容，应用会隐藏其余部分，而不是显示会被拒绝的控件。
你的设备Android 7.0 或更高版本、iOS 16.0 或更高版本、macOS 11.0 或更高版本，或 Windows。四个平台是同一个应用。
通往 NAS 的路径同一个本地网络、接入该网络的 VPN、自定义域名，或 QuickConnect。任意一种就够了。
只是查看的话，不需要管理员账户。任何 DSM 用户都可以使用监控功能。控制操作，比如重启容器、运行备份、弹出硬盘，需要 DSM 本身对该操作要求的权限，被拒绝时应用会如实报告，而不是假装成功。
它在哪里

查找你的 NAS 地址

如果你已经在浏览器中打开过 DSM，地址栏里就有你需要的一切：主机和端口正是应用要求的两个值。

从 DSM 本身查找

  • 控制面板 › 网络 › 网络界面会显示 NAS 在各个网络接口上的 IP 地址。
  • 控制面板 › 网络 › DSM 设置会显示 DSM 监听的 HTTP 和 HTTPS 端口。除非有人改过，否则分别是 5000 和 5001。

从浏览器查找

你输入什么来访问 DSM，应用就要什么。在 https://192.168.1.20:5001 中，主机是 192.168.1.20，端口是 5001，并且已开启 HTTPS。

从路由器查找

大多数路由器会按名称列出已连接的设备。NAS 会以它的服务器名称出现，也就是在控制面板 › 信息中心中设置的那个名称。

给它一个固定地址。如果路由器在重启后给 NAS 分配了不同的 IP，应用就会找不到它。在路由器上做 DHCP 保留，或给 NAS 设置静态地址，就能避免这一点。主机名或自定义域名也可以，不受 IP 变化的影响。
添加 NAS

表单中的每个字段

在设备列表中点按 + 添加 NAS。表单很短，只有三个字段没有合理的默认值。

字段填写内容
NAS 昵称随便起什么名字，它只会显示给你自己看。有多台 NAS 时很有用。
连接类型输入地址时选直接 IP，输入 QuickConnect ID 时选 QuickConnect。参见下文。
主机 / IP 地址NAS 的本地 IP、主机名，或指向它的自定义域名。
端口开启 HTTPS 时为 5001，关闭时为 5000，除非 DSM 已改用其他端口，那就填那些端口。
HTTPS默认开启，建议保持开启。手机和 NAS 之间的一切都会被加密，包括你的密码。
验证 SSL 证书默认关闭，因为大多数 DiskStation 使用的是自签名证书，无法通过公共机构验证。无论开不开，连接都是加密的。只有在你已安装正式证书时，才需要开启。
用户名你的 DSM 账户名。支持包含空格的用户名，应用会正确地为它们加引号，而这正是其他客户端常常失败的原因。
密码你的 DSM 密码。输入时可点按眼睛图标显示。它会被写入系统钥匙串或密钥库，绝不以明文保存。
双重身份验证如果你的 DSM 账户使用验证器应用，请开启。参见下文。
通过 DSM 端口隧道传输摄像头实时画面默认关闭。关闭时，摄像头实时画面直接连接 554 端口的 RTSP，在你自己的网络中更快，但无论你身在何处，都需要能访问该端口。开启时，视频流会通过你已在使用的 DSM HTTPS 端口建立隧道，因此无需暴露 554 端口，也能在外部观看实时画面。参见 Surveillance Station。
无需输入地址

QuickConnect

把连接类型切换为 QuickConnect，输入你的 QuickConnect ID，而不是主机和端口。Synology 的中继会找到你的 NAS，无论它在哪里，也无需任何路由器配置。

  • ID 在哪里。在 DSM 的控制面板 › 外部访问 › QuickConnect中。必须先在那里启用。
  • 代价是什么。中继会增加延迟，因此缩略图和实时画面的加载速度比在自己的网络中慢。一切功能仍然可用。
  • 省去了什么。无需端口转发，无需保持动态 DNS 更新，你这边也没有任何内容暴露在互联网上。
两种方式可以并存。把同一台 NAS 添加两次，一次用本地 IP，一次用 QuickConnect，就能在家时用快速入口，外出时用可靠入口。它们是各自独立的条目，布局也各自独立，哪个离你更近就用哪个。
2FA

双重身份验证

如果你的 DSM 账户由验证器应用保护，请在保存之前开启双重身份验证 (2FA)。密码通过后，应用会立即请你输入六位验证码。

  1. 在“添加 NAS”表单上开启开关。
  2. 保存 & 连接。应用登录后，DSM 会请求第二重验证。
  3. 输入验证器中的验证码。
  4. 选择是否记住此设备。如果选择记住，DSM 会签发一个设备令牌，这部手机之后不会再被要求输入验证码。令牌的保存方式与密码相同，存放在系统钥匙串中。
如果验证码被拒绝，请检查时钟。验证器的验证码由当前时间生成，因此手机或 NAS 的时钟出现偏差，会生成或期望错误的数字。NAS 的时间源显示在主屏幕的快速统计行中。
在确定之前

先测试连接，再保存

测试连接会尝试地址、端口和凭据，并告诉你结果，但不会保存任何内容。这是发现输入错误最快的方法，因为它能区分“连不上 NAS”和“连上了，但密码不对”。

提示的含义含义
连接超时没有任何响应。问题出在地址、端口或手机所在的网络，而不是凭据，因为凭据根本没有被尝试。
凭据无效NAS 响应了，但拒绝了登录。地址和端口是对的，用户名或密码不对。
证书错误已开启 HTTPS，同时验证 SSL 证书也已开启，而 NAS 使用的是自签名证书。请关闭验证。
需要 2FA该账户使用双重身份验证，而开关处于关闭状态。请开启后重试。

保存 & 连接会保存条目并登录。你会进入主屏幕，此时 NAS 已在加载。

已连接

首次连接时会发生什么

  • 应用会询问你的 NAS 能做什么。它查询 DSM 的 API 目录并保存列表。这就是没有 Surveillance Station 的 NAS 从不显示摄像头标签，而安装套件后其界面就会出现的原因。
  • 所有受支持的卡片都会开启。新卡片默认可见，而不是隐藏，因此你的 NAS 支持的功能你都看得到。自定义是用来关闭内容的，而不是用来发现有什么的。
  • 会记录 NAS 的 MAC 地址，这样以后无需你去查找，就能使用网络唤醒 (Wake-on-LAN)。
  • 会出现一次简短的欢迎页。它会说明应用的功能以及去哪里更改设置。有一个复选框可以让它不再出现。
  • 需要说明的界面会出现帮助卡片。长按即可关闭，之后可以在设置中逐个恢复。
连接之后又安装了套件？功能列表是在连接时读取的，因此在那之后安装的套件还没有对应的标签。下拉刷新，或重新打开应用，新的界面就会出现。
无法连接时

简短清单

  1. 在手机浏览器中打开 DSM，使用与你输入的完全相同的地址和端口。如果浏览器也连不上，问题出在网络或地址，而不是应用。
  2. 检查 HTTPS 是否与端口匹配。关闭 HTTPS 却用 5001 端口，或开启 HTTPS 却用 5000 端口，都会超时，它们是不同的监听端口。
  3. 如果 NAS 使用的是出厂自带的证书，请关闭“验证 SSL 证书”。
  4. 检查手机的网络。本地 IP 无法通过移动数据访问。请连接 Wi-Fi，或使用 QuickConnect、域名或 VPN。
  5. 在 iOS 上，请允许本地网络访问。设置 › 应用 › Syno Manager › 本地网络。否则 iOS 会悄悄阻止对你自己网络中地址的连接。
  6. 检查 DSM 的防火墙。控制面板 › 安全性 › 防火墙。只允许特定地址的规则，会阻止不在其中的手机。
  7. 检查自动封锁。控制面板 › 安全性 › 账户。多次登录失败可能会封锁你手机的地址，它会列在那里，可以移除。

完整的故障排除指南

常见问题

设置常见问题

使用 Syno Manager 需要什么？
一台运行 DSM 7.0 或更高版本的 Synology NAS，NAS 上的一个 DSM 账户，以及一台运行 Android 7+、iOS 16+、macOS 11+ 或 Windows 的设备。NAS 上无需安装任何东西，应用使用的是 DSM 自带的 API，它们本来就在那里。
要输入什么地址和端口？
在你自己的网络中，输入 NAS 的本地 IP 地址和 DSM 的端口：开启 HTTPS 时为 5001，关闭 HTTPS 时为 5000。你也可以输入主机名或自定义域名。如果你完全不想处理地址，把连接类型切换为 QuickConnect，输入你的 QuickConnect ID 即可。
为什么“验证 SSL 证书”默认是关闭的？
因为大多数 DiskStation 使用的是自签名证书，它不是由公共机构签发的，所以即使连接仍是加密的，也无法通过验证。关闭验证就会接受该证书。如果你已安装正式证书，例如来自 Let's Encrypt，请开启验证。
需要在路由器上开放端口吗？
不需要。在你自己的网络中无需转发任何端口。在外部，QuickConnect 会为你中继连接，VPN 也可以。只有在你明确想从互联网直连，或想在网络之外通过 RTSP 观看摄像头实时画面时，才需要端口转发。
提示连接超时，怎么办？
这条提示表示应用始终没有得到回应，几乎总是地址、端口或手机所在网络的问题。请检查 HTTPS 是否与端口匹配；如果使用本地 IP，手机是否与 NAS 在同一网络；以及 DSM 自带的网页界面能否在手机浏览器中用相同地址和端口打开。
可以添加多台 NAS 吗？
可以，想添加多少都行。每台都保留自己的凭据、仪表盘布局和设置，你可以在设备列表中切换。参见多台 NAS 设备。
