볼륨 & 풀

한눈에 보는 용량

볼륨마다 이름, RAID 유형, 상태, 구성 드라이브 수가 표시된 카드가 있고, 그 아래 사용 중, 비율, 전체, 여유 공간이 표시된 사용량 막대가 있습니다.

표시 항목의미
볼륨 이름DSM이 붙인 이름 그대로 표시됩니다. VOLUME_1 등입니다.
RAID 유형RAID 5, SHR, RAID 1, Basic 등 아래의 풀이 실제로 어떤 구성이든 그대로 표시됩니다.
상태볼륨 자체의 상태: 정상, 성능 저하, 손상. 성능 저하된 어레이는 이 화면에서 오늘 바로 조치해야 할 유일한 항목입니다.
드라이브 수볼륨이 걸쳐 있는 물리 드라이브의 수입니다.
사용량 막대평소에는 초록, 80%를 넘으면 호박색, 90%를 넘으면 빨간색입니다. 상태 배지가 쓰는 기준과 같습니다.
사용 중 / 전체 / 여유세 가지를 모두 표시합니다. “70% 사용 중”과 “13 TB 남음”은 서로 다른 질문에 답하기 때문입니다.
Drives

각 베이에 들어 있는 것

볼륨 아래에 모든 물리 드라이브가 베이 번호순으로 나열됩니다.

  • 베이 - 디스크 1, 디스크 2 등으로, 본체에 붙은 라벨과 일치합니다.
  • 모델 - 드라이브 자체의 모델 문자열입니다.
  • 제조사와 유형 - 제조사와 HDD인지 SSD인지 표시합니다. NAS가 제조사를 식별하지 못한 드라이브는 추측하지 않고 알 수 없음으로 표시합니다.
  • 온도는 아래 기준에 따라 색으로 표시됩니다.
  • SMART 판정 - 드라이브의 자체 진단이 정상이면 SMART OK로 표시됩니다.
디스크 상태

SMART와 직접 시작할 수 있는 테스트

디스크 상태 하위 보기는 같은 드라이브를 더 넓게 보여 주며, 용량, 유형, 온도, SMART 상태가 각각의 칩으로 표시되고 모든 드라이브에 빠른 SMART 테스트 버튼이 있습니다.

  • 빠른 SMART 테스트는 드라이브가 자체적인 짧은 진단을 실행하도록 요청합니다. 몇 분이 걸리며 볼륨을 사용하는 다른 작업을 방해하지 않습니다.
  • 판정은 앱이 아니라 드라이브가 내립니다. SMART는 드라이브가 스스로를 보고하는 것이고, 앱은 그것을 전달할 뿐입니다. 정상이라던 드라이브가 나중에 고장 나는 것은 읽기의 한계가 아니라 SMART 자체의 한계입니다.
  • 읽을 수 없는 SMART 상태는 알 수 없음으로 표시하며 절대 정상으로 표시하지 않습니다. 읽지 못한 것과 정상으로 읽은 것은 다르며, 둘을 섞지 않습니다.
색상 뒤에 있는 수치

기준

여기에 있는 것 중 사용자의 하드웨어를 추측한 값은 없습니다. 앱이 색을 바꾸는 시점이며, 해당하는 경우 홈 화면의 상태 배지도 함께 바뀌는 시점입니다.

외장

USB, eSATA 및 안전 제거

두 개의 섹션이 있습니다. 마운트하고 제거할 수 있는 드라이브를 위한 외장 스토리지와, UPS, 프린터, 동글처럼 그 밖에 연결된 모든 장치를 위한 USB 장치입니다.

  • 제거는 드라이브가 사라져야 확인됩니다. 요청이 OK로 응답했다고 성공으로 알리지 않고, 기기 목록을 다시 읽어 드라이브가 실제로 없어졌을 때만 제거되었다고 알려 줍니다. “안전하게 뽑아도 됩니다”와 “아마 안전하게 뽑아도 됩니다”의 차이입니다.
  • 사용 중인 드라이브는 제거할 수 없습니다. 포맷 중이거나 초기화 중인 드라이브는 쓰는 도중에 뽑히는 일이 없도록 이유와 함께 거부됩니다.
  • 연결된 장치가 없으면 분명하게 알려 줍니다. 빈 목록에는 해석해야 하는 빈 상자 대신 “연결된 외장 드라이브 없음”이라고 표시됩니다.
한계

이 화면에서 하지 않는 것

스토리지는 잘못 탭하면 되돌릴 수 없는 유일한 곳이므로, 앱은 쓰기보다 읽기를 훨씬 더 많이 합니다.

  • 볼륨이나 풀을 만들거나, 확장하거나, 삭제하지 않습니다. 이 작업은 하려는 일을 충분히 보여 줄 수 있는 큰 화면의 DSM 스토리지 관리자에서 합니다.
  • 성능이 저하된 어레이를 복구하지 않습니다. 다만 어레이가 성능 저하 상태라는 사실은 홈 화면에서 분명하게 알려 줍니다.
  • 무엇이든 포맷하지 않습니다.
  • 전체 SMART 테스트는 실행하지 않고 빠른 테스트만 실행합니다. 전체 표면 검사는 몇 시간이 걸리므로 자리를 비워도 되는 곳에서 해야 합니다.
스크러빙, 재구축, 패리티 검사는 진행 중에 실행 중인 작업으로 표시되므로, DSM에서 시작했더라도 앱에서 끝나는 모습을 지켜볼 수 있습니다.

스토리지 FAQ

드라이브별 SMART 상태를 볼 수 있나요?
네. 디스크 상태 하위 보기에 모든 드라이브가 모델, HDD 또는 SSD 구분, 용량, 온도, SMART 판정과 함께 나열됩니다. 휴대폰에서 원하는 드라이브에 빠른 SMART 테스트를 시작할 수도 있습니다.
NAS 드라이브는 몇 도부터 너무 뜨거운 건가요?
앱은 드라이브 온도가 45°C를 넘으면 호박색, 55°C를 넘으면 빨간색으로 표시하고, 시스템 온도는 50°C를 넘으면 호박색, 60°C를 넘으면 빨간색으로 표시합니다. 이 기준은 홈 화면의 상태 배지에도 반영됩니다.
앱에서 USB 드라이브를 안전하게 제거할 수 있나요?
네, 외장 하위 보기에서 가능합니다. 제거 요청이 받아들여진 것이 아니라 드라이브가 실제로 기기 목록에서 사라졌을 때 제거가 확인됩니다. 포맷 중이거나 초기화 중인 드라이브는 제거할 수 없습니다.
앱에서 볼륨을 만들거나 확장할 수 있나요?
아니요. 볼륨과 풀의 생성, 확장, 복구는 DSM의 스토리지 관리자에서 합니다. 앱은 스토리지의 상태를 알려 주고 드라이브에 대한 작업을 할 수 있게 해 주지만, 휴대폰으로 어레이 구조를 바꾸지는 않습니다.
드라이브의 제조사가 왜 알 수 없음으로 표시되나요?
NAS가 제조사를 알려 주지 않았기 때문입니다. 앱은 모델 문자열로 제조사를 추측해 사실처럼 보여 주지 않고, 전달받은 내용만 그대로 표시합니다.
