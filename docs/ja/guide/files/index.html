ファイル

共有フォルダに、どこからでも

File Station と共有フォルダ、NAS 上でのコピーと移動、そしてコンテンツに関わる3つの DSM アプリである Note Station、Synology Office、Contacts を利用できます。Download Station がインストールされている場合は、ここにも表示されます。Download Station には専用のページがあります。

File Station

閲覧とダウンロード

ルート（アカウントで見えるすべての共有フォルダ）から始まり、そこから下へ移動します。上部のパンくずリストで現在地を確認でき、上の階層へも戻れます。

  • フォルダとファイルには、DSM が保持するサイズ、作成日と更新日、所有者、権限などの詳細が表示されます。
  • 任意のファイルをダウンロードできます。Android と iOS では共有シートが開くため、保存したり、別のアプリで開いたり、送信したりできます。Windows と macOS では、ネイティブの名前を付けて保存ダイアログが開きます。
  • 外出先でも動作します。ダウンロードは、QuickConnect のリレーを含め、NAS に到達できる経路を通じて行われます。
  • デバイスからファイルを選んで、NAS にアップロードできます。
見えるのは、DSM が見ることを許可しているものだけです。ここでの File Station は、DSM アカウントの権限をそのまま反映します。アカウントが読み取れないフォルダは、Web インターフェースと同じように表示されません。
File Station

NAS 上でのコピーと移動

ファイルやフォルダを選び、コピー先または移動先を選ぶと、転送はスマートフォンではなく NAS が実行します。数百ギガバイトであっても、お手元のデバイスを経由することはありません。

  • 長押しで選択して、1つ以上のファイルやフォルダを選びます。上部のバーがコピー先...と移動先...に切り替わります。
  • File Station を閲覧するのと同じ方法で保存先を選び、共有やフォルダを開いて確定します。NAS が一覧表示するすべての共有が保存先になり、NAS に接続された外付けドライブも含まれます。NAS が共有フォルダとしてマウントするため、共有フォルダとまったく同じように表示されます。
  • 同じ名前がある場合は、先に確認します。保存先に同じ名前の項目がすでに存在する場合は、処理が始まる前に、上書きするか、スキップして既存のものを残すかを選びます。
  • 移動は、長押しで確定します。移動はコピーが完了すると元のファイルを削除するため、確定ボタンはタップではなく長押しが必要です。アプリからは元に戻せない操作の前に、あえて少し手間を加えています。

保存先の選択画面は、ファイルを開くのではなくフォルダを選ぶことに絞った、File Station そのものです。

  • 実行中の進行状況として、NAS 自身から読み取った転送済みのバイト数とパーセンテージが表示されます。NAS がまだ合計を計算中の場合は、まだ意味のない数値ではなく「計算中」と表示され、計算中でも、これまでにコピーされた量（例：「これまでに 6.82 GB」）が表示され、バーは止まらずに動き続けます。
  • NAS が速度を報告している間は、速度が表示されます。低速な USB ドライブへの書き込み中などに NAS が一時的に応答しなくなると、バナーはコピー済みの量を保持し、新しい値が届くまで速度を非表示にして、NAS が応答するまで確認の頻度を下げます。コピー自体は、その間もずっと NAS 上で続いています。
  • キャンセルすると、NAS 上で転送が停止します。転送の途中でもかまいません。すでにコピーされたものは保存先に残り、ロールバックはされません。
  • アプリを閉じても処理は続きます。タスクは NAS のものであり、開いたままにしておく必要のある画面のものではありません。File Station を再び開くと、アプリは同じタスクに再接続し、見失うことはありません。
タップではなく長押しである理由。コピーは元のファイルをそのまま残すため、誤ってタップしても害はなく、そちらは1回のタップです。移動はコピーが完了すると元のファイルを削除するため、アプリの他の場所にある再起動やシャットダウンの操作と同じ、長押しで確定するパターンを採用しています。
共有フォルダ

共有フォルダそのもの

ファイルではなく、共有フォルダそのものです。各項目には、名前、配置されているボリューム、説明が表示され、アクセス制御権限がある場合は ACL チップが付きます。

  • 右下のボタンで共有フォルダを作成できます。
  • 各行のオーバーフローに、その共有に対してできる操作があります。
  • 暗号化された共有はその旨が表示されるため、再起動後にロック解除が必要なものがひと目でわかります。
共有がどこにあるかは重要です。すべての行にボリュームが表示されるため、ストレージ画面で満杯のボリュームを見ているときに「どのボリュームがいっぱいになっているのか」を最も早く確認できます。
Note Station

ノートブックとノート

上部にノートの合計数、ノートブック数、タグ数のサマリーがあり、その下にすべてのノートと、それぞれ件数を表示した各ノートブックが並びます。

  • 任意のノートを開いて、全文を読めます。
  • 画像は、ノート内の位置に表示されます。削除されたり末尾にまとめられたりせず、段落の間に表示されます。
  • NAS が送信できない画像は、消える代わりに画像を読み込めませんでしたと表示されます。Web クリッパーが外部の Web ページから追加した画像のうち、NAS が返せないものも同様です。
  • 右下の2つのボタンで、ノートブックを作成したりノートを追加したりできます。
  • 行からノートブックを削除できます。

このスクリーンショットでは、3つのノートブックのタイトルにぼかしを入れています。実際の NAS のものだからです。

Synology Office

インストール状況と、対応する機能

エディタではなくステータス画面です。NAS で動作している Synology Office のバージョンと、対応するドキュメントの種類（ドキュメント、スプレッドシート、スライド）がチェックマークとともに表示されます。

ここまでにとどめている理由。Office のドキュメントは Synology Drive に保存され、Synology Drive を通じて開きます。NAS の監視アプリに中途半端なスプレッドシートエディタを組み込む代わりに、アプリは Office があることをお伝えし、ドキュメントが実際にある Drive へご案内します。
Contacts

アドレス帳

すべてのアドレス帳の合計と、それぞれのアドレス帳の件数が表示されます。Google からインポートしたアドレス帳も、NAS 上で作成したものと並んで表示されます。

  • 上部のボックスから、すべてを横断して検索できます。
  • アドレス帳を展開すると、その中の連絡先が表示されます。セクションは折りたたまれるため、2,000件のアドレス帳が6件のものを埋もれさせることはありません。
  • 行から、または右下のボタンで、特定のアドレス帳に連絡先を追加できます。
  • 既存の連絡先を編集または削除できます。

1つのアドレス帳の名前にぼかしを入れています。実際のアドレスだからです。

よくある質問

ファイル FAQ

NAS のファイルをスマートフォンにダウンロードできますか？
はい。File Station を開き、ファイルを見つけてダウンロードします。モバイルでは共有シートが開き、Windows と macOS ではネイティブの「名前を付けて保存」ダイアログが開きます。ダウンロードは QuickConnect 経由でも動作します。
NAS に接続した USB ドライブにファイルをコピーまたは移動できますか？
はい。外付けドライブは、NAS が共有フォルダとしてマウントするため、共有フォルダと同じように保存先として表示されます。「コピー先」または「移動先」を選び、ドライブを開いて確定すると、NAS が直接書き込みます。
コピーや移動は、スマートフォンを経由しますか？
いいえ。処理は NAS 自身が行います。スマートフォンはリクエストを送り、進行状況を見守るだけなので、数百ギガバイトの転送でもデータ通信量を消費せず、アプリを閉じても処理は続きます。
アプリから共有フォルダを作成できますか？
はい。共有フォルダのサブビューから作成できます。既存の共有には、名前、ボリューム、説明、ACL 権限があるかどうかが表示されます。
Note Station のノートを読めますか？
はい。ノートのサブビューには、ノートブックがノート数とタグ数とともに表示され、任意のノートを開いて全文を読んだり、ノートブックを作成したり、ノートを追加したりできます。ノート内の画像はノート内の位置に表示され、NAS が送信できない画像は、消える代わりに「読み込めませんでした」のプレースホルダーで表示されます。
Synology Office にステータスしか表示されないのはなぜですか？
Office のドキュメントは Synology Drive に保存され、Synology Drive を通じて開くためです。アプリは Office がインストールされていることと、対応するドキュメントの種類を報告します。ドキュメントの編集は、Synology 純正の Drive アプリが適しています。
存在するはずのフォルダが見えないのはなぜですか？
ここでの File Station は、DSM アカウントの権限をそのまま反映します。アカウントが読み取れないフォルダは、Web インターフェースと同じように表示されません。そのフォルダを見られるアカウントでサインインしてください。
