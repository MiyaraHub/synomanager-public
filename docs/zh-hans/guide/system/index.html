系统健康

各项读数

卡片显示内容
CPU & RAM仪表总 CPU 以圆环显示，下方单独标出用户占比，让你分清自己的工作负载和系统开销。RAM显示百分比和绝对数值。
内存以条形显示已用与总量。在需要关注之前都是绿色。
CPU 平均负载一分钟、五分钟和十五分钟的数值 - 等待 CPU 时间的进程数，而不是百分比。需结合核心数来判断，所以八核机架式设备上的健康数值，对双盘位设备来说就是繁忙。
磁盘 I/O读写吞吐量以及使用率百分比 - 即磁盘有多少时间处于繁忙状态；当 NAS 感觉很慢而 CPU 看起来很空闲时，这往往才是真正的答案。
温度历史带当前数值的滚动图表。单位为 °C 或 °F，取决于你的偏好设置。
进程NAS 正在运行多少个进程。
散热

用手机更改风扇转速模式

散热卡片显示风扇状态和 NAS 所处的模式，以三选一的控件呈现：

  • 全速 - 最大风量，最大噪音。适合机架或柜子。
  • 凉爽 - 均衡的默认模式。
  • 静音 - 转速较低，温度较高。适合放在客厅里的 NAS，前提是硬盘承受得住。
经过确认，而非想当然。应用从 NAS 读取当前模式，写入你的选择，然后读回确认。NAS 悄悄拒绝的模式会被报告为已拒绝，而不是停留在屏幕上假装已生效。
无法识别的模式保持只读。如果你的 NAS 报告的散热模式不在这三种之内，卡片会显示它报告的内容，而不提供更改选项 - 而不是错误地把它标成已知的三种之一。
识别 & 警报

找到设备，关掉蜂鸣

  • 识别会让 NAS 的状态灯闪烁，方便你分辨眼前是哪一台。停止可结束闪烁。
  • 静音蜂鸣会停止警报蜂鸣器。它消除的是噪音，而不是问题本身 - 触发警报的原因依然存在，健康状况标题栏仍会如实显示。
DSM 更新

是否有固件更新

“DSM 更新”卡片会显示你当前使用的版本，以及 Synology 是否有更新的版本。检查更新会让 NAS 重新查询一次。

这是你 NAS 的固件，而不是应用。Syno Manager 像其他应用一样，通过 App Store 或 Google Play 更新自己。这张卡片是 DSM 自己的更新入口，与控制面板中的相同。
电源控制

重启与关机

位于“系统健康”底部，以红色标注，因为它们会影响所有已连接的用户 - 包括正在复制文件的人。

  • 重启 NAS - 正常重启。执行前会要求确认。
  • 关闭 NAS - 正常关机。执行前会要求确认。
远程关机前请三思。关机后的 NAS 无法自己转发唤醒数据包。要在你的网络之外让它重新开机，需要通过 VPN 接入，或使用已设置转发Wake-on-LAN的路由器。请参阅Wake-on-LAN，了解在何处可行。
快捷方式不会跳过确认。synomanager://reboot 和 synomanager://shutdown 链接有意只会打开应用到这个界面。破坏性操作不会因为是从启动器触发的就变成一键完成。
资源

实时图表

“资源”子视图是同样的数据，以滚动图表形式呈现，当你想知道“这是突发峰值还是持续如此”时就该用它。

  • CPU 使用率，区分用户和系统占比。
  • 内存使用率，显示已用与总量。
  • 磁盘读取和磁盘写入，各有自己的图表，另有整体磁盘使用率。
  • 平均负载，涵盖一分钟、五分钟和十五分钟。
图表按轮询间隔填充。间隔越短，细节越精细，也越耗电；间隔越长则越省电，但更粗略。
日志

DSM 记录了什么

两个标签页：系统显示 DSM 自己的日志，连接显示登录和文件访问。两者都在你请求时才读取。

  • 只加载一次并保持不动。你想看某一行时日志却按定时器重新读取，那就毫无用处，还白白消耗电量和网络。
  • 点按播放键可实时跟随。再点一次暂停。离开界面或把应用切到后台时，跟随会自动停止，所以被遗忘的日志标签页不会在你口袋里悄悄轮询。
  • 有搜索框，可在冗长的日志中找到某一行。
  • 容器和堆栈日志的工作方式相同 - 请参阅 Docker。
  • 文字可以选择。长按某一行会出现系统的复制 / 全选 / 分享栏，与屏幕上其他任何文字的操作一样。
  • 导出你正在看的内容。“系统”标签页中实时开关旁边，以及“连接”标签页中列表上方，各有一个导出按钮。它会打开一个面板，提供三种方式：保存到文件、通过分享发送或发邮件，或复制到剪贴板。
导出的是屏幕上的内容，而不是整份日志。级别筛选标签和搜索框筛选出的结果就是导出的内容 - 你已经筛掉的条目不会重新出现在导出中。文件为纯文本，每条一行，时间、级别、用户和描述以制表符分隔。
如果日志无法加载并提示连接超时，而应用的其他部分正常，那么没有响应的是 NAS 上的日志中心服务，而不是你的连接。请在 DSM 的套件中心检查日志中心是否已安装并正在运行 - 系统日志 API 属于它。
常见问题

系统 FAQ

可以在应用中调节风扇转速吗？
可以。“系统健康”中有一张散热卡片，提供全速、凉爽和静音三种模式。应用会读取 NAS 当前所处的模式，写入你的选择，然后再读回确认。如果 NAS 报告的模式不在这三种之内，则保持只读显示，而不是错误地呈现。
可以用手机重启或关闭我的 NAS 吗？
可以，在“系统健康”底部的“电源控制”中操作。两者在执行前都会要求确认。远程关机需要三思 - 关机后的 NAS 无法通过互联网唤醒，除非有 VPN，或路由器已配置Wake-on-LAN。
“识别 NAS”有什么用？
它会让 NAS 的状态灯闪烁，方便你在机架或柜子里分辨眼前是哪一台。“静音蜂鸣”会停止警报蜂鸣器，但不会消除触发警报的情况。
日志会自动刷新吗？
不会，而且是有意为之。日志只加载一次并保持不动，方便你阅读。点按播放键可实时跟随，再点一次暂停，离开界面或把应用切到后台时它会自行停止跟随。
可以导出或复制我正在看的日志吗？
可以。长按任意一行会出现系统的复制 / 全选 / 分享栏，也可以使用“系统”标签页中实时开关旁边的导出按钮，或“连接”标签页中列表上方的导出按钮。它会打开一个面板，提供保存到文件、分享或发送邮件、复制到剪贴板三种方式，导出的内容正是经过级别筛选和搜索后屏幕上显示的条目 - 每条一行，时间、级别、用户和描述以制表符分隔。
为什么 CPU 看起来正常，平均负载却很高？
平均负载统计的是等待中的进程，而它们往往是在等磁盘而不是 CPU。请查看同一界面上的磁盘 I/O 使用率 - 使用率百分比很高而 CPU 很低，通常就是原因所在。
