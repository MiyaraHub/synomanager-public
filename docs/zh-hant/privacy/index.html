隱私權

哪些會離開手機，哪些不會

講的是具體事實，而不是安撫。以下是 App 實際的行為，包括那唯一會被傳送的東西。

重點摘要

你的 NAS 資料永遠在你的掌控之中

資料去向
你的 NAS 回報的一切 - 系統讀數、儲存空間、網路、容器、套件、記錄、使用者、工作手機直接到 NAS。路徑中沒有我們的伺服器。
你的檔案、相片與攝影機串流手機直接到 NAS，透過你設定的任何路徑。
你的 DSM 使用者名稱、密碼與雙重驗證的裝置權杖裝置的鑰匙圈或金鑰庫。除了登入時傳給你的 NAS 之外，絕不會傳送到任何地方。
你對助理的提問與它的回答哪裡都不去。由裝置上的模型處理。
App 設定 - 主題、版面配置、輪詢、單位留在裝置上，除非你自己匯出。
當機報告Firebase Crashlytics。唯一會離開的東西。詳見下方。
沒有中間人

你和你的 NAS 之間沒有任何 MiyaraHub 伺服器

這是架構上的設計，而不是政策。Syno Manager 是一個使用 DSM 自己 API 的用戶端 - 與 DSM 網頁介面呼叫的是同一套 - 直接從你的手機連到你的 DiskStation。

  • 在你自己的網路上，連線是經由區域網路從手機到 NAS。
  • 透過 QuickConnect，會經過 Synology 的轉送服務 - 那是 Synology 的服務，使用你的 Synology 帳號，而不是我們的。
  • 透過網域或 VPN，則是直接連線到你的位址。
  • 在以上任何一種情況下，路徑中都沒有 MiyaraHub 的服務。你的 NAS 資料沒有任何可經過的地方，也沒有任何地方可儲存。
憑證

你的密碼存放在哪裡

  • 平台的安全儲存空間。iOS 與 macOS 上是鑰匙圈；Android 上是以 Keystore 為基礎的加密儲存區。絕不以明文儲存，也絕不放在一般的偏好設定檔裡。
  • 排除在裝置備份之外。App 明確將其安全儲存檔案排除在 Android 雲端備份與裝置轉移之外，所以還原或搬移手機時，不會連同你的 NAS 密碼一起帶過去。你只需要重新輸入一次。
  • 排除在 App 本身的設定匯出之外。備份 & 還原檔案刻意不包含連線、密碼或工作階段 - 一個帶著 NAS 密碼的可攜檔案，就是一個帶著 NAS 密碼到處跑的檔案。
  • 無法讀取時就清除。如果儲存的憑證無法解密 - 在還原到新硬體後可能發生 - App 會清除它們並要求你登入，而不是用無法讀取的東西重試。
例外

當機報告

App 內含 Firebase Crashlytics，而且是啟用的。當 App 當機時，會傳送一份診斷報告，以便找出並修正當機問題。

當機報告包含什麼

  • 堆疊追蹤 - 哪段程式碼失敗了，以及在哪裡。
  • 裝置型號與作業系統版本。
  • App 版本與組建編號。

不包含什麼

  • 你的 NAS 位址、名稱或設定。
  • 你的 DSM 使用者名稱、密碼或權杖。
  • 你的檔案、相片、攝影機影像或記錄。
  • 你向助理提出的任何問題。
它為什麼存在：沒有人看得到的當機，就是不會被修正的當機。這是用一份堆疊追蹤換取錯誤被找到 - 我們在這裡明確說出來，而不是藏起來，因為一個悄悄略過唯一會傳送資料之處的隱私權頁面，就不算是隱私權頁面。
助理

由建置機制保證，而不是靠承諾

裝置端助理使用的是已經存在於你手機上的模型。你的問題、你的 NAS 資料與答案，都不會離開裝置，關閉網路也能運作。

值得直接說清楚的一點：這不是需要某人記得遵守的政策。只要助理的程式碼中出現任何雲端主機、雲端 SDK 或 API 金鑰，App 建置中的檢查就會失敗。這項保證是結構性的。

權限

App 要求什麼權限，以及原因

權限原因
區域網路（iOS）用來連到位於你自己網路上某個位址的 NAS。沒有它，iOS 會默默封鎖連線。
相片資料庫僅在你挑選要傳送到 NAS 的檔案時使用。App 在 iOS 與 macOS 上會宣告此權限，除此之外不會碰觸資料庫。
麥克風僅用於助理的語音輸入，而且只有在你使用時才會用到。沒有麥克風的裝置也完全受到支援 - 該功能只是不會出現。
通知選用，用於 App 自己的提醒。

常見問題

隱私權常見問題

Syno Manager 會把我的 NAS 資料傳送到任何地方嗎？
不會。你的手機直接連線到你的 NAS。路徑中沒有任何 MiyaraHub 伺服器，所以你的檔案、相片、攝影機影像、記錄、使用數據與設定，永遠不會傳到我們或其他任何人那裡。
有任何東西會離開我的手機嗎？
只有一樣：透過 Firebase Crashlytics 傳送的當機報告 - 內容是堆疊追蹤、裝置型號與 App 版本。它不包含你的 NAS 資料、你的憑證或你的檔案。
我的 NAS 憑證存放在哪裡？
存放在平台的安全儲存空間中 - iOS 上的鑰匙圈，Android 上以 Keystore 為基礎的儲存區 - 絕不以明文儲存，並明確排除在 Android 雲端備份和裝置轉移之外。
助理會把我的問題傳送到伺服器嗎？
不會。它執行的是已經存在於你裝置上的模型，關閉網路也能使用。只要助理中出現任何雲端主機、SDK 或 API 金鑰，App 的建置就會失敗。
有廣告或追蹤器嗎？
App 中沒有廣告、沒有訂閱，也沒有 App 內購買。

對以上任何內容有疑問嗎？

請到追蹤器提問 - 它是公開的，所以答案也能幫助下一位使用者。
