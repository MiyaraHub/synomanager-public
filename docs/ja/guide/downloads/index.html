Download Station

送り先は NAS です、スマートフォンではなく

リンクやマグネットを貼り付けるか、.torrent を選ぶだけで、ダウンロードは NAS が行います。進行状況の確認、一時停止と再開、実際に設定されている内容の変更ができます。

Download Station

実行中のもの

上部の速度ヘッダーに、すべてのタスクの合計ダウンロード速度とアップロード速度が表示され、その下にタスクが並びます。

  • 各タスクには、名前、状態、進行状況バー、現在の速度、推定残り時間が表示されます。
  • 任意のタスクを一時停止、再開、削除できます。
  • 実行中のものがない場合は、空のボックスの意味を考えさせるのではなく「アクティブなダウンロードはありません」と表示します。
  • ヘッダーから1タップで設定を開けます。
  • 2つの API 世代のどちらにも対応します。Download Station には2つの API バージョンがあり、アプリは NAS が提供するどちらにも対応します。
追加

3つの追加方法

右下の + をタップします。

  1. リンクまたはマグネットを貼り付けます。https:// の URL も magnet:?xt= のリンクも、同じ入力欄に入力できます。
  2. または .torrent ファイルを選びます。デバイスからファイルピッカーで選択します。
  3. 保存先を選ぶには保存先をタップします。そのままにすると、Download Station の既定のフォルダに保存されます。
  4. 追加をタップします。タスクが一覧に表示されます。
スマートフォンはリモコンにすぎません。ファイルは NAS が自身の回線で取得するため、アプリを閉じても、外出しても、ダウンロードは続きます。
ダウンロード設定

すべての設定を NAS から読み取って表示

専用のサブビューで、Download Station と同じ分類で表示します。編集できる値には変更を確定するチェックマークが付き、読み取り専用の値は事実として表示されます。

小さいけれど大切なこと

未取得のセクションを、ゼロではなく明示する理由

NAS が実際に報告した設定だけが表示されます。アプリが読み取れなかったセクションは、ゼロとして表示せず、未取得と明示します。

これは細かいこだわりではありません。ここでは0 は制限なしを意味するため、読み取りの失敗を 0 と表示すると、実際には誰にもわからないのに、ダウンロードに制限がないとお伝えしてしまうことになります。2通りに解釈できる値は、不明として明示する価値があり、この画面はそうしています。

見つかりませんか？

Download Station のタブが表示されない場合

  1. パッケージがインストールされているか確認します。Download Station は DSM の一部ではなく、パッケージセンターから入手します。このアプリからインストールできます。
  2. アプリが持つ NAS の情報を更新します。機能の一覧は接続時に読み取られるため、その後にインストールしたパッケージには、まだタブがありません。プルして更新するか、アプリを開き直してください。
  3. 非表示になっていないか確認します。ファイルタブのオーバーフローメニューにあるビューをカスタマイズで、サブビューをオフにできます。
Download Station は、ほとんどの DSM 7 のバージョンで Python2 を必要とします。パッケージをインストールすると、パッケージセンターが依存パッケージとして自動的にインストールします。
よくある質問

Download Station FAQ

スマートフォンからトレントを追加できますか？
はい。URL の貼り付け、マグネットリンクの貼り付け、デバイスからの .torrent ファイルの選択の3通りがあります。追加する前に、保存先のフォルダも選べます。
アプリから Download Station の設定を変更できますか？
はい。BitTorrent の待ち受けポート、ダウンロードとアップロードの速度制限、最大ピア数、同時に実行するタスクの数、保存先フォルダを変更できます。変更はすべて、あとで NAS から読み戻して確認するため、NAS が拒否した値は拒否されたものとして報告されます。
ダウンロード制限の「0」は何を意味しますか？
制限なしです。これは Download Station 独自の慣例であり、アプリが読み取れなかったセクションを決してゼロとして表示しない理由でもあります。読み取れなかったものをゼロのように見せるのは、異なる誤った表明になってしまいます。
Download Station のタブが表示されないのはなぜですか？
その NAS にパッケージがインストールされていないためです。パッケージセンターから Download Station をインストールし、プルして更新するかアプリを開き直すと、タブが表示されます。
アプリを閉じてもダウンロードは続きますか？
はい。ダウンロードは NAS が自身の回線で行います。スマートフォンはリモコンにすぎません。
