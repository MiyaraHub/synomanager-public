מדריך למשתמש של Syno Manager

כל מה שהאפליקציה עושה, מסך אחר מסך ופקד אחר פקד - כולל הדברים שהיא בכוונה לא תעשה, ולמה. כל מסך מסתגל ל-NAS שלכם, ולכן אצלכם ייתכנו פחות חלקים ממה שמופיע כאן: האפליקציה מסתירה את מה שה-DiskStation שלכם לא מריץ ולא מציגה כפתור שלא יכול לעבוד.

מתחילים כאן

חדשים באפליקציה

שלושה דפים מביאים אתכם מהתקנה חדשה ל-NAS שאפשר לראות מכל מקום.

🚀

להתחלה

מה צריך, איך מוסיפים את ה-NAS, פורטים ו-HTTPS, אימות דו-שלבי, ומה לעשות כשהוא לא מתחבר.
🏠

מסך הבית

כותרת הבריאות, שורת הנתונים המהירים ורשת הכרטיסים - ואיך מסדרים מחדש, מכווצים ומסתירים כל חלק בה.
🌐

הרחק מהבית

QuickConnect, דומיין מותאם אישית או VPN, ואילו תכונות עובדות באיזה נתיב.
כל מסך

הלשוניות, לפי הסדר

הסרגל התחתון מחזיק עד תשע לשוניות ועוד More. כל לשונית היא קבוצה של תצוגות משנה שאפשר לסדר מחדש או להסתיר.

🧠

System

System Health, Resources ו-Logs. מדים, עומס ממוצע, I/O של דיסקים, היסטוריית טמפרטורה, מצב מאוורר, זיהוי, עדכון DSM והפעלה.
💾

Storage

Volumes & Pools, Disk Health ו-External. סוג RAID, שטח פנוי, SMART לכל כונן, Quick SMART Test וניתוק בטוח.
📡

Network

Throughput, Connections, Services, VPN ו-DDNS עם הכתובת הציבורית שלכם.
📁

קבצים

File Station, העתקה והעברה ב-NAS עצמו, Shared Folders, Note Station, Synology Office ו-Contacts.
⬇️

Download Station

הוספה באמצעות קישור, magnet או .torrent, שליטה במשימות שרצות, ושינוי ההגדרות שה-NAS שלכם דיווח עליהן.
📦

אפליקציות

Package Center, Docker, Docker Projects ו-Virtual Machine Manager.
📷

מדיה

Synology Photos עם מציג מסך מלא להחלקה, Synology Drive וצפייה חיה ב-Surveillance Station.
🔄

גיבוי

משימות Hyper Backup עם גדלי יעד אמיתיים, והתקנים ועומסי עבודה של Active Backup for Business.
🔧

Control Panel

משתמשים, Task Scheduler, UPS וההגדרות של האפליקציה עצמה.
✨

העוזר

שאלו על ה-NAS שלכם במילים פשוטות, קבלו בחזרה את פסק דין הבריאות, ודרגו את התשובות - הוא לומד במכשיר שלכם בלבד.

🖥️

מכשירי NAS מרובים

הוספה, שינוי שם, סידור והחלפה. כל אחד שומר את פרטי ההתחברות, הפריסה וההגדרות שלו.
🔌

Wake-on-LAN

להעיר את ה-NAS, או כל מכונה אחרת דרכו - ובדיוק מה מזה עובד מחוץ לרשת שלכם.
📱

ווידג׳טים למסך הבית

שנים עשר ווידג׳טים, כל אחד עם תצוגה מקדימה וחותמת זמן כך שקריאה ישנה לעולם לא נראית עדכנית.
🔗

Shortcuts & קישורים

סכמת ה-URL של synomanager://, קיצורי launcher, ו-Siri ו-Shortcuts מקוריים ב-Mac.
