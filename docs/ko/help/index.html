연결

“연결 시간 초과”

아무 응답이 없었다는 뜻입니다. 자격 증명은 시도조차 되지 않았으므로 문제는 주소, 포트, 네트워크이며 비밀번호는 절대 아닙니다.

  1. 입력한 주소와 포트 그대로 휴대폰 브라우저에서 DSM을 열어 보세요. 브라우저에서도 접속할 수 없다면 앱의 문제가 아닙니다.
  2. HTTPS와 포트가 맞는지 확인하세요. 5001은 HTTPS용, 5000은 HTTP용입니다. 서로 바꾸면 시간 초과가 됩니다.
  3. 휴대폰의 네트워크를 확인하세요. 192.168.1.20 같은 로컬 주소는 모바일 데이터에서는 존재하지 않습니다. Wi-Fi에 연결하거나 QuickConnect, 도메인 또는 VPN을 사용하세요.
  4. iOS에서는 로컬 네트워크 접근을 허용하세요. 설정 › 앱 › Syno Manager › 로컬 네트워크. 허용하지 않으면 iOS가 내 네트워크로의 연결을 조용히 차단하며, 증상은 네트워크 오류처럼 보이는 시간 초과로 나타납니다.
  5. DSM의 방화벽을 확인하세요. 제어판 › 보안 › 방화벽. 특정 주소만 허용하는 규칙이 있으면 그에 해당하지 않는 휴대폰은 차단됩니다.
  6. NAS가 켜져 있는지 확인하세요. 절전 중인 NAS는 응답하지 않습니다. 먼저 깨우세요.
로그인

“잘못된 자격 증명” 또는 인증서 오류

메시지의미해결 방법
잘못된 자격 증명NAS가 응답했고 로그인을 거부했습니다. 주소와 포트는 맞습니다.사용자 이름과 비밀번호를 확인하세요. 계정에서 2FA를 사용하는지 확인하세요(토글을 켜야 합니다). 실패한 시도로 주소가 차단되었을 수 있으니 제어판 › 보안 › 계정에서 DSM의 자동 차단 목록을 확인하세요.
인증서 오류HTTPS와 인증서 검증이 모두 켜져 있는데 자체 서명 인증서를 사용 중입니다.SSL 인증서 확인을 끄세요. 대부분의 DiskStation은 자체 서명 인증서를 사용하며, 어느 쪽이든 연결은 암호화된 상태로 유지됩니다.
2FA 필요계정에서 2단계 인증을 사용하는데 토글이 꺼져 있습니다.NAS 구성에서 2단계 인증(2FA)을 켜고 다시 연결하세요.
2FA 코드가 거부됨대개 코드가 아니라 시계 문제입니다.코드는 현재 시각을 기준으로 생성됩니다. 휴대폰과 NAS의 시계를 확인하세요. NAS의 시간 소스는 홈 화면의 빠른 통계 줄에서 볼 수 있습니다.
잘 되다가 다시 로그인하라고 나옴저장된 자격 증명을 읽을 수 없게 되었습니다. 앱을 새 휴대폰에 복원한 뒤 생길 수 있습니다.앱은 읽을 수 없는 정보를 지우고 다시 로그인하라고 요청합니다. 비밀번호를 한 번 다시 입력하세요.
사용자 이름에 공백이 있나요? 괜찮습니다. 앱이 올바르게 따옴표 처리를 하는데, 다른 클라이언트가 John Smith 같은 계정에서 실패하는 흔한 이유입니다.
없는 것

탭, 하위 보기 또는 카드가 없음

이유는 정확히 세 가지이며 해결 방법은 각각 다릅니다.

  1. 패키지가 설치되어 있지 않습니다. 앱은 NAS가 할 수 있는 일을 읽고 할 수 없는 것은 모두 숨깁니다. Download Station 패키지가 없으면 Download Station 탭도 없습니다. 패키지 센터에서 설치하세요.
  2. 연결한 뒤에 설치했습니다. 기능 목록은 연결할 때 읽습니다. 아래로 당겨 새로 고치거나 앱을 다시 열면 나타납니다.
  3. 숨겨져 있습니다. 탭의 ⋮ 메뉴 › 보기 사용자 지정을 확인하고, 카드는 설정 › 대시보드 카테고리를 확인하세요. 사용자 지정을 참고하세요.
숨겨진 보기의 카드를 탭하면 그렇다고 알려 주고 사용자 지정 버튼을 제안합니다. NAS가 해당 보기를 제공하지 않는다고 나오면 패키지가 실제로 없는 것입니다.
Photos

사진 라이브러리의 빈 타일

  • 최근 iPhone 사진: HEIC 형식이며, DSM 7.2.2 이상에서는 NAS가 더 이상 미리보기를 만들지 않습니다. Syno Manager가 기기에서 직접 디코딩하므로 표시되어야 합니다. 표시되지 않는다면 최신 버전의 앱인지 확인하세요.
  • 오래된 사진도 비어 있음: NAS의 썸네일이 실제로 없는 것입니다. 사진 화면에서 다시 인덱싱을 실행해 NAS가 다시 만들도록 하세요. 사진이 많으면 시간이 걸리고 NAS에서 실행되므로 앱을 닫아도 됩니다.
  • QuickConnect에서 전부 비어 있고 느림: 중계에 속도 제한이 있습니다. 좀 더 기다리거나, 집에서는 직접 연결 항목을 사용하세요.
카메라

실시간 보기가 집에서는 되는데 밖에서는 안 됨

NAS 구성의 DSM 포트를 통해 카메라 실시간 보기 터널링 설정 하나로 해결됩니다.

  • 꺼짐 - 실시간 보기가 포트 554의 RTSP로 바로 연결됩니다. 내 네트워크에서는 빠르지만, 이 포트는 외부에서 접근할 수 있는 경우가 거의 없습니다.
  • 켜짐 - 스트림이 이미 사용 중인 DSM HTTPS 포트를 통해 터널링됩니다. 추가로 열어 둘 것이 없고, DSM에 접속할 수 있는 곳이면 어디서든 동작합니다.
  • “탭하여 보기”가 표시된 카메라는 고장이 아닙니다. H.265 카메라이며 DSM이 정지 스냅샷을 만들지 않기 때문입니다. 탭하면 스트림이 열립니다.
로그

시스템 로그가 불러와지지 않음

앱의 다른 부분은 정상인데 로그에서 연결 시간 초과가 보고된다면, 응답하지 않는 것은 내 연결이 아니라 NAS의 로그 센터 서비스입니다.

  • DSM 패키지 센터에서 로그 센터가 설치되어 실행 중인지 확인하세요. 시스템 로그 API는 로그 센터에 포함되어 있습니다.
  • 계정 권한을 확인하세요. 대부분의 DSM 구성에서 시스템 로그를 읽으려면 관리자 권한이 필요합니다.
  • 컨테이너와 스택 로그는 별개이며 Docker에서 가져오므로, 시스템 로그가 안 되어도 이쪽은 동작할 수 있습니다.
위젯

홈 화면 위젯이 오래됨

Android와 iOS가 위젯을 언제 새로 고칠 수 있는지 결정하며, 둘 다 배터리를 아끼기 위해 새로 고침을 강하게 제한합니다. 어떤 앱도 새로 고침을 강제할 수 없으며, 그래서 각 위젯에 약속 대신 수치를 측정한 시각을 표시합니다.

  • 앱을 여세요 - 가장 확실한 새로 고침입니다.
  • Android: Syno Manager를 배터리 최적화에서 제외하세요.
  • iOS: 앱의 백그라운드 앱 새로 고침이 켜져 있는지 확인하세요.
  • 접속 가능 여부를 확인하세요. 위젯은 휴대폰이 접속할 수 없는 NAS를 읽을 수 없습니다. 로컬 IP 항목만 있는 상태에서 모바일 데이터를 쓰고 있다면, 집에 올 때까지 업데이트되지 않습니다.
  • “업데이트된 적 없음”은 아직 읽기에 성공한 적이 없다는 뜻입니다. 방금 추가했거나 그 뒤로 앱을 실행하지 않은 경우입니다.
어시스턴트

어시스턴트 탭이 없음

어시스턴트에는 온디바이스 모델이 필요하며, 모델이 없는 하드웨어에서는 탭이 아예 숨겨집니다. 작동하지 않는 컨트롤은 없는 것보다 나쁩니다.

  • Android에는 Gemini Nano 모델을 사용할 수 있는 AICore가 필요합니다.
  • iOS 및 macOS에서는 Apple Intelligence가 지원되고 켜져 있어야 합니다.
  • 설정 › 온디바이스 AI에서 기기가 보고하는 내용을 확인하세요. 확인된 상태가 표시됩니다.
여전히 해결되지 않음

문의하기

버그와 기능 요청은 공개 트래커에 남겨 주세요. 받은편지함에 묻히지 않고 번호와 토론 스레드가 생깁니다.

버그 신고 또는 기능 요청

포함할 내용: 앱 버전(설정에 바로 표시되고 정보 화면에 빌드 번호가 있습니다), DSM 버전, NAS 모델, 내 네트워크인지 외부인지, 그리고 기대했던 동작. 개인 정보를 가린 스크린샷이 설명보다 훨씬 도움이 됩니다.
자주 묻는 질문

문제 해결 FAQ

연결 시간 초과라고 나옵니다. 무슨 뜻인가요?
입력한 주소와 포트에서 아무 응답이 없었다는 뜻이며, 자격 증명은 시도조차 되지 않았습니다. HTTPS와 포트가 맞는지, 휴대폰이 NAS에 접속할 수 있는 네트워크에 있는지, 휴대폰 브라우저에서 같은 주소로 DSM 웹 인터페이스가 열리는지 확인하세요.
비밀번호가 맞는데 자격 증명이 잘못되었다고 나오는 이유는 무엇인가요?
NAS가 응답했고 로그인을 거부했기 때문입니다. 오타가 없는지, 계정에서 2FA를 사용하는지 확인하고, 반복된 시도로 휴대폰 주소가 차단되었을 수 있으니 DSM의 자동 차단 목록도 확인하세요.
있어야 할 탭이 보이지 않는 이유는 무엇인가요?
해당 탭의 기반이 되는 패키지가 설치되어 있지 않거나 하위 보기가 숨겨져 있습니다. 연결한 뒤에 설치한 패키지는 새로 고쳐야 합니다. 아래로 당기거나 앱을 다시 여세요.
카메라가 집에서는 되는데 밖에서는 안 됩니다.
DSM 포트를 통해 카메라 실시간 보기 터널링을 켜세요. 꺼져 있으면 실시간 보기가 포트 554의 RTSP를 필요로 하는데, 보통 외부에서는 접근할 수 없습니다.
사진이 빈 타일로 표시됩니다.
DSM 7.2.2+에서는 HEIC 사진의 미리보기를 더 이상 만들지 않으므로 기기에서 직접 디코딩합니다. 오래된 사진도 비어 있다면 사진 화면에서 다시 인덱싱을 실행하세요.
위젯에 오래된 수치가 표시되는 이유는 무엇인가요?
위젯을 언제 새로 고칠 수 있는지는 운영체제가 결정하기 때문입니다. 바로 이런 이유로 각 위젯에 데이터를 가져온 시각이 표시되며, 가장 확실한 새로 고침은 앱을 여는 것입니다.
