Vertailu

DS finderin lisäksi, yhdessä sovelluksessa

DS finder on Synologyn oma sovellus NAS:in käyttöönottoon ja seurantaan. Syno Manager on itsenäinen sovellus, joka on tehty käyttöönoton jälkeistä päivää varten: kaiken NAS:in ajaman tarkistamiseen ja hallintaan ilman sovellusten välillä vaihtamista.

Rinnakkain

Kaksi sovellusta, kaksi tehtävää

Tämä ei ole tulostaulu. DS finder tekee asioita, joita Syno Manager ei tee, kuten uuden NAS:in käyttöönoton ja DSM:n oman Push Servicen ilmoitusten vastaanoton. Taulukko näyttää, mihin kumpikin sopii.
