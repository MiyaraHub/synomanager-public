File Station

瀏覽與下載

從根目錄開始 - 你的帳號看得到的每個共用資料夾 - 再往下層層瀏覽。頂端的導覽路徑會顯示你在哪裡，也能帶你回到上一層。

  • 資料夾與檔案，各附 DSM 掌握的詳細資料：大小、建立與修改日期、擁有者與權限。
  • 可以下載任何檔案。在 Android 與 iOS 上會開啟分享選單，你可以儲存、用其他 App 開啟或轉傳。在 Windows 與 macOS 上則會出現原生的另存新檔對話框。
  • 離開家也能用。下載會走 NAS 目前可連到的任何路徑，包括 QuickConnect 中繼。
  • 從你的裝置選取檔案，上傳到 NAS。
你看得到的，就是 DSM 允許你看的。這裡的 File Station 完全遵守你 DSM 帳號的權限 - 你的帳號無法讀取的資料夾不會出現，與網頁介面相同。
File Station

在 NAS 上直接複製與移動

選取檔案或資料夾，選擇複製到或移動到，傳輸由 NAS 執行 - 不是你的手機。即使是數百 GB，也完全不會經過你手上的裝置。

  • 長按選取一個或多個檔案與資料夾。頂端列會切換為複製到...與移動到...。
  • 選擇目的地的方式與瀏覽 File Station 相同 - 開啟共用資料夾或資料夾並確認。NAS 列出的每個共用資料夾都可作為目的地，包括插在 NAS 上的外接硬碟：它的呈現方式與共用資料夾完全相同，因為 NAS 是把它當作共用資料夾掛載的。
  • 檔名衝突時會先詢問。如果目的地已有同名項目，在任何動作開始前，你可以選擇覆寫或略過並保留現有的。
  • 移動需要長按確認。移動會在複製完成後刪除原始檔案，因此確認按鈕必須按住，而不是輕點 - 這是刻意設下的一點阻力，因為這項操作在 App 裡無法復原。

目的地選擇器其實還是 File Station，只是範圍限定在選擇資料夾，而不是開啟檔案。

  • 執行時顯示進度 - 已移動的位元組數與百分比，直接從 NAS 讀取。NAS 仍在計算的總量會顯示為計算中，而不是一個暫時沒有意義的數字；計算期間，橫幅仍會顯示目前已複製多少，例如「目前 6.82 GB」，並搭配會移動的進度列，而不是一條停住的進度列。
  • 只要 NAS 回報了速度就會顯示。如果 NAS 有一段時間沒有回應 - 寫入速度較慢的 USB 隨身碟時很常見 - 橫幅會保留已複製的量，在收到新讀數前先隱藏速度，並降低查詢頻率，直到 NAS 再次回應。複製本身在 NAS 上全程持續進行。
  • 取消會在 NAS 上中止傳輸，即使傳到一半。已複製到目的地的內容會保留，不會被復原。
  • 關閉 App，傳輸仍會繼續。這項工作屬於 NAS，而不是你得一直開著的畫面。重新開啟 File Station，App 會重新連上同一項工作，而不是失去追蹤。
為什麼要長按，而不是輕點。複製會保留原始檔案，所以誤觸也沒有代價 - 那個只要輕點一下。移動則會在複製完成後刪除原始檔案，所以採用與 App 其他地方的重新啟動和關機控制相同的長按確認模式。
共用資料夾

共用資料夾本身

不是檔案，而是共用資料夾。每個項目都會顯示名稱、所在磁碟區、說明，以及具備存取控制權限時的 ACL 標籤。

  • 用右下角的按鈕建立共用資料夾。
  • 每一列的更多選單收納了你可以對該共用資料夾執行的操作。
  • 加密的共用資料夾會被標示出來，讓你一眼看出重新開機後哪些需要解鎖。
共用資料夾放在哪裡很重要。每一列都會顯示磁碟區，當你在儲存空間畫面看到某個磁碟區快滿時，這是回答「哪個磁碟區快滿了」最快的方式。
Note Station

筆記本與筆記

頂端有摘要 - 筆記、筆記本與標籤的總數 - 接著是所有筆記與各個筆記本，各附自己的數量。

  • 開啟任何一則筆記閱讀完整內容。
  • 圖片會顯示在筆記中原本的位置，位於段落之間，而不是被移除或全擠在最後。
  • NAS 無法傳送的圖片會在原處顯示無法載入圖片，而不是直接消失 - 包括網頁剪輯工具從外部網頁加入的圖片，NAS 有時無法回傳這類圖片。
  • 用右下角的兩個按鈕建立筆記本或新增筆記。
  • 從筆記本所在列刪除筆記本。

這張截圖中有三個筆記本標題已模糊處理 - 它們是真實 NAS 上的內容。

Synology Office

已安裝，以及支援哪些功能

這是狀態畫面，不是編輯器：顯示你的 NAS 執行的 Synology Office 版本，以及它支援的文件類型 - 文件、試算表與投影片 - 各附一個勾號。

為什麼只到這裡。Office 文件是儲存在 Synology Drive 中，並透過 Synology Drive 開啟。與其在 NAS 監控 App 中做一個只有一半功能的試算表編輯器，App 選擇告訴你 Office 就在那裡，並引導你前往文件實際所在的 Drive。
聯絡人

通訊錄

所有通訊錄的總數，接著是各個通訊錄與其各自的數量 - 包括從 Google 匯入的通訊錄，與 NAS 上建立的通訊錄並列顯示。

  • 從頂端的搜尋框搜尋所有內容。
  • 展開通訊錄即可查看其中的聯絡人；各區段可以收合，因此有兩千筆資料的通訊錄不會淹沒只有六筆的通訊錄。
  • 從通訊錄所在列，或用右下角的按鈕，新增聯絡人到特定通訊錄。
  • 編輯或刪除現有的聯絡人。

有一個通訊錄名稱已模糊處理 - 那是真實的地址。

常見問題

檔案常見問題

可以把 NAS 上的檔案下載到手機嗎？
可以。開啟 File Station、找到檔案並下載。在行動裝置上會交由分享選單處理；在 Windows 與 macOS 上則會出現原生的另存新檔對話框。下載也能透過 QuickConnect 進行。
可以把檔案複製或移動到插在 NAS 上的 USB 隨身碟嗎？
可以。外接硬碟會像共用資料夾一樣出現在目的地清單中，因為 NAS 是把它當作共用資料夾掛載的。選擇「複製到」或「移動到」，開啟該硬碟並確認 - NAS 會直接寫入。
複製或移動時，資料會經過我的手機嗎？
不會。NAS 會自行完成工作。你的手機只負責送出請求並觀看進度，所以數百 GB 的傳輸不會動用你的行動數據，而且關閉 App 後仍會繼續執行。
可以在 App 裡建立共用資料夾嗎？
可以，在「共用資料夾」子檢視中進行。現有的共用資料夾會顯示名稱、所在磁碟區、說明，以及是否具備 ACL 權限。
可以閱讀我的 Note Station 筆記嗎？
可以。「筆記」子檢視會顯示你的筆記本，並附上筆記數量與標籤數量，你可以開啟任何一則筆記閱讀完整內容、建立筆記本或新增筆記。筆記中的圖片會顯示在筆記裡原本的位置，NAS 無法傳送的圖片則會顯示「無法載入」的替代圖示，而不是直接消失。
為什麼 Synology Office 只顯示狀態？
因為 Office 文件是儲存在 Synology Drive 中，並透過 Synology Drive 開啟。App 會回報 Office 是否已安裝，以及它支援哪些文件類型；編輯文件應該交給 Synology 的 Drive App。
為什麼看不到我明明知道存在的資料夾？
這裡的 File Station 完全遵守你 DSM 帳號的權限。你的帳號無法讀取的資料夾不會出現，與網頁介面相同。請改用看得到它的帳號登入。
