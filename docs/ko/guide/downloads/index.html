Download Station

휴대폰이 아닌 NAS로 보내세요

링크나 마그넷을 붙여 넣거나 .torrent을 고르면 다운로드는 NAS가 합니다. 진행 상황을 확인하고, 일시 정지하고 재개하고, NAS에 실제로 설정된 값을 변경할 수 있습니다.

실행 중인 작업

맨 위의 속도 헤더에 모든 작업의 전체 다운로드 및 업로드 속도가 표시되고, 그 아래에 작업 목록이 이어집니다.

  • 각 작업에는 이름, 상태, 진행 막대, 현재 속도, 예상 남은 시간이 표시됩니다.
  • 어떤 작업이든 일시 정지, 재개, 삭제할 수 있습니다.
  • 실행 중인 작업이 없으면 해석해야 하는 빈 상자 대신 "활성 다운로드 없음"이라고 알려 줍니다.
  • 설정은 헤더에서 한 번 탭하면 열립니다.
  • 두 세대의 API가 모두 작동합니다. Download Station에는 두 가지 API 버전이 있었는데, 앱은 NAS가 제공하는 쪽에 맞춥니다.
추가하기

세 가지 방법

오른쪽 아래의 +를 탭합니다.

  1. 링크나 마그넷을 붙여 넣습니다. https:// URL과 magnet:?xt= 링크 모두 같은 입력란에 넣으면 됩니다.
  2. 또는 기기에서 .torrent 파일을 선택하면 파일 선택기가 열립니다.
  3. 저장 위치에서 저장할 곳을 고르거나, 그대로 두면 Download Station의 기본 폴더가 사용됩니다.
  4. 추가를 탭합니다. 작업이 목록에 나타납니다.
휴대폰은 리모컨일 뿐입니다. 파일은 NAS가 자체 연결로 가져오므로, 앱을 닫고 집을 나서도 다운로드는 계속됩니다.

작지만 중요한 부분

읽지 못한 섹션을 0이 아니라 읽지 못했다고 표시하는 이유

NAS가 실제로 보고한 설정만 표시됩니다. 앱이 읽지 못한 섹션은 0으로 그리지 않고 읽지 못했다고 표시합니다.

까다롭게 구는 것이 아닙니다. 여기서는 0이 제한 없음을 뜻하므로, 읽기에 실패한 값을 0으로 표시하면 실제로는 아무도 모르는 상황에서 다운로드에 제한이 없다고 알려 주는 셈입니다. 두 가지로 읽힐 수 있는 값은 알 수 없음으로 밝히는 것이 맞고, 이 화면이 그렇게 합니다.

찾을 수 없나요?

Download Station 탭이 보이지 않는다면

  1. 패키지가 설치되어 있는지 확인하세요. Download Station은 DSM의 기본 구성이 아니라 Package Center에서 설치합니다. 이 앱에서 바로 설치할 수 있습니다.
  2. 앱이 보는 NAS 정보를 새로 고치세요. 기능 목록은 연결할 때 읽어 오므로, 그 이후에 설치한 패키지는 아직 탭이 없습니다. 당겨서 새로 고치거나 앱을 다시 여세요.
  3. 숨겨져 있지 않은지 확인하세요. 파일 탭의 더보기 메뉴에 화면 맞춤 설정이 있으며, 여기서 하위 화면을 끌 수 있습니다.
Download Station은 대부분의 DSM 7 버전에서 Python2가 필요하며, 패키지를 설치하면 Package Center가 종속 패키지로 함께 설치해 줍니다.

Download Station FAQ

휴대폰에서 토렌트를 추가할 수 있나요?
네, 세 가지 방법이 있습니다. URL 붙여넣기, 마그넷 링크 붙여넣기, 기기에서 .torrent 파일 선택입니다. 추가하기 전에 저장할 폴더도 고를 수 있습니다.
앱에서 Download Station 설정을 바꿀 수 있나요?
네. BitTorrent 수신 포트, 다운로드 및 업로드 속도 제한, 최대 피어 수, 동시에 실행할 작업 수, 저장 폴더를 바꿀 수 있습니다. 모든 변경은 이후 NAS에서 다시 읽어 확인하므로, NAS가 거부한 값은 거부되었다고 보고됩니다.
다운로드 제한이 0이면 무슨 뜻인가요?
제한 없음을 뜻합니다. 이는 Download Station 고유의 규칙이며, 앱이 읽지 못한 섹션을 0으로 표시하지 않는 이유이기도 합니다. 읽지 못한 값을 0처럼 꾸며 보여 주면 전혀 다른 잘못된 정보를 전달하게 됩니다.
Download Station 탭이 보이지 않는 이유는 무엇인가요?
해당 NAS에 패키지가 설치되어 있지 않기 때문입니다. Package Center에서 Download Station을 설치한 뒤, 당겨서 새로 고치거나 앱을 다시 열면 탭이 나타납니다.
앱을 닫아도 다운로드가 계속되나요?
네. 다운로드는 NAS가 자체 연결로 처리합니다. 휴대폰은 리모컨일 뿐입니다.
