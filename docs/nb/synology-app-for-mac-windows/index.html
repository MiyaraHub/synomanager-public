Synology NAS-en din på skrivebordet

Syno Manager er en uavhengig, innebygd app for Synology NAS-en din på macOS og Windows. Den samme appen som på telefonen, utformet for et større vindu: avlesninger i sanntid, Docker, sikkerhetskopier, filer og Wake-on-LAN, uten å åpne DSM i en nettleserfane.

Mac

På macOS

Siri og Snarveier, direkte ›

Åpne en del, Start NAS på nytt og Slå av NAS er ekte Snarveier-handlinger via App Intents. Planlegg dem eller kjed dem inn i dine egne snarveier.

Assistent med Apple Intelligence ›

Der Apple Intelligence er støttet og slått på, kan du spørre om NAS-en din med vanlige ord. Modellen kjører på Mac-en.

Pålogging i nøkkelringen ›

DSM-passord og enhetstokener lagres i macOS-nøkkelringen (Keychain), aldri i klartekst.

Apple er ett universelt kjøp: kjøp Syno Manager én gang, så er den på Mac-en, iPhone og iPad.

Windows

På Windows

Innebygd Lagre som ›

Last ned hvilken som helst fil fra File Station rett til en mappe på PC-en via den vanlige Windows-dialogen, hjemme eller over QuickConnect.

Vekk PC-en via NAS-en ›

NAS-en som alltid er på sender magic packet fra innsiden av nettverket ditt. Veiledningen dekker Windows-siden, inkludert å slå av Rask oppstart.

Sikkerhetskopier på et øyeblikk ›

Hyper Backup-oppgaver med plassen de tar, og Active Backup for Business-enheter med en deduplisert sum.

Microsoft Store-versjonen er et separat kjøp på $9.99.

På begge

Alt du sjekker på en NAS

  • System: CPU, RAM, belastning, disk-I/O og temperatur, viftemodus, kontroll av DSM-oppdatering, omstart og avslutning.
  • Lagring: volumer og pooler med RAID-type, SMART-helse og temperatur per stasjon, trygg utløsing.
  • Apper: Pakkesenter, Docker-containere og Compose-stacker, virtuelle maskiner.
  • Nettverk: gjennomstrømning i sanntid per grensesnitt, tilkoblinger, DSM-tjenester, VPN-profiler og DDNS.
  • Flere NAS: legg til så mange du vil, hver med eget oppsett og egne innstillinger.
