兼容性

只要运行 DSM 7，就能用

无需核对型号清单，因为应用没有这样的清单。连接时它会询问你的 NAS 能做什么，并据此构建自己。

规则

只有一项要求，其余自动适配

要求详情
DSM 版本DSM 7.0 或更高版本。这是唯一的硬性要求。
模型不限。DiskStation、RackStation、FlashStation 均可，无论是否带扩展单元。
盘位不限。一块硬盘或二十四块都行，应用会列出 DSM 报告的内容。
架构不限。应用与 DSM 的 API 通信，而不是直接和硬件通信。
你的设备Android 7.0、iOS 16.0、macOS 11.0 或 Windows，应用已在这四大应用商店上架。
不支持 DSM 6。它的 API 版本和认证方式都不同，同时支持两者就意味着要猜测 NAS 在用哪一种，而猜测恰恰是这款应用要避免的。
为什么没有型号对照表

靠发现，而不是写死的清单

按型号列出的支持表，在 Synology 发布新机型的那天就会过时，而在某个型号新增一个套件的那天又会再错一次。

  • 应用在连接时查询 DSM 的 API 目录并保存结果。这份目录就是你的 NAS 能做什么的最可靠依据。
  • 界面之所以出现，是因为你的 NAS 上报了对应的 API。安装 Surveillance Station，就会出现摄像头视图；卸载它，视图随之消失。
  • 绝不根据型号名称做假设。两台型号相同、套件不同的 NAS 会得到不同的应用界面，这才是正确的。
  • NAS 没有上报的数值会被标注为未读取，绝不会用看似合理的默认值来填充。

实际的判断方法是：如果DSM 自带的网页界面能在手机浏览器里打开，并且你的 DSM 账户能在那里看到某项内容，Syno Manager 同样能看到。

常见问题

兼容性常见问题

Syno Manager 支持哪些 Synology 型号？
任何运行 DSM 7.0 或更高版本的 Synology NAS，涵盖 DiskStation、RackStation 和 FlashStation，无论是否带扩展单元。没有按型号列出的清单，因为应用在连接时会直接询问你的 NAS 能做什么。
能在 DSM 6 上使用吗？
不能。需要 DSM 7.0 或更高版本。DSM 6 的 API 版本和认证方式都不同。
能用在小型双盘位 NAS 上吗？
可以。它显示的界面较少，是因为运行的服务较少，而不是不受支持。它运行的一切都会完整显示。
支持扩展单元吗？
可以。扩展单元里的硬盘会和内置硬盘一起显示。
如果我的 NAS 运行的是 DSM 测试版呢？
一般都能用，因为应用读取的是 API 目录，而不是假定某个版本。如果测试版改动了某个 API，可能会出现应用报告为未读取的数值，应用会如实说明，而不是显示错误的数字。
