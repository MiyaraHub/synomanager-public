乗り換える理由

1つのアプリで、NAS のすべてを

Syno Manager は、「スマートフォンアプリでファイルに何ができるか」ではなく、「NAS の持ち主が実際に何を確認し、ソファの上から何を直したいか」という問いから作られたサードパーティ製の Synology クライアントです。

全体像

乗り換える方が挙げる6つの理由

🔢

複数ではなく、1つのアプリ

システム、ストレージ、ネットワーク、コンテナ、パッケージ、カメラ、写真、バックアップ、ファイル、ユーザー、タスクを、1つの接続と1回のサインインで一か所にまとめています。

🚩

原因まで示すヘルスバッジ

単なる「警告」ではなく、どのドライブか、どのボリュームか、何度なのかまで表示します。取得できなかった値の上に、正常を示すチェックマークを出すこともありません。

🔧

監視だけでなく、操作も

コンテナの再起動、パッケージのインストール、バックアップの実行、サービスの切り替え、ドライブの取り外し、マシンの起動、ファンモードの変更を、スマートフォンから行えます。

🌐

外出先でも同じように使えます

写真、カメラのライブビュー、ファイルのダウンロードはすべて QuickConnect 経由です。ポート開放は不要で、外出しても機能が制限されることはありません。

🎨

自分好みのダッシュボード

カードの並べ替え、折りたたみ、非表示、下部バーのタブの選択、アクセントカラーの設定ができ、OLED ではピュアブラックで表示されます。前回の状態のまま再び開きます。

✨

デバイス上で動くアシスタント

NAS についてふだんの言葉で質問すると、スマートフォン上のモデルが答えます。オフラインでも動作し、どこにもデータを送信せず、読み取りしか行いません。

それぞれのツールの役割

DSM の代わりではありません

境界線がないと言い張るより、はっきり示すほうがお役に立てると考えています。

ボリュームの作成・拡張DSM元に戻せない操作で、アレイ全体を一度に見渡せる画面が必要だからです。
バックアップタスクの定義DSMソースの選択、スケジュール、保持期間の設定は入力項目が多いためです。
コンテナの作成DSM または Portainerポート、マウント、環境変数の設定には広い画面が必要だからです。
バックアップからの復元DSMスマートフォンで誤って始めてしまうような操作ではないためです。

設計の原則

2通りに解釈できる数値は、推測せず明示します

この考え方はアプリ全体に通っています。スクリーンショットでは最も伝わりにくいものの、日々の使用では最も価値のある部分です。

  • 読み取れていない設定は「未取得」と表示し、ゼロとは表示しません。Download Station ではゼロが「制限なし」を意味するため、読み取りに失敗した値をゼロで表示するのは、自信満々の嘘になってしまうからです。
  • VPN プロファイルの状態は断定しません。DSM のレコードには状態を読み取れるフィールドがないためです。
  • ウィジェットには数値の取得時刻を表示します。それがないと、静かな NAS と更新が止まったウィジェットを見分けられません。
  • 取り外しは、ドライブが実際に外れたことで確認します。リクエストが受け付けられただけでは完了とみなしません。
  • ファンモードの変更は読み戻して確認します。NAS が拒否したモードは、拒否されたものとして報告されます。
  • 認識できない状態は、そのまま表示します。実行中でも停止中でもない仮想マシンには、NAS が返した状態名と復旧用の操作を表示し、動作しない開始ボタンは出しません。

正しく読み取った値に誤ったラベルが付くと、本物の測定値と同じ重みで伝わってしまい、誰も気づけません。これは機能一覧よりも注意を払う価値のあることです。

プライバシー

間にサーバーは介在しません

  • MiyaraHub のサーバーはありません。スマートフォンが NAS に接続します。その経路には、ほかに何もありません。
  • 認証情報はプラットフォームのキーチェーンに保存され、平文では保存されず、デバイスのバックアップにも含まれません。
  • アシスタントはデバイス上で動作します。クラウド SDK や API キーが少しでも含まれていると、ビルドが失敗する仕組みです。
  • 買い切り $9.99で、価格はプラットフォームごとに設定されています。広告、サブスクリプション、アプリ内課金はありません。Apple は iPhone、iPad、Mac をまとめたユニバーサル購入です。
  • クラッシュレポートだけが唯一の例外であり、隠さずに明記しています。
独立したアプリであることを明示しています。Syno Manager は MiyaraHub Technologies が開発しており、Synology とは無関係です。DSM が公開しているドキュメント済みの APIs を使用しています。DSM 自身の Web インターフェースが呼び出すものと同じ API です。

よくある質問

乗り換えに関するご質問にお答えします

なぜサードパーティ製の Synology アプリを使うのですか？
Synology はモバイル向けの機能を複数のアプリに分けており、それぞれが1つの役割に特化しています。Syno Manager はその逆で、NAS の監視と、スマートフォンから操作したいことを、アプリを切り替えることなく1つにまとめています。
DSM の代わりになるのですか？
いいえ、代わりを目指してもいません。DSM は何かを作る場所で、Syno Manager はそれらの状態を確認して操作する場所です。
継続的な費用はかかりますか？
いいえ。Syno Manager は $9.99 の買い切りで、広告、サブスクリプション、アプリ内課金はありません。価格はプラットフォームごとに設定されており、Google Play と Microsoft Store は別々の購入になります。Apple は1回のユニバーサル購入で iPhone、iPad、Mac をカバーします。
サードパーティ製アプリでもデータは安全ですか？
Syno Manager は NAS に直接接続し、経路上に MiyaraHub のサーバーはありません。認証情報はデバイスのキーチェーンに保存され、デバイスのバックアップには含まれません。アシスタントのモデルもスマートフォン上で動作します。デバイス外に送信されるのはクラッシュレポートだけで、そこに含まれるのはスタックトレースのみで、NAS に関する情報は含まれません。詳しくはプライバシーをご覧ください。
お使いの NAS で動作しますか？
DSM 7.0 以降であれば動作します。詳しくは対応状況をご覧ください。
