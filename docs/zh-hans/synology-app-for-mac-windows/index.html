你的 Synology NAS，就在桌面上

Syno Manager 是一款独立的原生应用，适用于 macOS 和 Windows 上的 Synology NAS。与手机上是同一款应用，只是为更大的窗口重新布局：实时读数、Docker、备份、文件和 Wake-on-LAN，无需在浏览器标签页中打开 DSM。

Mac

在 macOS 上

原生支持 Siri 与快捷指令 ›

“打开某个部分”、“重启 NAS”和“关闭 NAS”是通过 App Intents 实现的真正的快捷指令操作。可以安排它们定时运行，或串联到你自己的快捷指令中。

Apple Intelligence 助手 ›

在支持并已启用 Apple Intelligence 的设备上，用平实的语言询问你的 NAS。模型运行在 Mac 上。

凭据保存在钥匙串中 ›

DSM 密码和设备令牌保存在 macOS 钥匙串中，绝不以明文保存。

Apple 是一次通用购买：购买一次 Syno Manager，你的 Mac、iPhone 和 iPad 上都能用。

Windows

在 Windows 上

原生“另存为” ›

通过标准的 Windows 对话框，把 File Station 中的任何文件直接下载到PC上的文件夹，在家或通过 QuickConnect 都可以。

通过 NAS 唤醒你的PC ›

始终开机的 NAS 在你的网络内部发送魔术包。指南涵盖了 Windows 一侧的设置，包括关闭快速启动。

备份一览 ›

显示所占空间的 Hyper Backup 任务，以及带有去重后总量的 Active Backup for Business 设备。

Microsoft Store 版本是另一次 $9.99 的独立购买。

两个平台通用

你会在 NAS 上查看的一切

  • 系统：CPU、RAM、负载、磁盘 I/O 和温度，风扇模式，DSM 更新检查，重启和关机。
  • 存储：显示 RAID 类型的存储卷与存储池，每块硬盘的 SMART 健康状况和温度，安全弹出。
  • 应用：套件中心、Docker 容器和 Compose 堆栈、虚拟机。
  • 网络：每个接口的实时吞吐量、连接、DSM 服务、VPN 配置和 DDNS。
  • 多台 NAS：想添加多少就添加多少，每台都有各自的布局和设置。
