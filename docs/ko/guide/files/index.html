파일

내 공유 폴더를 어디서나

File Station과 공유 폴더, NAS 안에서의 복사와 이동, 그리고 콘텐츠 중심의 DSM 앱 세 가지인 Note Station, Synology Office, Contacts를 다룹니다. Download Station이 설치되어 있다면 이곳에서도 사용할 수 있으며, 별도 페이지가 있습니다.

File Station

탐색 및 다운로드

계정에서 볼 수 있는 모든 공유 폴더가 모인 루트에서 시작해 아래로 내려갑니다. 맨 위의 이동 경로에는 현재 위치가 표시되고, 눌러서 위로 돌아갈 수 있습니다.

  • 폴더와 파일마다 DSM이 가진 크기, 생성 및 수정 날짜, 소유자, 권한 정보가 표시됩니다.
  • 어떤 파일이든 다운로드할 수 있습니다. Android와 iOS에서는 공유 시트가 열려 저장하거나, 다른 곳에서 열거나, 다른 곳으로 보낼 수 있습니다. Windows와 macOS에서는 기본 다른 이름으로 저장 대화 상자가 나타납니다.
  • 집 밖에서도 작동합니다. 다운로드는 QuickConnect 릴레이를 포함해 NAS에 연결할 수 있는 어떤 경로로든 진행됩니다.
  • 기기에서 파일을 골라 NAS에 업로드할 수 있습니다.
보이는 것은 DSM이 허용한 것입니다. 여기의 File Station은 DSM 계정의 권한을 그대로 따릅니다. 계정이 읽을 수 없는 폴더는 웹 인터페이스와 똑같이 나타나지 않습니다.
File Station

NAS 안에서 복사하고 이동하기

파일이나 폴더를 고르고 복사 위치 또는 이동 위치를 선택하면 전송은 휴대폰이 아닌 NAS가 수행합니다. 수백 기가바이트도 손에 든 기기를 거치지 않습니다.

  • 하나 이상의 파일과 폴더를 길게 눌러 선택합니다. 맨 위의 바가 복사 위치...와 이동 위치...로 바뀝니다.
  • File Station을 탐색하는 방식 그대로 대상 위치를 선택합니다. 공유 폴더나 폴더를 열고 확인하면 됩니다. NAS에 표시되는 모든 공유 폴더가 대상이 될 수 있으며, NAS에 연결한 외장 드라이브도 포함됩니다. NAS가 공유 폴더처럼 마운트하기 때문에 똑같이 나타납니다.
  • 이름이 겹치면 먼저 묻습니다. 대상 위치에 같은 항목이 이미 있다면, 작업이 시작되기 전에 덮어쓰기 또는 건너뛰고 기존 항목 유지 중에서 선택합니다.
  • 이동은 길게 눌러 확인합니다. 이동은 복사가 끝난 뒤 원본을 삭제하므로, 확인 버튼을 탭이 아닌 길게 눌러야 합니다. 앱에서 되돌릴 수 없는 작업 앞에 일부러 둔 한 박자의 마찰입니다.

대상 위치 선택기는 다시 File Station이며, 파일을 여는 것이 아니라 폴더를 고르는 용도로 범위가 제한됩니다.

  • 실행 중 진행 상황 - NAS가 직접 알려 주는 이동된 바이트 수와 퍼센트가 표시됩니다. NAS가 아직 계산 중인 전체 크기는 아직 의미 없는 숫자 대신 계산 중으로 표시되고, 계산 중에도 배너에는 지금까지 복사된 양(예: "6.82 GB so far")이 움직이는 막대와 함께 표시되어 멈춘 것처럼 보이지 않습니다.
  • NAS가 속도를 보고하면 항상 표시됩니다. 느린 USB 드라이브에 쓰는 중처럼 NAS가 한동안 응답이 없으면, 배너는 이미 복사된 양을 유지하고, 새 값이 올 때까지 속도를 숨기고, NAS가 다시 응답할 때까지 확인 빈도를 낮춥니다. 그동안에도 복사 자체는 NAS에서 계속 진행됩니다.
  • 취소하면 NAS에서 전송이 중단됩니다. 이미 복사된 내용은 대상 위치에 남으며, 되돌려지지 않습니다.
  • 앱을 닫아도 계속됩니다. 작업은 계속 열어 두어야 하는 화면이 아니라 NAS에 속해 있습니다. File Station을 다시 열면 앱이 같은 작업에 다시 연결되며, 작업을 놓치지 않습니다.
탭이 아니라 길게 누르는 이유. 복사는 원본을 그대로 두므로 잘못 눌러도 잃는 것이 없어서 한 번 탭하면 됩니다. 이동은 복사가 끝나면 원본을 삭제하므로, 앱의 다른 곳에 있는 재부팅 및 종료 컨트롤과 같은 길게 눌러 확인하는 방식을 씁니다.
공유 폴더

공유 폴더 자체

파일이 아니라 공유 폴더 자체입니다. 각 항목에는 이름, 위치한 볼륨, 설명이 표시되고, 접근 제어 권한이 있으면 ACL 칩이 붙습니다.

  • 오른쪽 아래 버튼으로 공유 폴더를 만들 수 있습니다.
  • 각 행의 더보기 메뉴에 그 공유 폴더에 할 수 있는 작업이 있습니다.
  • 암호화된 공유 폴더는 그렇게 표시되므로, 재부팅 후 잠금 해제가 필요한 폴더를 한눈에 알 수 있습니다.
공유 폴더의 위치는 중요합니다. 모든 행에 볼륨이 표시되므로, 스토리지 화면에서 가득 찬 볼륨을 보고 있을 때 "어느 볼륨이 차오르고 있나"를 가장 빨리 답할 수 있습니다.
Note Station

노트북과 노트

맨 위에 전체 노트, 노트북, 태그의 수가 요약되고, 그 아래에 모든 노트와 노트 수가 있는 각 노트북이 표시됩니다.

  • 노트를 열어 전체 내용을 읽을 수 있습니다.
  • 이미지는 노트 안의 제자리에 표시되며, 문단 사이에 그대로 놓여 있고 제거되거나 맨 끝에 몰려 있지 않습니다.
  • NAS가 보내지 못하는 이미지는 그냥 사라지는 대신 이미지를 불러올 수 없음으로 표시됩니다. 웹 페이지 외부에서 웹 클리퍼가 추가한 이미지처럼 NAS가 다시 제공하지 못하는 경우도 포함됩니다.
  • 오른쪽 아래의 두 버튼으로 노트북을 만들거나 노트를 추가합니다.
  • 해당 행에서 노트북을 삭제합니다.

이 스크린샷에서 노트북 제목 세 개는 실제 NAS의 것이라 흐리게 처리했습니다.

Synology Office

설치 여부와 지원 범위

편집기가 아니라 상태 화면입니다. NAS에서 실행 중인 Synology Office의 버전과 지원하는 문서 유형인 문서, 스프레드시트, 슬라이드가 체크 표시와 함께 표시됩니다.

여기까지만 제공하는 이유. Office 문서는 Synology Drive에 저장되고 Drive를 통해 열립니다. NAS 모니터에 스프레드시트 편집기를 어설프게 넣는 대신, 앱은 Office가 있음을 알려 주고 문서가 실제로 있는 Drive로 안내합니다.
Contacts

주소록

모든 주소록의 총합이 먼저 표시되고, 각 주소록과 연락처 수가 이어집니다. Google에서 가져온 주소록도 NAS에서 만든 주소록과 함께 표시됩니다.

  • 맨 위의 입력란으로 모든 항목을 검색합니다.
  • 주소록을 펼치면 그 안의 연락처가 보입니다. 섹션이 접히므로 연락처가 이천 개인 주소록이 여섯 개인 주소록을 덮어 버리지 않습니다.
  • 각 행에서, 또는 오른쪽 아래 버튼으로 특정 주소록에 연락처를 추가합니다.
  • 기존 연락처를 수정하거나 삭제합니다.

주소록 이름 하나는 실제 주소라서 흐리게 처리했습니다.

파일 FAQ

NAS의 파일을 휴대폰으로 다운로드할 수 있나요?
네. File Station을 열고 파일을 찾아 다운로드하세요. 모바일에서는 공유 시트가 열리고, Windows와 macOS에서는 기본 다른 이름으로 저장 대화 상자가 나타납니다. 다운로드는 QuickConnect로도 작동합니다.
NAS에 꽂은 USB 드라이브로 파일을 복사하거나 이동할 수 있나요?
네. 외장 드라이브는 NAS가 공유 폴더처럼 마운트하므로 공유 폴더와 똑같이 대상 위치로 나타납니다. 복사 위치 또는 이동 위치를 고르고, 드라이브를 열어 확인하면 됩니다. NAS가 직접 기록합니다.
복사나 이동이 내 휴대폰을 거치나요?
아니요. 작업은 NAS가 직접 처리합니다. 휴대폰은 요청을 보내고 진행 상황만 지켜보므로, 수백 기가바이트를 전송해도 데이터 요금을 쓰지 않으며, 앱을 닫아도 계속 진행됩니다.
앱에서 공유 폴더를 만들 수 있나요?
네, 공유 폴더 하위 화면에서 만들 수 있습니다. 기존 공유 폴더에는 이름, 볼륨, 설명, ACL 권한 유무가 표시됩니다.
Note Station 노트를 읽을 수 있나요?
네. 노트 하위 화면에는 노트북이 노트 수와 태그 수와 함께 표시되며, 노트를 열어 전체 내용을 읽고, 노트북을 만들고, 노트를 추가할 수 있습니다. 노트 안의 이미지는 노트의 해당 위치에 표시되고, NAS가 보내지 못하는 이미지는 사라지는 대신 불러올 수 없음을 알리는 자리 표시자로 나타납니다.
Synology Office에는 왜 상태만 표시되나요?
Office 문서는 Synology Drive에 저장되고 Drive를 통해 열리기 때문입니다. 앱은 Office가 설치되어 있는지와 지원하는 문서 유형을 보고합니다. 문서 편집은 Synology의 Drive 앱이 맡는 것이 맞습니다.
분명히 있는 폴더가 보이지 않는 이유는 무엇인가요?
여기의 File Station은 DSM 계정의 권한을 그대로 따릅니다. 계정이 읽을 수 없는 폴더는 웹 인터페이스와 똑같이 나타나지 않습니다. 그 폴더를 볼 수 있는 계정으로 로그인하세요.
