帮助

当出了问题时

大多数问题都属于少数几种类型。下面每一种都会说明症状的真实含义，这通常是找到解决办法的最快途径。

快速跳转
  • 无法连接
  • 登录被拒绝
  • 缺少标签页或卡片
  • 空白照片缩略图
  • 在外无法使用摄像头
  • 日志无法加载
  • 小组件过期
  • 没有助手标签页
  • 仍然解决不了
连接

“连接超时”

这意味着没有任何响应。你的凭据根本没有被尝试，所以问题出在地址、端口或网络上 - 绝不是密码。

  1. 在手机浏览器中打开 DSM，使用你输入的完全相同的地址和端口。如果浏览器也连不上，那问题不在应用。
  2. 检查 HTTPS 是否与端口匹配。5001 是 HTTPS 监听端口，5000 是 HTTP 端口。搞混了就会超时。
  3. 检查手机的网络。像 192.168.1.20 这样的本地地址在移动数据下并不存在。请加入 Wi-Fi，或使用 QuickConnect、域名或 VPN。
  4. 在 iOS 上，允许本地网络访问。设置 › 应用 › Syno Manager › 本地网络。没有它，iOS 会悄悄阻止对你自己网络的连接，表现为一个看起来像网络故障的超时。
  5. 检查 DSM 的防火墙。控制面板 › 安全性 › 防火墙 - 只允许特定地址的规则会拦住不在其中的手机。
  6. 检查 NAS 是否处于唤醒状态。休眠的 NAS 不会应答。请先唤醒它。
登录

“凭据无效”或证书错误

提示信息含义解决办法
凭据无效NAS 做出了应答，但拒绝了登录。地址和端口是正确的。检查用户名和密码。检查该账户是否使用了2FA - 开关必须打开。检查 DSM 的自动封锁列表，位于控制面板 › 安全性 › 账户，看看是否因登录失败而封锁了你的地址。
证书错误已开启 HTTPS，并且也开启了证书验证，但对方使用的是自签名证书。关闭验证 SSL 证书。大多数 DiskStation 使用自签名证书；无论如何，连接都保持加密。
需要 2FA该账户使用双重验证，但开关是关闭的。在 NAS 的配置中打开双重验证 (2FA)，然后重新连接。
2FA码被拒绝通常是时钟问题，而不是验证码问题。验证码由当前时间生成。请检查手机的时钟和 NAS 的时钟 - NAS 的时间来源显示在主屏幕的快速统计行中。
之前正常，现在要求重新登录保存的凭据变得无法读取 - 把应用还原到新手机后可能出现这种情况。应用会清除它无法读取的内容，并要求你重新登录。重新输入一次密码即可。
用户名里有空格？没问题。应用会正确地为其加引号，而这正是其他客户端在 John Smith 这类账户上出错的常见原因。
缺失的内容

缺少某个标签页、子视图或卡片

原因恰好有三种，它们的解决办法各不相同。

  1. 没有安装对应的套件。应用会读取你的 NAS 能做什么，并隐藏它做不到的一切。没有 Download Station 套件，就没有 Download Station 标签页。请从套件中心安装。
  2. 是在你连接之后才安装的。能力列表在连接时读取。下拉刷新，或重新打开应用，它就会出现。
  3. 被隐藏了。请检查标签页的 ⋮ 菜单 › 自定义视图，卡片则查看设置 › 仪表盘类别。详见自定义。
点按其视图被隐藏的卡片时会提示你，并提供“自定义”按钮。如果提示你的 NAS 不提供该视图，则说明套件确实不存在。
Photos

照片库中的空白缩略图

  • 最近的 iPhone 照片：这些是 HEIC 格式，在 DSM 7.2.2 及更高版本中，NAS 不再为它们生成预览。Syno Manager 会改在设备上解码，所以它们应该能显示。如果仍不显示，请确认应用是最新版本。
  • 较早的照片也是空白：NAS 的缩略图确实缺失。请在“照片”界面使用重新索引，让 NAS 重新生成。照片库很大时需要一段时间，并且在 NAS 上运行，所以你可以关闭应用。
  • 通过 QuickConnect 时全部空白且很慢：中转被限速了。请多等一会儿，或在家时使用直连条目。
摄像头

实时画面在家能用，在外不行

一项设置即可解决：NAS 配置中的通过 DSM 端口隧道传输摄像头实时画面。

  • 关闭 - 实时画面直接连接端口 554 上的 RTSP。在你自己的网络中很快，但这个端口几乎无法从外部访问。
  • 开启 - 视频流通过你已在使用的 DSM HTTPS 端口隧道传输。无需额外开放任何端口，只要能连上 DSM，在哪里都能用。
  • 显示“点按查看”的摄像头并没有坏。它是 H.265，而 DSM 不会为这类摄像头生成静态快照。点按后视频流就会打开。
日志

系统日志无法加载

如果日志提示连接超时，而应用的其他部分都正常，那么没有响应的是 NAS 上的日志中心服务，而不是你的连接。

  • 请在 DSM 的套件中心检查日志中心是否已安装并正在运行。系统日志 API 属于它。
  • 检查账户的权限。在大多数 DSM 配置中，读取系统日志需要管理员权限。
  • 容器和堆栈日志是独立的，来自 Docker，所以它们可能正常，而系统日志却不行。
小组件

主屏幕小组件已过期

小组件何时可以刷新由 Android 和 iOS 决定，而且两者都为了省电而严格限制。没有哪个应用能强制刷新 - 这就是为什么每个小组件都会打印数字的获取时间，而不是做出承诺。

  • 打开应用 - 最可靠的刷新方式。
  • Android：将 Syno Manager 排除在电池优化之外。
  • iOS：确认已为该应用开启“后台应用刷新”。
  • 检查可达性：手机连不上的 NAS，小组件也读不了。在移动数据下如果条目只有本地 IP，那么在你回家之前它不会更新。
  • “从未更新”表示还没有成功读取过 - 刚添加，或之后应用还没有运行过。
助手

没有助手标签页

助手需要设备端模型，在没有该模型的硬件上，这个标签页会被完全隐藏 - 不起作用的控件还不如没有。

  • Android 需要 AICore，并且有可用的 Gemini Nano 模型。
  • iOS 和 macOS 需要支持并已启用 Apple Intelligence。
  • 查看你的设备报告了什么，位于设置 › 设备端 AI，它会指出所检测到的状态。
仍然解决不了

反馈问题

错误报告和功能请求请提交到公开的问题追踪器，在那里它们会有编号和讨论串，而不是消失在某个收件箱里。

报告错误或提出功能建议

请提供：应用版本（设置中直接显示，“关于”中有构建号）、你的 DSM 版本、NAS 型号、你是在自己的网络中还是在外面，以及你期望的结果。一张裁掉隐私内容的截图，比一段描述更有帮助。
常见问题

故障排除 FAQ

提示连接超时。这是什么意思？
意思是你填写的地址和端口没有任何响应 - 凭据根本没有被尝试。请检查 HTTPS 是否与端口匹配，手机所在的网络能否访问 NAS，以及在手机浏览器中用同一地址能否打开 DSM 自己的网页界面。
我的密码是对的，为什么提示凭据无效？
因为 NAS 做出了应答，但拒绝了登录。请检查是否输错，检查该账户是否使用了2FA，还要检查 DSM 的自动封锁列表，看看是否因多次尝试而封锁了你手机的地址。
为什么看不到我预期的某个标签页？
要么是没有安装对应的套件，要么是该子视图被隐藏了。连接之后才安装的套件需要刷新 - 下拉刷新，或重新打开应用。
我的摄像头在家能用，在外面不行。
请打开“通过 DSM 端口隧道传输摄像头实时画面”。关闭时，实时画面需要端口 554 上的 RTSP，而这通常无法从外部访问。
我的照片显示为空白缩略图。
HEIC 照片在设备上解码，因为 DSM 7.2.2+ 的版本不再为它们生成预览。如果较早的照片也是空白，请在“照片”界面使用重新索引。
为什么我的小组件显示的是旧数字？
因为小组件何时可以刷新由操作系统决定。每个小组件显示其数据的获取时间，正是出于这个原因；打开应用是最可靠的刷新方式。
