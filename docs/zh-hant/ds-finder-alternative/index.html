比較

超越 DS finder，集中在一個 App

DS finder 是 Synology 官方用來設定 NAS 並隨時關注狀態的 App。Syno Manager 是獨立的 App，為設定完成後的日常而打造：查看 NAS 上執行的一切並採取行動，不必在不同 App 之間切換。

並排比較

兩個 App，兩種任務

這不是計分表。DS finder 有些事是 Syno Manager 做不到的，例如設定全新的 NAS，以及接收 DSM 自家 Push Service 的通知。下表呈現的是各自適合的場合。

你想要適合的 App
設定全新的 NASDS finder 或 DSM
接收 DSM Push Service 通知DS finder
查看儲存空間、硬碟健康狀態與使用者兩者皆有
重新啟動、關閉或喚醒 NAS兩者皆有
重新啟動 Docker 容器並查看其記錄檔Syno Manager
安裝或更新套件Syno Manager
即時觀看 Surveillance Station 攝影機Syno Manager
瀏覽 Synology Photos 與 DriveSyno Manager
查看 Hyper Backup 工作佔用多少空間Syno Manager
將下載項目加入 Download StationSyno Manager
透過 NAS 喚醒網路上的另一台電腦Syno Manager
切換 DSM 服務、查看 VPN 設定檔與 DDNSSyno Manager

DS finder 的功能依 Synology 知識中心的說明為準。Synology 可能隨時更動其 App；請查閱 Synology 的文件以取得最新清單。

Syno Manager 多了什麼

整台 NAS 盡在一個畫面

點出原因的健康狀態標章

哪一顆硬碟、哪一個磁碟區、什麼溫度，而不只是「警告」。

不只看狀態，還能控制

容器、套件、備份、服務、排程工作、下載與風扇模式，都能在手機上操作。

離開家也能用

相片、攝影機即時影像與檔案下載皆可透過 QuickConnect 進行。不需要連接埠轉送。

小工具與捷徑

十二款主畫面小工具、synomanager:// 連結，以及 Mac 上的 Siri 與捷徑。

裝置上的助理

用白話詢問你的 NAS。模型在你的裝置上執行，而且只讀取。

手機、平板與桌機

Android、iPhone、iPad、Mac 與 Windows。每個平台買斷 $9.99，無訂閱。

與 DS finder 並用試試看

一次買斷 $9.99。無廣告、無訂閱、無 App 內購買。需要執行 DSM 7.0 或更新版本的 Synology NAS。
