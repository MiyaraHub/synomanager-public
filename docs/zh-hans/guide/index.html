Syno Manager 用户指南

应用的一切功能，逐个界面、逐项控件讲解，包括它有意不做的事及其原因。每个界面都会适配你的 NAS，因此你看到的部分可能比本页所列的少：应用会隐藏你的 DiskStation 没有运行的内容，而不是显示一个无法使用的按钮。

应用新手

三个页面，带你从刚安装到随时随地都能查看你的 NAS。

🚀

入门指南

你需要什么、如何添加 NAS、端口与 HTTPS、双重身份验证，以及无法连接时该怎么办。
🏠

主屏幕

健康标题栏、快速统计行和卡片网格，以及如何重新排序、折叠和隐藏其中任何一项。
🌐

离家在外

QuickConnect、自定义域名或 VPN，以及哪些功能适用于哪种连接方式。
每个界面

各个标签，依序介绍

底部栏最多可容纳九个标签，外加“更多”。每个标签都是一组可重新排序或隐藏的子视图。

🧠

系统

系统健康、资源和日志。仪表、平均负载、磁盘 I/O、温度历史、风扇模式、定位、DSM 更新和电源。
💾

存储

存储空间 & 存储池、硬盘健康和外部存储。RAID 类型、可用空间、每块硬盘的 SMART、快速 SMART 测试和安全弹出。
📡

网络

吞吐量、连接、服务、VPN，以及显示你公网地址的 DDNS。
📁

文件

File Station、直接在 NAS 上复制与移动、共享文件夹、Note Station、Synology Office 和 Contacts。
⬇️

Download Station

通过链接、磁力链接或 .torrent 添加，控制运行中的任务，并更改你的 NAS 上报的设置。
📦

应用

Package Center、Docker、Docker Projects 和 Virtual Machine Manager。
📷

媒体

Synology Photos（支持滑动切换的全屏查看器）、Synology Drive 和 Surveillance Station 实时画面。
🔄

备份

显示真实目标位置大小的 Hyper Backup 任务，以及 Active Backup for Business 的设备和工作负载。
🔧

控制面板

用户、任务计划程序、UPS 和应用自己的设置。
✨

助手

用日常语言询问你的 NAS，得到健康结论，并为它的答案评分，它只在你的设备上学习。
标签之外

其他一切

⚙️

设置

每一项偏好：主题和强调色、仪表盘卡片、底部栏、28 种语言、启动行为、卡片视图、轮询、温度单位、帮助卡片和备份。
🖥️

多台 NAS 设备

添加、重命名、重新排序和切换。每台都保留自己的凭据、布局和设置。
🔌

Wake-on-LAN

唤醒 NAS，或通过它唤醒任何其他设备，以及其中哪些在你的网络之外也能用。
📱

主屏幕小组件

十二个小组件，各自附带预览和时间戳，让过期的读数绝不会显得像是最新的。
🔗

快捷方式&链接

synomanager:// URL 方案、启动器快捷方式，以及 Mac 上原生的 Siri 和快捷指令。
🔍

搜索

用你自己的语言或英文输入想要的内容，拼错也没关系，直接跳到对应的设置或页面。
🎨

自定义应用

重新排序和隐藏卡片、标签和子视图，折叠你不看的内容，并关闭帮助卡片。
💾

备份&还原设置

把应用自己的设置导出到文件，并在新手机上还原。
🔧

故障排除

连接失败、空白卡片、缺失标签、过期小组件，以及每条提示究竟是什么意思。
