為什麼選擇 Syno Manager

原生 App，而不是網頁主控台

確認備份有沒有執行，不該需要登入 DSM、操作一個為滑鼠設計的瀏覽器介面。Syno Manager 讀取 DSM 自己的網頁介面所使用的同一套 API，並以原生方式呈現答案 - 無論是手機、平板、Mac 或電腦，都會配合所在的螢幕調整。

隱私權

中間沒有任何伺服器

Syno Manager 是你 NAS 的用戶端，而不是一項服務。你的手機直接與你的 DiskStation 建立連線，整個架構就只是這樣。

  • 沒有 MiyaraHub 伺服器。關於你的 NAS 的任何資料都不會傳到我們這裡，因為路徑中根本沒有可去的地方。
  • 憑證存放在鑰匙圈。保存在平台的安全儲存空間中，絕不以明文儲存，也不會包含在裝置備份裡。
  • 雙重驗證與裝置信任。支援一次性驗證碼，並會記住受信任的裝置，讓你不必每次啟動都被詢問。
  • 助理在裝置端執行。你的問題、你的 NAS 資料與答案，都不會離開手機。
  • 只有一樣東西會離開：當機報告，這樣才能修正當機問題。其內容是堆疊追蹤，而不是你的 NAS。完整說明。

常見問題

手機上的 Synology，一次解答

Syno Manager 能做什麼？
它把 DSM 中你真正會在手機上查看的部分整合到一個 App 裡：即時 CPU、RAM、溫度與網路讀數、儲存磁碟區與每顆硬碟的 SMART 健康狀態、Docker 容器、套件中心、Surveillance Station 即時檢視、Synology Photos 與 Drive、Hyper Backup 與 Active Backup、Download Station、File Station、使用者、排程工作、UPS、DDNS 與 Wake-on-LAN。它使用 DSM 自己公開的 API 直接與你的 NAS 通訊。使用指南涵蓋了每個畫面。
它支援哪些 Synology 機種？
任何執行 DSM 7.0 或更新版本的 Synology NAS。App 會在連線時讀取你的特定 NAS 所回報的內容，只顯示它實際支援的畫面，所以雙槽的 DS223j 和機架式的 RS1221+ 各自得到符合其能力的儀表板。請參閱相容性。
我不在家時也能用嗎？
可以。只要新增一次 NAS，App 就會使用任何連得通的路徑 - 在家時用你的區域網路 IP，外出時用 QuickConnect、自訂網域或 VPN。相片、攝影機即時檢視，以及 File Station 與 Drive 的下載，都能透過 QuickConnect 轉送使用，因此不需要設定連接埠轉送。請參閱遠端存取。
我的資料會經過你們的伺服器嗎？
你的 NAS 資料不會。Syno Manager 直接連線到你的 NAS，路徑中沒有任何 MiyaraHub 伺服器，所以你的檔案、讀數與設定永遠不會傳到我們這裡。憑證存放在裝置的鑰匙圈或金鑰庫中，不會包含在裝置備份裡，助理的模型也是在你的手機上執行。唯一會離開裝置的東西是當機報告，透過 Firebase Crashlytics 傳送 - 內容是堆疊追蹤、裝置型號與 App 版本，完全不含你的 NAS 資料。完整細節在這裡。
Syno Manager 要多少錢？
一次性購買 $9.99。沒有廣告、沒有訂閱、沒有 App 內購買 - 所有功能都包含在內，更新也一併包含。

價格依平台分開計算，所以 Google Play 與 Microsoft Store 是各自獨立的購買。Apple 則是單一通用購買，涵蓋 iPhone、iPad 與 Mac - 買一次，三種裝置都能用。

它支援雙重驗證嗎？
支援。如果你的 DSM 帳號使用雙重驗證，App 會提示輸入一次性驗證碼，並可記住該裝置，讓你在那支手機上不必再被詢問。它也會在每個控制動作中擷取並傳送 DSM 的 SynoToken，這是 DSM 對任何會變更內容的用戶端的要求。
它可以管理多台 NAS 嗎？
可以。想加幾台都行，並可在裝置清單中切換。每一台都有自己的憑證、儀表板版面配置與設定。請參閱多台 NAS 裝置。
Syno Manager 是 Synology 製作的嗎？
不是。Syno Manager 是由 MiyaraHub Technologies LLC 製作的獨立 App。它與 Synology Inc. 無關聯，亦未獲其認可或贊助。它透過與 DSM 自己的網頁介面相同的公開 DSM API 連線到你的 NAS。本網站提到的 Synology、DSM 與套件名稱，皆為 Synology Inc. 的商標。
