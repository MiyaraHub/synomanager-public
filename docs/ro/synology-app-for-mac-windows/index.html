NAS-ul tău Synology pe desktop

Syno Manager este o aplicație nativă, independentă, pentru NAS-ul tău Synology pe macOS și Windows. Aceeași aplicație ca pe telefon, aranjată pentru o fereastră mai mare: valori live, Docker, backupuri, fișiere și Wake-on-LAN, fără a deschide DSM într-o filă de browser.

Mac

Pe macOS

Siri și Shortcuts, nativ ›

Open a section, Restart NAS și Shut down NAS sunt acțiuni Shortcuts reale prin App Intents. Programează-le sau înlănțuie-le în propriile scurtături.

Asistent Apple Intelligence ›

Acolo unde Apple Intelligence este acceptat și activat, întreabă despre NAS-ul tău în cuvinte simple. Modelul rulează pe Mac.

Date de autentificare în Keychain ›

Parolele DSM și tokenurile dispozitivului sunt păstrate în Keychain-ul macOS, niciodată în text simplu.

Apple este o singură achiziție universală: cumperi Syno Manager o dată și îl ai pe Mac, iPhone și iPad.

Windows

Pe Windows

Save As nativ ›

Descarcă orice fișier din File Station direct într-un folder de pe PC prin dialogul standard Windows, acasă sau prin QuickConnect.

Trezește-ți PC-ul prin NAS ›

NAS-ul mereu pornit trimite pachetul magic din interiorul rețelei tale. Ghidul acoperă partea Windows, inclusiv oprirea Fast Startup.

Backupuri dintr-o privire ›

Sarcini Hyper Backup cu spațiul pe care îl ocupă și dispozitive Active Backup for Business cu un total deduplicat.

Versiunea din Microsoft Store este o achiziție separată de $9.99.

Pe amândouă

Tot ce verifici pe un NAS

  • System: CPU, RAM, încărcare, I/O pe disc și temperatură, modul ventilatoarelor, verificarea actualizărilor DSM, repornire și oprire.
  • Storage: volume și pool-uri cu tip RAID, sănătate SMART și temperatură pe fiecare disc, scoatere sigură.
  • Apps: Package Center, containere Docker și stack-uri Compose, mașini virtuale.
  • Network: debit live pe fiecare interfață, conexiuni, servicii DSM, profiluri VPN și DDNS.
  • Mai multe NAS-uri: adaugă câte vrei, fiecare cu propriul aspect și propriile setări.
