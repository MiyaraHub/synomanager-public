Вдали от дома

То же приложение, другой маршрут

Syno Manager работает одинаково, находитесь вы рядом с NAS или на другом конце света. Меняется только путь подключения, и у каждого маршрута свои компромиссы, о которых стоит знать.

QuickConnect

Настройка

  1. В DSM: Панель управления › Внешний доступ › QuickConnect. Включите его и запомните ID QuickConnect.
  2. В приложении: добавьте NAS и переключите Тип подключения на QuickConnect.
  3. Введите ID, а не хост и порт.
  4. Ваши учётные данные DSM и 2FA, если учётная запись её использует.
  5. Сохранить & подключиться.
Ожидайте, что будет медленнее. Ретранслятор добавляет узел, а Synology ограничивает его скорость, поэтому библиотека фото прокручивается менее плавно, чем дома. Всё продолжает работать - разница в задержке, а не в возможностях.
Схема, которую стоит перенять

Добавьте один и тот же NAS дважды

Одна запись по локальному IP, другая через QuickConnect. Назовите их так, чтобы различать: «NAS (дом)» и «NAS (вне дома)».

  • Дома используйте прямую запись: без ретранслятора, на полной скорости, с мгновенными миниатюрами.
  • Вне дома переключитесь на запись QuickConnect.
  • У них раздельные раскладки, поэтому запись для поездок можно сократить до нескольких карточек, которые вы действительно проверяете по мобильному интернету.
  • Переключение в одно касание из списка устройств.

Установите для поведения при запуске значение Последний использованный NAS, и приложение будет оставаться на том, с которым вы работали.

Частые вопросы

Вопросы об удалённом доступе

Нужно ли пробрасывать порты для удалённого доступа к NAS?
Нет. QuickConnect передаёт подключение без какой-либо настройки роутера, а VPN тоже подойдёт. Проброс портов нужен, только если вам специально нужен прямой маршрут из интернета.
Работают ли фото и просмотр камер через QuickConnect?
Да. Миниатюры, полные изображения, просмотр камер и загрузки из File Station и Drive идут по любому активному маршруту, включая ретранслятор. Для просмотра камер должен быть включён переключатель туннеля через порт DSM.
Стоит ли добавлять NAS дважды?
Это хорошая схема: одна запись по локальному IP для дома и одна через QuickConnect для поездок, с отдельными раскладками и переключением в одно касание.
Безопасен ли QuickConnect?
При использовании HTTPS соединение шифруется от края до края, а ретранслятор лишь пропускает трафик и не хранит ваши данные. Ваши учётные данные DSM и двухфакторная аутентификация по-прежнему действуют.
Почему запись с локальным IP не работает по мобильному интернету?
Потому что частный адрес вроде 192.168.x.x существует только в вашей сети. Используйте запись QuickConnect, домен или сначала подключитесь к своему VPN.
