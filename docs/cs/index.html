Soukromí

Uprostřed není žádný server

Syno Manager je klient pro vaše NAS, ne služba. Váš telefon naváže spojení s vaším DiskStation a to je celá architektura.

  • Žádný server MiyaraHub. Nic o vašem NAS se k nám nedostane, protože v cestě není kam.
  • Přihlašovací údaje v klíčence. Uloženy v zabezpečeném úložišti platformy, nikdy ve formě prostého textu, a vyloučeny ze záloh zařízení.
  • 2FA a důvěryhodné zařízení. Jednorázové kódy jsou podporovány a důvěryhodné zařízení se pamatuje, takže se neptáme při každém spuštění.
  • Asistent běží v zařízení. Vaše otázka, data z vašeho NAS i odpověď telefon nikdy neopustí.
  • Jedna věc odchází: zprávy o pádech, aby šel pád opravit. Obsahují výpis zásobníku, ne vaše NAS. Celý obraz.

Časté dotazy

Synology v telefonu, zodpovězeno

Co Syno Manager dělá?
Dává části DSM, které na telefonu skutečně kontrolujete, do jedné aplikace: živé údaje o CPU, RAM, teplotě a síti, úložné svazky a stav SMART každého disku, kontejnery Docker, Centrum balíčků, živý náhled Surveillance Station, Synology Photos a Drive, Hyper Backup a Active Backup, Download Station, File Station, uživatele, plánované úlohy, UPS, DDNS a Wake-on-LAN. S vaším NAS komunikuje přímo pomocí zdokumentovaných API samotného DSM. Uživatelská příručka pokrývá každou obrazovku.
S jakými modely Synology funguje?
Jakékoli NAS Synology s DSM 7.0 nebo novějším. Aplikace při připojení přečte, co váš konkrétní NAS hlásí, a zobrazí jen obrazovky, které skutečně podporuje, takže dvoupozicové DS223j i rackové RS1221+ dostanou přehled, který odpovídá tomu, co umějí. Viz kompatibilita.
Funguje to, i když jsem pryč z domova?
Ano. Přidejte NAS jednou a aplikace použije cestu, která je dostupná - místní IP doma, nebo QuickConnect, vlastní doménu či VPN venku. Fotky, živý náhled kamer i stahování z File Station a Drive fungují přes relé QuickConnect, takže není třeba přesměrovávat porty. Viz vzdálený přístup.
Procházejí moje data vašimi servery?
Data z vašeho NAS ne. Syno Manager se k NAS připojuje přímo a v této cestě není žádný server MiyaraHub, takže vaše soubory, údaje ani konfigurace se k nám nikdy nedostanou. Přihlašovací údaje jsou uloženy v klíčence nebo úložišti klíčů zařízení a jsou vyloučeny ze záloh zařízení a asistent spouští svůj model ve vašem telefonu. Jediná věc, která zařízení opouští, je zpráva o pádu přes Firebase Crashlytics - výpis zásobníku, model zařízení a verze aplikace, a žádná data z vašeho NAS. Všechny podrobnosti jsou zde.
Kolik Syno Manager stojí?
Jednorázový nákup za $9.99. Bez reklam, bez předplatného a bez nákupů v aplikaci - všechny funkce jsou součástí, včetně aktualizací.

Cena je za platformu, takže Google Play a Microsoft Store jsou samostatné nákupy. Apple je jediný univerzální nákup pro iPhone, iPad i Mac - koupíte jednou a máte na všech třech.

Podporuje dvoufázové ověření?
Ano. Pokud váš účet DSM používá 2FA, aplikace požádá o jednorázový kód a může si zařízení zapamatovat, aby se na daném telefonu už neptala. Také zachytí a při každé ovládací akci odešle SynoToken DSM, což DSM vyžaduje od každého klienta, který něco mění.
Zvládne spravovat více než jedno NAS?
Ano. Přidejte jich, kolik chcete, a přepínejte mezi nimi v seznamu zařízení. Každé si drží vlastní přihlašovací údaje, vlastní rozložení přehledu a vlastní nastavení. Viz více zařízení NAS.
Vytváří Syno Manager společnost Synology?
Ne. Syno Manager je nezávislá aplikace společnosti MiyaraHub Technologies LLC. Nijak nesouvisí se společností Synology Inc., není jí schválena ani sponzorována. K NAS se připojuje přes stejná zdokumentovaná API DSM, která používá vlastní webové rozhraní DSM. Synology, DSM a názvy balíčků zmíněné na tomto webu jsou ochranné známky společnosti Synology Inc.
