ウィジェット

ホーム画面にNASを

AndroidとiOSの両方で12種類のウィジェットを用意しており、選択画面にはそれぞれプレビューがあります。さらに各ウィジェットは数値を取得した時刻も表示します。これは数値そのものより大切だったりします。

12種類

各ウィジェットの表示内容

このうち9つは、当初の3つ（システムステータス、ストレージの概要、クイックアクション）に追加されたものです。すべてランチャーのウィジェット選択画面にプレビューがあり、配置する前におおよその見た目を確認できます。

NASが実行していないサービスのウィジェットは表示されません。Docker、カメラ、バックアップ、UPS、ダウンロード、ボリュームは、アプリがNASからその機能の報告を受けて初めて選択画面に表示されます。ダッシュボードのカードと同じルールを、ランチャーにも適用しています。

Androidでは、すべてのウィジェットが縦横どちらにもサイズ変更でき、与えたスペースに合うレイアウトに自動で切り替わります。12種類すべてが、ランチャーのウィジェット選択画面のSyno Managerの下に表示されます。

このページにはウィジェット選択画面のスクリーンショットはありません。選択画面は実際にウィジェットがホーム画面に置かれて初めて内容が表示されますが、このサイトで撮影しているのは、すべて誰かが実際に使っているスマートフォンで、スクリーンショットのためにレイアウトを組み替える予備機ではないからです。

ウィジェットの配置方法

Android

  1. ホーム画面の空いている部分を長押しします。
  2. 「ウィジェット」をタップします。
  3. 一覧からSyno Managerを探します。
  4. 使いたいウィジェットをホーム画面にドラッグしてサイズを調整します。

iOS

  1. アイコンが揺れるまでホーム画面を長押しします。
  2. 上部の＋をタップします。
  3. Syno Managerを検索します。
  4. サイズを選んで「ウィジェットを追加」をタップします。
大切なポイント

すべてのウィジェットにタイムスタンプがある理由

ウィジェットが更新されるのは、OSが許可したときだけです。AndroidもiOSもバッテリー節約のためにウィジェットの更新を厳しく制限しており、ホーム画面の数値は見た目より何時間も古いことがあります。最新に見える古い数値は、数値がないよりも悪いものです。

表示される内容意味
たった今直近1分以内に取得。
12m前1時間未満。分単位で表示。
5時間前1日未満。時間単位で表示。
2日前1日以上。過去のデータとして扱ってください。
未更新まだ一度も正常に読み取れていません。追加したばかりか、それ以降アプリが起動していません。0とは表示されません。0は測定値のように見えてしまうからです。
6時間より古いものはすべて古いデータとして扱われ、NASの現在の状態としてではなく、その旨を示して表示されます。

ここで守っている区別は実際に意味があります。タイムスタンプがなければ、静かなNASと古くなったウィジェットは同じに見えます。「CPU 4%、3分前に取得」と「CPU 4%、昨日取得」は別の事実であり、対処する価値があるのはそのうちの1つだけです。

最新の状態を保つ

ウィジェットが更新されない場合

  • アプリを開きます。アプリが起動してNASを読み取るのが、最も確実な更新方法です。
  • Androidではバッテリー最適化を確認します。バックグラウンドが制限されたアプリは、ウィジェットの更新が減ります。Syno Managerを最適化の対象から除外すると改善します。
  • iOSではバックグラウンド更新を確認します。設定からアプリを開き、オフになっているとiOSはウィジェットをほとんど更新しません。
  • NASに接続できる必要があります。スマートフォンから到達できないNASは、ウィジェットも読み取れません。ローカルIPだけのエントリでモバイルデータ通信を使っている場合は、帰宅するまで更新されません。
どちらのプラットフォームも、更新間隔を保証していません。アプリが強制できるものではないため、約束の代わりにタイムスタンプを表示しています。
よくある質問

ウィジェットに関するよくある質問

Syno Manager にはどんなウィジェットがありますか？
12種類：システムステータス、ストレージの概要、クイックアクション、NASのヘルス、バックアップ、温度とファン、Docker、カメラ、ネットワーク、UPS、ダウンロード、ボリューム。12種類すべてがAndroidとiOSで利用でき、ウィジェット選択画面にプレビューがあります。
ウィジェットの数値が古いのはなぜですか？
ウィジェットをいつ更新してよいかを決めるのは、アプリではなくOSだからです。そのため、各ウィジェットにデータを取得した時刻を表示し、古い数値が最新のように見えないようにしています。
「未更新」とはどういう意味ですか？
ウィジェットがまだ一度も正常に値を読み取れていないということです。多くの場合、追加したばかりか、それ以降にアプリを開いていないことが原因です。0ではなく「未更新」と表示されます。
ウィジェットを追加するには？
Androidではホーム画面を長押しして「ウィジェット」を選び、Syno Managerを見つけて1つドラッグします。iOSではホーム画面を長押しして＋をタップし、Syno Managerを検索してサイズを選びます。
