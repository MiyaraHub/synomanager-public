단축 기능 & 링크

원하는 화면으로 바로

Syno Manager는 synomanager:// URL 스킴을 등록하므로, Siri 문구, 런처 바로가기, 자동화 앱으로 홈 화면이 아니라 필요한 화면에서 바로 앱을 열 수 있습니다. Mac에서는 Siri와 단축어 앱이 URL 입력 없이 Syno Manager를 기본 앱처럼 인식합니다.

의도된 제한

재부팅과 종료가 앱만 열기만 하는 이유

전원 컨트롤 화면으로 이동할 뿐, 스스로 재시작이나 종료를 하지는 않습니다.

단축어는 실수로 누르기 쉽습니다. 런처 아이콘을 잘못 탭하거나, 음성을 잘못 알아듣거나, 자동화가 엉뚱한 조건에서 실행될 수 있습니다. NAS를 재시작하면 사용 중인 모든 사람의 연결이 끊어지고 진행 중이던 작업이 중단됩니다. 이 두 가지는 함께 있어서는 안 되므로, 링크는 화면까지만 열어 주고 기존의 확인 절차가 그대로 적용됩니다.

나머지 링크는 본질적으로 안전합니다. 무언가를 보여 줄 뿐이기 때문입니다. 그래서 나머지는 한 번의 탭으로 열리고, 이 두 가지는 그렇지 않습니다.
사용 방법

플랫폼별 안내

iOS - Siri와 단축어

  1. 단축어 앱을 열고 새 단축어를 만드세요.
  2. URL 열기 동작을 추가하세요.
  3. 링크를 입력하세요. 예: synomanager://storage.
  4. 소리 내어 말하기 쉬운 이름을 붙이세요. 예: “내 NAS 스토리지 확인”.
  5. 홈 화면에 추가하거나 Siri에게 바로 말하면 됩니다.

Android - 런처와 자동화

  1. 대부분의 런처는 URL을 여는 바로가기를 만들 수 있습니다.
  2. Tasker, MacroDroid 같은 자동화 앱은 어떤 트리거에서든 링크를 열 수 있습니다.
  3. 메모나 페이지에 있는 <a href="synomanager://system"> 링크도 사용할 수 있습니다.
어떤 NAS에서 열릴지는 시작 동작 설정을 따릅니다. 단축어는 기기가 아니라 화면을 고르므로, “마지막으로 사용한 NAS”로 설정했다면 synomanager://storage은 마지막에 쓰던 NAS의 스토리지를 보여 줍니다.
macOS

Siri와 단축어를 기본 기능처럼

Mac에서는 Syno Manager에 URL이 전혀 필요하지 않습니다. Apple의 App Intents에 세 가지 동작을 직접 등록하므로, Siri와 단축어 앱이 Apple 자체 앱과 똑같이 Syno Manager를 고유한 명령어를 가진 앱으로 인식합니다.

동작기능Siri에게 말하기
섹션 열기대시보드, 스토리지, 시스템, 네트워크, 앱, 백업, 파일, 깨우기 중 선택한 섹션에서 Syno Manager를 엽니다.“Syno Manager 열어 줘”
NAS 재시작먼저 확인을 요청한 뒤 앱의 전원 컨트롤 화면을 엽니다. 그곳에서 다시 확인하기 전까지는 NAS로 아무것도 전송되지 않습니다.“Syno Manager로 내 NAS 재시작해 줘”
NAS 종료재시작과 같은 방식입니다. Siri나 단축어로 확인한 뒤 앱의 전원 컨트롤 화면이 열립니다.“Syno Manager로 내 NAS 종료해 줘”
재시작과 종료는 여전히 두 번 확인합니다. 먼저 Siri나 단축어가 “Syno Manager를 열어 NAS를 재시작할까요? 아직 NAS에는 아무것도 전송되지 않으며, 앱에서 확인하게 됩니다”라고 묻고, 앱의 전원 컨트롤이 다시 한 번 묻습니다. 잘못 알아들은 말 한마디로 NAS가 재부팅되는 음성 명령은 있을 필요가 없는 기능입니다.

이를 바탕으로 나만의 자동화를 만들어 보세요. 일반적인 단축어 동작이기 때문에 섹션 열기는 직접 만드는 어떤 단축어에도 넣을 수 있습니다. 일정에 맞춰 실행하거나, 홈 허브에서 트리거하거나, 다른 동작 뒤에 이어 붙일 수 있으며, 다른 Mac 앱의 동작과 똑같이 쓸 수 있습니다.

단축어 FAQ

Syno Manager에 URL 스킴이 있나요?
네. synomanager://<name>으로 앱의 특정 화면을 열 수 있습니다. 대시보드, 스토리지, 시스템, 네트워크, 앱, 백업, 파일, 깨우기에 각각 링크가 있습니다.
단축어 하나로 NAS를 바로 재시작할 수 있나요?
아니요. 의도적으로 막아 두었습니다. 재부팅과 종료 링크는 전원 컨트롤 화면까지만 열어 주며, 거기서 기존의 확인 절차가 그대로 적용됩니다.
Siri에서도 사용할 수 있나요?
네. Apple 단축어 앱에서 해당 URL을 여는 단축어를 만들고 호출 문구를 지정하면, Siri가 바로 그 화면으로 안내합니다.
단축어로 특정 NAS를 지정할 수 있나요?
아니요. 단축어는 화면을 열 뿐이며, 어떤 NAS에서 열지는 시작 동작 설정을 따릅니다.
Mac의 단축어 앱에서도 Syno Manager를 쓸 수 있나요?
네, 기본 앱처럼 사용할 수 있습니다. macOS의 Apple 단축어 앱에 섹션 열기, NAS 재시작, NAS 종료가 Syno Manager 동작으로 나타나며, URL을 입력할 필요가 없습니다. 두 전원 동작은 무언가를 하기 전에 Siri나 단축어가 먼저 확인을 요청하고, 그다음 앱의 전원 컨트롤 화면만 엽니다.
