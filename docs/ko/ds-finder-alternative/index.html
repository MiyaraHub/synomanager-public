DS finder를 넘어, 하나의 앱으로

DS finder는 NAS를 설정하고 상태를 지켜보기 위한 Synology의 공식 앱입니다. Syno Manager는 설정 이후의 일상을 위해 만든 독립 앱으로, NAS에서 실행되는 모든 것을 확인하고 조치하는 일을 앱을 오가지 않고 할 수 있습니다.

나란히 비교

두 앱, 두 가지 역할

이 표는 성적표가 아닙니다. DS finder는 새 NAS 설정이나 DSM 자체 Push Service의 알림 수신처럼 Syno Manager가 하지 않는 일을 합니다. 각 앱이 어디에 잘 맞는지 표에서 확인해 보세요.

DS finder 기능은 Synology 지식 센터(Knowledge Center)의 설명을 기준으로 합니다. Synology는 언제든 앱을 변경할 수 있으므로 최신 목록은 Synology 문서를 확인하세요.

집 밖에서도 작동
