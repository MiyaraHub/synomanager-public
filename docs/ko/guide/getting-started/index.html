1분 안에 연결

시작하기 전에

준비물

요건상세
Synology NASDSM 7.0 이상을 실행하는 모든 모델. NAS에 설치하는 것은 없으며, 앱은 DSM 웹 인터페이스가 쓰는 것과 같은 API를 사용합니다.
DSM 계정평소 쓰는 DSM 사용자 이름과 비밀번호입니다. 관리자 계정은 모든 것을 볼 수 있고, 일반 계정은 DSM이 허용하는 범위만 볼 수 있으며, 앱은 거부될 컨트롤을 보여 주는 대신 나머지를 숨깁니다.
사용 중인 기기Android 7.0 이상, iOS 16.0 이상, macOS 11.0 이상, 또는 Windows. 네 가지 모두 같은 앱입니다.
NAS로 가는 경로같은 로컬 네트워크, 그 안으로 들어가는 VPN, 사용자 지정 도메인, 또는 QuickConnect. 이 중 하나면 충분합니다.
보기만 하는 데는 관리자 계정이 필요 없습니다. 모니터링은 모든 DSM 사용자가 할 수 있습니다. 컨테이너 재시작, 백업 실행, 드라이브 분리 같은 제어 동작에는 DSM 자체가 해당 동작에 요구하는 권한이 필요하며, 앱은 거부되었을 때 성공한 척하지 않고 거부되었다고 보고합니다.
어디에 있나요

NAS 주소 찾기

이미 브라우저로 DSM을 열고 있다면 주소 표시줄에 필요한 정보가 모두 있습니다. 호스트와 포트가 앱이 요구하는 두 값입니다.

DSM에서 확인하기

  • 제어판 › 네트워크 › 네트워크 인터페이스에서 각 인터페이스의 NAS IP 주소를 볼 수 있습니다.
  • 제어판 › 네트워크 › DSM 설정에서 DSM이 수신하는 HTTP 및 HTTPS 포트를 볼 수 있습니다. 누군가 바꾸지 않았다면 5000과 5001입니다.

브라우저에서 확인하기

DSM에 접속하려고 입력하는 주소가 앱이 원하는 값입니다. https://192.168.1.20:5001에서 호스트는 192.168.1.20, 포트는 5001이며, HTTPS가 켜져 있습니다.

공유기에서 확인하기

대부분의 공유기는 연결된 기기를 이름으로 보여 줍니다. NAS는 제어판 › 정보 센터에 지정된 서버 이름으로 표시됩니다.

고정 주소를 지정하세요. 공유기가 재부팅 후 NAS에 다른 IP를 할당하면 앱이 NAS를 찾지 못하게 됩니다. 공유기의 DHCP 예약이나 NAS의 고정 주소로 이를 막을 수 있습니다. 호스트 이름이나 사용자 지정 도메인은 IP가 무엇이든 상관없이 작동합니다.
NAS 추가

양식의 모든 입력란

기기 목록에서 + NAS 추가를 탭하세요. 양식은 짧으며, 합리적인 기본값이 없는 입력란은 세 개뿐입니다.

입력란입력할 내용
NAS 별칭원하는 이름이면 됩니다. 나에게만 보입니다. NAS가 둘 이상일 때 유용합니다.
연결 유형직접 입력하는 주소는 Direct IP, QuickConnect ID는 QuickConnect를 선택합니다. 아래를 참고하세요.
호스트 / IP 주소NAS의 로컬 IP, 호스트 이름, 또는 NAS를 가리키는 사용자 지정 도메인.
포트HTTPS를 켰다면 5001, 껐다면 5000입니다. DSM 포트를 변경했다면 그 포트를 사용하세요.
HTTPS기본적으로 켜져 있으며, 켜 두는 것이 좋습니다. 비밀번호를 포함해 휴대폰과 NAS 사이의 모든 통신이 암호화됩니다.
SSL 인증서 확인대부분의 DiskStation은 공인 인증 기관으로 확인할 수 없는 자체 서명 인증서를 사용하므로 기본적으로 꺼져 있습니다. 어느 쪽이든 연결은 암호화됩니다. 정식 인증서를 설치한 경우에만 켜세요.
사용자 이름DSM 계정 이름입니다. 공백이 포함된 사용자 이름도 지원됩니다. 앱이 따옴표 처리를 올바르게 하는데, 다른 클라이언트가 실패하는 흔한 이유가 바로 이 부분입니다.
비밀번호DSM 비밀번호입니다. 눈 아이콘을 누르면 입력하는 동안 표시됩니다. 플랫폼 키체인 또는 키스토어에 기록되며 평문으로 저장되지 않습니다.
2단계 인증DSM 계정에서 인증 앱을 사용한다면 켜세요. 아래를 참고하세요.
DSM 포트를 통해 카메라 라이브 뷰 터널링기본적으로 꺼져 있습니다. 꺼짐이면 카메라 라이브 뷰가 포트 554의 RTSP에 직접 연결되며, 내 네트워크에서는 더 빠르지만 어디에 있든 그 포트에 접근할 수 있어야 합니다. 켜짐이면 이미 사용 중인 DSM HTTPS 포트로 스트림을 터널링하므로, 554를 노출하지 않고도 외부에서 라이브 뷰가 작동합니다. Surveillance Station을 참고하세요.
주소를 입력할 필요가 없습니다

QuickConnect

연결 유형을 QuickConnect로 바꾸고 호스트와 포트 대신 QuickConnect ID를 입력하세요. Synology의 릴레이가 NAS가 어디에 있든 찾아 주며, 공유기 설정은 필요 없습니다.

  • ID를 확인하는 곳. DSM의 제어판 › 외부 액세스 › QuickConnect입니다. 먼저 그곳에서 활성화해야 합니다.
  • 감수할 점. 릴레이로 인해 지연 시간이 늘어나므로 썸네일과 라이브 뷰가 내 네트워크에서보다 느리게 로드됩니다. 모든 기능은 그대로 작동합니다.
  • 덜어 주는 것. 포트 포워딩도, 계속 갱신해야 하는 동적 DNS도 필요 없고, 내 쪽에서 인터넷에 노출되는 것도 없습니다.
둘 다 쓸 수 있습니다. 같은 NAS를 로컬 IP와 QuickConnect로 두 번 추가하면 집에서는 빠른 항목을, 밖에서는 안정적인 항목을 쓸 수 있습니다. 두 항목은 레이아웃이 별개이므로 더 가까운 쪽을 고르세요.
2FA

2단계 인증

DSM 계정이 인증 앱으로 보호되고 있다면 저장하기 전에 2단계 인증(2FA)을 켜세요. 비밀번호가 확인된 직후 앱이 여섯 자리 코드를 요청합니다.

  1. NAS 추가 양식에서 토글을 켭니다.
  2. 저장 & 연결을 탭합니다. 앱이 로그인하면 DSM이 두 번째 인증 요소를 요청합니다.
  3. 인증 앱의 코드를 입력합니다.
  4. 이 기기를 기억할지 선택합니다. 기억하면 DSM이 기기 토큰을 발급하고, 이 휴대폰은 다시 코드를 요청받지 않습니다. 토큰은 비밀번호와 같은 방식으로 플랫폼 키체인에 저장됩니다.
코드가 거부된다면 시계를 확인하세요. 인증 코드는 현재 시각으로 만들어지므로, 시계가 어긋난 휴대폰이나 NAS는 틀린 숫자를 생성하거나 기대하게 됩니다. NAS의 시간 소스는 홈 화면의 빠른 통계 줄에 표시됩니다.
저장하기 전에

연결 테스트 후 저장

연결 테스트는 주소, 포트, 자격 증명을 시도해 보고 아무것도 저장하지 않은 채 결과를 알려 줍니다. "NAS에 연결할 수 없음"과 "연결은 됐지만 비밀번호가 틀림"을 구분해 주므로, 오타를 찾는 가장 빠른 방법입니다.

표시되는 메시지의미
연결 시간 초과아무 응답이 없습니다. 주소, 포트, 또는 휴대폰이 연결된 네트워크가 원인이며, 시도조차 하지 않은 자격 증명은 아닙니다.
잘못된 자격 증명NAS가 응답했지만 로그인을 거부했습니다. 주소와 포트는 맞고, 사용자 이름이나 비밀번호가 틀렸습니다.
인증서 오류HTTPS가 켜져 있고 자체 서명 인증서에 대해 SSL 인증서 확인도 켜져 있습니다. 확인을 끄세요.
2FA 필요계정이 2단계 인증을 사용하는데 토글이 꺼져 있습니다. 켜고 다시 시도하세요.

저장 & 연결은 항목을 저장하고 로그인합니다. NAS가 이미 로딩 중인 홈 화면으로 이동합니다.

연결되었습니다

처음 연결하면 일어나는 일

  • 앱이 NAS에 무엇을 할 수 있는지 묻습니다. DSM의 API 카탈로그를 조회해 목록을 저장합니다. Surveillance Station이 없는 NAS에 카메라 탭이 나타나지 않고, 패키지를 설치하면 해당 화면이 나타나는 이유입니다.
  • 지원되는 모든 카드가 켜진 상태입니다. 새 카드는 숨겨지지 않고 보이는 상태로 추가되므로, NAS가 지원하는 기능은 바로 볼 수 있습니다. 맞춤 설정은 항목을 끄는 곳이지, 항목을 찾으러 가는 곳이 아닙니다.
  • NAS의 MAC 주소가 저장되므로 나중에 직접 찾지 않아도 Wake-on-LAN이 작동합니다.
  • 짧은 환영 화면이 한 번 나타납니다. 앱이 하는 일과 설정을 바꾸는 곳을 안내하며, 다시 나타나지 않게 하는 체크박스가 있습니다.
  • 설명이 필요한 화면에 도움말 카드가 나타납니다. 길게 눌러 닫을 수 있고, 설정에서 하나씩 복원할 수 있습니다.
연결한 뒤에 패키지를 설치하셨나요? 기능 목록은 연결할 때 읽어 오므로, 그 이후에 설치한 패키지는 아직 탭이 없습니다. 당겨서 새로 고치거나 앱을 다시 열면 새 화면이 나타납니다.
연결되지 않을 때

간단한 점검 목록

  1. 입력한 주소와 포트 그대로 휴대폰 브라우저에서 DSM을 열어 보세요. 브라우저도 접속하지 못한다면 앱이 아니라 네트워크나 주소의 문제입니다.
  2. HTTPS가 포트와 일치하는지 확인하세요. HTTPS를 끈 상태의 5001 포트, 또는 켠 상태의 5000 포트는 시간 초과가 됩니다. 서로 다른 수신 포트이기 때문입니다.
  3. NAS가 출고 시 설치된 인증서를 쓰고 있다면 SSL 인증서 확인을 끄세요.
  4. 휴대폰의 네트워크를 확인하세요. 로컬 IP는 모바일 데이터로는 접근할 수 없습니다. Wi-Fi에 연결하거나, QuickConnect, 도메인, VPN을 사용하세요.
  5. iOS에서는 로컬 네트워크 접근을 허용하세요. 설정 › 앱 › Syno Manager › 로컬 네트워크. 허용하지 않으면 iOS가 내 네트워크 주소로의 연결을 말없이 차단합니다.
  6. DSM의 방화벽을 확인하세요. 제어판 › 보안 › 방화벽. 특정 주소만 허용하는 규칙이 있으면 해당 주소가 아닌 휴대폰은 차단됩니다.
  7. 자동 차단을 확인하세요. 제어판 › 보안 › 계정. 로그인 실패가 반복되면 휴대폰의 주소가 차단될 수 있으며, 그곳에 표시되므로 제거할 수 있습니다.

설정 FAQ

Syno Manager를 사용하려면 무엇이 필요한가요?
DSM 7.0 이상을 실행하는 Synology NAS, 그 NAS의 DSM 계정, 그리고 Android 7+, iOS 16+, macOS 11+ 또는 Windows가 실행되는 기기가 필요합니다. NAS에 설치할 것은 없습니다. 앱은 이미 NAS에 있는 DSM 자체 API를 사용합니다.
어떤 주소와 포트를 입력해야 하나요?
내 네트워크에서는 NAS의 로컬 IP 주소와 DSM 포트를 입력합니다. HTTPS를 켰다면 5001, 껐다면 5000입니다. 호스트 이름이나 사용자 지정 도메인도 입력할 수 있습니다. 주소를 다루고 싶지 않다면 연결 유형을 QuickConnect로 바꾸고 QuickConnect ID를 입력하세요.
SSL 인증서 확인이 기본적으로 꺼져 있는 이유는 무엇인가요?
대부분의 DiskStation은 공인 인증 기관이 서명하지 않은 자체 서명 인증서를 사용하므로, 연결은 암호화되어 있어도 확인에 실패하기 때문입니다. 확인을 꺼 두면 그 인증서를 허용합니다. Let's Encrypt 등에서 발급받은 정식 인증서를 설치했다면 확인을 켜세요.
공유기의 포트를 열어야 하나요?
아니요. 내 네트워크에서는 포워딩이 필요 없습니다. 외부에서는 QuickConnect가 연결을 중계해 주며, VPN도 사용할 수 있습니다. 포트 포워딩은 인터넷에서 직접 연결하는 경로가 꼭 필요하거나, 네트워크 밖에서 RTSP로 카메라 라이브 뷰를 보고 싶을 때만 필요합니다.
연결 시간 초과라고 나옵니다. 어떻게 해야 하나요?
이 메시지는 앱이 응답을 받지 못했다는 뜻이며, 거의 항상 주소, 포트, 또는 휴대폰이 연결된 네트워크가 원인입니다. HTTPS 설정이 포트와 일치하는지, 로컬 IP를 사용한다면 휴대폰이 NAS와 같은 네트워크에 있는지, 그리고 휴대폰 브라우저에서 같은 주소와 포트로 DSM 웹 인터페이스가 열리는지 확인하세요.
NAS를 둘 이상 추가할 수 있나요?
네, 원하는 만큼 추가할 수 있습니다. 각 NAS는 자체 자격 증명, 대시보드 레이아웃, 설정을 유지하며, 기기 목록에서 전환할 수 있습니다. 여러 대의 NAS를 참고하세요.
