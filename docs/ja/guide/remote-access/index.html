外出先から

同じアプリで、別のルートから

Syno Manager は、NASのすぐそばにいても地球の反対側にいても同じように使えます。変わるのは接続の経路だけで、それぞれの経路にはあらかじめ知っておきたい長所と短所があります。

QuickConnect

セットアップ方法

  1. DSMで：コントロールパネル › 外部アクセス › QuickConnectを開き、有効にしてQuickConnect IDを控えます。
  2. アプリで：NASを追加し、接続タイプをQuickConnectに切り替えます。
  3. IDを入力 - ホストとポートではありません。
  4. DSMの認証情報と、アカウントで使っている場合は2FA。
  5. 保存 & 接続。
速度は遅くなります。中継によって経由点が1つ増え、Synology側でも速度が制限されるため、写真ライブラリのスクロールは自宅ほど滑らかではありません。それでもすべて動作します。違いは遅延であって、機能ではありません。
真似したい使い方

同じNASを2回追加する

ローカルIPで1つ、QuickConnectで1つ登録します。見分けがつくよう、「NAS（自宅）」「NAS（外出先）」のように名前を付けましょう。

  • 自宅では直接接続のほうを使います。中継なしでフルスピード、サムネイルも即座に表示されます。
  • 外出先ではQuickConnectのほうに切り替えます。
  • レイアウトは別々に保持されるので、外出先用のエントリは、モバイルデータ通信で実際に確認するカードだけに絞り込めます。
  • 切り替えはデバイス一覧からワンタップです。

起動時の動作を最後に使ったNASに設定すれば、アプリは直前に使っていたほうを維持します。

よくある質問

リモートアクセスに関するよくある質問

NASをリモートで使うには、ポート転送が必要ですか？
いいえ。QuickConnectはルーターの設定なしに接続を中継し、VPNでも利用できます。ポート転送が必要なのは、インターネットからの直接ルートを特に望む場合だけです。
QuickConnectでも写真やカメラのライブビューは使えますか？
はい。サムネイル、フル画像、カメラのライブビュー、File StationとDriveのダウンロードは、中継を含め、有効な経路のどれでも利用できます。カメラのライブビューには、DSMポートのトンネル設定をオンにする必要があります。
NASを2回追加したほうがいいですか？
おすすめの使い方です。自宅用にローカルIPで1つ、外出先用にQuickConnectで1つ登録すれば、レイアウトは別々で、ワンタップで切り替えられます。
QuickConnectは安全ですか？
HTTPSを使えば接続はエンドツーエンドで暗号化され、中継はデータを保持せずに通過させるだけです。DSMの認証情報と2段階認証も引き続き有効です。
モバイルデータ通信でローカルIPのエントリが使えないのはなぜですか？
192.168.x.xのようなプライベートアドレスは、自分のネットワーク内にしか存在しないからです。QuickConnectのエントリか、ドメインを使うか、先にVPNに接続してください。
