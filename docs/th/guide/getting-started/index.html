ขั้นตอนที่ศูนย์

สิ่งที่คุณต้องมี

ข้อกำหนดรายละเอียด
Synology NASรุ่นใดก็ได้ที่ใช้ DSM 7.0 ขึ้นไป ไม่ต้องติดตั้งอะไรบนมัน แอปใช้ API เดียวกับที่เว็บอินเทอร์เฟซของ DSM ใช้
บัญชี DSMชื่อผู้ใช้และรหัสผ่าน DSM ปกติของคุณ บัญชีผู้ดูแลระบบเห็นทุกอย่าง ส่วนบัญชีที่ไม่ใช่ผู้ดูแลระบบเห็นสิ่งที่ DSM ให้เห็น และแอปจะซ่อนที่เหลือแทนที่จะแสดงปุ่มควบคุมที่จะถูกปฏิเสธ
อุปกรณ์ของคุณAndroid 7.0 ขึ้นไป, iOS 16.0 ขึ้นไป, macOS 11.0 ขึ้นไป หรือ Windows แอปเดียวกันบนทั้งสี่
เส้นทางไปยัง NASเครือข่ายภายในเดียวกัน VPN เข้าไปยังเครือข่ายนั้น โดเมนที่กำหนดเอง หรือ QuickConnect อย่างใดอย่างหนึ่งก็เพียงพอ
ไม่จำเป็นต้องใช้บัญชีผู้ดูแลระบบเพียงเพื่อดู การตรวจสอบใช้ได้กับผู้ใช้ DSM ทุกคน ส่วนการสั่งการ เช่น รีสตาร์ตคอนเทนเนอร์ สั่งสำรองข้อมูล ถอดไดรฟ์ ต้องใช้สิทธิ์ที่ DSM เองกำหนดสำหรับการกระทำนั้น และแอปจะรายงานเมื่อถูกปฏิเสธ แทนที่จะแสร้งว่าสำเร็จ
อยู่ที่ไหน

หาที่อยู่ NAS ของคุณ

หากคุณเปิด DSM ในเบราว์เซอร์อยู่แล้ว แถบที่อยู่มีทุกอย่างที่ต้องใช้ โฮสต์และพอร์ตคือสองค่าที่แอปถาม

จาก DSM เอง

  • Control Panel › Network › Network Interface แสดง IP แอดเดรสของ NAS บนแต่ละอินเทอร์เฟซ
  • Control Panel › Network › DSM Settings แสดงพอร์ต HTTP และ HTTPS ที่ DSM รับฟัง ซึ่งเป็น 5000 และ 5001 เว้นแต่มีคนเปลี่ยน

จากเบราว์เซอร์ของคุณ

สิ่งที่คุณพิมพ์เพื่อเข้า DSM คือสิ่งที่แอปต้องการ ใน https://192.168.1.20:5001 โฮสต์คือ 192.168.1.20 พอร์ตคือ 5001 และเปิด HTTPS

จากเราเตอร์ของคุณ

เราเตอร์ส่วนใหญ่แสดงรายการอุปกรณ์ที่เชื่อมต่อตามชื่อ NAS ปรากฏภายใต้ชื่อเซิร์ฟเวอร์ ซึ่งตั้งไว้ใน Control Panel › Info Center

ให้ที่อยู่คงที่ หากเราเตอร์ให้ IP ใหม่แก่ NAS หลังรีบูต แอปจะหามันไม่เจอ การจอง DHCP บนเราเตอร์ หรือที่อยู่คงที่บน NAS ป้องกันเรื่องนี้ได้ ชื่อโฮสต์หรือโดเมนที่กำหนดเองก็ใช้ได้เช่นกันและไม่สนใจว่า IP คืออะไร
Add NAS

ทุกช่องในฟอร์ม

แตะ + Add NAS ในรายการอุปกรณ์ ฟอร์มสั้น และมีเพียงสามช่องที่ไม่มีค่าเริ่มต้นที่สมเหตุสมผล

ช่องใส่อะไร
NAS Nicknameชื่อใดก็ได้ที่คุณชอบ แสดงให้คุณเห็นเท่านั้น มีประโยชน์เมื่อมีมากกว่าหนึ่งเครื่อง
Connection TypeDirect IP สำหรับที่อยู่ที่คุณพิมพ์ หรือ QuickConnect สำหรับ QuickConnect ID ดูด้านล่าง
Host / IP AddressIP ภายในของ NAS ชื่อโฮสต์ หรือโดเมนที่กำหนดเองที่ชี้มาที่มัน
Port5001 เมื่อเปิด HTTPS 5000 เมื่อปิด เว้นแต่ DSM ถูกย้ายไปพอร์ตอื่น ในกรณีนั้นให้ใช้พอร์ตเหล่านั้น
HTTPSเปิดเป็นค่าเริ่มต้น และควรเปิดไว้ ทุกอย่างระหว่างมือถือกับ NAS ถูกเข้ารหัส รวมถึงรหัสผ่านของคุณ
Verify SSL Certificateปิดเป็นค่าเริ่มต้น เพราะ DiskStation ส่วนใหญ่ใช้ใบรับรองที่ลงนามด้วยตนเองซึ่งตรวจสอบกับหน่วยงานสาธารณะไม่ได้ การเชื่อมต่อยังเข้ารหัสไม่ว่าแบบใด เปิดตัวเลือกนี้เฉพาะเมื่อคุณติดตั้งใบรับรองจริง
Usernameชื่อบัญชี DSM ของคุณ รองรับชื่อผู้ใช้ที่มีช่องว่าง แอปใส่เครื่องหมายคำพูดให้ถูกต้อง ซึ่งเป็นเหตุผลที่ไคลเอนต์อื่นมักล้มเหลว
รหัสผ่านรหัสผ่าน DSM ของคุณ ไอคอนรูปตาแสดงรหัสขณะที่คุณพิมพ์ รหัสผ่านถูกเขียนลง keychain หรือ keystore ของแพลตฟอร์ม และไม่เคยเก็บเป็นข้อความธรรมดา
การยืนยันตัวตนสองขั้นตอนเปิดหากบัญชี DSM ของคุณใช้แอปยืนยันตัวตน ดูด้านล่าง
ส่งภาพสดจากกล้องผ่านอุโมงค์พอร์ต DSMปิดเป็นค่าเริ่มต้น ปิดหมายถึงภาพสดจากกล้องเชื่อมต่อตรงกับ RTSP ที่พอร์ต 554 ซึ่งเร็วกว่าในเครือข่ายของคุณเอง แต่ต้องให้เข้าถึงพอร์ตนั้นได้จากที่ที่คุณอยู่ เปิดจะส่งสตรีมผ่านพอร์ต HTTPS ของ DSM ที่คุณใช้อยู่แล้ว ภาพสดจึงใช้ได้จากภายนอกโดยไม่ต้องเปิดพอร์ต 554 ดู Surveillance Station
ไม่ต้องพิมพ์ที่อยู่

QuickConnect

เปลี่ยน Connection Type เป็น QuickConnect แล้วกรอก QuickConnect ID แทนโฮสต์และพอร์ต รีเลย์ของ Synology จะหา NAS ของคุณไม่ว่าอยู่ที่ไหน และไม่ต้องตั้งค่าเราเตอร์

  • ID ของคุณอยู่ที่ไหน ใน DSM ภายใต้ Control Panel › External Access › QuickConnect ต้องเปิดใช้งานที่นั่นก่อน
  • ราคาที่ต้องจ่าย รีเลย์เพิ่มความหน่วง ภาพขนาดย่อและภาพสดจึงโหลดช้ากว่าในเครือข่ายของคุณเอง แต่ทุกอย่างยังใช้งานได้
  • สิ่งที่ประหยัดให้ ไม่ต้องส่งต่อพอร์ต ไม่ต้องคอยอัปเดต dynamic-DNS และไม่มีอะไรเปิดสู่อินเทอร์เน็ตฝั่งคุณ
มีได้ทั้งสองแบบ เพิ่ม NAS เครื่องเดียวกันสองครั้ง ครั้งหนึ่งด้วย IP ภายใน อีกครั้งด้วย QuickConnect จะได้ทางเข้าที่เร็วสำหรับที่บ้านและทางเข้าที่เชื่อถือได้สำหรับนอกบ้าน ทั้งสองเป็นรายการแยกกันที่มีเลย์เอาต์แยกกัน เลือกอันที่ใกล้กว่า
2FA

การยืนยันตัวตนสองขั้นตอน

หากบัญชี DSM ของคุณป้องกันด้วยแอปยืนยันตัวตน ให้เปิด Two-Factor Authentication (2FA) ก่อนบันทึก แอปจะขอรหัสหกหลักทันทีหลังรหัสผ่านถูกยอมรับ

  1. เปิดสวิตช์ในฟอร์ม Add NAS
  2. Save & Connect แอปเข้าสู่ระบบ แล้ว DSM จะขอปัจจัยที่สอง
  3. กรอกรหัสจากแอปยืนยันตัวตนของคุณ
  4. เลือกว่าจะจดจำอุปกรณ์นี้หรือไม่ หากเลือก DSM จะออกโทเค็นอุปกรณ์ และมือถือเครื่องนี้จะไม่ถูกขอรหัสอีก โทเค็นถูกเก็บแบบเดียวกับรหัสผ่าน คือใน keychain ของแพลตฟอร์ม
หากรหัสถูกปฏิเสธ ให้ตรวจสอบนาฬิกา รหัสจากแอปยืนยันตัวตนคำนวณจากเวลาปัจจุบัน มือถือหรือ NAS ที่นาฬิกาเพี้ยนจึงสร้างหรือคาดหวังตัวเลขผิด แหล่งเวลาของ NAS แสดงอยู่ในแถวสถิติด่วนบนหน้าจอหลัก
ก่อนยืนยัน

Test Connection แล้วจึงบันทึก

Test Connection ลองที่อยู่ พอร์ต และข้อมูลรับรอง แล้วบอกว่าเกิดอะไรขึ้นโดยไม่บันทึกอะไร เป็นวิธีที่เร็วที่สุดในการหาที่พิมพ์ผิด เพราะแยก "ติดต่อ NAS ไม่ได้" ออกจาก "ติดต่อได้ แต่รหัสผ่านผิด"

ข้อความที่ขึ้นความหมาย
Connection timeoutไม่มีอะไรตอบกลับ อาจเป็นที่อยู่ พอร์ต หรือเครือข่ายที่มือถืออยู่ ไม่ใช่ข้อมูลรับรอง ซึ่งยังไม่เคยถูกลอง
Invalid credentialsNAS ตอบกลับและปฏิเสธการเข้าสู่ระบบ ที่อยู่และพอร์ตถูกต้อง แต่ชื่อผู้ใช้หรือรหัสผ่านไม่ถูก
Certificate errorเปิด HTTPS และเปิด Verify SSL Certificate ไว้กับใบรับรองที่ลงนามด้วยตนเองด้วย ให้ปิดการตรวจสอบ
2FA requiredบัญชีใช้การยืนยันตัวตนสองขั้นตอนแต่สวิตช์ปิดอยู่ เปิดแล้วลองอีกครั้ง

Save & Connect บันทึกรายการและเข้าสู่ระบบ คุณจะไปถึงหน้าจอหลักโดย NAS ของคุณกำลังโหลดอยู่แล้ว

คุณเข้ามาแล้ว

เกิดอะไรขึ้นเมื่อเชื่อมต่อครั้งแรก

  • แอปถามว่า NAS ของคุณทำอะไรได้บ้าง โดยสอบถามแคตตาล็อก API ของ DSM และเก็บรายการไว้ นั่นเป็นเหตุผลที่ NAS ที่ไม่มี Surveillance Station ไม่เคยแสดงแท็บกล้อง และเหตุผลที่การติดตั้งแพ็กเกจทำให้หน้าจอของมันปรากฏ
  • ทุกการ์ดที่รองรับถูกเปิดไว้ การ์ดใหม่มาแบบมองเห็นได้ ไม่ซ่อน ฟีเจอร์ที่ NAS ของคุณรองรับจึงเป็นสิ่งที่คุณเห็น Customize คือที่ที่คุณปิดสิ่งต่าง ๆ ไม่ใช่ที่ที่ต้องไปหาว่ามีอะไร
  • ระบบเก็บ MAC address ของ NAS ไว้ เพื่อให้ Wake-on-LAN ใช้ได้ภายหลังโดยไม่ต้องไปค้นหาเอง
  • ข้อความต้อนรับสั้น ๆ ปรากฏครั้งเดียว บอกว่าแอปทำอะไรและไปเปลี่ยนค่าได้ที่ไหน มีช่องทำเครื่องหมายเพื่อไม่ให้ปรากฏอีก
  • การ์ดช่วยเหลือปรากฏบนหน้าจอที่ต้องอธิบาย กดค้างที่การ์ดเพื่อปิด กู้คืนทีละใบได้จากการตั้งค่า
ติดตั้งแพ็กเกจหลังเชื่อมต่อแล้วหรือ รายการความสามารถถูกอ่านตอนเชื่อมต่อ แพ็กเกจที่ติดตั้งหลังจากนั้นจึงยังไม่มีแท็บ ดึงลงเพื่อรีเฟรช หรือเปิดแอปใหม่ แล้วหน้าจอใหม่จะปรากฏ
เมื่อเชื่อมต่อไม่ได้

เช็กลิสต์สั้น ๆ

  1. เปิด DSM ในเบราว์เซอร์ของมือถือที่ที่อยู่และพอร์ตตรงกับที่คุณพิมพ์ หากเบราว์เซอร์ก็เข้าไม่ได้เช่นกัน ปัญหาคือเครือข่ายหรือที่อยู่ ไม่ใช่แอป
  2. ตรวจสอบว่า HTTPS ตรงกับพอร์ต พอร์ต 5001 เมื่อปิด HTTPS หรือ 5000 เมื่อเปิด จะหมดเวลา เพราะเป็นตัวรับฟังคนละตัว
  3. ปิด Verify SSL Certificate หาก NAS ใช้ใบรับรองที่มากับเครื่อง
  4. ตรวจสอบเครือข่ายของมือถือ IP ภายในเข้าถึงไม่ได้ผ่านข้อมูลมือถือ ให้เชื่อมต่อ Wi-Fi หรือใช้ QuickConnect โดเมน หรือ VPN
  5. บน iOS ให้อนุญาตการเข้าถึงเครือข่ายภายใน การตั้งค่า › แอป › Syno Manager › เครือข่ายภายใน หากไม่เปิด iOS จะบล็อกการเชื่อมต่อไปยังที่อยู่ในเครือข่ายของคุณแบบเงียบ ๆ
  6. ตรวจสอบไฟร์วอลล์ของ DSM Control Panel › Security › Firewall กฎที่อนุญาตเฉพาะบางที่อยู่จะบล็อกมือถือที่ไม่ใช่หนึ่งในนั้น
  7. ตรวจสอบ auto-block Control Panel › Security › Account การเข้าสู่ระบบล้มเหลวซ้ำ ๆ อาจทำให้ที่อยู่ของมือถือถูกบล็อก จะแสดงอยู่ที่นั่นและลบออกได้

Synology NAS ที่ใช้ DSM 7.0 ขึ้นไป บัญชี DSM บน NAS นั้น และอุปกรณ์ที่ใช้ Android 7+, iOS 16+, macOS 11+ หรือ Windows ไม่ต้องติดตั้งอะไรบน NAS แอปใช้ API ของ DSM เองที่มีอยู่แล้ว
ต้องกรอกที่อยู่และพอร์ตอะไร
ในเครือข่ายของคุณเอง ให้ใช้ IP แอดเดรสภายในของ NAS และพอร์ตของ DSM คือ 5001 เมื่อเปิด HTTPS หรือ 5000 เมื่อปิด HTTPS หรือจะกรอกชื่อโฮสต์หรือโดเมนที่กำหนดเองก็ได้ หากไม่อยากยุ่งกับที่อยู่เลย ให้เปลี่ยน Connection Type เป็น QuickConnect แล้วกรอก QuickConnect ID
ทำไม Verify SSL Certificate จึงปิดเป็นค่าเริ่มต้น
เพราะ DiskStation ส่วนใหญ่ใช้ใบรับรองที่ลงนามด้วยตนเอง ซึ่งไม่ได้ลงนามโดยหน่วยงานสาธารณะ จึงไม่ผ่านการตรวจสอบแม้การเชื่อมต่อยังเข้ารหัสอยู่ การปิดการตรวจสอบจะยอมรับใบรับรองนั้น หากคุณติดตั้งใบรับรองจริง เช่นจาก Let's Encrypt ให้เปิดการตรวจสอบ
ต้องเปิดพอร์ตบนเราเตอร์ไหม
ไม่ต้อง ในเครือข่ายของคุณเองไม่ต้องส่งต่อพอร์ตใด ๆ จากภายนอก QuickConnect จะรีเลย์การเชื่อมต่อให้ และ VPN ก็ใช้ได้เช่นกัน การส่งต่อพอร์ตจำเป็นเฉพาะเมื่อคุณต้องการเส้นทางตรงจากอินเทอร์เน็ต หรือต้องการดูภาพสดจากกล้องผ่าน RTSP จากนอกเครือข่าย
ขึ้นว่า connection timeout ทำอย่างไรดี
ข้อความนั้นหมายความว่าแอปไม่ได้รับคำตอบเลย ซึ่งเกือบทุกครั้งเกิดจากที่อยู่ พอร์ต หรือเครือข่ายที่มือถืออยู่ ตรวจสอบว่า HTTPS ตรงกับพอร์ต มือถืออยู่ในเครือข่ายเดียวกับ NAS หากใช้ IP ภายใน และเว็บอินเทอร์เฟซของ DSM โหลดได้ในเบราว์เซอร์ของมือถือที่ที่อยู่และพอร์ตเดียวกัน
เพิ่ม NAS ได้มากกว่าหนึ่งเครื่องไหม
ได้ กี่เครื่องก็ได้ แต่ละเครื่องเก็บข้อมูลรับรอง เลย์เอาต์แดชบอร์ด และการตั้งค่าของตัวเอง และสลับระหว่างกันได้จากรายการอุปกรณ์ ดูการใช้ NAS หลายเครื่อง
