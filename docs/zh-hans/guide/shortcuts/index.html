快捷方式&链接

直达你想要的界面

Syno Manager 注册了 synomanager:// URL 方案，因此 Siri 口令、启动器快捷方式或自动化应用可以让应用直接打开到你需要的位置，而不是主屏幕。在 Mac 上，Siri 和“快捷指令”应用能原生识别 Syno Manager，完全不需要输入 URL。

有意设置的限制

为什么重启和关机只会打开应用

它们只会带你前往电源控制界面，自己不会重启或关闭任何设备。

快捷方式是很容易误触的东西 - 点错的启动器图标、听错的语音口令、在错误时机触发的自动化。重启 NAS 会断开所有正在使用它的人，并打断它正在做的一切。这两点不应该凑在一起，所以链接只到界面为止，原有的确认流程依然适用。

其他所有链接本质上都是安全的，因为它们只是把内容展示给你。这就是为什么其余链接一键即达，而这两个不行。
使用方法

各平台的做法

iOS - Siri 与快捷指令

  1. 打开快捷指令，新建一个快捷指令。
  2. 添加打开 URL 操作。
  3. 输入链接，例如 synomanager://storage。
  4. 起一个你愿意说出口的名字 - “查看我的 NAS 存储”。
  5. 把它添加到主屏幕，或者直接问 Siri。

Android - 启动器与自动化

  1. 大多数启动器都可以放置一个打开 URL 的快捷方式。
  2. 自动化应用 - 如 Tasker、MacroDroid 等 - 可以由任意触发条件打开它。
  3. 笔记或网页中的 <a href="synomanager://system"> 链接同样有效。
具体打开哪台 NAS，取决于你的启动行为设置。快捷方式选择的是界面，而不是设备 - 所以如果设为“上次使用的 NAS”，synomanager://storage 会显示你上次使用的那台 NAS 的存储。
macOS

原生支持 Siri 与快捷指令

在 Mac 上，Syno Manager 完全不需要 URL。它直接向苹果的 App Intents 注册了三个操作，所以 Siri 和“快捷指令”应用会把 Syno Manager 当作拥有自己词汇的应用，就像对待苹果自家的应用一样。

操作功能对 Siri 说
打开某个部分打开 Syno Manager 到你选择的任意部分 - 仪表盘、存储、系统、网络、应用、备份、文件或唤醒。“打开 Syno Manager”
重启 NAS请你确认，然后让应用打开到电源控制界面。在那里再次确认之前，不会向 NAS 发送任何指令。“用 Syno Manager 重启我的 NAS”
关闭 NAS与“重启”流程相同：先通过 Siri 或快捷指令确认，然后应用打开到电源控制界面。“用 Syno Manager 关闭我的 NAS”
重启和关机仍需确认两次。Siri 或快捷指令会先询问 - “打开 Syno Manager 以重启 NAS？目前尚未向 NAS 发送任何指令 - 你需要在应用中确认” - 然后应用自己的电源控制会再次询问。听错一个词就重启 NAS 的语音指令，不是什么值得拥有的功能。

可以在此基础上构建你自己的自动化。由于它们是普通的快捷指令操作，“打开某个部分”可以放进你创建的任何快捷指令中 - 按计划运行、由家庭中枢触发，或接在其他操作之后 - 与任何其他 Mac 应用的操作完全一样。

常见问题

快捷方式 FAQ

Syno Manager 有 URL 方案吗？
有。synomanager://<name> 会让应用直接打开指定界面。仪表盘、存储、系统、网络、应用、备份、文件和唤醒各有一个。
快捷方式能一键重启我的 NAS 吗？
不能，而且是有意为之。重启和关机链接只会让应用打开到电源控制界面，那里仍会走原有的确认流程。
可以配合 Siri 使用吗？
可以。在苹果的“快捷指令”应用中创建一个打开该 URL 的快捷指令，给它起个口令，Siri 就会直接带你过去。
快捷方式能指定某台 NAS 吗？
不能。快捷方式只打开一个界面；具体打开哪台 NAS，取决于你的“启动行为”设置。
Syno Manager 能在 Mac 上配合“快捷指令”应用使用吗？
可以，而且是原生支持。“打开某个部分”、“重启 NAS”和“关闭 NAS”会作为 Syno Manager 的操作出现在 macOS 版苹果“快捷指令”应用中，无需输入任何 URL。两个电源操作会先请求 Siri 或快捷指令确认，然后也只是让应用打开到电源控制界面。
