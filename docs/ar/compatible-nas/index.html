اكتشاف، لا قائمة مكتوبة سلفاً

جدول دعم لكل طراز سيصبح خاطئاً يوم تُصدر Synology طرازاً جديداً، وخاطئاً مرة أخرى يوم يكتسب أحدها حزمة جديدة.

  • يستعلم التطبيق عن فهرس DSM API عند الاتصال ويحتفظ بالجواب. وهذا الفهرس هو المرجع الحقيقي لما يستطيع NAS الخاص بك فعله.
  • تظهر الشاشات لأن NAS أبلغ عن API الذي تقف خلفها. ثبّت Surveillance Station فتظهر شاشة الكاميرات. احذفه فتختفي الشاشة.
  • لا شيء يُفترض من اسم الطراز. طرازان متطابقان بحزم مختلفة يحصلان على تطبيقين مختلفين، وهذا هو الصواب.
  • القيمة التي لم يبلغ عنها NAS تُسمّى غير مقروءة، ولا تُملأ أبداً بقيمة افتراضية معقولة.

الخلاصة العملية: إذا كانت واجهة DSM على الويب تعمل من متصفح هاتفك، ويستطيع حساب DSM الخاص بك رؤية شيء هناك، فيستطيع Syno Manager رؤيته أيضاً.

أسئلة شائعة

الأسئلة الشائعة (FAQ) حول التوافق

ما طُرز Synology التي يدعمها Syno Manager؟
أي جهاز Synology NAS بنظام DSM 7.0 أو أحدث - DiskStation وRackStation وFlashStation، مع وحدات توسعة أو بدونها. لا توجد قائمة طُرز لأن التطبيق يسأل جهازك عمّا يستطيع فعله عند الاتصال.
هل يعمل على DSM 6؟
لا. يلزم DSM 7.0 أو أحدث. فـ DSM 6 يستخدم إصدارات API وسلوك مصادقة مختلفين.
هل سيعمل على جهاز NAS صغير بخانتين؟
نعم. يعرض شاشات أقل لأنه يشغّل خدمات أقل، لا لأنه غير مدعوم. وكل ما يشغّله يُعرض كاملاً.
هل يدعم وحدات التوسعة؟
نعم. تظهر الأقراص في وحدة التوسعة بجانب الأقراص الداخلية.
ماذا لو كان NAS الخاص بي يعمل بإصدار تجريبي من DSM؟
سيعمل عموماً، لأن التطبيق يقرأ فهرس API ولا يفترض إصداراً. وقد يؤدي إصدار تجريبي يغيّر API إلى قيمة يبلغ عنها التطبيق على أنها غير مقروءة - وسيقول ذلك بدل عرض رقم خاطئ.
