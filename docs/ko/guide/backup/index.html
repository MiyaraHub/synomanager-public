Hyper Backup

맨 위에 작업 수, 정상 작업 수, 문제가 있는 작업 수가 요약되고, 그 아래에 작업별 카드가 표시됩니다.

표시 항목의미
작업 이름Hyper Backup에서 지정한 이름 그대로입니다.
대상백업 대상 위치입니다. Synology C2, 원격 NAS, 로컬 폴더, 클라우드 제공업체 등이 있습니다.
상태대기 중, 실행 중, 또는 실패입니다. 실행 중인 작업에는 실시간 진행 막대가 표시됩니다.

백업 크기와 소스 크기를 나란히

대부분의 도구는 둘 중 하나만 보여 줍니다. 함께 보면 어느 하나로는 답할 수 없는 질문에 답할 수 있습니다.

  • 중복 제거와 압축으로 얼마나 절약하는지. 758 GB 소스가 대상에서 814 GB를 차지하는 것은 300 GB를 차지하는 것과 전혀 다른 이야기이며, 이는 두 값을 함께 봐야만 드러납니다.
  • 대상 위치가 곧 가득 찰지. 소스의 증가와 대상의 증가는 같은 곡선이 아니며, "다음 달에 실패할까"를 판단할 때 중요한 것은 대상 쪽입니다.
  • 버전 관리가 통제를 벗어나고 있는지. 대상이 소스보다 훨씬 빠르게 커진다면 보존 정책이 의도보다 많은 것을 남기고 있을 가능성이 큽니다.
Active Backup

Active Backup for Business

기기와 작업 수가 표시된 헤더, 그 아래에 저장소 크기, 그리고 기기 목록이 이어집니다.

백업 크기

  • 볼륨별 저장소의 전체 중복 제거 용량.
  • 워크로드별 구분 - PC, 서버, 가상 머신, DSM 기기 - 각각의 기기 수와 용량이 표시됩니다.
  • 있는 그대로 표시합니다. Active Backup이 보고한 대상 위치의 중복 제거 용량입니다. 소스 크기의 합계를 그럴듯하게 포장한 값이 아닙니다.

기기

  • 보호 중인 각 기기의 주소와 운영 체제.
  • 마지막 백업, 아직 실행되지 않았다면 없음으로 표시됩니다. 눈여겨볼 항목은 바로 이쪽입니다.
  • 기기별 지금 백업.
문제가 생겼을 때

찾아보지 않아도 알 수 있습니다

  • 작업 카드에 NAS가 보고한 상태가 표시됩니다.
  • 홈 화면의 상태 배지에도 반영되므로, 백업 실패는 세 번 탭해서 들어가는 화면이 아니라 처음 보는 화면에 나타납니다.
  • 한 번도 백업되지 않은 기기는 빈칸이나 0이 아니라 없음으로 표시됩니다. 빈칸이나 0은 "괜찮음"으로 읽히기 때문입니다.
앱이 하지 않는 일: 백업 작업 생성 또는 편집, 보존 정책 변경, 백업에서 복원. 이는 Hyper Backup 고유의 역할이며, 특히 복원은 휴대폰에서 실수로 시작할 만한 작업이 아닙니다.

백업 FAQ

휴대폰에서 백업을 시작할 수 있나요?
네. 모든 Hyper Backup 작업에는 지금 실행 버튼이 있고, 실행 중인 작업에는 취소할 수 있는 실시간 진행 막대가 표시됩니다.
백업 크기와 소스 크기는 어떻게 다른가요?
소스 크기는 작업이 백업하는 데이터의 양이고, 백업 크기는 중복 제거와 압축 후 대상 위치에서 실제로 차지하는 공간입니다. 두 값을 함께 보면 얼마나 절약되는지, 그리고 대상 위치가 소스의 증가 속도보다 빨리 차오르는지 알 수 있습니다.
Active Backup for Business도 표시되나요?
네. 워크로드별 중복 제거 저장소 크기와 기기 수, 보호 중인 모든 기기의 마지막 백업 시각, 지금 백업 버튼이 표시됩니다.
백업이 실패하면 알려 주나요?
네. 작업 상태가 작업별로 표시되고, 실패한 작업은 홈 화면의 상태 배지에도 반영됩니다.
앱에서 백업을 복원할 수 있나요?
아니요. 복원은 버전 선택기와 대상 선택이 있는 Hyper Backup 또는 Active Backup에서 진행합니다. 앱은 백업을 모니터링하고 실행하지만, 데이터를 되돌리지는 않습니다.
