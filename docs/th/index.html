ไม่มีเซิร์ฟเวอร์คั่นกลาง

Syno Manager เป็นไคลเอนต์สำหรับ NAS ของคุณ ไม่ใช่บริการ โทรศัพท์ของคุณเปิดการเชื่อมต่อไปยัง DiskStation ของคุณ และนั่นคือสถาปัตยกรรมทั้งหมด

  • ไม่มีเซิร์ฟเวอร์ MiyaraHub ไม่มีอะไรเกี่ยวกับ NAS ของคุณมาถึงเรา เพราะในเส้นทางไม่มีที่ให้มันไป
  • ข้อมูลเข้าสู่ระบบใน keychain เก็บในที่เก็บข้อมูลปลอดภัยของแพลตฟอร์ม ไม่เคยเป็นข้อความธรรมดา และถูกยกเว้นจากการสำรองข้อมูลของอุปกรณ์
  • 2FA และการเชื่อถืออุปกรณ์ รองรับรหัสใช้ครั้งเดียว และจำอุปกรณ์ที่เชื่อถือได้ เพื่อไม่ต้องถามทุกครั้งที่เปิดแอป
  • ผู้ช่วยทำงานบนอุปกรณ์ คำถาม ข้อมูล NAS และคำตอบของคุณไม่เคยออกจากโทรศัพท์
  • มีสิ่งเดียวที่ออกไป: รายงานการแครช เพื่อให้แก้ไขการแครชได้ ซึ่งมี stack trace ไม่ใช่ NAS ของคุณ ดูภาพรวมทั้งหมด

Syno Manager ทำอะไรได้บ้าง
รวมส่วนของ DSM ที่คุณตรวจสอบจริง ๆ บนโทรศัพท์ไว้ในแอปเดียว: ค่า CPU, RAM, อุณหภูมิ และเครือข่ายแบบสด วอลุ่มพื้นที่จัดเก็บและสุขภาพ SMART ของแต่ละไดรฟ์ คอนเทนเนอร์ Docker Package Center ภาพสด Surveillance Station Synology Photos และ Drive Hyper Backup และ Active Backup Download Station File Station ผู้ใช้ งานตามกำหนด UPS DDNS และ Wake-on-LAN แอปสื่อสารกับ NAS ของคุณโดยตรงผ่าน API ที่ DSM เปิดเผยเอง คู่มือผู้ใช้ครอบคลุมทุกหน้าจอ
ใช้ได้กับ Synology รุ่นใดบ้าง
Synology NAS ทุกรุ่นที่ใช้ DSM 7.0 ขึ้นไป แอปอ่านสิ่งที่ NAS ของคุณรายงานตอนเชื่อมต่อ และแสดงเฉพาะหน้าจอที่รองรับจริง DS223j แบบสองช่องและ RS1221+ แบบแร็กเมาต์จึงได้แดชบอร์ดที่ตรงกับสิ่งที่แต่ละเครื่องทำได้ ดูความเข้ากันได้
ใช้ได้เมื่ออยู่นอกบ้านไหม
ได้ เพิ่ม NAS ครั้งเดียว แอปจะใช้เส้นทางใดก็ตามที่เข้าถึงได้ ไม่ว่าจะเป็น IP ในเครือข่ายที่บ้าน หรือ QuickConnect โดเมนของคุณเอง หรือ VPN เมื่อออกไปข้างนอก รูปภาพ ภาพสดจากกล้อง และการดาวน์โหลดจาก File Station และ Drive ใช้ได้ผ่านรีเลย์ QuickConnect จึงไม่ต้องฟอร์เวิร์ดพอร์ต ดูการเข้าถึงระยะไกล
ข้อมูลของฉันผ่านเซิร์ฟเวอร์ของคุณไหม
ข้อมูล NAS ของคุณไม่ผ่าน Syno Manager เชื่อมต่อกับ NAS ของคุณโดยตรง และไม่มีเซิร์ฟเวอร์ MiyaraHub ในเส้นทางนั้น ไฟล์ ค่าที่อ่านได้ และการกำหนดค่าของคุณจึงไม่เคยมาถึงเรา ข้อมูลเข้าสู่ระบบเก็บใน keychain หรือ keystore ของอุปกรณ์และถูกยกเว้นจากการสำรองข้อมูลของอุปกรณ์ และผู้ช่วยรันโมเดลบนโทรศัพท์ของคุณ สิ่งเดียวที่ออกจากอุปกรณ์คือรายงานการแครช ผ่าน Firebase Crashlytics ซึ่งเป็น stack trace รุ่นอุปกรณ์ และเวอร์ชันแอป และไม่มีข้อมูล NAS ของคุณ รายละเอียดทั้งหมดอยู่ที่นี่
