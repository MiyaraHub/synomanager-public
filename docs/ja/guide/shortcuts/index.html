ショートカット & リンク

見たい画面へ直接移動

Syno Manager はsynomanager://というURLスキームを登録しているため、Siriのフレーズ、ランチャーのショートカット、自動化アプリから、ホーム画面ではなく必要な画面でアプリを開けます。MacではSiriとショートカットアプリがSyno Managerをネイティブに認識するので、URLを入力する必要はまったくありません。

意図的な制限

再起動とシャットダウンがアプリを開くだけの理由

電源コントロールまで移動するだけで、それ自体でNASを再起動したりシャットダウンしたりすることはありません。

ショートカットは、うっかり実行してしまうことがあります。ランチャーのアイコンの押し間違い、音声の聞き間違い、誤ったトリガーで動く自動化などです。NASを再起動すると、使用中のユーザーはすべて切断され、実行中の処理も中断されます。この2つは同居させるべきではないので、リンクは画面を開くところまでにとどめ、通常の確認が表示されます。

他のリンクは、性質上すべて安全です。何かを表示するだけだからです。そのため、他のものはワンタップで、この2つはそうではありません。
使い方

プラットフォーム別

iOS - Siriとショートカット

  1. ショートカットを開き、新しいショートカットを作成します。
  2. URLを開くアクションを追加します。
  3. リンクを入力します。例：synomanager://storage。
  4. 声に出して言える名前を付けます。たとえば「NASのストレージを確認」。
  5. ホーム画面に追加するか、Siriに頼むだけです。

Android - ランチャーと自動化

  1. ほとんどのランチャーで、URLを開くショートカットを配置できます。
  2. TaskerやMacroDroidなどの自動化アプリなら、あらゆるトリガーからURLを開けます。
  3. メモやページに<a href="synomanager://system">リンクを置いても動作します。
どのNASで開くかは起動時の動作の設定に従います。ショートカットが選ぶのは画面であってデバイスではありません。そのため「最後に使ったNAS」に設定している場合、synomanager://storageは最後に使っていたNASのストレージを表示します。
macOS

Siriとショートカットにネイティブ対応

Macでは、Syno ManagerはURLを必要としません。AppleのApp Intentsに3つのアクションを直接登録しているため、SiriとショートカットアプリはApple自身のアプリと同じように、Syno Managerを独自の語彙を持つアプリとして認識します。

動作できることSiriへの呼びかけ
セクションを開く選んだセクション（ダッシュボード、ストレージ、システム、ネットワーク、アプリ、バックアップ、ファイル、Wake）でSyno Managerを開きます。「Syno Managerを開いて」
NASを再起動確認を求めたうえで、アプリを電源コントロールで開きます。そこでもう一度確認するまで、NASには何も送信されません。「Syno ManagerでNASを再起動して」
NASをシャットダウン再起動と同じ流れです。SiriまたはショートカットでConfirmしたあと、アプリが電源コントロールで開きます。「Syno ManagerでNASをシャットダウンして」
再起動とシャットダウンは、2回確認します。まずSiriまたはショートカットが「NASを再起動するためにSyno Managerを開きますか？ NASにはまだ何も送信されません。アプリ内で確認します」と尋ね、続いてアプリ自身の電源コントロールが再度確認します。最初の聞き間違いでNASが再起動してしまう音声コマンドは、あっても役に立ちません。

これらを使って、独自の自動化を組み立てられます。通常のショートカットのアクションなので、「セクションを開く」は自作のどのショートカットにも組み込めます。スケジュール実行、Home Hubからのトリガー、他の処理の後に連結するなど、他のMacアプリのアクションとまったく同じように使えます。

よくある質問

ショートカットに関するよくある質問

Syno Manager にはURLスキームがありますか？
はい。synomanager://<name>で、アプリを特定の画面で開けます。ダッシュボード、ストレージ、システム、ネットワーク、アプリ、バックアップ、ファイル、Wakeにそれぞれ用意されています。
ショートカットでNASをワンタップで再起動できますか？
いいえ。これは意図的な仕様です。再起動とシャットダウンのリンクは、アプリを電源コントロールで開くだけで、そこでは通常の確認が表示されます。
Siriで使えますか？
はい。AppleのショートカットアプリでURLを開くショートカットを作成してフレーズを設定すれば、Siriがその画面へ直接移動します。
ショートカットでNASを指定できますか？
いいえ。ショートカットが開くのは画面で、どのNASで開くかは「起動時の動作」の設定に従います。
MacのショートカットアプリでSyno Managerを使えますか？
はい、ネイティブに対応しています。「セクションを開く」「NASを再起動」「NASをシャットダウン」が、macOSのAppleショートカットアプリにSyno Managerのアクションとして表示され、URLを入力する必要はありません。2つの電源アクションは、何かを実行する前にSiriまたはショートカットで確認を求め、アプリを電源コントロールで開くだけです。
