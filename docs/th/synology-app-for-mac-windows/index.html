Synology NAS ของคุณ บนเดสก์ท็อป

Syno Manager เป็นแอปเนทีฟอิสระสำหรับ Synology NAS ของคุณบน macOS และ Windows แอปเดียวกับบนโทรศัพท์ จัดวางสำหรับหน้าต่างที่ใหญ่ขึ้น: ค่าแบบสด Docker การสำรองข้อมูล ไฟล์ และ Wake-on-LAN โดยไม่ต้องเปิด DSM ในแท็บเบราว์เซอร์

Mac

บน macOS

Siri และ Shortcuts แบบเนทีฟ ›

เปิดส่วนหนึ่ง รีสตาร์ท NAS และปิด NAS เป็นการทำงานของ Shortcuts จริงผ่าน App Intents ตั้งเวลาหรือเชื่อมต่อเข้ากับทางลัดของคุณเองได้

ผู้ช่วย Apple Intelligence ›

บนอุปกรณ์ที่รองรับและเปิดใช้ Apple Intelligence ถามเกี่ยวกับ NAS ของคุณด้วยภาษาธรรมดา โมเดลรันบน Mac

ข้อมูลเข้าสู่ระบบใน Keychain ›

รหัสผ่าน DSM และโทเคนอุปกรณ์เก็บใน macOS Keychain ไม่เคยเป็นข้อความธรรมดา

Apple เป็นการซื้อแบบยูนิเวอร์ซัลครั้งเดียว: ซื้อ Syno Manager ครั้งเดียวก็ใช้ได้บน Mac, iPhone และ iPad ของคุณ

บน Windows

ปลุกพีซีผ่าน NAS ›

NAS ที่เปิดตลอดเวลาส่งแพ็กเก็ตมายากลจากภายในเครือข่ายของคุณ คู่มือครอบคลุมฝั่ง Windows รวมถึงการปิด Fast Startup

ภาพรวมการสำรองข้อมูลในพริบตา ›

งาน Hyper Backup พร้อมพื้นที่ที่ใช้ และอุปกรณ์ Active Backup for Business พร้อมยอดรวมแบบ deduplicate

ทุกอย่างที่คุณตรวจสอบบน NAS

  • ระบบ: CPU, RAM, โหลด, ดิสก์ I/O และอุณหภูมิ โหมดพัดลม การตรวจสอบการอัปเดต DSM รีสตาร์ท และปิดเครื่อง
  • พื้นที่จัดเก็บ: วอลุ่มและพูลพร้อมประเภท RAID สุขภาพ SMART และอุณหภูมิของแต่ละไดรฟ์ การถอดอย่างปลอดภัย
  • แอป: Package Center คอนเทนเนอร์ Docker และสแตก Compose เครื่องเสมือน
  • เครือข่าย: ปริมาณข้อมูลสดต่ออินเทอร์เฟซ การเชื่อมต่อ บริการ DSM โปรไฟล์ VPN และ DDNS
  • หลาย NAS: เพิ่มได้ไม่จำกัด แต่ละเครื่องมีเลย์เอาต์และการตั้งค่าของตัวเอง
