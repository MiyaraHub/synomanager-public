Synology DSM 7対応

Synology NASを、どこにいても。

Syno Manager は、Android、iOS、macOS、Windows向けの、Synology NAS用の独立系ネイティブアプリです。システム、ストレージ、ネットワークのリアルタイムの測定値、Docker、カメラ、写真、バックアップ、ファイルなど、実際に確認するDSMの機能を、NASが実行している内容に正確に合わせて変化する1つの高速なアプリで提供します。

Syno Managerの特長

ウェブコンソールではなく、ネイティブアプリ

バックアップが実行されたか確認するために、DSMにサインインしてマウス向けのブラウザーUIを操作する必要はありません。Syno Manager はDSM自身のウェブインターフェースと同じAPIを読み取り、結果をネイティブに表示します。スマートフォン、タブレット、Mac、PCのいずれでも、それぞれの画面に合わせて最適化されます。

プライバシー

間にサーバーは介在しません

Syno Manager はNASのクライアントであり、サービスではありません。スマートフォンがDiskStationに接続を開く、それがアーキテクチャのすべてです。

  • MiyaraHubのサーバーはありません。経路上にNASのデータが届く場所がないため、NASに関する情報が当社に届くことはありません。
  • 認証情報はキーチェーンに保存。プラットフォームのセキュアストレージに保存され、平文で保存されることはなく、デバイスのバックアップからも除外されます。
  • 2FAとデバイスの信頼。ワンタイムコードに対応し、信頼したデバイスは記憶されるので、起動のたびに求められることはありません。
  • アシスタントはデバイス上で動作します。質問、NASのデータ、回答がスマートフォンの外に出ることはありません。
  • 外に出るものが1つだけあります：クラッシュを修正できるようにするための、クラッシュレポートです。含まれるのはスタックトレースであり、NASの情報ではありません。詳しくはこちら。

よくある質問

スマートフォンでSynologyを使う、あれこれにお答えします

Syno Manager は何ができますか？
スマートフォンで確認する価値のあるDSMの機能を1つのアプリにまとめています。リアルタイムのCPU、RAM、温度、ネットワークの測定値、ストレージボリュームとドライブごとのSMARTヘルス、Dockerコンテナー、Package Center、Surveillance Stationのライブビュー、Synology PhotosとDrive、Hyper BackupとActive Backup、Download Station、File Station、ユーザー、スケジュールされたタスク、UPS、DDNS、Wake-on-LANです。DSM自身の公開APIを使って、NASと直接通信します。ユーザーガイドで、すべての画面を解説しています。
どのSynologyモデルに対応していますか？
DSM 7.0以降を実行しているすべてのSynology NASに対応しています。アプリは接続時にお使いのNASが報告する内容を読み取り、実際に対応している画面だけを表示するため、2ベイのDS223jでもラックマウントのRS1221+でも、それぞれの機能に合ったダッシュボードになります。互換性もご覧ください。
外出先でも使えますか？
はい。NASを一度追加すれば、あとはアプリが到達可能な経路を使います。自宅ではローカルIP、外出先ではQuickConnect、独自ドメイン、VPNです。写真、カメラのライブビュー、File StationとDriveのダウンロードはいずれもQuickConnectの中継経由で動作するため、ポート転送は不要です。リモートアクセスもご覧ください。
データはMiyaraHubのサーバーを経由しますか？
NASのデータは経由しません。Syno Manager はNASと直接通信し、その経路にMiyaraHubのサーバーはないため、ファイル、測定値、設定が当社に届くことはありません。認証情報はデバイスのキーチェーンまたはキーストアに保存されてデバイスのバックアップからも除外され、アシスタントはお使いのスマートフォン上でモデルを実行します。デバイスの外に出る唯一のものは、Firebase Crashlyticsを通じて送信されるクラッシュレポートで、スタックトレース、デバイスのモデル、アプリのバージョンが含まれますが、NASのデータは一切含まれません。詳しくはこちら。
Syno Manager の料金はいくらですか？
$9.99の買い切りです。広告、サブスクリプション、アプリ内課金はなく、アップデートを含め、すべての機能が含まれます。

価格はプラットフォームごとに設定されており、Google PlayとMicrosoft Storeは別々の購入になります。Appleは単一のユニバーサル購入で、iPhone、iPad、Macに対応し、1回購入すれば3台すべてで使えます。

2段階認証に対応していますか？
はい。DSMアカウントで2FAを使っている場合、アプリはワンタイムコードの入力を求め、そのスマートフォンで再度求められないようにデバイスを記憶できます。また、操作を行うたびにDSMのSynoTokenを取得して送信します。これは、何かを変更するクライアントにDSMが求める仕様です。
複数のNASを管理できますか？
はい。好きなだけ追加して、デバイス一覧から切り替えられます。認証情報、ダッシュボードのレイアウト、設定はそれぞれ個別に保持されます。複数のNASデバイスもご覧ください。
Syno Manager は Synology が作っているのですか？
いいえ。Syno Manager は、MiyaraHub Technologies LLCが開発した独立系アプリです。Synology Inc.とは提携しておらず、同社の承認・後援も受けていません。DSM自身のウェブインターフェースが使用しているのと同じ、公開されているDSMのAPIを通じてNASに接続します。当サイトで言及しているSynology、DSM、パッケージ名は、Synology Inc.の商標です。
