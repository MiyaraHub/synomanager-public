為什麼要換

一個 App，掌握整台 NAS

Syno Manager 是第三方的 Synology 用戶端，圍繞一個不同的問題而設計：不是「手機 App 能對檔案做什麼」，而是「NAS 擁有者實際會查看什麼，又想在沙發上順手處理什麼」。

整體架構

大家轉用的六個理由

🔢

一個 App，不用好幾個

系統、儲存空間、網路、容器、套件、攝影機、相片、備份、檔案、使用者與排程工作 - 全部集中在一處，只需一次連線、一次登入。

🚩

點出原因的健康狀態標章

不只是「警告」，而是哪一顆硬碟、哪一個磁碟區、什麼溫度。而且對於無法讀取的數值，絕不會顯示健康的勾勾。

🔧

不只監控，還能控制

重新啟動容器、安裝套件、執行備份、切換服務、退出磁碟、喚醒主機、變更風扇模式 - 全都能在手機上完成。

🌐

離開家也一樣好用

相片、攝影機即時影像與檔案下載，全都透過 QuickConnect 進行。不必設定連接埠轉送，離開家也不會少掉任何功能。

🎨

屬於你的儀表板

重新排列、收合或隱藏任一張卡片，自選底部列的分頁、挑選強調色，OLED 螢幕還有純黑模式。下次開啟時，保持你離開時的樣子。

✨

裝置上的助理

用白話詢問你的 NAS，由手機上的模型回答。離線也能用，不會傳送任何資料，而且只讀取、不修改。

設計原則

可能有兩種意思的數字，要明確標示，不能亂猜

這個原則貫穿整個 App，在截圖裡最難看出來，卻是日常使用中最有價值的一點。

  • 未讀取到的設定會標示為未讀取，而不是顯示成零 - 因為在 Download Station 中，零代表「無限制」，讀取失敗卻顯示為零，就是一個信誓旦旦的謊言。
  • 不會宣稱 VPN 設定檔的狀態，因為DSM 的記錄中沒有狀態欄位可供讀取。
  • 小工具會標明數字的取得時間，因為少了這項資訊，安靜的 NAS 和過期的小工具看起來完全一樣。
  • 退出磁碟以磁碟確實移除為準，而不是以請求被接受為準。
  • 風扇模式變更後會回讀確認，因此 NAS 拒絕的模式會如實回報為遭拒絕。
  • 無法辨識的狀態會照實顯示 - 既非執行中也非關機的虛擬機器，會顯示 NAS 回報的字眼與復原控制，而不是一個根本無法運作的啟動按鈕。

正確讀取的數值若配上錯誤的標籤，看起來就跟真實讀數一樣權威，沒有人看得出來。這比功能清單更值得花心思。

隱私權

中間沒有任何伺服器

  • 沒有 MiyaraHub 伺服器。你的手機直接連到你的 NAS，這條路徑上沒有其他任何東西。
  • 憑證存放在平台鑰匙圈，絕不以純文字儲存，也不納入裝置備份。
  • 助理在裝置上執行，只要助理中出現任何雲端 SDK 或 API 金鑰，建置就會失敗。
  • 一次買斷 $9.99，依平台分開計價。無廣告、無訂閱、無 App 內購買。Apple 為單一通用購買，涵蓋 iPhone、iPad 與 Mac。
  • 當機報告是唯一的例外，而且我們明白告知，不藏在角落。
獨立開發，並坦白說明。Syno Manager 由 MiyaraHub Technologies 製作，與 Synology 無任何隸屬關係。它使用 DSM 公開記載的 API - 與 DSM 自己的網頁介面呼叫的是同一批。

隱私權政策

常見問題

為何改用，一次解答

為什麼要用第三方的 Synology App？
因為 Synology 把行動功能拆成好幾個 App，每個只專精一件事。Syno Manager 走的是另一條路：一個 App 就能監控 NAS，並讓你在手機上操控想控制的項目，不必在不同 App 之間來回切換。
它是 DSM 的替代品嗎？
不是，也不打算成為。DSM 是用來建立設定的地方；Syno Manager 則是用來查看狀態並採取行動的地方。
之後還要持續付費嗎？
不用。Syno Manager 為一次買斷 $9.99，無廣告、無訂閱、無 App 內購買。價格依平台分開計算，因此 Google Play 與 Microsoft Store 需分別購買；Apple 則是單一通用購買，涵蓋 iPhone、iPad 與 Mac。
用第三方 App，我的資料安全嗎？
Syno Manager 直接連線到你的 NAS，中間沒有任何 MiyaraHub 伺服器。登入憑證存放在裝置鑰匙圈，且不納入裝置備份，助理所用的模型也在手機上執行。唯一會離開裝置的是當機報告，內容只有堆疊追蹤，不含任何 NAS 資訊 - 詳見隱私權。
我的 NAS 能用嗎？
只要執行 DSM 7.0 或更新版本就能用。詳見相容性。
