Поза домом

Той самий застосунок, інший маршрут

Syno Manager працює однаково, чи ви поруч із NAS, чи на іншому кінці світу. Змінюється лише те, як з'єднання туди потрапляє, і в кожного маршруту є свої компроміси, які варто знати.

Усе, з двома примітками

Поза домом застосунок не втрачає функцій. Лише дві речі потребують уваги: перегляд камер наживо та пробудження вимкненого NAS.

QuickConnect

Налаштування

  1. У DSM: Панель керування › Зовнішній доступ › QuickConnect. Увімкніть його й запишіть ID QuickConnect.
  2. У застосунку: додайте NAS і змініть Тип підключення на QuickConnect.
  3. Введіть ID, а не хост і порт.
  4. Ваші облікові дані DSM і 2FA, якщо обліковий запис її використовує.
  5. Зберегти & підключити.
Очікуйте, що буде повільніше. Ретранслятор додає ще одну ланку, а Synology обмежує його швидкість, тож фотобібліотека прокручується менш плавно, ніж удома. Усе працює, різниця лише в затримці, а не в можливостях.
Підхід, який варто повторити

Додайте той самий NAS двічі

Один запис за локальною IP, інший через QuickConnect. Назвіть їх так, щоб відрізняти: «NAS (дім)» і «NAS (поза домом)».

  • Вдома користуйтеся прямим: без ретранслятора, повна швидкість, миттєві мініатюри.
  • Поза домом перемкніться на QuickConnect.
  • Вони мають окремі розташування, тож запис для поїздок можна скоротити до кількох карток, які ви справді перевіряєте на мобільному інтернеті.
  • Перемикання - один дотик зі списку пристроїв.

Встановіть для Поведінки під час запуску значення Останній використаний NAS, і застосунок запам'ятовуватиме той, на якому ви були.

Поширені запитання

Поширені запитання про віддалений доступ

Чи потрібно пробрасувати порти для віддаленого доступу до NAS?
Ні. QuickConnect передає з'єднання без жодного налаштування роутера, а VPN теж працює. Переспрямування портів потрібне, лише якщо вам конче потрібен прямий маршрут з інтернету.
Чи працюють фото й перегляд камер наживо через QuickConnect?
Так. Мініатюри, повні зображення, перегляд камер наживо та завантаження з File Station і Drive йдуть будь-яким активним маршрутом, зокрема через ретранслятор. Для перегляду камер потрібен увімкнений перемикач тунелю через порт DSM.
Чи варто додати NAS двічі?
Це хороший підхід: один запис за локальною IP для дому й один через QuickConnect для поїздок, з окремими розташуваннями та перемиканням одним дотиком.
Чи безпечний QuickConnect?
З'єднання наскрізно зашифроване, коли ви використовуєте HTTPS, а ретранслятор лише пропускає трафік, не зберігаючи ваші дані. Ваші облікові дані DSM і двофакторна автентифікація, як і раніше, діють.
Чому мій запис із локальною IP не працює на мобільному інтернеті?
Бо приватна адреса на кшталт 192.168.x.x існує лише у вашій власній мережі. Використайте запис QuickConnect, домен або спершу підключіться до VPN.
