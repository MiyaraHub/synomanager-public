Download Station

发送到 NAS，而不是手机

粘贴链接或磁力链接，或选择 .torrent，由 NAS 负责下载。查看进度，暂停和继续，并更改它实际使用的配置。

Download Station

正在运行的内容

顶部是速度栏，显示所有任务的总下载和上传速度，下面是各个任务。

  • 每个任务都会显示名称、状态、进度条、当前速度和预计剩余时间。
  • 可以对任意任务暂停、继续或删除。
  • 没有运行中的任务时会明确说明，显示“没有进行中的下载”，而不是一个需要你自己解读的空框。
  • 设置从标题栏一点即达。
  • 两代 API 都支持。Download Station 先后有两个 API 版本，应用会使用你的 NAS 提供的那一个。
添加

三种入口

点按右下角的 +。

  1. 粘贴链接或磁力链接。https:// URL 和 magnet:?xt= 链接都填在同一个输入框里。
  2. 或者从设备选择 .torrent 文件，这会打开文件选择器。
  3. 通过保存到选择保存位置，也可以不选，Download Station 会使用它自己的默认文件夹。
  4. 添加。任务会出现在列表中。
手机只是遥控器。文件由 NAS 通过它自己的网络连接获取，所以你可以关闭应用、出门，下载照常进行。
下载设置

每项设置，都读取自你的 NAS

它自己的子视图，按 Download Station 的分组方式排列。可编辑的值带有对勾，用于确认更改，只读的值则作为事实陈列。

分组设置功能
BitTorrent监听端口Download Station 监听的 TCP 端口。可编辑。
下载限制单位为 KB/s。0 表示无限制。可编辑。
上传限制单位为 KB/s。0 表示无限制。可编辑。
最大连接数一个种子最多可连接多少个对等端。
DHT分布式哈希表是否开启，以及使用哪个端口。
FTP 和 HTTP下载限制普通 HTTP 和 FTP 下载的单独限速。0 表示无限制。可编辑。
任务与计划同时进行的任务数同时运行多少个下载，应用还会告诉你NAS 允许的最大值，让你不必猜测上限。可编辑。
备用计划是否在特定时段启用另一套速度计划。
目标位置默认文件夹任务未指定文件夹时，下载保存的位置。没有设置时显示为未设置，而不是留空。
运行于Download Station 套件本身安装在哪个存储空间。
eMuleeMule 服务是否已启用。
每项更改都会通过回读来确认。应用写入你的值，然后从 NAS 重新读取该设置。如果 NAS 悄悄调整或拒绝了它，你会被告知，而不是让你输入的数字停留在那里，看起来像已生效。
一个很重要的小细节

为什么读不到的部分会标明，而不是填零

只会显示你的 NAS 实际上报的设置。应用无法读取的部分会标注为未读取，而不是显示成零。

这不是吹毛求疵。在这里，0 表示无限制，所以读取失败却显示为 0，会让你以为下载不受限制，而实际情况是没人知道。可能有两种含义的值，应当标明为未知，这个界面就是这么做的。

没有看到？

如果看不到 Download Station 标签

  1. 检查套件是否已安装。Download Station 不属于 DSM，它来自 Package Center。你可以在本应用中安装它。
  2. 刷新应用对你 NAS 的了解。功能列表是在连接时读取的，因此在那之后安装的套件还没有对应的标签。下拉刷新，或重新打开应用。
  3. 检查它是否被隐藏。“文件”标签的溢出菜单中有自定义视图，子视图可以在那里关闭。
在大多数 DSM 7 版本上，Download Station 需要 Python2，安装该套件时，Package Center 会把它作为依赖项自动为你安装。
常见问题

Download Station 常见问题

能在手机上添加种子吗？
可以，有三种方式：粘贴 URL、粘贴磁力链接，或从设备中选择 .torrent 文件。添加之前，你还可以选择保存到哪个文件夹。
能在应用里更改 Download Station 的设置吗？
可以，包括 BitTorrent 监听端口、下载和上传速度上限、最大连接数、同时运行的任务数，以及保存位置。每次更改之后都会从 NAS 回读确认，因此 NAS 拒绝的值会如实报告为被拒绝。
下载限制为 0 是什么意思？
表示无限制。这是 Download Station 自己的约定，也正因如此，应用从不把无法读取的部分显示为零：把读取缺失伪装成零，是另一种错误的表述。
为什么看不到 Download Station 标签？
因为该 NAS 上没有安装这个套件。请从 Package Center 安装 Download Station，然后下拉刷新或重新打开应用，标签就会出现。
关闭应用后下载还会继续吗？
会。NAS 通过它自己的网络连接完成下载，手机只是遥控器。
