ส่วนหัว

ป้ายที่บอกว่าทำไม

การ์ดบนสุดแสดงรุ่นของคุณ ชื่อเล่นที่คุณตั้ง และเวอร์ชัน DSM พร้อมป้ายสถานะสุขภาพทางขวา ป้ายนี้ไม่ได้มีไว้ประดับ แตะแล้วจะแสดงรายการที่ใช้ตัดสิน

สิ่งที่ใช้ประเมิน

  • สุขภาพไดรฟ์ - สถานะ SMART ของทุกไดรฟ์
  • การใช้งานวอลุ่ม - สีเหลืองอำพันเมื่อเกิน 80% สีแดงเมื่อเกิน 90%
  • อุณหภูมิระบบ - สีเหลืองอำพันเมื่อเกิน 50°C สีแดงเมื่อเกิน 60°C
  • อุณหภูมิไดรฟ์ - สีเหลืองอำพันเมื่อเกิน 45°C สีแดงเมื่อเกิน 55°C
  • ประจุ UPS เมื่อมี UPS เชื่อมต่ออยู่
  • สถานะพัดลมและโหลดเฉลี่ยเทียบกับจำนวนคอร์

สิ่งที่จะไม่ทำ

จะไม่แสดงเครื่องหมายถูกว่าปกติทับค่าที่อ่านไม่ได้ หากแอปติดต่อ NAS ไม่ได้ หรือค่าบางอย่างกลับมาหายไป ส่วนหัวจะบอกเช่นนั้น คือกำลังโหลด หรือติดต่อไม่ได้ แทนที่จะเงียบ ๆ ถือว่าตัวเลขที่หายไปเป็นค่าที่ดี

ส่วนหัวก็ย่อได้ ส่วนหัวเป็นส่วนที่สูงที่สุดบนหน้าจอและย่อได้เหมือนทุกอย่าง เมื่อย่อแล้วก็ยังรายงานสถานะที่เป็นจริง คือสุขภาพที่อ่านได้ ว่ายังโหลดอยู่ หรือว่าติดต่อ NAS ไม่ได้

แถวสถิติด่วน

ห้าค่าที่ตอบคำถามว่า "ปกติดีไหม" โดยไม่ต้องเลื่อน

Tempอุณหภูมิระบบ เป็น °C หรือ °F ตามค่ากำหนดของคุณ สีเปลี่ยนเป็นเหลืองอำพันแล้วแดงเมื่ออุณหภูมิสูงขึ้น
Coolingโหมดความเร็วพัดลมที่ NAS ใช้อยู่จริง ได้แก่ Full Speed, Cool หรือ Quiet เปลี่ยนได้จากระบบ

Uptimeนับตั้งแต่ NAS บูตครั้งล่าสุดนานเท่าไร
Timeนาฬิกาของ NAS เองและแหล่งเวลาที่ซิงก์ด้วย NAS ที่นาฬิกาเพี้ยนทำให้รหัสสองขั้นตอนใช้ไม่ได้และเวลาในบันทึกโกหก

ทุกการ์ดที่วางได้

แต่ละการ์ดเป็นสรุปพร้อมทางเข้าสู่หน้าจอเต็ม เสนอเฉพาะการ์ดที่ NAS ของคุณรองรับ แอปถาม DSM ว่าทำอะไรได้ และไม่เคยแสดงการ์ดของแพ็กเกจที่ไม่ได้ติดตั้ง แตะชื่อการ์ดเพื่อเปิดหน้าจอที่การ์ดนั้นสรุป

การ์ดสิ่งที่แสดงเปิด
Systemเกจ CPU และ RAM พร้อมส่วนของผู้ใช้แยกออกมาSystem Health
Storageแต่ละวอลุ่มพร้อมชนิด RAID แถบการใช้งาน ใช้ไปและว่างVolumes & Pools
Networkดาวน์โหลดและอัปโหลดสดบนอินเทอร์เฟซหลัก พร้อมสปาร์กไลน์Network
Resource Monitorกราฟ CPU หน่วยความจำ และ I/O ดิสก์ แบบต่อเนื่องResources
Disk Healthสถานะ SMART และอุณหภูมิต่อไดรฟ์Disk Health
Firmwareเวอร์ชัน DSM และมีอัปเดตรออยู่หรือไม่System Health
Packagesติดตั้งและรันแพ็กเกจ DSM อยู่กี่รายการPackage Center
Dockerคอนเทนเนอร์ที่รันเทียบกับทั้งหมด และไม่กี่รายการแรกตามชื่อพร้อมเวลาทำงานDocker
Docker Projectsสแตก Compose และกี่สแตกที่ทำงานอยู่Projects
Virtual Machinesเครื่องเสมือนและสถานะพลังงานVirtual Machines
Surveillanceกล้องออนไลน์กี่ตัวจากทั้งหมดกล้อง
Photosขนาดคลังและจำนวนอัลบั้มPhotos
DriveSynology Drive และโฟลเดอร์ทีมDrive
สำรองข้อมูลงาน Hyper Backup พร้อมขนาดและรอบถัดไปสำรองข้อมูล
Active Backupอุปกรณ์และงานภายใต้ Active Backup for BusinessActive Backup
Download Stationการดาวน์โหลดที่กำลังทำงานพร้อมความเร็วและความคืบหน้าDownload Station
Task Schedulerงานที่เปิดใช้เทียบกับปิดใช้ และไม่กี่งานถัดไปที่จะรันTasks
UPS Statusรุ่น ประจุ เวลาทำงานโดยประมาณ และออนไลน์อยู่หรือไม่สถานะเปิดปิด
DDNS & External IPที่อยู่สาธารณะของคุณและชื่อโฮสต์ที่ NAS เผยแพร่ พร้อมปุ่มรีเฟรชDDNS
Log Centerรายการบันทึกระบบล่าสุด อ่านครั้งเดียวพร้อมปุ่มรีเฟรชบันทึก
โฟลเดอร์ที่แชร์ชื่อโฟลเดอร์ที่แชร์ วอลุ่ม และมี ACL หรือไม่โฟลเดอร์ที่แชร์
Active Connectionsใครลงชื่อเข้าใช้ จากที่ไหน ผ่านโปรโตคอลใดConnections
Servicesบริการ DSM ที่ทำงานเทียบกับที่หยุดServices
ผู้ใช้บัญชี DSM และสถานะผู้ใช้
File Browserทางเข้าสู่ File StationFile Station
USB Devices / External Storageอุปกรณ์ USB และ eSATA ที่เชื่อมต่อ พร้อมการถอดอย่างปลอดภัยExternal
VPNโปรไฟล์ไคลเอนต์ VPN ที่ตั้งค่าบน NASVPN
NotificationsDSM ตั้งค่าให้แจ้งเตือนคุณอย่างไร ผ่านพุช อีเมล SMSการตั้งค่าการแจ้งเตือน
Note Station / Office / Contactsสมุดบันทึก เอกสาร และสมุดที่อยู่ไฟล์

สองการ์ดในตาราง แต่ละใบสรุปแล้วเปิดหน้าจอเต็ม

การ์ดที่ไม่พาไปไหนจะบอกเหตุผล หากคุณซ่อนมุมมองย่อยแล้วแตะการ์ดที่เปิดมัน แอปจะบอกว่าถูกซ่อนและเสนอพาไปที่ Customize แทนที่จะพาไปหน้าจออื่นแบบเงียบ ๆ ซึ่งให้ความรู้สึกเหมือนลิงก์เสีย
ย่อสิ่งที่คุณไม่ได้อ่าน

การย่อ และสิ่งที่คงอยู่

แตะลูกศรบนการ์ดใดก็ได้เพื่อพับ การเลือกถูกจดจำต่อมุมมองและอยู่รอดหลังปิดแอป แดชบอร์ดจึงเปิดในสภาพที่คุณปล่อยไว้ ไม่รีเซ็ตทุกครั้งที่เปิด

  • การ์ดที่ย่อยังรายงาน แถวยังมีสัญลักษณ์สถานะ และแต่ละสัญลักษณ์มีรูปทรงของตัวเอง ได้แก่ เครื่องหมายถูกสำหรับปกติ สามเหลี่ยมสำหรับคำเตือน กากบาทสำหรับปัญหา ขีดสำหรับไม่ทราบ และนาฬิกาทรายขณะโหลด อ่านได้เหมือนกันสำหรับผู้ที่แยกสีแดงกับเขียวไม่ได้ และทุกสัญลักษณ์บอกชื่อตัวเองให้โปรแกรมอ่านหน้าจอ
  • ชื่อยาวจะเลื่อน ไม่ถูกตัด ชื่อที่กว้างเกินแถวที่ย่อจะเคลื่อนที่ แทนที่จะถูกตัดกลางคำ
  • ส่วนหัวก็พับได้ และยังรายงานสถานะจริงเมื่อพับ
Edit Dashboard

จัดลำดับ เอาออก รีเซ็ต

แตะดินสอที่มุมซ้ายบนของหน้าจอหลัก แถบเครื่องมือจะปรากฏ และทุกการ์ดจะมีที่จับลากและเครื่องหมายลบสีแดง

  1. ลากการ์ดด้วยที่จับเพื่อย้าย
  2. แตะเครื่องหมายลบสีแดงเพื่อเอาการ์ดออกจากแดชบอร์ด ไม่ได้ถูกลบ เพียงซ่อน
  3. Add เปิดรายการการ์ดที่คุณเอาออก เพื่อให้นำกลับมาได้
  4. Reset คืนชุดและลำดับเริ่มต้น
  5. Done ออกจากโหมดแก้ไข เลย์เอาต์ถูกบันทึกไปเรื่อย ๆ
การ์ดยังทำงานขณะแก้ไข แสดงข้อมูลสดในโหมดแก้ไข ไม่ใช่กลายเป็นกล่องสีเทา คุณจึงเห็นสิ่งที่กำลังย้าย การ์ดที่ยังดึงข้อมูลอยู่เมื่อคุณเข้าโหมดแก้ไขอาจดูว่างชั่วครู่ นั่นคือการดึงข้อมูล ไม่ใช่ตัวการ์ด
แยกตาม NAS ไม่ใช่ตามแอป แต่ละ NAS ที่เพิ่มเก็บเลย์เอาต์ของตัวเอง เซิร์ฟเวอร์สื่อกับเป้าหมายสำรองข้อมูลจึงไม่ต้องหน้าตาเหมือนกัน
ให้ทันสมัยอยู่เสมอ

รีเฟรชบ่อยแค่ไหน

ค่าที่อ่านสดจะดึงตามตัวตั้งเวลาที่คุณตั้งใน การตั้งค่า › ช่วงเวลาดึงข้อมูล ค่าระบบใช้ช่วงสั้น ส่วนพื้นที่จัดเก็บใช้ช่วงที่ยาวกว่า เพราะการใช้งานวอลุ่มไม่เปลี่ยนทุกห้าวินาที และการถามสิ้นเปลืองแบตเตอรี่

  • ดึงลงเพื่อรีเฟรชทุกอย่างพร้อมกัน ไม่ว่าช่วงเวลาจะตั้งไว้เท่าไร
  • บันทึกไม่ดึงอัตโนมัติ การ์ด Log Center อ่านครั้งเดียวและมีปุ่มรีเฟรช แทนที่จะอ่านซ้ำตามตัวตั้งเวลาไม่ว่าคุณจะดูอยู่หรือไม่
  • การดึงข้อมูลหยุดเมื่ออยู่เบื้องหลัง แอปไม่กินแบตเตอรี่ของคุณขณะที่ไม่ได้อยู่บนหน้าจอ
การเดินทางในแอป

ย้อนกลับคือย้อนกลับ ทุกที่

ทุกหน้าจอมีลูกศรย้อนกลับ และท่าทางหรือปุ่มย้อนกลับของอุปกรณ์ทำสิ่งเดียวกับที่ลูกศรชี้

  • ทุกที่ที่เลยหน้าจอหลักไป ย้อนกลับพาคุณขึ้นหนึ่งหน้า ที่เดียวกับที่ลูกศรย้อนกลับในแถบแอปไป
  • บนหน้าจอหลักเอง ท่าทางหรือปุ่มย้อนกลับจะถาม Exit Syno Manager? พร้อม Stay และ Exit app แทนที่จะปิดทันที
คำถามที่พบบ่อย

คำถามที่พบบ่อยเรื่องหน้าจอหลัก

ป้ายสถานะสุขภาพหมายถึงอะไรกันแน่
เป็นสรุปของทุกอย่างที่แอปอ่านได้ ได้แก่ สถานะ SMART ของไดรฟ์ การใช้งานวอลุ่ม อุณหภูมิระบบ ประจุ UPS สถานะพัดลม และโหลดเฉลี่ย แตะแล้วมันจะบอกว่าอันไหนเป็นต้นเหตุ ไม่ใช่แค่บอกว่าคำเตือน ป้ายที่อ่านบางอย่างไม่ได้จะบอกตรง ๆ แทนที่จะแสดงเครื่องหมายถูกว่าปกติทับการอ่านที่ล้มเหลว
เลือกการ์ดที่จะปรากฏได้ไหม
ได้ แตะดินสอเพื่อเข้า Edit Dashboard แล้วลากเพื่อจัดลำดับ แตะเครื่องหมายลบสีแดงเพื่อเอาออก Add เพื่อนำกลับมา Reset เพื่อค่าเริ่มต้น Done เมื่อเสร็จ การ์ดของบริการที่ NAS ไม่ได้รันจะไม่ถูกเสนอเลย
การ์ดที่ย่อไว้จะย่ออยู่ต่อไหม
ได้ ต่อมุมมอง และอยู่รอดหลังปิดแอป แถวที่ย่อยังมีสัญลักษณ์สถานะที่มีรูปทรงของตัวเอง จึงอ่านได้ถูกต้องโดยไม่ต้องพึ่งสี
ทำไมการ์ดที่ฉันต้องการจึงหายไป
อาจปิดอยู่ใน Edit Dashboard หรือ NAS ของคุณไม่ได้รันบริการเบื้องหลังนั้น ทุกการ์ดที่ NAS รองรับเปิดอยู่เป็นค่าเริ่มต้น ดังนั้นการ์ดที่หายไปโดยที่คุณไม่เคยแตะหมายความว่ายังไม่ได้ติดตั้งแพ็กเกจ
หน้าจอหลักต่างกันได้ต่อ NAS ไหม
ได้ เลย์เอาต์ ลำดับ และสถานะการย่อเก็บแยกตาม NAS ดังนั้นแต่ละเครื่องจึงเปิดตามที่คุณจัดไว้
จะเกิดอะไรขึ้นถ้ากดย้อนกลับบนหน้าจอหลัก
แอปจะถาม Exit Syno Manager? พร้อมปุ่ม Stay และ Exit app แทนที่จะปิดทันที หน้าจออื่นทั้งหมดมีลูกศรย้อนกลับ และท่าทางหรือปุ่มย้อนกลับก็แค่ย้อนหนึ่งหน้า
