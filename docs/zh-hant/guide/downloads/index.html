Download Station

送到 NAS，而不是手機

貼上連結或磁力連結，或選擇 .torrent，由 NAS 負責下載。查看進度、暫停與繼續，並變更它實際使用的設定。

Download Station

正在執行的項目

頂端有速度標題 - 所有工作的總下載與上傳速度 - 接著是各個工作。

  • 每個工作都會顯示名稱、狀態、進度列、目前速度與預估剩餘時間。
  • 可以對任何工作暫停、繼續或刪除。
  • 沒有執行中的項目時會明說 - 「沒有進行中的下載」，而不是留下一個你得自己解讀的空盒子。
  • 從標題點一下就能進入設定。
  • 兩代 API 都支援。Download Station 曾有兩個 API 版本；App 會使用你的 NAS 提供的那一種。
新增

三種新增方式

點選右下角的 +。

  1. 貼上連結或磁力連結。https:// 網址或 magnet:?xt= 連結都可以填在同一個欄位。
  2. 或選擇 .torrent 檔案，從裝置開啟檔案選擇器。
  3. 選擇儲存位置，使用儲存至，或保持不動，Download Station 會使用它自己的預設資料夾。
  4. 新增。工作就會出現在清單中。
手機只是遙控器。檔案由 NAS 透過自己的連線擷取，所以你可以關閉 App、離開家，下載仍會繼續。
下載設定

每一項設定，皆從你的 NAS 讀取

它有自己的子檢視，分組方式與 Download Station 相同。可編輯的值會附上勾號確認變更；唯讀的值則當作事實呈現。

群組設定功能
BitTorrent監聽連接埠Download Station 監聽的 TCP 連接埠。可編輯。
下載限制單位為 KB/s。0 代表無限制。可編輯。
上傳限制單位為 KB/s。0 代表無限制。可編輯。
最大連線對象數一個種子最多可連線的對象數量。
DHT是否已開啟分散式雜湊表，以及使用哪個連接埠。
FTP 與 HTTP下載限制針對一般 HTTP 與 FTP 下載的另一組速度上限。0 代表無限制。可編輯。
工作與排程同時工作數同時執行的下載數量 - 而且 App 會告訴你NAS 允許的上限，所以你不必猜天花板在哪裡。可編輯。
替代排程是否在特定時段套用不同的速度排程。
目的地預設資料夾工作未指定資料夾時，下載檔案存放的位置。若尚未設定，會顯示未設定，而不是留白。
執行於Download Station 套件本身安裝在哪個磁碟區。
eMule是否已啟用 eMule 服務。
每項變更都會回讀確認。App 會寫入你的值，再從 NAS 重新讀取該設定。如果 NAS 悄悄調整或拒絕了它，你會被告知 - 而不是讓你輸入的數字留在那裡，看起來好像已生效。
一件看似很小、其實很重要的事

為什麼未讀取的區段會標明，而不是填零

只會顯示你的 NAS 實際回報的設定。App 讀不到的區段會標示為未讀取，而不是畫成零。

這不是吹毛求疵。在這裡，0 代表無限制 - 所以讀取失敗卻顯示成 0，就等於告訴你下載沒有上限，但實際上是沒有人知道。可能有兩種意思的值，就該標示為未知，而這個畫面就是這麼做的。

找不到？

如果看不到 Download Station 分頁

  1. 確認套件已安裝。Download Station 不是 DSM 內建的一部分 - 它來自套件中心。你可以直接從這個 App 安裝。
  2. 重新整理 App 對你 NAS 的認知。功能清單是在連線時讀取的，所以連線後才安裝的套件還沒有分頁。下拉重新整理，或重新開啟 App。
  3. 確認它沒有被隱藏。檔案分頁的更多選單中有自訂檢視，子檢視可能在那裡被關閉了。
在多數 DSM 7 版本上，Download Station 需要 Python2，安裝套件時，套件中心會自動將它當作相依套件安裝。
常見問題

Download Station 常見問題

可以用手機新增種子下載嗎？
可以，有三種方式：貼上網址、貼上磁力連結，或從裝置選擇 .torrent 檔案。新增前也可以選擇要儲存到哪個資料夾。
可以在 App 裡變更 Download Station 的設定嗎？
可以 - BitTorrent 監聽連接埠、下載與上傳速度上限、最大連線對象數、同時執行的工作數量，以及目的地資料夾。每項變更之後都會從 NAS 回讀確認，因此被 NAS 拒絕的值會如實回報遭拒絕。
下載限制為 0 是什麼意思？
代表無限制。這是 Download Station 本身的慣例，也是 App 絕不會把讀不到的區段顯示成零的原因 - 把讀不到的結果假裝成零，就成了另一個錯誤的說法。
為什麼看不到 Download Station 分頁？
因為那台 NAS 沒有安裝該套件。請先從套件中心安裝 Download Station，然後下拉重新整理或重新開啟 App，分頁就會出現。
關閉 App 後下載還會繼續嗎？
會。NAS 透過自己的連線負責下載。手機只是遙控器。
