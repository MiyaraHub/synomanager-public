DS finder の先へ、1つのアプリで

DS finder は、NAS のセットアップと見守りのための Synology 純正アプリです。Syno Manager は、セットアップ後の毎日のために作られた独立アプリで、NAS が動かしているすべてを確認し、アプリを切り替えることなく操作できます。

比較表

2つのアプリ、2つの役割

優劣を競う表ではありません。DS finder には、新しい NAS のセットアップや DSM 純正の Push Service からの通知受信など、Syno Manager にはできないことがあります。この表は、それぞれの適した使いどころを示しています。

DS finder の機能は Synology のナレッジセンターの記載に基づいています。Synology はアプリを随時変更する場合があるため、最新の内容は Synology のドキュメントをご確認ください。

Syno Manager が加えるもの

NAS のすべてを1つの画面で

原因まで示すヘルスバッジ

単なる「警告」ではなく、どのドライブか、どのボリュームか、何度なのかまでわかります。

状態の確認だけでなく、操作も

コンテナ、パッケージ、バックアップ、サービス、タスク、ダウンロード、ファンモードを、スマートフォンから操作できます。

外出先でも使えます

写真、カメラのライブビュー、ファイルのダウンロードを QuickConnect 経由で利用できます。ポート開放は不要です。

ウィジェットとショートカット

12種類のホーム画面ウィジェット、synomanager:// リンク、Mac での Siri とショートカットに対応しています。

デバイス上のアシスタント

NAS についてふだんの言葉で質問できます。モデルはデバイス上で動作し、読み取りしか行いません。

スマートフォン、タブレット、デスクトップに対応

Android、iPhone、iPad、Mac、Windows に対応。プラットフォームごとに $9.99 の買い切りで、サブスクリプションはありません。

DS finder と一緒にお試しください

買い切り $9.99。広告なし、サブスクリプションなし、アプリ内課金なし。DSM 7.0 以降の Synology NAS が必要です。
