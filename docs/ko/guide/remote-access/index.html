집 밖에서

같은 앱, 다른 경로

NAS 바로 옆에 있든 지구 반대편에 있든 Syno Manager는 똑같이 동작합니다. 달라지는 것은 연결이 도달하는 방식이며, 경로마다 알아 둘 만한 장단점이 있습니다.

경로설정속도외부에 노출되는 것이 있나요?
QuickConnectDSM에서 켜고 ID를 입력하면 됩니다. 공유기 설정은 필요 없습니다.비교적 느림 - 트래픽이 Synology의 중계 서버를 거칩니다.없음. 내 쪽에서 열어 두는 포트가 없습니다.
사용자 도메인 / DDNS내 주소를 가리키는 호스트 이름과 공유기의 포트 포워딩이 필요합니다.직접 연결이므로 업로드 속도가 허용하는 만큼 빠릅니다.예 - DSM 포트가 인터넷에서 접근 가능해집니다.

잘 모르겠다면 QuickConnect를 쓰세요. 공유기 지식이 필요 없고 열어 두는 것도 없으며, 앱의 모든 기능이 이 경로에서 동작합니다.
원격에서 동작하는 기능

모든 기능, 단 두 가지 참고 사항이 있습니다

밖에 있다고 해서 앱의 기능이 줄어들지는 않습니다. 잠깐 생각해 볼 것은 카메라 실시간 보기와 꺼져 있는 NAS를 깨우는 일, 이 두 가지입니다.

기능집 밖에서
모니터링 - 시스템, 스토리지, 네트워크, 상태어느 경로에서든 동작합니다.
Docker, 패키지, 서비스, 작업, 사용자어느 경로에서든 동작합니다.
Synology Photos - 썸네일과 원본 이미지중계를 포함해 동작합니다.
File Station과 Drive 다운로드중계를 포함해 동작합니다.
백업 - 상태 확인과 지금 실행어느 경로에서든 동작합니다.
NAS를 통해 다른 기기 깨우기NAS 자체가 켜져 있다면 동작합니다.
카메라 실시간 보기DSM 포트를 통해 카메라 실시간 보기 터널링을 켜세요. 켜지 않으면 실시간 보기가 포트 554의 RTSP를 필요로 하는데, 외부에서는 대개 접근할 수 없습니다. 실시간 보기 연결 방식을 참고하세요.
꺼져 있는 NAS 자체 깨우기VPN 또는 공유기의 Wake-on-LAN 포워딩이 필요합니다. QuickConnect로는 꺼져 있는 NAS에 접근할 수 없습니다. Wake-on-LAN을 참고하세요.
QuickConnect

설정 방법

  1. DSM에서: 제어판 › 외부 액세스 › QuickConnect로 이동합니다. 기능을 켜고 QuickConnect ID를 메모해 두세요.
  2. 앱에서: NAS를 추가하고 연결 유형을 QuickConnect로 바꿉니다.
  3. 호스트와 포트가 아니라 ID를 입력합니다.
  4. DSM 자격 증명을 입력하고, 계정에서 2FA를 사용한다면 그것도 입력합니다.
  5. 저장 & 연결.
다소 느리다는 점은 감안하세요. 중계 때문에 구간이 하나 늘고 Synology가 속도를 제한하므로, 사진 라이브러리가 집에서처럼 부드럽게 스크롤되지는 않습니다. 모든 기능은 그대로 동작하며, 달라지는 것은 지연 시간일 뿐 기능이 아닙니다.
따라 해 볼 만한 방법

같은 NAS를 두 번 추가하기

로컬 IP로 하나, QuickConnect로 하나를 만드세요. 구분할 수 있도록 “NAS (집)”, “NAS (외출)”처럼 이름을 붙이면 좋습니다.

  • 집에서는 직접 연결 항목을 쓰세요. 중계 없이 최고 속도로, 썸네일도 즉시 표시됩니다.
  • 밖에서는 QuickConnect 항목으로 전환하세요.
  • 레이아웃이 따로 저장되므로 외출용 항목은 모바일 데이터로 실제로 확인하는 몇 개의 카드만 남기고 간소하게 만들 수 있습니다.
  • 전환은 한 번의 탭이면 되며 기기 목록에서 할 수 있습니다.

시작 동작을 마지막으로 사용한 NAS로 설정하면 앱이 마지막에 쓰던 NAS를 그대로 유지합니다.

원격 접속 FAQ

NAS에 원격으로 접속하려면 포트 포워딩을 해야 하나요?
아니요. QuickConnect는 공유기 설정 없이 연결을 중계하며, VPN도 사용할 수 있습니다. 포트 포워딩은 인터넷에서 직접 연결하는 경로가 꼭 필요할 때만 필요합니다.
QuickConnect로도 사진과 카메라 실시간 보기가 되나요?
네. 썸네일, 원본 이미지, 카메라 실시간 보기, File Station과 Drive 다운로드가 모두 중계를 포함해 현재 사용 중인 경로로 전달됩니다. 카메라 실시간 보기는 DSM 포트 터널 설정을 켜야 합니다.
NAS를 두 번 등록해도 되나요?
좋은 방법입니다. 집에서 쓸 로컬 IP 항목 하나와 밖에서 쓸 QuickConnect 항목 하나를 만들면 레이아웃이 따로 저장되고 한 번의 탭으로 전환할 수 있습니다.
QuickConnect는 안전한가요?
HTTPS를 사용하면 연결이 종단 간 암호화되며, 중계 서버는 데이터를 보관하지 않고 트래픽만 전달합니다. DSM 자격 증명과 2단계 인증도 그대로 적용됩니다.
모바일 데이터에서 로컬 IP 항목이 동작하지 않는 이유는 무엇인가요?
192.168.x.x 같은 사설 주소는 내 네트워크 안에서만 존재하기 때문입니다. QuickConnect 항목이나 도메인을 사용하거나, 먼저 VPN에 연결하세요.
