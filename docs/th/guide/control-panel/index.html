ผู้ใช้

บัญชี DSM

ทุกบัญชีบน NAS พร้อมชื่อที่แสดง คำอธิบาย และอีเมลหากตั้งไว้ ชิปหมดอายุระบุบัญชีที่ DSM ปิดใช้งาน

สิ่งที่ทำได้

  • เพิ่มผู้ใช้ด้วยรายละเอียดที่ DSM ต้องการ
  • แก้ไขบัญชีที่มีอยู่
  • เปลี่ยนรหัสผ่าน
  • ลบบัญชีที่คุณสร้างเอง
บัญชีระบบลบไม่ได้ admin, guest และบัญชีบริการที่ DSM สร้างให้แพ็กเกจของตัวเองจะถูกตรวจพบและป้องกันไว้ การลบบัญชีเหล่านั้นทำให้ NAS เสียหายในแบบที่แก้กลับได้ยาก และมือถือไม่ใช่ที่ที่ควรไปรู้เรื่องนี้

สองบัญชีในภาพหน้าจอนี้ถูกเบลอไว้ เพราะเป็นชื่อและที่อยู่ของบุคคลจริง

Task Scheduler

อะไรถูกตั้งเวลาไว้ และอะไรจะรันต่อไป

ทุกงานที่ DSM มี เปิดใช้อยู่หรือไม่ ทำอะไร และจะทำงานครั้งถัดไปเมื่อใด

  • ชื่องานและประเภท เช่น งาน Hyper Backup สคริปต์ที่ผู้ใช้กำหนด การล้างถังขยะ โดยแต่ละงานระบุว่าเป็นประเภทใด
  • ทำอะไรจริง ๆ งานสคริปต์แสดงคำสั่งที่รัน งานสำรองข้อมูลแสดงคำอธิบาย
  • รอบถัดไป เป็นวันที่และเวลา
  • สวิตช์ต่องานเพื่อเปิดหรือปิดโดยไม่ต้องเปิด DSM
  • Run Now บนงานที่ DSM อนุญาตให้สั่งเริ่มได้ตามต้องการ
Run Now รันทันที สคริปต์ตามกำหนดเวลาที่คาดว่าจะรันตอนตีสามบน NAS ที่ว่าง จะทำงานต่างออกไปตอนหกโมงเย็นขณะกำลังคัดลอกไฟล์ ปุ่มทำตามที่บอกไว้
สถานะเปิดปิด

UPS

ปรากฏเมื่อมี UPS เชื่อมต่ออยู่ หนึ่งการ์ด รวมทุกอย่างไว้

ที่แสดงความหมาย
ผู้ผลิตและรุ่นตามที่ UPS รายงานตัวเอง
สถานะออนไลน์ใช้ไฟหลัก หรือใช้แบตเตอรี่
ประจุเปอร์เซ็นต์และแถบ สีเหลืองอำพันต่ำกว่า 50% สีแดงต่ำกว่า 20%
โหมดNAS สื่อสารกับ UPS อย่างไร ผ่าน USB หรือผ่านเครือข่าย
เวลาทำงานUPS ประเมินว่ารับโหลดได้นานเท่าไร
เปิดใช้งานเปิดการรองรับ UPS ใน DSM หรือไม่
ประจุส่งผลต่อป้ายสถานะสุขภาพ UPS ที่กำลังคายประจุจะปรากฏบนหน้าจอหลักโดยไม่ต้องเปิดแท็บนี้ ซึ่งเป็นประเด็นสำคัญ เพราะเมื่อคุณนึกจะไปตรวจ อาจเหลือเวลาไม่มาก
การตั้งค่า

ค่ากำหนดของแอปเอง

มุมมองย่อยที่สี่คือการตั้งค่า ฝังไว้ที่นี่เพื่อให้คุณเปลี่ยนช่วงเวลาดึงข้อมูลหรือสีเน้นได้โดยไม่ต้องออกจากแท็บ เป็นหน้าจอเดียวกับที่ไอคอนเฟืองเปิด

คำถามที่พบบ่อย

คำถามที่พบบ่อยเรื่องแผงควบคุม

เพิ่มหรือแก้ไขผู้ใช้ DSM จากแอปได้ไหม
ได้ เพิ่มผู้ใช้ แก้ไขรายละเอียด เปลี่ยนรหัสผ่าน หรือลบบัญชี บัญชีระบบ ได้แก่ admin, guest และบัญชีบริการที่ DSM สร้างขึ้น จะถูกตรวจพบและป้องกันไม่ให้ลบ
รันงานตามกำหนดเวลาด้วยตัวเองได้ไหม
ได้ สำหรับงานที่ DSM อนุญาตให้สั่งเริ่ม และยังเปิดหรือปิดงานใดก็ได้โดยไม่ต้องเปิด DSM
หน้าจอ UPS แสดงอะไร
รุ่นของ UPS ว่าใช้ไฟหลักหรือแบตเตอรี่ ประจุเป็นเปอร์เซ็นต์และแถบ วิธีเชื่อมต่อ เวลาทำงานที่เหลือโดยประมาณ และว่าเปิดการรองรับ UPS บน NAS หรือไม่
เปลี่ยนนโยบายการปิดเครื่องเมื่อใช้แบตเตอรี่ได้ไหม
ไม่ได้ แอปรายงานสถานะ UPS นโยบายตั้งใน DSM ภายใต้ฮาร์ดแวร์และพลังงาน ซึ่งอธิบายผลของการตั้งค่าไว้ชัดเจน
ทำไมมุมมองย่อย Power จึงหายไป
เพราะไม่มี UPS เชื่อมต่ออยู่ หรือปิดการรองรับ UPS ใน DSM แอปซ่อนหน้าจอของฮาร์ดแวร์ที่ไม่มีอยู่
