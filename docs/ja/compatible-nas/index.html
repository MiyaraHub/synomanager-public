対応状況

DSM 7 が動いていれば、使えます

アプリはモデル一覧を使わないため、確認すべき一覧はありません。接続時に NAS へ何ができるかを問い合わせ、その答えに合わせて自らを構成します。

対応表がない理由

決め打ちの一覧ではなく、動的な検出

モデル別の対応表は、Synology が新モデルを出した日に不正確になり、そのモデルにパッケージが追加された日にまた不正確になります。

  • アプリは接続時に DSM の API カタログを問い合わせ、その結果を保持します。このカタログこそが、NAS にできることの唯一の正解です。
  • 画面が表示されるのは、その元になる API を NAS が報告したときです。Surveillance Station をインストールするとカメラの画面が現れ、アンインストールすると消えます。
  • モデル名から何かを推測することはありません。同じモデルでもパッケージが違えば、アプリの内容も変わります。それが正しい動作です。
  • NAS が報告しなかった値は「未取得」と表示し、それらしい既定値で埋めることはありません。

実用面で言えば、DSM 自身の Web インターフェースがスマートフォンのブラウザで動作し、お使いの DSM アカウントでそこに何かが見えるなら、Syno Manager でも見えます。

よくある質問

対応状況 FAQ

Syno Manager はどの Synology モデルに対応していますか？
DSM 7.0 以降を実行している Synology NAS であれば、拡張ユニットの有無にかかわらず、DiskStation、RackStation、FlashStation のすべてが対象です。接続時にアプリが NAS へ何ができるかを問い合わせるため、モデル別の一覧はありません。
DSM 6 でも動作しますか？
いいえ。DSM 7.0 以降が必要です。DSM 6 は API のバージョンや認証の挙動が異なります。
小型の2ベイ NAS でも動作しますか？
はい。表示される画面が少ないのは、実行しているサービスが少ないためで、非対応だからではありません。実行中のものはすべて完全に表示されます。
拡張ユニットに対応していますか？
はい。拡張ユニットのドライブは、内蔵ドライブと並んで表示されます。
ベータ版の DSM を NAS で使っている場合はどうなりますか？
アプリはバージョンを決め打ちせず API カタログを読み取るため、たいていは動作します。ベータ版で API が変更された場合は、ある値が「未取得」と報告されることがありますが、誤った数値を表示するのではなく、その旨をきちんとお伝えします。
