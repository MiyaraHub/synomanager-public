แอปเดียวกัน คนละเส้นทาง

Syno Manager ทำงานเหมือนกันไม่ว่าคุณจะอยู่ข้าง NAS หรืออยู่อีกฟากโลก สิ่งที่เปลี่ยนคือวิธีที่การเชื่อมต่อเดินทางไปถึง และแต่ละเส้นทางมีข้อแลกเปลี่ยนที่ควรรู้

สามเส้นทาง

เลือกอันที่เหมาะกับคุณ

เส้นทางการตั้งค่าความเร็วเปิดเผยอะไรไหม
QuickConnectเปิดใช้ใน DSM แล้วกรอก ID ไม่ต้องแตะเราเตอร์ช้ากว่า เพราะทราฟฟิกผ่านรีเลย์ของ Synologyไม่มี ไม่มีพอร์ตเปิดทางฝั่งคุณ
โดเมนของคุณเอง / DDNSชื่อโฮสต์ที่ชี้ไปยังที่อยู่ของคุณ พร้อมการฟอร์เวิร์ดพอร์ตที่เราเตอร์ตรง จึงเร็วเท่าที่ความเร็วอัปโหลดของคุณให้ได้มี พอร์ต DSM เข้าถึงได้จากอินเทอร์เน็ต
VPNเซิร์ฟเวอร์ VPN บนเราเตอร์หรือ NAS และไคลเอนต์บนโทรศัพท์ตรงเมื่อเชื่อมต่อแล้วเฉพาะพอร์ต VPN ส่วนอื่นยังเป็นส่วนตัว
หากไม่แน่ใจ ให้ใช้ QuickConnect เป็นตัวเลือกที่ไม่ต้องมีความรู้เรื่องเราเตอร์และไม่เปิดอะไรเลย และทุกฟีเจอร์ในแอปใช้งานได้ผ่านมัน
สิ่งที่ใช้ได้จากระยะไกล

ทุกอย่าง พร้อมเชิงอรรถสองข้อ

แอปไม่ได้ลดฟีเจอร์เมื่อคุณอยู่นอกบ้าน มีสองเรื่องที่ต้องคิดสักนิด คือภาพสดจากกล้อง และการปลุก NAS ที่ปิดอยู่

ฟีเจอร์นอกบ้าน
การตรวจสอบ - ระบบ พื้นที่จัดเก็บ เครือข่าย สุขภาพใช้ได้กับทุกเส้นทาง
Docker แพ็กเกจ บริการ งานตามกำหนด ผู้ใช้ใช้ได้กับทุกเส้นทาง
Synology Photos - ภาพขนาดย่อและรูปเต็มใช้ได้ รวมถึงผ่านรีเลย์
การดาวน์โหลดจาก File Station และ Driveใช้ได้ รวมถึงผ่านรีเลย์
การสำรองข้อมูล - สถานะและเรียกใช้ทันทีใช้ได้กับทุกเส้นทาง
ปลุกอุปกรณ์อื่นผ่าน NASใช้ได้ ตราบใดที่ตัว NAS เปิดอยู่
ภาพสดจากกล้องเปิด ส่งภาพสดจากกล้องผ่านพอร์ต DSM หากไม่เปิด ภาพสดจะต้องใช้ RTSP พอร์ต 554 ซึ่งมักเข้าถึงจากภายนอกไม่ได้ ดูวิธีที่ภาพสดเชื่อมต่อ
การปลุก NAS เองขณะที่ปิดอยู่ต้องใช้ VPN หรือการฟอร์เวิร์ด Wake-on-LAN ที่เราเตอร์ QuickConnect เข้าถึง NAS ที่ปิดอยู่ไม่ได้ ดู Wake-on-LAN
QuickConnect

การตั้งค่า

  1. ใน DSM: แผงควบคุม › การเข้าถึงภายนอก › QuickConnect เปิดใช้งานแล้วจด QuickConnect ID ไว้
  2. ในแอป: เพิ่ม NAS แล้วสลับประเภทการเชื่อมต่อเป็น QuickConnect
  3. กรอก ID ไม่ใช่โฮสต์และพอร์ต
  4. ข้อมูลเข้าสู่ระบบ DSM ของคุณ และ 2FA หากบัญชีใช้อยู่
  5. บันทึก & เชื่อมต่อ
คาดไว้ได้เลยว่าจะช้ากว่า รีเลย์เพิ่มอีกหนึ่งช่วง และ Synology จำกัดอัตราไว้ คลังรูปจึงเลื่อนไม่ลื่นเท่าที่บ้าน ทุกอย่างยังใช้งานได้ เป็นเรื่องของความหน่วง ไม่ใช่ความสามารถ
วิธีที่ควรทำตาม

เพิ่ม NAS เครื่องเดียวกันสองครั้ง

รายการหนึ่งใช้IP ในเครือข่าย อีกรายการใช้ QuickConnect ตั้งชื่อให้แยกออก เช่น “NAS (บ้าน)” และ “NAS (นอกบ้าน)”

  • เมื่ออยู่บ้าน ใช้รายการที่เชื่อมต่อตรง ไม่ผ่านรีเลย์ เร็วเต็มที่ ภาพขนาดย่อขึ้นทันที
  • เมื่ออยู่นอกบ้าน สลับไปใช้รายการ QuickConnect
  • เลย์เอาต์แยกกัน คุณจึงตัดรายการนอกบ้านให้เหลือเฉพาะการ์ดที่คุณดูจริงบนเน็ตมือถือ
  • สลับได้ในแตะเดียว จากรายการอุปกรณ์

ตั้งพฤติกรรมการเปิดแอปเป็น NAS ที่ใช้ล่าสุด แอปก็จะอยู่กับเครื่องที่คุณใช้ค้างไว้

คำถามที่พบบ่อย

คำถามที่พบบ่อยเกี่ยวกับการเข้าถึงระยะไกล

ต้องเปิดพอร์ตฟอร์เวิร์ดเพื่อใช้ NAS จากระยะไกลไหม
ไม่ต้อง QuickConnect ส่งต่อการเชื่อมต่อโดยไม่ต้องตั้งค่าเราเตอร์ และ VPN ก็ใช้ได้เช่นกัน จำเป็นต้องฟอร์เวิร์ดพอร์ตเฉพาะเมื่อคุณต้องการเส้นทางตรงจากอินเทอร์เน็ตเท่านั้น
รูปภาพและภาพสดจากกล้องใช้ได้ผ่าน QuickConnect ไหม
ได้ ภาพขนาดย่อ รูปเต็ม ภาพสดจากกล้อง และการดาวน์โหลดจาก File Station และ Drive ทั้งหมดไปตามเส้นทางที่ใช้งานอยู่ รวมถึงรีเลย์ ภาพสดจากกล้องต้องเปิดสวิตช์อุโมงค์พอร์ต DSM
ควรเพิ่ม NAS เครื่องเดียวกันสองครั้งไหม
เป็นวิธีที่ดี รายการหนึ่งใช้ IP ในเครือข่ายสำหรับที่บ้าน อีกรายการใช้ QuickConnect สำหรับนอกบ้าน เลย์เอาต์แยกกันและสลับได้ในแตะเดียว
QuickConnect ปลอดภัยไหม
การเชื่อมต่อถูกเข้ารหัสตลอดเส้นทางเมื่อคุณใช้ HTTPS และรีเลย์เพียงส่งต่อทราฟฟิกโดยไม่เก็บข้อมูลของคุณ ข้อมูลเข้าสู่ระบบ DSM และการยืนยันตัวตนสองขั้นตอนยังคงใช้อยู่
ทำไมรายการที่ใช้ IP ในเครือข่ายใช้ไม่ได้บนเน็ตมือถือ
เพราะที่อยู่ส่วนตัวอย่าง 192.168.x.x มีอยู่เฉพาะในเครือข่ายของคุณเอง ให้ใช้รายการ QuickConnect โดเมน หรือเชื่อมต่อ VPN ก่อน
