สามหน้าพาคุณจากการติดตั้งใหม่ไปสู่ NAS ที่เห็นได้จากทุกที่

🚀

เริ่มต้นใช้งาน

สิ่งที่ต้องมี วิธีเพิ่ม NAS ของคุณ พอร์ตและ HTTPS การยืนยันตัวตนสองขั้นตอน และวิธีแก้เมื่อเชื่อมต่อไม่ได้
🏠

หน้าจอหลัก

ส่วนหัวสถานะสุขภาพ แถวสถิติด่วน และตารางการ์ด และวิธีจัดลำดับ ย่อ และซ่อนทุกอย่าง
🌐

นอกบ้าน

QuickConnect โดเมนที่กำหนดเอง หรือ VPN และฟีเจอร์ใดทำงานผ่านเส้นทางใด
ทุกหน้าจอ

แท็บ ตามลำดับ

แถบด้านล่างมีได้ถึงเก้าแท็บบวก More แต่ละแท็บคือกลุ่มของมุมมองย่อยที่จัดลำดับหรือซ่อนได้

🧠

System

System Health, Resources และ Logs เกจ โหลดเฉลี่ย I/O ดิสก์ ประวัติอุณหภูมิ โหมดพัดลม ระบุเครื่อง อัปเดต DSM และพลังงาน
💾

Storage

Volumes & Pools, Disk Health และ External ชนิด RAID พื้นที่ว่าง SMART ต่อไดรฟ์ Quick SMART Test และการถอดอย่างปลอดภัย
📡

Network

Throughput, Connections, Services, VPN และ DDNS พร้อมที่อยู่สาธารณะของคุณ
📁

ไฟล์

File Station การคัดลอกและย้ายบน NAS เอง Shared Folders, Note Station, Synology Office และ Contacts
⬇️

Download Station

เพิ่มด้วยลิงก์ แมกเน็ต หรือ .torrent ควบคุมงานที่กำลังทำงาน และเปลี่ยนการตั้งค่าที่ NAS ของคุณรายงาน
📦

แอป

Package Center, Docker, Docker Projects และ Virtual Machine Manager
📷

สื่อ

Synology Photos พร้อมตัวดูเต็มจอที่ปัดได้ Synology Drive และภาพสดจาก Surveillance Station
🔄

สำรองข้อมูล

งาน Hyper Backup พร้อมขนาดปลายทางจริง และอุปกรณ์กับปริมาณงานของ Active Backup for Business
🔧

แผงควบคุม

ผู้ใช้ Task Scheduler UPS และ Settings ของแอปเอง
✨

ผู้ช่วย

ถามเรื่อง NAS ของคุณด้วยภาษาธรรมดา รับผลสถานะสุขภาพกลับมา และให้คะแนนคำตอบ ผู้ช่วยเรียนรู้บนอุปกรณ์ของคุณเท่านั้น

การตั้งค่า

ทุกค่ากำหนด ได้แก่ ธีมและสีเน้น การ์ดแดชบอร์ด แถบด้านล่าง 28 ภาษา พฤติกรรมตอนเปิดแอป มุมมองการ์ด การดึงข้อมูล หน่วยอุณหภูมิ การ์ดช่วยเหลือ และการสำรองข้อมูล
🖥️

การใช้ NAS หลายเครื่อง

เพิ่ม เปลี่ยนชื่อ จัดลำดับ และสลับ แต่ละเครื่องเก็บข้อมูลรับรอง เลย์เอาต์ และการตั้งค่าของตัวเอง
🔌

Wake-on-LAN

ปลุก NAS หรือเครื่องอื่นผ่านมัน และสิ่งใดบ้างที่ใช้ได้จากนอกเครือข่ายของคุณ
📱

วิดเจ็ตหน้าจอหลัก

วิดเจ็ตสิบสองแบบ แต่ละแบบมีตัวอย่างและเวลาประทับ เพื่อให้ค่าที่ค้างเก่าไม่ดูเหมือนค่าปัจจุบัน
🔗

ทางลัด & ลิงก์

รูปแบบ URL synomanager:// ทางลัดบนตัวเปิดแอป และ Siri กับ Shortcuts แบบเนทีฟบน Mac
🎨

การปรับแต่งแอป

จัดลำดับและซ่อนการ์ด แท็บ และมุมมองย่อย ย่อสิ่งที่คุณไม่ได้อ่าน และปิดการ์ดช่วยเหลือ
💾

สำรอง & กู้คืนการตั้งค่า

ส่งออกการตั้งค่าของแอปเองเป็นไฟล์ แล้วกู้คืนบนมือถือเครื่องใหม่
