การปรับแต่ง

สี่ชั้น จดจำทั้งหมด

การ์ด แท็บ มุมมองย่อย และสถานะการย่อ ทุกอย่างจัดลำดับใหม่หรือปิดได้ ทุกอย่างถูกจดจำระหว่างการเปิดแอป และทุกอย่างรีเซ็ตได้

แผนที่

แต่ละอย่างอยู่ที่ไหน

ชั้นที่ไหนการจัดเก็บ
การ์ดแดชบอร์ดไอคอนดินสอบนหน้าจอหลัก หรือ การตั้งค่า › หมวดหมู่แดชบอร์ดแยกตาม NAS
แถบนำทางด้านล่างการตั้งค่า › ปรับแต่งการนำทางทั้งแอป
มุมมองย่อยในแท็บเมนู ⋮ › Customize views ของแท็บแยกตาม NAS
ย่อหรือขยายลูกศรบนการ์ดใดก็ได้ โดยค่าเริ่มต้นอยู่ใน การตั้งค่า › มุมมองการ์ดเริ่มต้นแยกตาม NAS
การ์ดช่วยเหลือปิดที่การ์ด กู้คืนใน การตั้งค่า › ช่วยเหลือทั้งแอป
ภายในแท็บ

Customize views

ทุกแท็บที่มีมากกว่าหนึ่งส่วนมีเมนู ⋮ ที่มุมขวาบน และมี Customize views อยู่ในนั้น

  • ตัวอย่างสดของแถวมุมมองย่อยอยู่ด้านบน คุณจึงเห็นผลลัพธ์ก่อนบันทึก
  • ช่องทำเครื่องหมายต่อมุมมองเพื่อแสดงหรือซ่อน
  • ที่จับลากเพื่อจัดลำดับ - อันแรกในรายการคืออันที่แท็บเปิดขึ้นมา
  • ต้องเหลืออย่างน้อยหนึ่งมุมมองที่มองเห็นได้ ดังนั้นจะทำให้แท็บว่างเปล่าไม่ได้
  • Reset คืนค่าเริ่มต้น Save ใช้การเปลี่ยนแปลง
นี่คือวิธีทำให้แท็บเปิดที่ที่คุณต้องการ หากอยากให้แท็บ System ไปที่ Logs เสมอ ให้ลาก Logs ขึ้นบนสุด แท็บจะเปิดที่นั่นตั้งแต่นั้น
หลักการออกแบบ

สิ่งที่คุณซ่อนจะไม่กลายเป็นทางตัน

การซ่อนของสร้างกับดัก คือการ์ดแดชบอร์ดที่หน้าจอของมันถูกซ่อนอยู่ แตะแล้วจะไปไหน

เมื่อก่อนมันไปที่ส่วนแรกของแท็บนั้นไม่ว่าจะเป็นอะไร ดังนั้นการซ่อน Disk Health แล้วแตะการ์ด Disk Health จะไปจบที่ Volumes & Pools โดยไม่มีคำอธิบาย ซึ่งดูเหมือนแอปเสีย

ตอนนี้การ์ดบอกคุณ หากมุมมองถูกซ่อนอยู่ มันบอกเช่นนั้นและมีปุ่ม Customize พาคุณไปที่การตั้งค่าที่จะนำมันกลับมา หาก NAS ของคุณไม่ได้รันบริการนั้นเลย มันจะบอกอย่างนั้นแทน ซึ่งเป็นปัญหาคนละอย่างที่มีคำตอบคนละแบบ และแอปไม่สับสนสองอย่างนี้

เริ่มใหม่

คืนทุกอย่างกลับมา

  • แดชบอร์ด: Reset ในแถบเครื่องมือแก้ไขคืนค่าการ์ดและลำดับเริ่มต้น
  • แถบด้านล่าง: Reset ใน Customize Navigation
  • มุมมองย่อย: Reset ใน Customize views ของแต่ละแท็บ
  • การ์ดช่วยเหลือ: Restore all ในการตั้งค่า › ช่วยเหลือ หรือกู้คืนทีละใบ
  • ทุกอย่างบนมือถือเครื่องใหม่: ส่งออกและกู้คืนการตั้งค่าของแอป
การ์ดใหม่มาพร้อมเปิดใช้งาน เมื่อเวอร์ชันใหม่เพิ่มการ์ดที่ NAS ของคุณรองรับ การ์ดนั้นจะปรากฏเลย ไม่ต้องรอให้ไปค้นพบในหน้าการตั้งค่า Customize คือที่ที่คุณปิดสิ่งต่าง ๆ ไม่ใช่ที่ที่ต้องไปหาว่ามีอะไรบ้าง
คำถามที่พบบ่อย

คำถามที่พบบ่อยเรื่องการปรับแต่ง

จัดเรียงอะไรได้บ้าง
การ์ดแดชบอร์ดใดจะปรากฏและเรียงอย่างไร แท็บใดอยู่ในแถบด้านล่างและเรียงอย่างไร มุมมองย่อยใดปรากฏในแต่ละแท็บและเรียงอย่างไร และแต่ละการ์ดขยายหรือย่ออยู่ ทั้งสี่อย่างถูกจดจำไว้
ซ่อนส่วนหนึ่งในแท็บได้อย่างไร
เปิดแท็บ แตะเมนูสามจุดที่มุมขวาบน แล้วเลือก Customize views เอาเครื่องหมายถูกออกจากสิ่งที่ไม่ต้องการ แล้วลากที่เหลือเรียงลำดับ ต้องเหลืออย่างน้อยหนึ่งมุมมองที่มองเห็นได้
ฉันซ่อนบางอย่างแล้วตอนนี้การ์ดไม่ทำอะไรเลย
มันบอกคุณว่ามุมมองถูกซ่อนอยู่ และมีปุ่ม Customize พาคุณไปที่การตั้งค่า มันจะไม่เปิดหน้าจออื่นแบบเงียบ ๆ
เลย์เอาต์ของฉันเก็บไว้บน NAS หรือบนมือถือ
บนมือถือ แยกตาม NAS หากต้องการย้ายไปมือถือเครื่องใหม่ ให้ใช้สำรองและกู้คืน
