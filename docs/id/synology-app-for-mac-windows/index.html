NAS Synology Anda di desktop

Syno Manager adalah aplikasi native yang independen untuk NAS Synology Anda di macOS dan Windows. Aplikasi yang sama seperti di ponsel, ditata untuk jendela yang lebih besar: pembacaan langsung, Docker, pencadangan, file, dan Wake-on-LAN, tanpa membuka DSM di tab browser.

Mac

Di macOS

Siri dan Pintasan, secara native ›

Open a section, Restart NAS, dan Shut down NAS adalah tindakan Pintasan sungguhan lewat App Intents. Jadwalkan atau rangkai ke dalam pintasan Anda sendiri.

Asisten Apple Intelligence ›

Di tempat Apple Intelligence didukung dan diaktifkan, tanyakan tentang NAS Anda dengan kata-kata biasa. Model berjalan di Mac.

Kredensial di Keychain ›

Kata sandi DSM dan token perangkat disimpan di Keychain macOS, tidak pernah dalam teks biasa.

Apple adalah satu pembelian universal: beli Syno Manager sekali dan tersedia di Mac, iPhone, dan iPad Anda.

Windows

Di Windows

Save As native ›

Unduh file apa pun dari File Station langsung ke folder di PC Anda lewat dialog Windows standar, di rumah atau lewat QuickConnect.

Bangunkan PC Anda lewat NAS ›

NAS yang selalu menyala mengirim magic packet dari dalam jaringan Anda. Panduan membahas sisi Windows, termasuk mematikan Fast Startup.

Pencadangan sekilas ›

Tugas Hyper Backup dengan ruang yang dipakai, dan perangkat Active Backup for Business dengan total terdeduplikasi.

Versi Microsoft Store adalah pembelian terpisah seharga $9.99.

Di keduanya

Semua yang Anda cek pada NAS

  • Sistem: CPU, RAM, beban, I/O disk, dan suhu, mode kipas, pemeriksaan pembaruan DSM, restart dan shutdown.
  • Penyimpanan: volume dan pool dengan jenis RAID, kesehatan SMART dan suhu per drive, eject aman.
  • Aplikasi: Package Center, kontainer Docker dan stack Compose, mesin virtual.
  • Jaringan: throughput langsung per antarmuka, koneksi, layanan DSM, profil VPN, dan DDNS.
  • Beberapa NAS: tambahkan sebanyak yang Anda mau, masing-masing dengan tata letak dan pengaturannya sendiri.
