离家在外

同一个应用，不同的线路

无论你就在 NAS 旁边还是在地球另一端，Syno Manager 的使用体验都一样。不同的只是连接的建立方式，而每种线路各有取舍，值得了解。

三种线路

选择适合你的一种

线路设置速度是否暴露内网服务？
QuickConnect在 DSM 中启用并输入 ID。路由器无需任何设置。速度较慢 - 流量经由 Synology 的中转服务。不会。你这一侧没有任何开放端口。
自定义域名 / DDNS一个指向你地址的主机名，外加路由器上的端口转发。直连，速度取决于你的上行带宽。会 - DSM 端口可从互联网访问。
VPN在路由器或 NAS 上搭建 VPN 服务器，并在手机上安装客户端。连接后即为直连。只暴露 VPN 端口。其他一切仍保持私密。
拿不准的话，就用 QuickConnect。它不需要任何路由器知识，也不会开放任何端口，而且应用的所有功能都能通过它使用。
远程时哪些功能可用

全部可用，只有两点说明

你在外时，应用的功能并不会缩水。需要稍加留意的只有两点：摄像头实时画面，以及唤醒已关机的 NAS。

功能离家在外
监控 - 系统、存储、网络、健康状况任何线路都可用。
Docker、套件、服务、任务、用户任何线路都可用。
Synology Photos - 缩略图和原图可用，包括中转。
File Station 和 Drive 下载可用，包括中转。
备份 - 状态和立即运行任何线路都可用。
通过 NAS 唤醒其他设备可用，前提是 NAS 本身处于开机状态。
摄像头实时画面请打开通过 DSM 端口隧道传输摄像头实时画面。不开启的话，实时画面需要端口 554 上的 RTSP，而这通常无法从外网访问。详见实时画面如何连接。
在 NAS 关机时唤醒它需要 VPN 或路由器上的Wake-on-LAN转发。QuickConnect 无法连接已关机的 NAS。详见Wake-on-LAN。
QuickConnect

设置方法

  1. 在 DSM 中：控制面板 › 外部访问 › QuickConnect。启用它并记下 QuickConnect ID。
  2. 在应用中：添加 NAS，并将连接类型切换为 QuickConnect。
  3. 输入 ID - 而不是主机和端口。
  4. 你的 DSM 凭据；如果账户启用了2FA，还需输入验证码。
  5. 保存 & 连接。
速度会慢一些。中转会多出一跳，而且 Synology 对其做了限速，所以浏览照片库时不如在家里流畅。所有功能仍然可用 - 差别只在延迟，而不在能力。
值得借鉴的做法

把同一台 NAS 添加两次

一个条目用本地 IP，一个用 QuickConnect。起个名字以便区分，比如“NAS（家）”和“NAS（外）”。

  • 在家时用直连的那个：无需中转，全速运行，缩略图瞬间加载。
  • 外出时切换到 QuickConnect 的那个。
  • 它们的布局相互独立，所以你可以把外出用的条目精简到只剩使用移动数据时真正会看的几张卡片。
  • 在设备列表中一键切换。

将启动行为设为上次使用的 NAS，应用就会记住你用的是哪一个。

常见问题

远程访问 FAQ

远程使用 NAS 需要做端口转发吗？
不需要。QuickConnect 无需任何路由器配置即可中转连接，VPN 同样可行。只有在你明确想要从互联网直连时，才需要端口转发。
照片和摄像头实时画面能通过 QuickConnect 使用吗？
可以。缩略图、原图、摄像头实时画面，以及 File Station 和 Drive 的下载，都会走当前可用的线路，包括中转。摄像头实时画面需要打开 DSM 端口隧道开关。
我应该把 NAS 添加两次吗？
这是个好做法 - 一个条目用本地 IP 在家使用，一个用 QuickConnect 外出使用，布局各自独立，一键切换。
QuickConnect 安全吗？
使用 HTTPS 时，连接是端到端加密的，中转只转发流量，不保存你的数据。你的 DSM 凭据和双重验证依然有效。
为什么我的本地 IP 条目在移动数据下无法使用？
因为像 192.168.x.x 这样的私有地址只存在于你自己的网络中。请使用 QuickConnect 条目、域名，或先连接到你的 VPN。
