Kompatibilitet

Om den kör DSM 7 fungerar det

Det finns ingen modellista att kontrollera, eftersom appen inte använder någon. Den frågar din NAS vad den kan göra när den ansluter och bygger upp sig själv efter svaret.

Varför det inte finns någon matris

Upptäckt, inte en hårdkodad lista

En supporttabell per modell skulle bli fel samma dag Synology släppte en ny modell, och fel igen den dag en av dem fick ett nytt paket.

  • Appen frågar DSM:s API-katalog vid anslutning och behåller svaret. Den katalogen är sanningen om vad din NAS kan göra.
  • Skärmar dyker upp för att din NAS rapporterade API:et bakom dem. Installera Surveillance Station så dyker en kameravy upp. Avinstallera det så försvinner vyn.
  • Inget antas utifrån modellnamnet. Två identiska modeller med olika paket får olika appar, vilket är rätt.
  • Ett värde som NAS-enheten inte rapporterade anges som oläst, och fylls aldrig i med ett rimligt standardvärde.

Den praktiska versionen: om DSM:s eget webbgränssnitt fungerar i telefonens webbläsare, och ditt DSM-konto kan se något där, kan Syno Manager se det också.

Vanliga frågor

FAQ om kompatibilitet

Vilka Synology-modeller stöder Syno Manager?
Alla Synology NAS med DSM 7.0 eller senare - DiskStation, RackStation och FlashStation, med eller utan expansionsenheter. Det finns ingen modellista eftersom appen frågar din NAS vad den kan göra när den ansluter.
Fungerar den på DSM 6?
Nej. DSM 7.0 eller senare krävs. DSM 6 använder andra API-versioner och ett annat autentiseringsbeteende.
Fungerar den på en liten NAS med två diskplatser?
Ja. Den visar färre skärmar eftersom den kör färre tjänster, inte för att den saknar stöd. Allt den kör visas fullt ut.
Stöder den expansionsenheter?
Ja. Diskar i en expansionsenhet visas bredvid de interna.
Vad händer om min NAS kör en beta-version av DSM?
Det fungerar i regel, eftersom appen läser API-katalogen i stället för att anta en version. En beta som ändrar ett API kan ge ett värde som appen rapporterar som oläst - vilket den säger, i stället för att visa ett felaktigt tal.
