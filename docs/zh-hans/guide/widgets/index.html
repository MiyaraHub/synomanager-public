小组件

在主屏幕上查看你的 NAS

Android 和 iOS 上都有十二个小组件，在选择器中各有预览 - 而且每个都会告诉你数字是何时获取的，这一点事实上比数字本身更重要。

十二个小组件

每个小组件显示什么

其中九个是后来加入的，原有的三个是：系统状态、存储概览和快捷操作。每个都在启动器的小组件选择器中带有预览，所以放置之前你就能大致看到它的样子。

小组件显示内容前提条件
系统状态一眼看清 NAS 的健康状况 - 机器的状态，无需打开任何东西。-
存储概览存储卷用量，所以存储卷快满了在启动器上就能看到。-
快捷操作直达你常用的界面，无需先经过主屏幕。-
NAS 健康是否有问题，以及是什么问题。-
备份上次和下次备份，以及任何失败。已配置备份任务
温度与风扇系统温度及风扇模式。-
Docker正在运行的容器及其名称。Container Manager
摄像头在线的摄像头。Surveillance Station
网络最繁忙接口的实时流量。-
UPSUPS 电量和预计运行时间。已连接 UPS
下载进行中的下载及其速度。Download Station
存储卷每个存储卷的用量。-
你的 NAS 没有运行的服务，不会提供对应的小组件。Docker、摄像头、备份、UPS、下载和存储卷只有在应用看到你的 NAS 报告了对应能力后，才会出现在选择器中 - 与仪表盘卡片遵循的规则相同，只是用在了启动器上。

在 Android 上，每个小组件都可以双向调整大小，变宽或变高，并自动选择适合你所给空间的布局。十二个都位于启动器小组件选择器中的 Syno Manager 下。

本页没有选择器的截图。只有小组件真正放在主屏幕上之后，选择器才会显示相应内容，而本站拍摄的每台设备都是某个人真实在用的手机 - 不是为了截图而随意重新布置的备用机。
添加小组件

如何放置小组件

Android

  1. 长按主屏幕的空白处。
  2. 点按“小组件”。
  3. 在列表中找到 Syno Manager。
  4. 把你想要的小组件拖动到主屏幕上并调整大小。

iOS

  1. 长按主屏幕，直到图标开始抖动。
  2. 点按顶部的加号。
  3. 搜索 Syno Manager。
  4. 选择尺寸并点按“添加小组件”。
重点所在

为什么每个小组件都带有时间戳

小组件只有在操作系统允许时才会刷新。Android 和 iOS 都会严格限制小组件的更新以节省电量，所以主屏幕上的数字可能比看起来旧上好几个小时 - 而看似最新的过期读数，比没有读数更糟。

提示的含义含义
刚刚在最近一分钟内读取。
12m 前不足一小时，以分钟计。
5h 前不足一天，以小时计。
2d 前一天或更久。请视为历史数据。
从未更新还没有成功读取过 - 刚添加，或之后应用还没有运行过。绝不会显示为零，因为零看起来像是一次测量值。
超过六小时的数据都视为过期并加以标注，而不是当作你的 NAS 当前的状态呈现。

这样做保留的区别是真实存在的：没有时间戳的话，安静的 NAS 和过期的小组件看起来一模一样。“CPU 4%，3 分钟前获取”和“CPU 4%，昨天获取”是不同的事实，只有其中一个值得你采取行动。

保持数据最新

如果小组件不刷新

  • 打开应用。最可靠的刷新方式，就是让应用运行并读取 NAS。
  • 在 Android 上检查电池优化。后台受限的应用获得的小组件刷新机会更少。将 Syno Manager 排除在优化之外会有帮助。
  • 在 iOS 上检查“后台应用刷新”。进入设置，然后找到该应用 - 如果它是关闭的，iOS 很少会唤醒小组件。
  • 记住 NAS 必须能够访问。手机连不上的 NAS，小组件也读不了 - 如果在移动数据下条目只有本地 IP，那么在你回家之前它不会更新。
两个平台都不保证刷新间隔。没有哪个应用能强制刷新，这正是这里放时间戳而不是做出承诺的原因。
常见问题

小组件 FAQ

Syno Manager 有哪些小组件？
共十二个：系统状态、存储概览、快捷操作、NAS 健康、备份、温度与风扇、Docker、摄像头、网络、UPS、下载和存储卷。十二个在 Android 和 iOS 上均可使用，在小组件选择器中都有预览。
为什么我的小组件显示的是旧数字？
因为小组件何时可以刷新是由操作系统决定的，而不是应用。正因如此，每个小组件都会显示其数据的获取时间 - 这样旧读数看起来就是旧的，而不是冒充最新。
“从未更新”是什么意思？
表示小组件还没有成功读取过一次数据 - 通常是因为刚添加不久，或之后还没有打开过应用。它显示为“从未更新”而不是零。
如何添加小组件？
在 Android 上，长按主屏幕，选择“小组件”，找到 Syno Manager 并拖动一个出来。在 iOS 上，长按主屏幕，点按加号，搜索 Syno Manager 并选择尺寸。
