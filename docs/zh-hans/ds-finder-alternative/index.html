对比

超越 DS finder，集于一个应用

DS finder 是 Synology 自家的应用，用于设置 NAS 并随时留意它。Syno Manager 是一款独立应用，为设置之后的日子而生：查看 NAS 运行的一切并加以操作，无需在多个应用之间切换。

并排对比

两个应用，各司其职

这不是评分表。DS finder 有 Syno Manager 做不到的事，比如设置新的 NAS，以及接收 DSM 自带 Push Service 的通知。下表说明了两者各自适合什么。

你想要适合用
设置全新的 NASDS finder 或 DSM
接收 DSM Push Service 通知DS finder
查看存储、硬盘健康和用户两者均有
重启、关闭或唤醒 NAS两者均有
重启 Docker 容器并查看其日志Syno Manager
安装或更新套件Syno Manager
实时观看 Surveillance Station 摄像头Syno Manager
浏览 Synology Photos 和 DriveSyno Manager
查看 Hyper Backup 任务占用多少空间Syno Manager
向 Download Station 添加下载Syno Manager
通过 NAS 唤醒网络中的另一台电脑Syno Manager
开关 DSM 服务，查看 VPN 配置和 DDNSSyno Manager

DS finder 的功能依据 Synology 知识中心的描述。Synology 可能随时更改其应用，最新功能请查阅 Synology 的文档。

Syno Manager 的优势

整台 NAS，一屏尽览

指出原因的健康徽章

哪块硬盘、哪个存储空间、什么温度，而不只是“警告”。

不只是状态，还能控制

在手机上操作容器、套件、备份、服务、任务、下载和风扇模式。

离家在外也能用

通过 QuickConnect 查看照片、摄像头实时画面和下载文件。无需端口转发。

小组件与快捷方式

十二个主屏幕小组件、synomanager:// 链接，以及 Mac 上的 Siri 和快捷指令。

设备端助手

用日常语言询问你的 NAS。模型在你的设备上运行，而且只读不写。

手机、平板和桌面端

支持 Android、iPhone、iPad、Mac 和 Windows。每个平台一次性 $9.99，无订阅。

和 DS finder 搭配试试

一次性购买，$9.99。无广告，无订阅，无内购。需要运行 DSM 7.0 或更高版本的 Synology NAS。

Syno Manager 是一款独立应用，与 Synology Inc. 没有隶属、认可或赞助关系。DS finder 是 Synology Inc. 的产品。
