隐私

中间没有服务器

Syno Manager 是你 NAS 的客户端，而不是一项服务。你的手机直接与 DiskStation 建立连接，整个架构就是这样。

  • 没有 MiyaraHub 服务器。关于你 NAS 的任何信息都不会到达我们这里，因为路径上根本没有可去的地方。
  • 凭据保存在钥匙串中。存放在平台的安全存储里，绝不以明文保存，并且不会包含在设备备份中。
  • 2FA与设备信任。支持一次性验证码，并会记住受信任的设备，这样你不必每次启动都输入。
  • 助手运行在设备端。你的问题、你的 NAS 数据和回答都不会离开手机。
  • 只有一样东西会离开：崩溃报告，以便修复崩溃。它包含堆栈跟踪，而不包含你的 NAS。完整说明。

常见问题

手机上的 Synology，答疑解惑

Syno Manager 能做什么？
它把 DSM 中你真正会在手机上查看的部分集中到一个应用里：实时 CPU、RAM、温度和网络读数，存储卷和每块硬盘的 SMART 健康状况，Docker 容器，套件中心，Surveillance Station 实时画面，Synology Photos 和 Drive，Hyper Backup 和 Active Backup，Download Station，File Station，用户，计划任务，UPS，DDNS 以及Wake-on-LAN。它使用 DSM 自己公开的 API 直接与你的 NAS 通信。用户指南涵盖了每一个界面。
支持哪些 Synology 型号？
任何运行 DSM 7.0 或更高版本的 Synology NAS 都支持。应用会在连接时读取你的 NAS 上报的信息，只显示它真正支持的界面，因此双盘位的 DS223j 和机架式的 RS1221+ 各自得到与其能力相匹配的仪表盘。详见兼容性。
我不在家时能用吗？
能。只需添加一次 NAS，应用就会使用任何可达的线路 - 在家用本地 IP，外出时用 QuickConnect、自定义域名或 VPN。照片、摄像头实时画面，以及 File Station 和 Drive 下载都可以通过 QuickConnect 中转使用，所以无需端口转发。详见远程访问。
我的数据会经过你们的服务器吗？
你的 NAS 数据不会。Syno Manager 直接连接你的 NAS，这条路径上没有 MiyaraHub 的服务器，所以你的文件、读数和配置都不会到达我们这里。凭据保存在设备的钥匙串或密钥库中，不会包含在设备备份中，助手的模型也运行在你的手机上。唯一会离开设备的是崩溃报告，通过 Firebase Crashlytics 发送 - 包含堆栈跟踪、设备型号和应用版本，不含你的任何 NAS 数据。完整详情见这里。

支持双重验证吗？
支持。如果你的 DSM 账户使用2FA，应用会提示输入一次性验证码，并可以记住该设备，这样那部手机上不会再次询问。它还会在每次控制操作时获取并发送 DSM 的 SynoToken，这是 DSM 对任何会更改内容的客户端的要求。
能管理多台 NAS 吗？
能。想添加多少就添加多少，并从设备列表中切换。每台都保留各自的凭据、仪表盘布局和设置。详见多台 NAS 设备。
