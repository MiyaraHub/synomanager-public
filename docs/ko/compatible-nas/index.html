호환 표가 없는 이유

하드코딩된 목록이 아닌 탐색 방식

모델별 지원 표는 Synology가 새 모델을 내놓는 날 틀려지고, 그중 한 모델에 패키지가 추가되는 날 또다시 틀려집니다.

  • 앱은 연결할 때 DSM의 API 카탈로그를 조회하고 그 답을 저장합니다. 이 카탈로그가 NAS가 할 수 있는 일에 대한 기준입니다.
  • 화면은 NAS가 해당 API를 보고했기 때문에 나타납니다. Surveillance Station을 설치하면 카메라 화면이 나타나고, 제거하면 사라집니다.
  • 모델명으로 짐작하는 것은 없습니다. 패키지가 다른 동일 모델 두 대는 서로 다른 앱 화면을 받게 되며, 그것이 올바른 동작입니다.
  • NAS가 보고하지 않은 값은 읽지 못했다고 표시하며, 그럴듯한 기본값으로 채우지 않습니다.

실용적으로 말하면, 휴대폰 브라우저에서 DSM 웹 인터페이스가 작동하고 DSM 계정으로 어떤 항목이 보인다면 Syno Manager에서도 볼 수 있습니다.

호환성 FAQ

Syno Manager는 어떤 Synology 모델을 지원하나요?
DSM 7.0 이상을 실행하는 모든 Synology NAS를 지원합니다. 확장 유닛 유무와 상관없이 DiskStation, RackStation, FlashStation이 모두 해당합니다. 앱이 연결할 때 NAS에 무엇을 할 수 있는지 직접 물어보므로 모델별 목록은 없습니다.
DSM 6에서도 작동하나요?
아니요. DSM 7.0 이상이 필요합니다. DSM 6은 API 버전과 인증 방식이 다릅니다.
작은 2베이 NAS에서도 작동하나요?
네. 실행하는 서비스가 적어서 화면이 더 적게 표시될 뿐, 지원되지 않아서가 아닙니다. 실행 중인 모든 항목은 빠짐없이 표시됩니다.
확장 유닛도 지원하나요?
네. 확장 유닛의 드라이브도 내장 드라이브와 함께 표시됩니다.
NAS가 베타 DSM을 실행 중이라면요?
앱이 버전을 가정하지 않고 API 카탈로그를 읽기 때문에 대체로 잘 작동합니다. 베타에서 API가 바뀌면 앱이 읽지 못한 값으로 표시할 수 있는데, 틀린 숫자를 보여 주는 대신 그렇게 알려 드립니다.
