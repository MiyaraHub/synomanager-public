Synology NAS-en din på Android

Syno Manager er en uavhengig, innebygd Android-app for Synology NAS-en din. Avlesninger av system, lagring og nettverk i sanntid, Docker, kameraer, bilder, sikkerhetskopier og filer i én app, med widgeter som kan endre størrelse, snarveier på startskjermen og en assistent som kjører på telefonen.

Laget for Android

Hva Android-appen gjør

Tolv widgeter som kan endre størrelse ›

Hver widget kan gjøres bredere eller høyere og velger utformingen som passer. Hver og en viser når tallene ble hentet.

Snarveier på startskjermen og Tasker ›

Åpne hvilken som helst skjerm fra en snarvei på startskjermen eller fra Tasker, MacroDroid og andre automatiseringsapper via synomanager://-lenker.

Gemini Nano-assistent ›

På en enhet med AICore og Gemini Nano kan du spørre om NAS-en din med vanlige ord. Modellen kjører på telefonen og fungerer uten nett.

Docker og pakker ›

Start, stopp og start containere på nytt, les loggene deres, kjør Compose-stacker, og installer eller oppdater pakker.

Download Station ›

Send en lenke, en magnet eller en .torrent til NAS-en fra telefonen og følg fremdriften.

Utelatt fra sikkerhetskopier ›

Pålogginger ligger i den Keystore-baserte lagringen og er utelatt fra Androids skysikkerhetskopi og enhetsoverføring.
Inni appen

Alt du sjekker på en NAS

  • System: CPU, RAM, belastning, disk-I/O og temperatur, viftemodus, kontroll av DSM-oppdatering, omstart og avslutning.
  • Lagring: volumer og pooler med RAID-type, SMART-helse og temperatur per stasjon, trygg utløsing.
  • Media: Synology Photos, Drive og direktevisning fra Surveillance Station, også over QuickConnect.
  • Sikkerhetskopier: Hyper Backup og Active Backup for Business, med reelle størrelser.
  • Filer: File Station, kopier og flytt på NAS-en, delte mapper. Nedlastinger åpner delingsarket.
  • Wake-on-LAN: vekk NAS-en, eller en hvilken som helst maskin på nettverket ditt via den.
