Порівняння

Більше, ніж DS finder, в одному застосунку

DS finder - це власний застосунок Synology для налаштування NAS і нагляду за ним. Syno Manager - незалежний застосунок, створений для дня після налаштування: перевіряти все, що запускає NAS, і керувати цим без перемикання між застосунками.
