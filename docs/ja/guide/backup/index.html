バックアップサイズとソースサイズを並べて表示

多くのツールはどちらか一方しか見せません。2つを並べて見ることで、どちらか一方だけでは答えられない疑問に答えられます。

  • 重複排除と圧縮でどれだけ節約できているか。758 GB のソースがバックアップ先で 814 GB を占めている場合と、300 GB を占めている場合では、意味がまったく違います。それがわかるのは、2つの数値が揃っているときだけです。
  • バックアップ先がまもなく満杯になるかどうか。ソースの増加とバックアップ先の増加は同じ曲線ではなく、「来月失敗するか」を判断するうえで重要なのはバックアップ先のほうです。
  • バージョン管理が膨らみすぎていないか。バックアップ先がソースよりはるかに速く増えている場合は、意図した以上に世代を保持する保持ポリシーになっていることがほとんどです。
Active Backup

Active Backup for Business

デバイス数とタスク数を示すヘッダー、リポジトリサイズ、そしてデバイス自体が続きます。

バックアップサイズ

  • ボリュームごとの、リポジトリの重複排除後の合計サイズです。
  • ワークロード別の内訳（PCs、サーバー、仮想マシン、DSM デバイス）に、それぞれのデバイス数とサイズが表示されます。
  • 見たままの値として表示します。Active Backup が報告するバックアップ先での重複排除後サイズであり、ソースサイズの合計をそれらしく見せたものではありません。

端末

  • 保護されている各デバイスと、そのアドレスおよび OS が表示されます。
  • 前回のバックアップ。まだ実行されていない場合はなしと表示され、これが最も注意すべき項目です。
  • デバイスごとに今すぐバックアップができます。
失敗したとき

確認しに行かなくても気づけます

  • タスクのカードに、NAS が報告した状態が表示されます。
  • ホーム画面のヘルスバッジにも反映されるため、失敗したバックアップは3タップ先ではなく、最初に見る画面に表示されます。
  • 一度もバックアップされていないデバイスは、空欄やゼロではなくなしと表示されます。空欄やゼロでは「問題なし」に見えてしまうためです。
アプリにできないこと：バックアップタスクの作成・編集、保持ポリシーの変更、バックアップからの復元。これらは Hyper Backup 自身の役割で、特に復元は、スマートフォンで誤って始めてしまうような操作ではありません。
よくある質問

バックアップのFAQ

スマートフォンからバックアップを開始できますか？
はい。すべての Hyper Backup タスクに「今すぐ実行」ボタンがあり、実行中のタスクにはリアルタイムの進行状況バーが表示され、キャンセルもできます。
バックアップサイズとソースサイズの違いは何ですか？
ソースサイズは、タスクがバックアップしているデータ量です。バックアップサイズは、重複排除と圧縮のあとにバックアップ先で実際に占めている容量です。両方を並べて見ることで、どれだけ節約できているか、そしてバックアップ先がソースの増加より速く埋まっていないかがわかります。
Active Backup for Business は表示されますか？
はい。リポジトリの重複排除後のサイズが、ワークロード別にデバイス数とともに表示されます。保護されているすべてのデバイスについて、最後のバックアップ時刻と「今すぐバックアップ」ボタンも表示されます。
バックアップが失敗したら通知されますか？
はい。タスクの状態はタスクごとに表示され、失敗したタスクはホーム画面のヘルスバッジにも反映されます。
アプリからバックアップを復元できますか？
いいえ。復元は、バージョンの選択と復元先の指定ができる Hyper Backup または Active Backup で行います。アプリはバックアップの監視と実行のみを行い、データを元に戻すことはありません。
