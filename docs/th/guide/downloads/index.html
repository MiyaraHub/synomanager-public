Download Station

วางลิงก์หรือแมกเน็ต หรือเลือก .torrent แล้ว NAS จะดาวน์โหลดให้ ดูความคืบหน้า หยุดชั่วคราวและดำเนินการต่อ และเปลี่ยนการตั้งค่าที่ NAS ถูกกำหนดไว้จริง ๆ

Download Station

อะไรกำลังทำงานอยู่

ส่วนหัวแสดงความเร็วด้านบน คือความเร็วดาวน์โหลดและอัปโหลดรวมของทุกงาน จากนั้นเป็นตัวงานเอง

  • แต่ละงานแสดงชื่อ สถานะ แถบความคืบหน้า ความเร็วปัจจุบัน และเวลาที่เหลือโดยประมาณ
  • หยุดชั่วคราว ดำเนินการต่อ หรือลบงานใดก็ได้
  • เมื่อไม่มีงานก็บอกตรง ๆ - "ไม่มีการดาวน์โหลดที่กำลังทำงาน" แทนที่จะเป็นกล่องว่างที่ต้องตีความเอง
  • การตั้งค่าอยู่ห่างจากส่วนหัวแค่หนึ่งแตะ
  • ใช้ได้ทั้งสอง API รุ่น Download Station มี API สองเวอร์ชัน แอปใช้เวอร์ชันที่ NAS ของคุณมี
การเพิ่ม

สามทางเข้า

แตะ + ที่มุมขวาล่าง

  1. วางลิงก์หรือแมกเน็ต URL แบบ https:// หรือลิงก์แบบ magnet:?xt= ใส่ในช่องเดียวกัน
  2. หรือเลือกไฟล์ .torrentจากอุปกรณ์ ซึ่งจะเปิดตัวเลือกไฟล์
  3. เลือกที่บันทึกด้วย Save to หรือปล่อยไว้แล้ว Download Station จะใช้โฟลเดอร์เริ่มต้นของตัวเอง
  4. เพิ่ม งานจะปรากฏในรายการ
มือถือเป็นเพียงรีโมตคอนโทรล NAS ดึงไฟล์ผ่านการเชื่อมต่อของมันเอง คุณจึงปิดแอป ออกจากบ้าน แล้วมันก็ยังทำงานต่อ
การตั้งค่าดาวน์โหลด

ทุกการตั้งค่า อ่านจาก NAS ของคุณ

มุมมองย่อยของตัวเอง จัดกลุ่มแบบที่ Download Station จัดกลุ่ม ค่าที่แก้ไขได้มีเครื่องหมายถูกยืนยันการเปลี่ยนแปลง ค่าที่อ่านอย่างเดียวแสดงเป็นข้อเท็จจริง

กลุ่มการตั้งค่าทำอะไรได้
BitTorrentพอร์ตรับฟังพอร์ต TCP ที่ Download Station รับฟัง แก้ไขได้
ขีดจำกัดการดาวน์โหลดหน่วย KB/s 0 หมายถึงไม่จำกัด แก้ไขได้
ขีดจำกัดการอัปโหลดหน่วย KB/s 0 หมายถึงไม่จำกัด แก้ไขได้
เพียร์สูงสุดทอร์เรนต์หนึ่งเชื่อมต่อกับเพียร์ได้กี่ตัว
DHTเปิดตารางแฮชแบบกระจายหรือไม่ และใช้พอร์ตใด
FTP และ HTTPขีดจำกัดการดาวน์โหลดเพดานแยกสำหรับการดาวน์โหลด HTTP และ FTP ธรรมดา 0 หมายถึงไม่จำกัด แก้ไขได้
งานและตารางเวลางานพร้อมกันจำนวนการดาวน์โหลดที่รันพร้อมกัน และแอปบอกค่าสูงสุดที่ NAS ของคุณอนุญาต คุณจึงไม่ต้องเดาเพดาน แก้ไขได้
ตารางเวลาทางเลือกมีตารางความเร็วอีกแบบที่ใช้ในบางช่วงเวลาหรือไม่
ปลายทางโฟลเดอร์เริ่มต้นที่ที่การดาวน์โหลดไปอยู่เมื่องานไม่ระบุโฟลเดอร์ แสดงเป็นยังไม่ตั้งค่าเมื่อไม่มี แทนที่จะเว้นว่าง
รันบนแพ็กเกจ Download Station เองติดตั้งอยู่บนวอลุ่มใด
eMuleเปิดบริการ eMule หรือไม่
ทุกการเปลี่ยนแปลงถูกยืนยันด้วยการอ่านกลับ แอปเขียนค่าของคุณ แล้วอ่านการตั้งค่านั้นจาก NAS อีกครั้ง หาก NAS ปรับค่าเงียบ ๆ หรือปฏิเสธ คุณจะรู้ แทนที่จะเห็นตัวเลขที่คุณพิมพ์ค้างอยู่เหมือนมีผลแล้ว
เรื่องเล็กที่สำคัญ

ทำไมส่วนที่อ่านไม่ได้จึงถูกระบุชื่อ ไม่ใช่แสดงเป็นศูนย์

จะแสดงเฉพาะการตั้งค่าที่ NAS ของคุณรายงานจริง ส่วนที่แอปอ่านไม่ได้จะถูกระบุว่าอ่านไม่ได้ ไม่ใช่แสดงเป็นศูนย์

นี่ไม่ใช่การจู้จี้ ที่นี่ 0 หมายถึงไม่จำกัด ดังนั้นการอ่านที่ล้มเหลวแต่แสดงเป็น 0 จะบอกคุณว่าการดาวน์โหลดไม่มีเพดาน ทั้งที่ความจริงคือไม่มีใครรู้ ค่าที่มีความหมายได้สองแบบควรถูกระบุว่าไม่ทราบ และหน้าจอนี้ทำเช่นนั้น

ไม่เจอหรือ

หากไม่เห็นแท็บ Download Station

  1. ตรวจสอบว่าติดตั้งแพ็กเกจแล้ว Download Station ไม่ได้เป็นส่วนหนึ่งของ DSM แต่มาจาก Package Center คุณติดตั้งจากแอปนี้ได้
  2. รีเฟรชมุมมองของแอปต่อ NAS ของคุณ รายการความสามารถถูกอ่านตอนเชื่อมต่อ ดังนั้นแพ็กเกจที่ติดตั้งหลังจากนั้นจึงยังไม่มีแท็บ ดึงลงเพื่อรีเฟรช หรือเปิดแอปใหม่
  3. ตรวจสอบว่าไม่ได้ซ่อนไว้ เมนูเพิ่มเติมบนแท็บ Files มี Customize views ซึ่งปิดมุมมองย่อยได้
Download Station ต้องใช้ Python2 บน DSM 7 ส่วนใหญ่ และ Package Center จะติดตั้งให้เป็นแพ็กเกจที่ต้องพึ่งพาเมื่อคุณติดตั้งแพ็กเกจ
คำถามที่พบบ่อย

คำถามที่พบบ่อยเรื่อง Download Station

เพิ่มทอร์เรนต์จากมือถือได้ไหม
ได้ สามวิธี คือ วาง URL วางลิงก์แมกเน็ต หรือเลือกไฟล์ .torrent จากอุปกรณ์ และเลือกโฟลเดอร์ที่จะบันทึกได้ก่อนเพิ่ม
เปลี่ยนการตั้งค่า Download Station จากแอปได้ไหม
ได้ ทั้งพอร์ตรับฟัง BitTorrent เพดานความเร็วดาวน์โหลดและอัปโหลด จำนวนเพียร์สูงสุด จำนวนงานที่รันพร้อมกัน และโฟลเดอร์ปลายทาง ทุกการเปลี่ยนแปลงจะถูกอ่านกลับจาก NAS หลังจากนั้น ค่าที่ NAS ปฏิเสธจึงถูกรายงานว่าถูกปฏิเสธ
ขีดจำกัดการดาวน์โหลดที่เป็น 0 หมายถึงอะไร
ไม่จำกัด นั่นเป็นธรรมเนียมของ Download Station เอง และเป็นเหตุผลที่แอปไม่แสดงส่วนที่อ่านไม่ได้เป็นศูนย์ เพราะการอ่านที่ขาดหายแต่แต่งตัวเป็นศูนย์จะเป็นข้อความที่ต่างออกไปและผิด
ทำไมแท็บ Download Station จึงหายไป
เพราะ NAS เครื่องนั้นยังไม่ได้ติดตั้งแพ็กเกจ ติดตั้ง Download Station จาก Package Center แล้วดึงลงเพื่อรีเฟรชหรือเปิดแอปใหม่ แท็บจะปรากฏ
การดาวน์โหลดยังทำต่อไหมถ้าฉันปิดแอป
ทำต่อ NAS ดาวน์โหลดผ่านการเชื่อมต่อของมันเอง มือถือเป็นเพียงรีโมตคอนโทรล
