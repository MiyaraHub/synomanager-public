Hyper Backup

ทุกงาน และกำลังทำอะไรอยู่

สรุปด้านบน มีกี่งาน กี่งานปกติ กี่งานมีปัญหา จากนั้นเป็นการ์ดต่องาน

ที่แสดงความหมาย
ชื่องานตามที่คุณตั้งชื่อใน Hyper Backup
ปลายทางสำรองไปที่ไหน เช่น Synology C2, NAS ระยะไกล, โฟลเดอร์ในเครื่อง, ผู้ให้บริการคลาวด์
สถานะว่าง กำลังทำงาน หรือล้มเหลว งานที่กำลังทำงานจะแสดงแถบความคืบหน้าสด
ขนาดข้อมูลสำรองพื้นที่ที่งานใช้ที่ปลายทาง
ขนาดต้นทางปริมาณข้อมูลที่กำลังสำรอง
สำรองล่าสุดรอบล่าสุดเสร็จเมื่อนานเท่าไรแล้ว
สำรองครั้งถัดไปตารางเวลาจะทำงานครั้งถัดไปเมื่อใด
Run Nowเริ่มงานทันที งานที่กำลังทำงานสามารถยกเลิกได้
สองตัวเลข โดยตั้งใจ

ขนาดข้อมูลสำรองข้างขนาดต้นทาง

เครื่องมือส่วนใหญ่แสดงให้คุณเห็นเพียงอย่างใดอย่างหนึ่ง แต่เมื่อแสดงคู่กันจะตอบคำถามที่ค่าใดค่าหนึ่งตอบไม่ได้

  • การขจัดข้อมูลซ้ำและการบีบอัดประหยัดให้คุณเท่าไร ต้นทาง 758 GB ที่ใช้พื้นที่ปลายทาง 814 GB บอกเรื่องที่ต่างจากที่ใช้ 300 GB มาก และมีเพียงคู่ตัวเลขนี้เท่านั้นที่เผยให้เห็น
  • ปลายทางกำลังจะเต็มหรือไม่ การเติบโตของต้นทางกับปลายทางไม่ใช่เส้นโค้งเดียวกัน และสำหรับคำถามว่า "เดือนหน้าจะล้มเหลวไหม" สิ่งที่สำคัญคือปลายทาง
  • การเก็บเวอร์ชันบานปลายหรือไม่ ปลายทางที่โตเร็วกว่าต้นทางมากมักหมายความว่านโยบายการเก็บรักษาเก็บไว้มากกว่าที่ตั้งใจ
Active Backup

Active Backup for Business

ส่วนหัวแสดงจำนวนอุปกรณ์และงาน จากนั้นเป็นขนาดที่เก็บข้อมูล แล้วจึงเป็นตัวอุปกรณ์

ขนาดข้อมูลสำรอง

  • ขนาดรวมหลังขจัดข้อมูลซ้ำของที่เก็บข้อมูล แยกตามวอลุ่ม
  • แยกตามปริมาณงาน ได้แก่ พีซี เซิร์ฟเวอร์ เครื่องเสมือน และอุปกรณ์ DSM พร้อมจำนวนอุปกรณ์และขนาดของแต่ละประเภท
  • ระบุตามที่เป็นจริง: ขนาดหลังขจัดข้อมูลซ้ำที่ปลายทาง ตามที่ Active Backup รายงาน ไม่ใช่ผลรวมของขนาดต้นทางที่แต่งตัวมาให้ดูเหมือน

อุปกรณ์

  • แต่ละอุปกรณ์ที่ได้รับการป้องกัน พร้อมที่อยู่และระบบปฏิบัติการ
  • สำรองล่าสุด หรือ ไม่เคย เมื่อยังไม่เคยทำงาน ซึ่งเป็นรายการที่ควรสังเกต
  • Backup Now ต่ออุปกรณ์
เมื่อมีบางอย่างล้มเหลว

รู้โดยไม่ต้องไปหา

  • งานบอกเองบนการ์ด พร้อมสถานะที่ NAS รายงาน
  • ป้ายสถานะสุขภาพบนหน้าจอหลักสะท้อนเรื่องนี้ การสำรองข้อมูลที่ล้มเหลวจึงปรากฏบนหน้าจอแรกที่คุณเห็น ไม่ใช่ต้องแตะเข้าไปสามชั้น
  • อุปกรณ์ที่ไม่เคยถูกสำรองข้อมูลจะแสดงเป็นไม่เคย ไม่ใช่ช่องว่างหรือศูนย์ เพราะสองอย่างนั้นจะดูเหมือน "ปกติดี"
สิ่งที่แอปจะไม่ทำ: สร้างหรือแก้ไขงานสำรองข้อมูล เปลี่ยนนโยบายการเก็บรักษา หรือกู้คืนจากข้อมูลสำรอง สิ่งเหล่านั้นเป็นหน้าที่ของ Hyper Backup และโดยเฉพาะการกู้คืนไม่ใช่สิ่งที่ควรเผลอเริ่มบนมือถือ
คำถามที่พบบ่อย

คำถามที่พบบ่อยเกี่ยวกับการสำรองข้อมูล

เริ่มการสำรองข้อมูลจากมือถือได้ไหม
ได้ ทุกงาน Hyper Backup มีปุ่ม Run Now และงานที่กำลังทำงานจะแสดงแถบความคืบหน้าสดที่ยกเลิกได้
ขนาดข้อมูลสำรองกับขนาดต้นทางต่างกันอย่างไร
ขนาดต้นทางคือปริมาณข้อมูลที่งานกำลังสำรอง ขนาดข้อมูลสำรองคือพื้นที่ที่ใช้จริงที่ปลายทาง หลังขจัดข้อมูลซ้ำและบีบอัด การดูทั้งสองค่าด้วยกันบอกได้ว่าทั้งสองกระบวนการประหยัดให้คุณเท่าไร และปลายทางกำลังเต็มเร็วกว่าที่ต้นทางโตหรือไม่
แสดง Active Backup for Business ด้วยไหม
แสดง ขนาดที่เก็บข้อมูลหลังขจัดข้อมูลซ้ำแยกตามปริมาณงาน พร้อมจำนวนอุปกรณ์ของแต่ละประเภท รวมถึงทุกอุปกรณ์ที่ได้รับการป้องกันพร้อมเวลาสำรองล่าสุดและปุ่ม Backup Now
จะบอกไหมถ้าการสำรองข้อมูลล้มเหลว
บอก สถานะของงานแสดงแยกรายงาน และงานที่ล้มเหลวจะทำให้ป้ายสถานะสุขภาพบนหน้าจอหลักเตือนด้วย
กู้คืนจากข้อมูลสำรองในแอปได้ไหม
ไม่ได้ การกู้คืนทำใน Hyper Backup หรือ Active Backup ซึ่งมีตัวเลือกเวอร์ชันและการเลือกเป้าหมาย แอปตรวจสอบและสั่งเริ่มการสำรองข้อมูล แต่ไม่คืนข้อมูลกลับ
