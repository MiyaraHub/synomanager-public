Synology NASをiPhoneとiPadで

Syno Manager は、Synology NAS用の独立系ネイティブiOSアプリです。システム、ストレージ、ネットワークのリアルタイムの測定値、Docker、カメラ、写真、バックアップ、ファイルを1つのアプリで確認でき、ホーム画面のウィジェット、Siri、スマートフォン上で動作するアシスタントも備えています。

$9.99のユニバーサル購入1回で、iPhone、iPad、Macに対応します。

iOSのために作りました

iPhoneとiPadアプリでできること

お持ちのすべてのAppleデバイスで同じアプリが使え、それぞれの画面に合わせてレイアウトされます。

12種類のウィジェット ›

ヘルス、ストレージ、バックアップ、温度とファン、Docker、カメラ、ネットワーク、UPS、ダウンロード、ボリュームなど。どれも数値を取得した時刻を表示します。

SiriとShortcuts ›

synomanager://リンクでどの画面でも開けるので、Siriのフレーズを設定したショートカットから、ストレージ、バックアップ、Wake-on-LANへ直接移動できます。

Apple Intelligenceアシスタント ›

NASについて普通の言葉で質問できます。Apple Intelligenceに対応し有効にしているデバイスでは、モデルはスマートフォン上で動作し、何も外に出ません。

読み込めるHEIC写真 ›

最新のiPhoneで撮った写真はデバイス上でデコードされるので、Synology Photosのライブラリには表示が崩れたタイルではなく画像が表示されます。

カメラのライブビュー ›

Surveillance Stationのカメラを、自宅でも外出先でもライブで確認できます。QuickConnectでも利用できます。

平文ではなくキーチェーン ›

DSMの認証情報はiOSのキーチェーンに保存されます。2FAコードに対応し、信頼したデバイスは記憶されます。
アプリの中身

NASで確認するすべてを

  • システム：CPU、RAM、負荷、ディスクI/O、温度、ファンモード、DSMのアップデート確認、再起動とシャットダウン。
  • ストレージ：RAIDタイプ付きのボリュームとプール、ドライブごとのSMARTヘルスと温度、安全な取り外し。
  • アプリ：Package Center、Dockerコンテナーとコンポーズスタック、仮想マシン。
  • バックアップ：Hyper BackupとActive Backup for Business。実際の容量を表示します。
  • ファイル：File Station、NAS上でのコピーと移動、共有フォルダー。ダウンロードするとiOSの共有シートが開きます。
  • 外出先から：QuickConnect、独自ドメイン、VPN。ポート転送は不要です。
iOSで初めて使いますか？設定 › アプリ › Syno Manager › ローカルネットワークで、ローカルネットワークへのアクセスを許可してください。許可しないと、iOSは自宅のWi-Fi上の接続をブロックします。その他ははじめにで説明しています。

App Storeで入手

iPhone、iPad、Macで$9.99の買い切り。広告、サブスクリプション、アプリ内課金はありません。DSM 7.0以降のSynology NASが必要です。
