Tanpa perantara

Tidak ada server MiyaraHub di antara Anda dan NAS Anda

Ini soal arsitektur, bukan kebijakan. Syno Manager adalah klien yang berbicara dengan API DSM sendiri - yang sama dengan yang dipanggil antarmuka web DSM - langsung dari ponsel Anda ke DiskStation Anda.

  • Di jaringan Anda sendiri, koneksinya dari ponsel ke NAS lewat LAN.
  • Lewat QuickConnect, koneksi melewati relay Synology - layanan Synology, di bawah akun Synology Anda, bukan milik kami.
  • Lewat domain atau VPN, koneksinya langsung ke alamat Anda.
  • Pada semua kasus itu tidak ada layanan MiyaraHub di jalurnya. Tidak ada tempat bagi data NAS Anda untuk lewat, dan tidak ada tempat untuk menyimpannya.
Kredensial

Tempat kata sandi Anda berada

  • Penyimpanan aman platform. Keychain di iOS dan macOS; penyimpanan terenkripsi berbasis Keystore di Android. Tidak pernah dalam teks biasa, dan tidak pernah dalam file preferensi biasa.
  • Dikecualikan dari cadangan perangkat. Aplikasi secara eksplisit mengecualikan file penyimpanan amannya dari cadangan cloud Android dan transfer perangkat, jadi memulihkan atau memigrasikan ponsel tidak membawa kata sandi NAS Anda. Anda memasukkannya lagi sekali.
  • Dikecualikan dari ekspor pengaturan aplikasi sendiri. File Pencadangan & Pemulihan sengaja tidak berisi koneksi, kata sandi, atau sesi - file portabel berisi kata sandi NAS adalah file portabel berisi kata sandi NAS.
  • Dihapus saat tidak terbaca. Jika kredensial tersimpan tidak bisa didekripsi - yang bisa terjadi setelah memulihkan ke perangkat keras baru - aplikasi menghapusnya dan meminta Anda masuk, bukan mencoba ulang dengan sesuatu yang tidak bisa dibacanya.
Pengecualiannya

Laporan crash

Aplikasi menyertakan Firebase Crashlytics, dan fitur itu aktif. Saat aplikasi crash, laporan diagnostik dikirim agar crash bisa ditemukan dan diperbaiki.

Isi laporan crash

  • Stack trace - kode mana yang gagal, dan di mana.
  • Model perangkat dan versi sistem operasi.
  • Versi aplikasi dan nomor build.

Yang tidak ada di dalamnya

  • Alamat, nama, atau konfigurasi NAS Anda.
  • Nama pengguna, kata sandi, atau token DSM Anda.
  • File, foto, rekaman kamera, atau log Anda.
  • Apa pun yang Anda tanyakan kepada asisten.
Mengapa ini ada sama sekali: crash yang tidak bisa dilihat siapa pun adalah crash yang tidak akan diperbaiki. Imbal baliknya adalah stack trace demi ditemukannya bug - dan hal ini disebutkan di sini, bukan dikubur, karena halaman privasi yang diam-diam menghilangkan satu-satunya hal yang dikirim bukanlah halaman privasi.
Asisten

Ditegakkan oleh build, bukan oleh janji

Asisten di perangkat memakai model yang sudah ada di ponsel Anda. Pertanyaan Anda, data NAS Anda, dan jawabannya tidak pernah meninggalkan perangkat, dan berfungsi dengan jaringan dimatikan.

Bagian yang perlu dinyatakan dengan jelas: ini bukan kebijakan yang harus diingat siapa pun. Pemeriksaan dalam build aplikasi gagal jika host cloud, SDK cloud, atau kunci API muncul di bagian mana pun dari kode asisten. Jaminannya bersifat struktural.

FAQ Privasi

Apakah Syno Manager mengirim data NAS saya ke mana pun?
Tidak. Ponsel Anda terhubung langsung ke NAS Anda. Tidak ada server MiyaraHub di jalur itu, sehingga file, foto, rekaman kamera, log, angka penggunaan, dan konfigurasi Anda tidak pernah sampai ke kami maupun siapa pun.
Apakah ada yang meninggalkan ponsel saya sama sekali?
Satu hal: laporan crash, melalui Firebase Crashlytics - stack trace, model perangkat, dan versi aplikasi. Laporan itu tidak berisi data NAS, kredensial, atau file Anda.
Di mana kredensial NAS saya disimpan?
Di penyimpanan aman platform - Keychain di iOS, penyimpanan berbasis Keystore di Android - tidak pernah dalam teks biasa, dan secara eksplisit dikecualikan dari cadangan cloud Android dan transfer perangkat.
Apakah asisten mengirim pertanyaan saya ke server?
Tidak. Asisten menjalankan model yang sudah ada di perangkat Anda dan berfungsi tanpa jaringan. Build aplikasi gagal jika host cloud, SDK, atau kunci API muncul di bagian mana pun dari asisten.
Apakah ada iklan atau pelacak?
Tidak ada iklan, tidak ada langganan, dan tidak ada pembelian dalam aplikasi.

Ada pertanyaan tentang ini?

Tanyakan di pelacak - bersifat publik, jadi jawabannya juga membantu orang berikutnya.
