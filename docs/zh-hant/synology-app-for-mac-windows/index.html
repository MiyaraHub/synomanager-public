你的 Synology NAS，在桌面上

Syno Manager 是一款獨立的原生 App，可在 macOS 與 Windows 上使用你的 Synology NAS。與手機上是同一個 App，只是配合較大的視窗調整版面：即時讀數、Docker、備份、檔案與 Wake-on-LAN，不必在瀏覽器分頁中開啟 DSM。

Mac

在 macOS 上

Siri 與捷徑的原生支援 ›

「開啟區段」、「重新啟動 NAS」與「關閉 NAS」是透過 App Intents 提供的真正捷徑動作。你可以排程執行，或串接到自己的捷徑中。

Apple Intelligence 助理 ›

在支援並啟用 Apple Intelligence 的裝置上，可用平常說話的方式詢問你的 NAS。模型在 Mac 上執行。

憑證存放在鑰匙圈 ›

DSM 密碼與裝置權杖存放在 macOS 鑰匙圈中，絕不以明文儲存。

Apple 是一次通用購買：買一次 Syno Manager，你的 Mac、iPhone 與 iPad 都能用。

Windows

在 Windows 上

原生另存新檔 ›

透過標準的 Windows 對話框，將 File Station 中的任何檔案直接下載到電腦上的資料夾，在家或透過 QuickConnect 都行。

透過 NAS 喚醒你的電腦 ›

一直開著的 NAS 會從你的網路內部發送魔術封包。指南涵蓋了 Windows 端的設定，包括關閉快速啟動。

備份一目了然 ›

Hyper Backup 工作並顯示它們占用的空間，以及 Active Backup for Business 裝置並顯示去重複後的總量。

Microsoft Store 版本是另外的一次購買 $9.99。

兩者皆有

你在 NAS 上會查看的一切

  • 系統：CPU、RAM、負載、磁碟 I/O 與溫度、風扇模式、DSM 更新檢查、重新啟動與關機。
  • 儲存空間：顯示 RAID 類型的磁碟區與儲存池、每顆硬碟的 SMART 健康狀態與溫度、安全退出。
  • App：套件中心、Docker 容器與 Compose 堆疊、虛擬機器。
  • 網路：每個介面的即時傳輸量、連線、DSM 服務、VPN 設定檔與 DDNS。
  • 多台 NAS：想加幾台都可以，每台都有自己的版面配置與設定。

安裝到你的電腦

每個平台一次性購買 $9.99。沒有廣告、沒有訂閱、沒有 App 內購買。需要執行 DSM 7.0 或更新版本的 Synology NAS。
