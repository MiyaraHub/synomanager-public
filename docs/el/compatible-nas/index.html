Αν τρέχει DSM 7, λειτουργεί

Δεν υπάρχει λίστα μοντέλων να ελέγξετε, επειδή η εφαρμογή δεν χρησιμοποιεί καμία. Ρωτά το NAS σας τι μπορεί να κάνει όταν συνδεθεί και χτίζεται γύρω από την απάντηση.

Ο κανόνας

Μία απαίτηση, και μετά προσαρμόζεται

ΑπαίτησηΛεπτομέρεια
Έκδοση DSMDSM 7.0 ή νεότερο. Αυτή είναι η μοναδική σκληρή απαίτηση.
ΜοντέλοΟποιοδήποτε. DiskStation, RackStation, FlashStation, με ή χωρίς μονάδες επέκτασης.
Θέσεις δίσκωνΟποιεσδήποτε. Ένας δίσκος ή είκοσι τέσσερις· η εφαρμογή απαριθμεί ό,τι αναφέρει το DSM.
ΑρχιτεκτονικήΟποιαδήποτε. Η εφαρμογή μιλά με το API του DSM, όχι με το υλικό.
Η συσκευή σαςAndroid 7.0, iOS 16.0, macOS 11.0 ή Windows - η εφαρμογή διατίθεται και στα τέσσερα καταστήματα.
Το DSM 6 δεν υποστηρίζεται. Χρησιμοποιεί διαφορετικές εκδόσεις API και διαφορετική συμπεριφορά ταυτοποίησης, και η υποστήριξη και των δύο θα σήμαινε να μαντεύουμε ποια μιλά το NAS. Το μάντεμα είναι ακριβώς αυτό που αποφεύγει αυτή η εφαρμογή.
Γιατί δεν υπάρχει πίνακας

Ανακάλυψη, όχι σκληρά κωδικοποιημένη λίστα

Ένας πίνακας υποστήριξης ανά μοντέλο θα ήταν λάθος από τη μέρα που η Synology θα κυκλοφορούσε ένα νέο μοντέλο, και πάλι λάθος τη μέρα που κάποιο από αυτά θα αποκτούσε ένα πακέτο.

  • Η εφαρμογή ρωτά τον κατάλογο API του DSM κατά τη σύνδεση και κρατά την απάντηση. Αυτός ο κατάλογος είναι η απόλυτη αλήθεια για το τι μπορεί να κάνει το NAS σας.
  • Οι οθόνες εμφανίζονται επειδή το NAS σας ανέφερε το API πίσω από αυτές. Εγκαταστήστε το Surveillance Station και εμφανίζεται μια προβολή Καμερών. Απεγκαταστήστε το και η προβολή φεύγει.
  • Τίποτα δεν υποτίθεται από το όνομα του μοντέλου. Δύο πανομοιότυπα μοντέλα με διαφορετικά πακέτα παίρνουν διαφορετική εφαρμογή, κάτι που είναι σωστό.
  • Μια τιμή που το NAS δεν ανέφερε ονομάζεται μη αναγνωσμένη, ποτέ δεν συμπληρώνεται με μια εύλογη προεπιλογή.

Η πρακτική εκδοχή: αν η ίδια η διαδικτυακή διεπαφή του DSM λειτουργεί από το πρόγραμμα περιήγησης του κινητού σας, και ο λογαριασμός σας στο DSM βλέπει κάτι εκεί, το Syno Manager μπορεί να το δει κι αυτό.

Ποιες οθόνες παίρνετε

Η διαφορά ανάμεσα σε ένα DiskStation δύο θέσεων και ένα rackmount δεν είναι πόσο καλά λειτουργεί η εφαρμογή - είναι πόσες υπηρεσίες τρέχει το NAS.

Σύστημα, Αποθήκευση, ΔίκτυοΠάντα. Κάθε NAS με DSM 7 τα αναφέρει.
Docker, ProjectsΕίναι εγκατεστημένο το Container Manager. Δεν είναι διαθέσιμο σε κάθε μοντέλο.
Εικονικές μηχανέςΕίναι εγκατεστημένο το Virtual Machine Manager - που απαιτεί μοντέλο που το υποστηρίζει.

Photos, Drive, Office, Notes, ContactsΚαθεμία εμφανίζεται όταν είναι εγκατεστημένο το δικό της πακέτο.

Backup, Active BackupHyper Backup και Active Backup for Business αντίστοιχα.
UPS / ΙσχύςΕίναι συνδεδεμένο ένα UPS και η υποστήριξη UPS είναι ενεργή στο DSM.

Συχνές ερωτήσεις

Συχνές ερωτήσεις συμβατότητας

Ποια μοντέλα Synology υποστηρίζει το Syno Manager;
Κάθε Synology NAS που τρέχει DSM 7.0 ή νεότερο - DiskStation, RackStation και FlashStation, με ή χωρίς μονάδες επέκτασης. Δεν υπάρχει λίστα ανά μοντέλο, επειδή η εφαρμογή ρωτά το NAS σας τι μπορεί να κάνει όταν συνδεθεί.
Λειτουργεί με DSM 6;
Όχι. Απαιτείται DSM 7.0 ή νεότερο. Το DSM 6 χρησιμοποιεί διαφορετικές εκδόσεις API και διαφορετική συμπεριφορά ταυτοποίησης.
Θα λειτουργήσει σε ένα μικρό NAS δύο θέσεων;
Ναι. Δείχνει λιγότερες οθόνες επειδή τρέχει λιγότερες υπηρεσίες, όχι επειδή δεν υποστηρίζεται. Ό,τι τρέχει εμφανίζεται πλήρως.
Υποστηρίζει μονάδες επέκτασης;
Ναι. Οι δίσκοι μιας μονάδας επέκτασης εμφανίζονται δίπλα στους εσωτερικούς.
Τι γίνεται αν το NAS μου τρέχει beta DSM;
Γενικά θα λειτουργεί, αφού η εφαρμογή διαβάζει τον κατάλογο API αντί να υποθέτει έκδοση. Μια beta που αλλάζει ένα API μπορεί να παράγει μια τιμή που η εφαρμογή αναφέρει ως μη αναγνωσμένη - κάτι που θα το πει, αντί να δείξει λάθος αριθμό.
