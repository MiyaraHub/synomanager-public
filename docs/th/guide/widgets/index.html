วิดเจ็ต

NAS ของคุณบนหน้าจอหลัก

สิบสองวิดเจ็ตทั้งบน Android และ iOS แต่ละอันมีตัวอย่างของตัวเองในตัวเลือก และแต่ละอันบอกว่าตัวเลขถูกวัดเมื่อไร ซึ่งปรากฏว่าสำคัญกว่าตัวเลขเอง

ทั้งสิบสอง

แต่ละวิดเจ็ตแสดงอะไร

เก้าอันเข้ามาเสริมสามอันแรก ได้แก่ สถานะระบบ ภาพรวมพื้นที่จัดเก็บ และการดำเนินการด่วน ทุกอันมีตัวอย่างในตัวเลือกวิดเจ็ตของตัวเรียกใช้ คุณจึงเห็นหน้าตาคร่าว ๆ ก่อนวาง

วิดเจ็ตแสดงต้องมี
สถานะระบบสุขภาพของ NAS ในพริบตา - สถานะของเครื่องโดยไม่ต้องเปิดอะไร-
ภาพรวมพื้นที่จัดเก็บการใช้งานวอลุ่ม เพื่อให้เห็นวอลุ่มที่กำลังเต็มจากตัวเรียกใช้-
การดำเนินการด่วนตรงเข้าสู่หน้าจอที่คุณใช้บ่อย โดยไม่ต้องผ่านหน้าจอหลักก่อน-
สุขภาพ NASมีอะไรผิดปกติหรือไม่ และคืออะไร-
สำรองข้อมูลการสำรองข้อมูลครั้งล่าสุดและครั้งถัดไป และความล้มเหลวใด ๆตั้งค่างานสำรองข้อมูลไว้
อุณหภูมิและพัดลมอุณหภูมิระบบพร้อมโหมดพัดลม-
Dockerคอนเทนเนอร์ที่กำลังทำงานพร้อมชื่อContainer Manager
กล้องกล้องที่ออนไลน์Surveillance Station
Networkทราฟฟิกสดบนอินเทอร์เฟซที่ยุ่งที่สุด-
UPSประจุ UPS และเวลาทำงานโดยประมาณมี UPS เชื่อมต่ออยู่
ดาวน์โหลดดาวน์โหลดที่กำลังทำงานและความเร็วDownload Station
วอลุ่มการใช้งานของทุกวอลุ่ม-
วิดเจ็ตสำหรับบริการที่ NAS ของคุณไม่ได้รันจะไม่ถูกเสนอ Docker กล้อง การสำรองข้อมูล UPS ดาวน์โหลด และวอลุ่ม จะปรากฏในตัวเลือกเมื่อแอปเห็น NAS รายงานความสามารถนั้นแล้วเท่านั้น เป็นกฎเดียวกับที่การ์ดแดชบอร์ดใช้ นำมาใช้กับตัวเรียกใช้

บน Android ทุกวิดเจ็ตปรับขนาดได้ทั้งสองทาง กว้างขึ้นหรือสูงขึ้น และเลือกเลย์เอาต์ที่เหมาะกับพื้นที่ที่คุณให้ ทั้งสิบสองอันอยู่ใต้ Syno Manager ในตัวเลือกวิดเจ็ตของตัวเรียกใช้

ไม่มีภาพหน้าจอตัวเลือกในหน้านี้ ตัวเลือกจะแสดงผลเมื่อมีวิดเจ็ตอยู่บนหน้าจอหลักจริงเท่านั้น และทุกอุปกรณ์ที่เว็บไซต์นี้ถ่ายภาพเป็นโทรศัพท์ที่มีคนใช้งานจริง ไม่ใช่เครื่องสำรองที่ตั้งไว้เพื่อจัดใหม่ถ่ายภาพหน้าจอ
การเพิ่มวิดเจ็ต

วิธีวางวิดเจ็ต

Android

  1. กดค้างที่ส่วนว่างของหน้าจอหลัก
  2. แตะวิดเจ็ต
  3. หา Syno Managerในรายการ
  4. ลากวิดเจ็ตที่ต้องการมาวางบนหน้าจอหลักและปรับขนาด

iOS

  1. กดค้างที่หน้าจอหลักจนไอคอนสั่น
  2. แตะเครื่องหมายบวกที่ด้านบน
  3. ค้นหา Syno Manager
  4. เลือกขนาดแล้วแตะเพิ่มวิดเจ็ต
ส่วนสำคัญ

ทำไมทุกวิดเจ็ตมีเวลากำกับ

วิดเจ็ตรีเฟรชเมื่อระบบปฏิบัติการอนุญาตเท่านั้น ทั้ง Android และ iOS จำกัดการอัปเดตวิดเจ็ตอย่างเข้มงวดเพื่อประหยัดแบตเตอรี่ ตัวเลขบนหน้าจอหลักจึงอาจเก่ากว่าที่ดูหลายชั่วโมง และค่าเก่าที่ดูเหมือนปัจจุบันแย่กว่าไม่มีค่าเลย

ข้อความที่ขึ้นความหมาย
เมื่อสักครู่อ่านภายในหนึ่งนาทีที่ผ่านมา
12m ที่แล้วเก่าไม่ถึงหนึ่งชั่วโมง นับเป็นนาที
5 ชม.ที่แล้วเก่าไม่ถึงหนึ่งวัน นับเป็นชั่วโมง
2 วันที่แล้วหนึ่งวันขึ้นไป ถือเป็นข้อมูลในอดีต
ยังไม่เคยอัปเดตยังอ่านค่าสำเร็จไม่ได้ - เพิ่งเพิ่ม หรือแอปยังไม่ได้ทำงานตั้งแต่นั้น ไม่แสดงเป็นศูนย์ เพราะศูนย์จะถูกอ่านเป็นค่าที่วัดได้
สิ่งที่เก่ากว่าหกชั่วโมงถือว่าล้าสมัยและถูกทำเครื่องหมายไว้ แทนที่จะนำเสนอเป็นสถานะปัจจุบันของ NAS ของคุณ

ความต่างที่รักษาไว้นี้เป็นเรื่องจริง: NAS ที่เงียบกับวิดเจ็ตที่ล้าสมัยดูเหมือนกันหากไม่มีเวลากำกับ “CPU 4% วัดเมื่อ 3 นาทีที่แล้ว” กับ “CPU 4% วัดเมื่อวาน” เป็นข้อเท็จจริงคนละอย่าง และมีเพียงอย่างเดียวที่ควรลงมือ

ทำให้ทันสมัยอยู่เสมอ

หากวิดเจ็ตไม่รีเฟรช

  • เปิดแอป วิธีรีเฟรชที่แน่นอนที่สุดคือให้แอปทำงานและอ่าน NAS
  • ตรวจสอบการเพิ่มประสิทธิภาพแบตเตอรี่บน Android แอปที่ถูกจำกัดเบื้องหลังจะได้รีเฟรชวิดเจ็ตน้อยลง การยกเว้น Syno Manager จากการเพิ่มประสิทธิภาพช่วยได้
  • ตรวจสอบการรีเฟรชแอปเบื้องหลังบน iOS การตั้งค่า แล้วเลือกแอป - หากปิดอยู่ iOS จะปลุกวิดเจ็ตน้อยมาก
  • อย่าลืมว่า NAS ต้องเข้าถึงได้ วิดเจ็ตอ่าน NAS ที่โทรศัพท์เข้าถึงไม่ได้ไม่ได้ บนเน็ตมือถือกับรายการที่ใช้ IP ในเครือข่ายอย่างเดียว วิดเจ็ตจะไม่อัปเดตจนกว่าคุณจะถึงบ้าน
ทั้งสองแพลตฟอร์มไม่รับประกันช่วงเวลารีเฟรช ไม่มีแอปใดบังคับได้ ซึ่งเป็นเหตุผลที่มีเวลากำกับแทนคำสัญญา

คำถามที่พบบ่อยเกี่ยวกับวิดเจ็ต

Syno Manager มีวิดเจ็ตอะไรบ้าง
สิบสองอัน: สถานะระบบ ภาพรวมพื้นที่จัดเก็บ การดำเนินการด่วน สุขภาพ NAS การสำรองข้อมูล อุณหภูมิและพัดลม Docker กล้อง เครือข่าย UPS ดาวน์โหลด และวอลุ่ม ทั้งสิบสองมีให้ใช้บน Android และ iOS แต่ละอันมีตัวอย่างในตัวเลือกวิดเจ็ต
ทำไมวิดเจ็ตของฉันแสดงตัวเลขเก่า
เพราะระบบปฏิบัติการเป็นผู้ตัดสินว่าวิดเจ็ตรีเฟรชได้เมื่อไร ไม่ใช่แอป ด้วยเหตุนี้แต่ละวิดเจ็ตจึงแสดงเวลาที่จับข้อมูล เพื่อให้ค่าเก่าดูเก่า ไม่ใช่ดูเหมือนปัจจุบัน
“ยังไม่เคยอัปเดต” หมายความว่าอะไร
หมายความว่าวิดเจ็ตยังอ่านค่าสำเร็จไม่ได้ มักเพราะเพิ่งเพิ่ม หรือยังไม่ได้เปิดแอปตั้งแต่นั้น จึงแสดงเป็น “ยังไม่เคยอัปเดต” แทนที่จะเป็นศูนย์
เพิ่มวิดเจ็ตอย่างไร
บน Android กดค้างที่หน้าจอหลัก เลือกวิดเจ็ต หา Syno Manager แล้วลากมาวางหนึ่งอัน บน iOS กดค้างที่หน้าจอหลัก แตะเครื่องหมายบวก ค้นหา Syno Manager แล้วเลือกขนาด
