데스크톱에서 만나는 Synology NAS

Syno Manager는 macOS와 Windows에서 Synology NAS를 위한 독립적인 네이티브 앱입니다. 휴대폰과 같은 앱을 더 큰 창에 맞게 구성했으며, 브라우저 탭에서 DSM을 열지 않고도 실시간 수치, Docker, 백업, 파일, Wake-on-LAN을 사용할 수 있습니다.

Mac

macOS에서

Siri와 단축어를 기본 기능처럼 ›

섹션 열기, NAS 재시작, NAS 종료는 App Intents를 통한 실제 단축어 동작입니다. 일정에 맞춰 실행하거나 나만의 단축어에 이어 붙일 수 있습니다.

Apple Intelligence 어시스턴트 ›

Apple Intelligence가 지원되고 켜져 있다면 NAS에 대해 쉬운 말로 물어보세요. 모델은 Mac에서 실행됩니다.

키체인에 보관되는 자격 증명 ›

DSM 비밀번호와 기기 토큰은 macOS 키체인에 보관되며 일반 텍스트로 저장되지 않습니다.

Apple은 하나의 유니버설 구매입니다. Syno Manager를 한 번 구매하면 Mac, iPhone, iPad에서 모두 사용할 수 있습니다.

NAS를 통해 PC 깨우기 ›

항상 켜져 있는 NAS가 네트워크 안에서 매직 패킷을 보냅니다. 빠른 시작을 끄는 방법을 포함해 Windows 쪽 설정은 가이드에서 다룹니다.

한눈에 보는 백업 ›

차지하는 공간이 표시되는 Hyper Backup 작업과, 중복 제거 합계가 표시되는 Active Backup for Business 기기.

Microsoft Store 버전은 별도의 $9.99 구매입니다.

공통 기능

NAS에서 확인하는 모든 것

  • 시스템: CPU, RAM, 부하, 디스크 I/O, 온도, 팬 모드, DSM 업데이트 확인, 재시작 및 종료.
  • 스토리지: RAID 유형이 표시되는 볼륨과 풀, 드라이브별 SMART 상태와 온도, 안전 제거.
  • 앱: 패키지 센터, Docker 컨테이너와 Compose 스택, 가상 머신.
  • 네트워크: 인터페이스별 실시간 처리량, 연결, DSM 서비스, VPN 프로필, DDNS.
  • 여러 대의 NAS: 원하는 만큼 추가할 수 있으며 NAS마다 레이아웃과 설정이 따로 저장됩니다.
