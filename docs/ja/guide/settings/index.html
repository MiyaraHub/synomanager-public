NAS接続

デバイスと起動

  • NASデバイスの管理 - 追加、編集、並べ替え、名前の変更、切り替え。複数のNASデバイスもご覧ください。
  • デバイスのWake - NAS経由で起動できる、ネットワーク上の他のマシン。Wake-on-LANもご覧ください。
設定へは2通りの方法で移動できます。ホーム画面の歯車アイコン、またはコントロールパネルタブの最後のサブビューです。
外観

テーマ & カラー

上部にはライブプレビューがあり、アクセントとサーフェスが即座に反映されます。サンプルボタンで、確定前にボタンの見た目も確認できます。

設定オプションできること
明るさ自動 / ライト / ダーク自動はデバイス自体のライト／ダーク設定に従います。
サーフェスライト / ダーク / AMOLED背景の正確なスタイル。AMOLEDは純黒で、OLED画面ではその部分の画素が完全に消灯します。バッテリーへの負担が目に見えて減り、午前2時の目にもやさしくなります。
文字サイズ小 / デフォルト / 大アプリ内の文字をスケールします。システムのフォントサイズ設定とは独立しているので、他の場所は大きな文字、ここだけコンパクト、あるいはその逆も可能です。
アクセントカラーブルー、シアン、パープル、グリーン、アンバー、ピンク、カスタムシード色にとどまらず、アプリ全体に反映されます。ボタン、ハイライト、カードの枠線、各種UIがすべて連動します。カスタムでは、好きな色を選べるピッカーが開きます。
カスタムカラーをクリア-ブルーのアクセントに戻します。
明るさとサーフェスは、あえて2つの設定に分けています。一方がアプリをライトにするかダークにするかを決め、もう一方がどのダークにするかを決めます。これにより「スマートフォンに合わせつつ、ダークになったら純黒にする」という使い方ができます。
アクセントカラー

同じNASを、6通りで

アクセントはボタンの色味だけではありません。カードの枠線、アイコン、セクションの見出し、ブランドライン、ボトムバーにまで反映されるので、1つ選ぶとコントロール1つではなくアプリ全体が変わります。同じホーム画面を、名前付きの各アクセントで並べました。

好きな色も選べます。カスタムではカラーピッカーが開くので、アクセントを6色に限る必要はありません。カスタムカラーをクリアでブルーに戻ります。
ステータスの色はアクセントに連動しません。これは意図的な仕様です。正常は緑、警告はアンバー、問題は赤というルールは、どのアクセントを選んでも変わりません。テーマで色が変わってしまっては、健全性のシグナルとして役に立たなくなるからです。上のスクリーンショットでも、ボリュームバーは6枚すべてで緑、アンバーの画面ではCPUのスパイクを捉えたのでゲージが赤になっています。

ダッシュボードのカテゴリ

すべてのダッシュボードカードをスイッチ付きで並べ、オンの数も表示する一覧です。ホーム画面の編集モードと同じカードが、ダッシュボードをスクロールせずにまとめて確認したいときのために、リストとして表示されます。

  • NASが対応するすべてのカードがここに表示され、デフォルトではオンになっています。
  • ドラッグして並べ替えられます。順序はホーム画面と共通です。
  • お持ちでないパッケージのカードは表示されません。裏付けとなるものがないためです。

ナビゲーションのカスタマイズ

ボトムバーに2〜9個の項目を選びます。リストの上にバー自体のライブプレビューが表示されるので、ラベルが収まるか確認できます。

  • 選択済み - ドラッグで並べ替え、赤いマイナスをタップで削除。ホームは固定で、常に先頭です。
  • 利用可能 - それ以外のすべて。チェックボックスで追加できます。
  • バーにない項目は「その他」にまとまります。削除しても、到達できなくなる項目はありません。
  • リセットでデフォルトに戻し、保存で選択内容を反映します。
NASが対応しているタブのみ表示されます。Surveillance Stationがないと、メディアのカメラビューは表示されません。空になるタブを固定してしまうことはありません。

起動時の動作

複数のNASを登録している場合に、アプリを完全に終了した状態から起動したときの画面です。

オプションコールドスタート時の動作
常にNAS選択画面を表示デバイス選択画面が開き、開くNASを選べます。
最後に使ったNAS最後に切り替えたNASを自動的に選択します。
特定のNAS最後に使ったNASに関係なく、常に同じNASを開きます。
NASが1台だけの場合、この設定は何も行わず、その旨が表示されます。2台以上で初めて有効になることを画面でお知らせし、効果のない設定を黙って受け付けることはありません。スクリーンショットで選択肢がグレーアウトしているのはそのためです。

デフォルトのカード表示

カードが前回の状態を記憶するかどうかを設定します。

オプション動作
前回の表示を記憶各カードが前回終了時のまま開きます。展開・折りたたみの状態は起動をまたいで保持されます。デフォルトの設定です。
常に展開起動のたびに、すべてのカードが開いた状態で始まります。
常に折りたたみすべてのカードが折りたたまれた状態で始まるので、コンパクトに全体を見渡し、必要に応じて展開できます。
「常に折りたたみ」は、カードが多いNASでぜひお試しください。折りたたまれた行にもステータスのアイコンが表示されるので、すべて折りたたんだダッシュボードが1画面のステータスボードになります。
外観

28言語

設定から言語を開きます。先頭のシステムのデフォルトはスマートフォンの設定に従い、その下に対応するすべての言語が、その言語自身の表記（GermanではなくDeutsch）で並びます。英語が先頭で、残りは五十音順ではなくアルファベット順です。

  • 28言語：アラビア語、中国語（簡体字・繁体字）、チェコ語、デンマーク語、オランダ語、英語、フィンランド語、フランス語、ドイツ語、ギリシャ語、ヘブライ語、ヒンディー語、ハンガリー語、インドネシア語、イタリア語、日本語、韓国語、ノルウェー語、ポーランド語、ポルトガル語（ブラジル）、ルーマニア語、ロシア語、スペイン語、スウェーデン語、タイ語、トルコ語、ウクライナ語、ベトナム語。
  • Synology公式の用語を採用。パッケージ、ステータス、DSMの用語は、その言語のSynology公式Webインターフェースで使われている言葉に合わせており、汎用的に訳し直したものではありません。
  • すぐに反映されます。アプリ内のどこでも、再起動は不要です。
システムに従うか、固定するか。「システムのデフォルト」のままなら、スマートフォンの言語設定に合わせて変わります。特定の言語を選べば、あとからスマートフォンの言語を変えてもそのままです。
環境設定

ポーリング、温度、バックアップ

設定できること
ポーリング間隔リアルタイムの値を更新する頻度です。システムの値には選んだ間隔が使われ、ストレージにはより長い間隔が使われます。ボリュームの使用量は5秒ごとに変わるものではなく、問い合わせるとバッテリーを消費するためです。間隔を短くするとチャートが細かくなり、消費電力は増えます。
温度の単位°Cまたは°F。ホーム画面、システムチャート、ドライブ一覧、ウィジェットのすべてに即座に反映されます。
バックアップ&復元アプリ自体の設定をファイルに書き出し、別のデバイスで復元できます。バックアップ & 復元もご覧ください。
バックグラウンドではポーリングが停止します。どの間隔を選んでも、画面に表示されていないときにアプリがバッテリーを消耗することはありません。
ヘルプ

説明カード

いくつかの画面には、そのビューでできること・できないことを説明する短いカードがあります。ライブビューのストリーミングのしくみ、リモートWake-on-LANの動作、システムパネルの表示内容などです。最初は便利でも、そのあとは邪魔になります。

  • ヘルプカードを表示 - すべてを切り替えるマスタースイッチです。
  • カードをタップすると展開し、Xをタップすると閉じます。長押しでも閉じられます。
  • 非表示のヘルプカードには閉じたカードがすべて表示され、カードごとの復元とすべて復元が使えます。一度閉じても、元に戻せないことはありません。

よくある質問

設定のよくある質問

アプリのアクセントカラーを変更できますか？
はい。「テーマとカラー」にはブルー、シアン、パープル、グリーン、アンバー、ピンクの6つのアクセントと、好きな色を選べる「カスタム」があります。アクセントはアプリ全体に反映され、変更の様子はライブプレビューで確認できます。
OLED画面向けの純黒モードはありますか？
はい。サーフェスにはライト、ダーク、AMOLEDがあり、AMOLEDは純黒です。明るさとサーフェスは別々の設定なので、ライト／ダークはシステムに合わせたまま、背景のスタイルだけを固定できます。
アプリはNASをどのくらいの頻度で確認しますか？
設定したポーリング間隔に従います。システムの値にはその間隔が使われ、ストレージにはより長い間隔が使われます。アプリがバックグラウンドにあるときは、ポーリングが完全に停止します。
よく使う画面をボトムバーに置けますか？
はい。「ナビゲーションのカスタマイズ」で2〜9個の項目を選び、ドラッグして並べ替えられます。ライブプレビュー付きです。ホームは常に先頭で、削除できません。
華氏に切り替えられますか？
はい。「温度の単位」で変更でき、ウィジェットを含め、アプリ内のすべての温度が即座に切り替わります。
Syno Manager は何語に対応していますか？
28言語から選べるほか、デバイスの言語にも合わせられます。設定の「言語」には、先頭に「システムのデフォルト」、続いて対応するすべての言語が、その言語自身の表記で並びます。Synologyの画面、パッケージ、ステータスにはSynologyのDSMで使われている用語を採用しています。
設定はすべてのNASデバイスに適用されますか？
外観と環境設定はアプリ全体に適用されます。ダッシュボードのレイアウト、カードの順序、折りたたみ状態はNASごとなので、各デバイスは設定したとおりの状態で開きます。
