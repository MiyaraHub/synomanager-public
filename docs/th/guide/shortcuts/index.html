ตรงไปที่หน้าจอที่คุณต้องการ

Syno Manager ลงทะเบียนรูปแบบ URL synomanager:// วลี Siri ทางลัดตัวเรียกใช้ หรือแอปอัตโนมัติจึงเปิดแอปตรงจุดที่ต้องการ แทนที่จะเปิดที่หน้าจอหลัก บน Mac นั้น Siri และแอป Shortcuts มองเห็น Syno Manager โดยตรง โดยไม่ต้องพิมพ์ URL เลย

ทุกทางลัด

ลิงก์เปิด
synomanager://dashboardหน้าจอหลัก
synomanager://storageStorage - วอลุ่ม สุขภาพดิสก์ ภายนอก
synomanager://systemSystem - สุขภาพ ทรัพยากร บันทึก
synomanager://networkNetwork - ปริมาณข้อมูล การเชื่อมต่อ บริการ VPN DDNS

synomanager://backupBackup - Hyper Backup และ Active Backup
synomanager://filesFiles - File Station และโฟลเดอร์ที่แชร์
synomanager://wakeหน้าจอปลุกอุปกรณ์
synomanager://rebootตัวควบคุมพลังงาน เปิดเท่านั้น - ดูด้านล่าง
synomanager://shutdownตัวควบคุมพลังงาน เปิดเท่านั้น - ดูด้านล่าง
ข้อจำกัดที่ตั้งใจ

ทำไมรีบูตและปิดเครื่องจึงเพียงเปิดแอป

ลิงก์พาคุณไปที่ตัวควบคุมพลังงาน ไม่ได้รีสตาร์ทหรือปิดอะไรด้วยตัวเอง

ทางลัดเป็นสิ่งที่กดพลาดได้ ไม่ว่าจะเป็นแตะไอคอนผิด ฟังวลีเสียงผิด หรือระบบอัตโนมัติที่ทำงานผิดตัวกระตุ้น การรีสตาร์ท NAS ตัดการเชื่อมต่อของทุกคนที่ใช้อยู่และขัดจังหวะงานที่กำลังทำ สองข้อนี้ไม่ควรมาด้วยกัน ลิงก์จึงหยุดที่หน้าจอ และการยืนยันตามปกติยังคงใช้อยู่

ลิงก์อื่นทั้งหมดปลอดภัยโดยธรรมชาติ เพราะทำแค่แสดงบางอย่างให้คุณดู ด้วยเหตุนี้ลิงก์ที่เหลือจึงแตะเดียว ส่วนสองลิงก์นี้ไม่ใช่
การใช้งาน

บนแต่ละแพลตฟอร์ม

iOS - Siri และ Shortcuts

  1. เปิด Shortcuts แล้วสร้างทางลัดใหม่
  2. เพิ่มการทำงาน เปิด URL
  3. ใส่ลิงก์ เช่น synomanager://storage
  4. ตั้งชื่อที่คุณพูดออกเสียงได้ เช่น “ตรวจสอบพื้นที่จัดเก็บ NAS ของฉัน”
  5. เพิ่มลงหน้าจอหลัก หรือแค่ถาม Siri

Android - ตัวเรียกใช้และระบบอัตโนมัติ

  1. ตัวเรียกใช้ส่วนใหญ่วางทางลัดที่เปิด URL ได้
  2. แอปอัตโนมัติ เช่น Tasker, MacroDroid และอื่น ๆ เปิดลิงก์ได้จากตัวกระตุ้นใดก็ได้
  3. ลิงก์ <a href="synomanager://system"> ในโน้ตหรือหน้าเว็บก็ใช้ได้เช่นกัน
NAS เครื่องไหนที่เปิดเป็นไปตามการตั้งค่าพฤติกรรมการเปิดแอปของคุณ ทางลัดเลือกหน้าจอ ไม่ใช่อุปกรณ์ ดังนั้นเมื่อตั้งเป็น “NAS ที่ใช้ล่าสุด” synomanager://storage จะแสดงพื้นที่จัดเก็บของเครื่องที่คุณใช้ล่าสุด
macOS

Siri และ Shortcuts โดยตรง

บน Mac, Syno Manager ไม่ต้องใช้ URL เลย แอปลงทะเบียนสามการทำงานโดยตรงกับ App Intents ของ Apple ทำให้ Siri และแอป Shortcuts มอง Syno Manager เป็นแอปที่มีคำศัพท์ของตัวเอง เหมือนที่มองแอปของ Apple เอง

การทำงานทำอะไรได้พูดกับ Siri
เปิดส่วนหนึ่งเปิด Syno Manager ที่ส่วนที่คุณเลือก - Dashboard, Storage, System, Network, Apps, Backup, Files หรือ Wake“เปิด Syno Manager”
รีสตาร์ท NASขอให้คุณยืนยัน จากนั้นเปิดแอปที่ตัวควบคุมพลังงาน ไม่มีอะไรถูกส่งไปยัง NAS จนกว่าคุณจะยืนยันอีกครั้งที่นั่น“รีสตาร์ท NAS ของฉันด้วย Syno Manager”
ปิด NASรูปแบบเดียวกับรีสตาร์ท คือยืนยันกับ Siri หรือ Shortcuts จากนั้นแอปเปิดที่ตัวควบคุมพลังงาน“ปิด NAS ของฉันด้วย Syno Manager”
รีสตาร์ทและปิดเครื่องยังคงยืนยันสองครั้ง Siri หรือ Shortcuts ถามก่อนว่า “เปิด Syno Manager เพื่อรีสตาร์ท NAS หรือไม่ ยังไม่มีอะไรถูกส่งไปยัง NAS - คุณยืนยันในแอป” จากนั้นตัวควบคุมพลังงานของแอปถามอีกครั้ง คำสั่งเสียงที่รีบูต NAS เพียงเพราะฟังคำแรกผิดไม่ใช่ฟีเจอร์ที่ควรมี

สร้างระบบอัตโนมัติของคุณเองต่อยอดจากสิ่งเหล่านี้ เพราะเป็นการทำงานของ Shortcuts ตามปกติ เปิดส่วนหนึ่งจึงใส่ในทางลัดใดก็ได้ที่คุณสร้าง เช่น รันตามกำหนดเวลา เรียกจาก Home Hub หรือต่อหลังสิ่งอื่น เหมือนการทำงานจากแอป Mac อื่นทุกประการ

คำถามที่พบบ่อย

คำถามที่พบบ่อยเกี่ยวกับทางลัด

Syno Manager มีรูปแบบ URL ไหม
มี synomanager://<name> เปิดแอปที่หน้าจอที่ระบุ แดชบอร์ด storage system network apps backup files และ wake ต่างมีลิงก์ของตัวเอง
ทางลัดรีสตาร์ท NAS ในแตะเดียวได้ไหม
ไม่ได้ และตั้งใจ ลิงก์รีบูตและปิดเครื่องเพียงเปิดแอปที่ตัวควบคุมพลังงาน ซึ่งมีการยืนยันตามปกติ
ใช้กับ Siri ได้ไหม
ได้ สร้างทางลัดในแอป Shortcuts ของ Apple ที่เปิด URL ตั้งวลีให้ แล้ว Siri จะพาคุณไปที่นั่นทันที
ทางลัดเลือก NAS เครื่องใดเครื่องหนึ่งได้ไหม
ไม่ได้ ทางลัดเปิดหน้าจอ ส่วน NAS เครื่องไหนนั้นเป็นไปตามการตั้งค่าพฤติกรรมการเปิดแอปของคุณ
Syno Manager ใช้กับแอป Shortcuts บน Mac ได้ไหม
ได้ โดยตรง เปิดส่วนหนึ่ง รีสตาร์ท NAS และปิด NAS ปรากฏเป็นการทำงานของ Syno Manager ในแอป Shortcuts ของ Apple บน macOS โดยไม่ต้องพิมพ์ URL สองการทำงานด้านพลังงานขอให้ Siri หรือ Shortcuts ยืนยันก่อนทำอะไร จากนั้นเพียงเปิดแอปที่ตัวควบคุมพลังงาน
