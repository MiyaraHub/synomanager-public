システム

NASが実際に何をしているか

3つのサブビュー：マシンの状態を確認するシステムヘルス、リアルタイムチャートのリソース、DSMが記録した内容を確認するログ。さらに、ファンモード、識別ライト、DSMのアップデート、再起動、シャットダウンなど、実際に何かを変える操作も備えています。

システムの状態

測定値

カード表示内容
CPU & RAMのゲージCPU全体をリングで表示し、その下にユーザーの割合も表示するので、自分のワークロードとシステムのオーバーヘッドを区別できます。RAMはパーセンテージと実際の数値を表示します。
メモリ使用量を合計に対するバーで表示します。問題になるまでは緑です。
CPU負荷平均1分、5分、15分の値で、CPU時間を待っているプロセスの数であり、パーセンテージではありません。コア数と照らして判断するため、8コアのラックマウント機では健全な値が、2ベイ機では高負荷になります。
ディスクI/O読み取りと書き込みのスループットと使用率のパーセンテージ。ディスクがどれだけの時間ビジー状態だったかを示し、CPUは空いているのにNASが遅く感じられるときの本当の原因であることがよくあります。
温度履歴現在の値付きの推移チャート。設定に従い、°Cまたは°Fで表示されます。
プロセスNASで実行中のプロセスの数です。
冷却

スマートフォンから変更できるファン速度モード

冷却カードには、ファンの状態とNASの現在のモードが3段階の切り替えで表示されます。

  • フルスピード - 最大の風量で、騒音も最大。ラックや戸棚の中に向いています。
  • クール - バランスの取れたデフォルトです。
  • 静音 - 速度を抑え、温度は高め。ドライブが耐えられるなら、リビングに置くNASに向いています。
想定ではなく確認します。アプリはNASから現在のモードを読み取り、選択内容を書き込んだあと、読み戻します。NASが黙って拒否したモードは、適用されたように画面に残るのではなく、拒否されたと報告されます。
認識できないモードは読み取り専用のままです。この3つ以外の冷却モードをNASが報告した場合、カードは報告された内容を表示するだけで変更は提示しません。知っている3つのどれかに誤って当てはめることはありません。
識別 & アラート

NASを見つけて、ブザーを止める

  • 識別はNASのステータスランプを点滅させるので、目の前にあるのがどのNASかわかります。停止で終了します。
  • ビープ音を消すはアラームのブザーを止めます。止まるのは音であって、状態ではありません。アラームを鳴らした原因は残ったままで、ヘルスのヘッダーにもそのとおり表示されます。
DSMのアップデート

ファームウェアのアップデートはあるか

DSMアップデートカードには、現在のバージョンと、Synologyから新しいものが出ているかどうかが表示されます。アップデートを確認でNASにもう一度確認させます。

これはNASのファームウェアであり、アプリではありません。Syno Manager は、他のアプリと同じくApp StoreまたはGoogle Playから更新します。このカードはDSM自身のアップデート画面で、コントロールパネルにあるものと同じです。
電源コントロール

再起動とシャットダウン

システムヘルスの下部にあり、赤で示されています。ファイルのコピー中のユーザーを含め、接続中のすべてのユーザーに影響するためです。

  • NASを再起動 - 正常な再起動です。実行前に確認が表示されます。
  • NASをシャットダウン - 正常な電源オフです。実行前に確認が表示されます。
リモートでのシャットダウンは慎重に。電源が切れたNASは、自分のWakeパケットを中継できません。ネットワークの外から復帰させるには、NASへのVPN接続か、Wake-on-LANを転送するよう設定したルーターが必要です。どこから何ができるかはWake-on-LANをご覧ください。
ショートカットでも確認は省略されません。synomanager://rebootとsynomanager://shutdownのリンクは、意図的にこの画面でアプリを開くだけです。ランチャーから実行したからといって、破壊的な操作がワンタップになることはありません。
リソース

リアルタイムチャート

リソースサブビューは同じデータを推移グラフで表示するもので、「これは一時的なスパイクか、それとも継続しているのか」を知りたいときに役立ちます。

  • CPU使用率。ユーザーとシステムの内訳付き。
  • メモリ使用率。使用量と合計の比較付き。
  • ディスク読み取りとディスク書き込み。それぞれ専用のチャートと、ディスク全体の使用率付き。
  • 負荷平均。1分、5分、15分。
チャートはポーリング間隔ごとに更新されます。間隔を短くすると細かくなりバッテリー消費は増え、長くすると負担は軽くなりますが粗くなります。
ログ

DSMが記録した内容

2つのタブ：DSM自身のログを見るシステムと、サインインやファイルアクセスを見る接続。どちらも、要求したときに読み込まれます。

  • 一度だけ読み込まれ、そのまま止まっています。1行を読もうとしているときにタイマーで再読み込みされるログは役に立たず、バッテリーと通信も無駄に消費します。
  • 再生を押すとリアルタイムで追従します。もう一度押すと一時停止します。画面を離れたりアプリをバックグラウンドにしたりすると自動的に追従を停止するので、開きっぱなしのログタブがポケットの中で黙ってポーリングを続けることはありません。
  • 検索ボックスがあり、長いログの中から1行を探せます。
  • コンテナーとスタックのログも同じ仕組みです。Dockerをご覧ください。
  • テキストは選択できます。行を長押しすると、システムの「コピー / すべて選択 / 共有」バーが表示されます。画面上の他のテキストと同じです。
  • 表示している内容を書き出せます。システムタブのライブ切り替えの横、接続タブのリストの上にエクスポートボタンがあります。3つの出力方法のシートが開きます：ファイルに保存、送信やメールのための共有、クリップボードにコピー。
書き出されるのは画面上の内容で、ログ全体ではありません。レベルフィルターのチップと検索ボックスで絞り込んだリストがそのまま書き出され、すでに除外した内容がエクスポートに戻ってくることはありません。ファイルはプレーンテキストで、1行に1エントリ、時刻、レベル、ユーザー、説明がタブで区切られます。
ログが読み込まれず、アプリの他の部分は問題ないのに接続タイムアウトと表示される場合、応答していないのは接続ではなく、NAS上のログセンターサービスです。DSMのパッケージセンターで、ログセンターがインストールされ実行中か確認してください。システムログAPIはその一部です。
よくある質問

システムに関するよくある質問

アプリからファン速度を変更できますか？
はい。システムヘルスの冷却カードに、フルスピード、クール、静音の3つのモードがあります。アプリはNASの現在のモードを読み取り、選択内容を書き込み、読み戻して確認します。この3つ以外のモードをNASが報告した場合は、誤って表示せず、読み取り専用の表示のままになります。
スマートフォンからNASを再起動・シャットダウンできますか？
はい、システムヘルスの下部にある電源コントロールから可能です。どちらも実行前に確認が表示されます。リモートでのシャットダウンはよく考えてください。電源が切れたNASは、VPNかWake-on-LAN対応のルーター設定がなければ、インターネット経由で起動できません。
「NASを識別」は何のためのものですか？
NASのステータスランプを点滅させるので、ラックや戸棚の中で目の前にあるのがどのNASかわかります。「ビープ音を消す」はアラームのブザーを止めますが、鳴らした原因が解消されるわけではありません。
ログは自動的に更新されますか？
いいえ。これは意図的な仕様です。ログは一度だけ読み込まれ、読めるようにそのまま止まっています。再生を押すとリアルタイムで追従し、もう一度押すと一時停止します。画面を離れたりアプリをバックグラウンドにしたりすると、自動的に追従を停止します。
表示しているログを書き出したりコピーしたりできますか？
はい。任意の行を長押しすると、システムの「コピー / すべて選択 / 共有」バーが表示されます。または、システムタブのライブ切り替えの横、接続タブのリストの上にあるエクスポートボタンも使えます。ファイルに保存、共有またはメール、クリップボードにコピーを選べるシートが開き、レベルフィルターと検索で絞り込んだ後の画面上のエントリがそのまま書き出されます。1行に1エントリで、時刻、レベル、ユーザー、説明がタブで区切られます。
CPUは問題なさそうなのに、負荷平均が高いのはなぜですか？
負荷平均は待機中のプロセスを数えたもので、その多くはCPUではなくディスクを待っています。同じ画面でディスクI/Oの使用率を確認してください。CPUが低いのに使用率のパーセンテージが高ければ、それが通常の原因です。
