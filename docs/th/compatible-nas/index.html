ถ้าใช้ DSM 7 ก็ใช้ได้

ไม่มีรายชื่อรุ่นให้ตรวจสอบ เพราะแอปไม่ได้ใช้รายชื่อ แต่จะถาม NAS ของคุณว่าทำอะไรได้บ้างเมื่อเชื่อมต่อ แล้วปรับตัวเองตามคำตอบนั้น

ข้อกำหนดเดียว ที่เหลือแอปปรับเอง

ข้อกำหนดรายละเอียด
เวอร์ชัน DSMDSM 7.0 ขึ้นไป นี่เป็นข้อกำหนดเดียวที่ต้องมี
โมเดลรุ่นใดก็ได้ DiskStation, RackStation, FlashStation ทั้งที่มีและไม่มีชุดต่อขยาย
จำนวนช่องเท่าไรก็ได้ หนึ่งไดรฟ์หรือยี่สิบสี่ไดรฟ์ แอปแสดงตามที่ DSM รายงาน
สถาปัตยกรรมแบบใดก็ได้ แอปสื่อสารกับ API ของ DSM ไม่ใช่กับฮาร์ดแวร์
อุปกรณ์ของคุณAndroid 7.0, iOS 16.0, macOS 11.0 หรือ Windows - แอปมีให้บนสโตร์ทั้งสี่แห่ง
ไม่รองรับ DSM 6 เพราะใช้ API เวอร์ชันและพฤติกรรมการยืนยันตัวตนที่ต่างออกไป และการรองรับทั้งสองแบบหมายถึงต้องเดาว่า NAS กำลังใช้แบบไหน ซึ่งการเดาคือสิ่งที่แอปนี้หลีกเลี่ยงมาตลอด
ทำไมจึงไม่มีตารางรุ่นที่รองรับ

ค้นพบเอง ไม่ใช่รายชื่อที่เขียนตายตัว

ตารางรองรับรายรุ่นจะผิดตั้งแต่วันที่ Synology เปิดตัวรุ่นใหม่ และจะผิดอีกครั้งในวันที่รุ่นใดรุ่นหนึ่งได้แพ็กเกจเพิ่ม

  • แอปจะสอบถามแคตตาล็อก API ของ DSM ตอนเชื่อมต่อ และจดจำคำตอบไว้ แคตตาล็อกนั้นคือความจริงว่า NAS ของคุณทำอะไรได้บ้าง
  • หน้าจอปรากฏเพราะ NAS ของคุณรายงาน API ที่อยู่เบื้องหลัง ติดตั้ง Surveillance Station แล้วมุมมองกล้องก็ปรากฏ ถอนการติดตั้งมุมมองนั้นก็หายไป
  • ไม่มีอะไรถูกสมมติจากชื่อรุ่น สองเครื่องรุ่นเดียวกันแต่มีแพ็กเกจต่างกันจะได้แอปที่ต่างกัน ซึ่งถูกต้องแล้ว
  • ค่าที่ NAS ไม่ได้รายงานจะถูกระบุว่าอ่านไม่ได้ ไม่เคยเติมด้วยค่าเริ่มต้นที่ดูสมเหตุสมผล

สรุปแบบใช้งานจริง: ถ้าหน้าเว็บของ DSM เปิดได้จากเบราว์เซอร์บนมือถือ และบัญชี DSM ของคุณเห็นสิ่งนั้นได้ที่นั่น Syno Manager ก็เห็นได้เช่นกัน

คำถามที่พบบ่อยเรื่องความเข้ากันได้

Syno Manager รองรับ Synology รุ่นไหนบ้าง
Synology NAS ทุกเครื่องที่ใช้ DSM 7.0 ขึ้นไป ทั้ง DiskStation, RackStation และ FlashStation ทั้งที่มีและไม่มีชุดต่อขยาย ไม่มีรายชื่อรุ่นเพราะแอปจะถาม NAS ของคุณว่าทำอะไรได้บ้างเมื่อเชื่อมต่อ
ใช้กับ DSM 6 ได้ไหม
ไม่ได้ ต้องใช้ DSM 7.0 ขึ้นไป DSM 6 ใช้ API เวอร์ชันและพฤติกรรมการยืนยันตัวตนที่ต่างออกไป
ใช้กับ NAS ขนาดเล็กแบบสองช่องได้ไหม
ได้ แสดงหน้าจอน้อยกว่าเพราะรันบริการน้อยกว่า ไม่ใช่เพราะไม่รองรับ ทุกอย่างที่มันรันจะแสดงครบถ้วน
รองรับชุดต่อขยายไหม
รองรับ ไดรฟ์ในชุดต่อขยายจะปรากฏควบคู่กับไดรฟ์ภายใน
ถ้า NAS ของฉันใช้ DSM เวอร์ชันเบต้าล่ะ
โดยทั่วไปจะใช้ได้ เพราะแอปอ่านแคตตาล็อก API แทนที่จะสมมติเวอร์ชัน เบต้าที่เปลี่ยน API อาจทำให้เกิดค่าที่แอปรายงานว่าอ่านไม่ได้ ซึ่งแอปจะบอกตรง ๆ แทนที่จะแสดงตัวเลขที่ผิด
