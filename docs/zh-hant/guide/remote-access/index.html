離開家時

同一個 App，不同的路徑

不論你就在 NAS 旁邊，還是在世界的另一端，Syno Manager 的運作都一樣。不同的只是連線抵達的方式，而每種路徑各有值得了解的取捨。

三種路徑

挑選最適合你的

路徑設定方式速度會對外開放什麼嗎？
QuickConnect在 DSM 中啟用並輸入 ID。路由器完全不用動。較慢 - 流量會經由 Synology 的轉送服務。什麼都不會。你這邊沒有任何開放的連接埠。
自訂網域 / DDNS一個指向你位址的主機名稱，再加上路由器上的連接埠轉送。直接連線，速度取決於你的上傳頻寬。會 - DSM 連接埠可從網際網路連到。
VPN在路由器或 NAS 上架設 VPN 伺服器，並在手機上安裝用戶端。連線後即為直接連線。只開放 VPN 連接埠。其他一切都保持私密。
如果不確定，就用 QuickConnect。它不需要任何路由器知識，也不會開放任何東西，而且 App 的所有功能都能透過它使用。
遠端時可使用的功能

全部都行，只有兩個附註

你不在家時，App 的功能並不會縮水。需要稍微想一下的只有兩件事：攝影機即時檢視，以及喚醒已關機的 NAS。

功能離開家時
監控 - 系統、儲存空間、網路、健康狀態任何路徑都能使用。
Docker、套件、服務、工作、使用者任何路徑都能使用。
Synology Photos - 縮圖與完整影像可使用，包含轉送。
File Station 與 Drive 下載可使用，包含轉送。
備份 - 狀態與立即執行任何路徑都能使用。
透過 NAS 喚醒其他裝置可使用，前提是 NAS 本身是開機的。
攝影機即時檢視請開啟透過 DSM 連接埠以通道傳送攝影機即時檢視。若沒有開啟，即時檢視需要連接埠 554 上的 RTSP，而這通常無法從外部連到。請參閱即時檢視如何連線。
在 NAS 關機時喚醒它需要 VPN 或路由器的 Wake-on-LAN 轉送。QuickConnect 無法連到已關機的 NAS。請參閱 Wake-on-LAN。
QuickConnect

設定方式

  1. 在 DSM 中：控制台 › 外部存取 › QuickConnect。啟用後記下 QuickConnect ID。
  2. 在 App 中：新增 NAS，並將連線類型切換為 QuickConnect。
  3. 輸入 ID - 不是主機與連接埠。
  4. 你的 DSM 憑證，如果帳號有啟用雙重驗證，也要輸入驗證碼。
  5. 儲存 & 連線。
速度會比較慢，請有心理準備。轉送多了一個跳點，Synology 也會對其限速，所以相簿捲動起來不如在家時流暢。所有功能仍然正常 - 差別只在延遲，而不是能力。
值得仿效的做法

把同一台 NAS 加兩次

一個項目用區域網路 IP，一個用 QuickConnect。幫它們取好名字以便區分 - 例如「NAS（家裡）」和「NAS（外出）」。

  • 在家時，使用直接連線的那個：沒有轉送、全速、縮圖秒開。
  • 外出時，切換到 QuickConnect 的那個。
  • 它們的版面配置各自獨立，所以你可以把外出用的項目精簡成只剩你在行動數據下真正會看的幾張卡片。
  • 切換只要一點，在裝置清單中就能完成。

將啟動行為設為上次使用的 NAS，App 就會停留在你上次使用的那一台。

常見問題

遠端存取常見問題

遠端使用 NAS 需要設定連接埠轉送嗎？
不需要。QuickConnect 不需任何路由器設定就能轉送連線，使用 VPN 也行得通。只有在你特別想要從網際網路直接連線時，才需要連接埠轉送。
相片與攝影機即時檢視可以透過 QuickConnect 使用嗎？
可以。縮圖、完整影像、攝影機即時檢視，以及 File Station 與 Drive 的下載，都會走目前使用中的路徑，包括轉送。攝影機即時檢視需要開啟 DSM 連接埠通道開關。
我應該把 NAS 加兩次嗎？
這是個好做法 - 一個項目用區域網路 IP 在家使用，一個用 QuickConnect 在外使用，版面配置各自獨立，一點即可切換。
QuickConnect 安全嗎？
使用 HTTPS 時，連線全程加密，轉送服務只負責傳遞流量，不會保存你的資料。你的 DSM 憑證與雙重驗證仍然有效。
為什麼我的區域網路 IP 項目在行動數據下無法使用？
因為像 192.168.x.x 這類私有位址只存在於你自己的網路中。請改用 QuickConnect 項目、網域，或先連上你的 VPN。
