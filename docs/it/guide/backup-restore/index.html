Backup & ripristino

La tua configurazione, sul prossimo telefono

Un solo file contiene ogni preferenza che hai impostato - tema, barra inferiore, layout della dashboard, polling, unità. Di proposito non contiene alcuna credenziale.

Cosa c'è nel file

E cosa non c'è

Incluso

  • Tema, superficie, colore d'accento e dimensione del testo.
  • La barra di navigazione inferiore e il suo ordine.
  • Il layout della dashboard e quali schede sono attive.
  • Le categorie della dashboard.
  • Il comportamento all'avvio.
  • L'intervallo di polling.
  • L'unità di temperatura.

Mai incluso

  • Connessioni al NAS - indirizzi, porte e opzioni.
  • Password.
  • Sessioni e token dei dispositivi 2FA.
Questa esclusione è il punto. Un file che puoi inviarti per email e mettere in una cartella cloud è un file che può trapelare. Le credenziali stanno nel portachiavi o keystore del dispositivo proprio perché un'esportazione non possa raggiungerle, e l'app non fa eccezioni per la propria comodità.
Esporta

Estrarre il file

Impostazioni › Backup & ripristino, poi uno dei due pulsanti.

  • Scarica salva il file JSON direttamente sul dispositivo.
  • Condividi lo passa al foglio di condivisione, così puoi inviarlo a File, Drive, un'altra app o a te stesso.
Ripristina

Rimetterlo a posto

  1. Apri il file di backup e copiane il contenuto.
  2. Incolla nella casella Ripristina, oppure tocca Incolla dagli appunti.
  3. Tocca Ripristina impostazioni.
  4. Aggiungi di nuovo il tuo NAS - quella parte non è mai stata nel file.
Le voci sconosciute vengono ignorate, non rifiutate. Vengono applicate solo le impostazioni che l'app riconosce, così un backup di una versione più vecchia si ripristina senza problemi in una più recente - le impostazioni che allora non esistevano restano semplicemente ai valori predefiniti.
Correlati

Da non confondere con

  • Hyper Backup e Active Backup - il tuo NAS che fa il backup dei tuoi dati. Non c'entra nulla con questa schermata.
  • Backup della configurazione di DSM - le impostazioni del NAS stesso, esportate dal Pannello di controllo di DSM.
  • Backup del dispositivo. Le credenziali salvate di Syno Manager sono escluse di proposito dai backup dei dispositivi Android e iOS, quindi ripristinare un telefono da un backup del dispositivo non porta con sé le password del NAS.
Domande frequenti

Domande frequenti su backup & ripristino

Cosa include il backup delle impostazioni?
Solo le impostazioni dell'app: tema, navigazione, layout della dashboard, comportamento all'avvio, categorie, intervallo di polling e unità di temperatura. Connessioni al NAS, password e sessioni non sono mai incluse.
Perché le credenziali del mio NAS non sono nel backup?
Perché un file portatile che contiene le password del NAS è un file portatile che contiene le password del NAS. Le credenziali stanno nel portachiavi o keystore del dispositivo, che un'esportazione di proposito non può raggiungere.
Come passo a un nuovo telefono?
Esporta sul vecchio, porta il file sul nuovo, installa l'app, incolla il contenuto in Ripristina e aggiungi di nuovo il tuo NAS.
Cosa succede alle impostazioni che il file non conosce?
Vengono applicate solo le impostazioni note e tutto il resto è ignorato, così un vecchio backup ripristinato in un'app più recente lascia le nuove impostazioni ai valori predefiniti.

Qualcosa non funziona?

La guida alla risoluzione dei problemi copre errori di connessione, riquadri vuoti, schede mancanti e widget non aggiornati.
