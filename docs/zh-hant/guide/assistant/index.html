助理 · 測試版

直接問你的 NAS，用白話就行

「我的儲存空間有什麼值得擔心的嗎？」這類問題原本得打開四個畫面才能回答。助理會讀取你的 NAS 回報的內容並回答 - 使用在手機上執行的模型，離線可用，不會把任何資料傳到任何地方。

提問

用打字或用說的

助理分頁有兩個子檢視：提問與運作方式。提問畫面一開始會有四個建議，用意是示範好問題的樣子，而不是限制你。

  • 在底部的輸入框輸入問題，或點選其中一個建議。
  • 如果你想，也可以用麥克風口述。
  • 用右上角的喇叭控制項朗讀回答。
  • 回答會邊產生邊顯示，而不是一次全部出現 - 所以你不必等它說完，就可以開始閱讀。
  • 清除會清空對話。
模型在你開啟畫面時就會載入，而不是等你送出第一個問題才載入，所以第一個回答不會是最慢的。
範圍

沒有主題清單

這一點很容易被忽略。助理不是一組關於儲存空間與備份的現成答案 - 它針對的是你的 NAS 實際公布的所有內容。

  • 你的 NAS 會公布它能回報的所有項目 - 一般機型超過一千項 - 助理會搜尋這份目錄，並讀取與你的問題相關的內容。
  • 安裝新套件後，它也能回答相關問題，而且立即生效，不需要更新 App。目錄中的任何內容都沒有寫死在 App 裡，全都是從你的裝置探索而來。
  • 用得越多，速度越快。如何解讀 DSM 各個部分只需摸索一次並記住，之後再問同樣的事就會更快。
  • 「我的 NAS 狀況如何？」會以健康判定回答 - 與主畫面顯示的正常、警告或嚴重判定相同，並附上背後的原因，而不是單獨抽出的溫度或某個脫離脈絡的讀數。
好問題看起來就像一般的問句。「我的 NAS 狀況如何？」、「我的備份正常嗎？」、「什麼最佔空間？」、「你能看到這台 NAS 的哪些資訊？」 - 最後一個值得問一次，因為答案會告訴你它能存取你的 NAS 的哪些內容。
隱私權

資料不會離開手機

模型屬於裝置本身。你的問題、NAS 的資料與回答全都在手機上處理，關閉網路也能使用。

  • 沒有雲端方案可退而求其次。不是「我們選擇不用」 - 只要助理中出現任何雲端主機、雲端 SDK 或 API 金鑰，App 的建置就會失敗。這項承諾是由建置流程來確保，而不是靠誰記得。
  • 因為沒有任何資料被傳送，所以沒有副本可供儲存、分享，或用來訓練任何東西。
  • 免費且不需要帳號，因為模型本來就在你的裝置上。
界線

它只會讀取

助理無法啟動、停止、刪除或重新啟動任何東西。不是因為我們客客氣氣地請它不要，而是因為一開始就沒有給它這些工具。

這點比聽起來更重要。被指示不要做某件事的模型，可能被說服去做；而完全沒有辦法做的模型，就做不到。如果你想重新啟動容器，Docker 畫面只要三下點擊，而且會請你確認。

誠實

它可能會出錯，畫面上也會這樣說

這是在手機上執行的小型模型，不是資料中心裡的大型模型。它可能讀錯數字，或說得比實際更有把握。App 會直接在畫面上說明，而不是藏在註腳裡。

  • 重要的事情請到對應的畫面確認。每個回答談的都是 App 也會直接顯示給你看的內容。
  • 分頁標題上標示 BETA，正是為了這個原因。

暫時無法回答時，它會說明原因

不是籠統的錯誤，而是三種明確原因之一，並說明大約要等多久。

原因意思
已達使用上限這個 App 目前已用完它在裝置端模型中的份額。裝置上所有使用該模型的 App 共用同一個模型；份額重新計算後就會恢復回答，通常在一兩分鐘內。
忙碌中裝置端模型目前正在回答另一個請求。請稍後再試。
在背景執行中裝置端模型只在 Syno Manager 顯示於螢幕上時才會回答。請將 App 切回前景，再問一次。
發生以上任何情況時，都不會遺失任何內容。你的問題仍留在對話中；原因排除後再問一次即可。
越用越好

它會從你的評分中學習，而且只在這台裝置上

每個回答下方都有大拇指向上或向下的按鈕。評分之後，類似的問題就會從那個回答所讀取的位置開始 - 你用得越多，助理就越會解讀你的 NAS，而且不會有任何資料離開手機。

  • 好答案或不是好答案 - 回答下方的兩個大拇指，點一下即可。
  • 依 NAS 分開保存。評分會記錄在回答問題的那台 NAS 之下，且存放於這台裝置上，因此切換到另一台 NAS 時，會從頭開始。
  • 絕不傳送到任何地方。評分就像模型本身一樣完全在本機 - 沒有帳號、沒有同步、沒有上傳。

「運作方式」分頁中的在此學到了什麼，會計算目前這台 NAS 上有多少回答被評為好答案，並用白話讀出來。

  • 這台 NAS 上尚無任何回答被評為好答案，是你第一次評分之前會看到的文字 - 而不是顯示零，因為零會被當成測量結果，而不是「尚無資料」。
  • 清除此 NAS 的評分只要點一下，就能刪除這台裝置上為目前這台 NAS 保存的所有評分。

常見問題

助理常見問題

助理在哪裡執行？
在你的手機上。Android 使用透過 AICore 提供的 Gemini Nano，iOS 與 macOS 使用 Apple Intelligence。沒有雲端方案可退而求其次 - 只要助理中出現任何雲端主機、雲端 SDK 或 API 金鑰，App 的建置就會失敗。
我的 NAS 資料會被傳送到任何地方嗎？
不會。你的問題、NAS 的資料與回答，都不會離開裝置，關閉網路也能使用。因為沒有任何資料被傳送，所以也沒有任何副本可供儲存、分享或用來訓練。
我可以問什麼？
沒有固定的清單。你的 NAS 會公布它能回報的所有項目 - 一般機型超過一千項 - 助理會搜尋這份目錄。安裝新套件後，它也能回答相關問題，不需要更新 App。
它能更改我 NAS 上的任何設定嗎？
不能。它只會讀取。它無法啟動、停止、刪除或重新啟動任何東西 - 因為根本沒有給它這些工具。
需要額外付費嗎？
不用。它使用你裝置內建的模型，所以不必付費，也不用建立帳號。
為什麼我看不到助理分頁？
因為你的裝置沒有可用的裝置端模型。與其顯示一個無法運作的功能，App 會在無法執行它的硬體上將它完全隱藏。
助理會學習嗎？
它會從你的評分中學習，而且只在這台裝置上。用回答下方的大拇指為回答評分，之後類似的問題就會從那個回答所讀取的位置開始。評分不會離開裝置，而「清除此 NAS 的評分」可將它們清除。
為什麼會顯示模型忙碌或已超出次數？
裝置端模型與手機上的其他 App 共用，而且只在 Syno Manager 顯示於螢幕上時才會運作。助理會指出遇到的是哪一種情況，而不是顯示籠統的錯誤。
