はじめに

1分以内に接続できます

NAS には何もインストールされません。Syno Manager は、すでに動作している DSM 自身の APIs と通信します。DiskStation の場所と、あなたが誰かを伝えるだけです。

ステップ0

必要なもの

要件詳細
Synology NASDSM 7.0 以降を実行しているモデルであれば、どれでも構いません。NAS には何もインストールされません。アプリは、DSM の Web インターフェースが使うのと同じ APIs を使います。
DSM アカウントいつもお使いの DSM のユーザー名とパスワードです。管理者アカウントではすべてが表示され、管理者以外のアカウントでは DSM が許可する範囲が表示されます。アプリは、拒否される操作を表示する代わりに、それ以外を非表示にします。
お使いのデバイスAndroid 7.0 以降、iOS 16.0 以降、macOS 11.0 以降、または Windows。4つとも同じアプリです。
NAS への経路同じローカルネットワーク、そこへの VPN、カスタムドメイン、または QuickConnect のいずれかです。どれか1つで十分です。
見るだけなら、管理者アカウントは不要です。監視はどの DSM ユーザーでも行えます。コンテナの再起動、バックアップの実行、ドライブの取り外しなどの操作には、DSM 自体がその操作に必要とする権限が必要で、拒否された場合、アプリは成功したふりをせず、拒否されたことを報告します。
どこにあるか

NAS のアドレスを調べる

すでにブラウザで DSM を開いている場合は、アドレスバーに必要なものがすべてあります。ホストとポートが、アプリが求める2つの値です。

DSM から

  • コントロールパネル › ネットワーク › ネットワークインターフェースに、各インターフェースの NAS の IP アドレスが表示されます。
  • コントロールパネル › ネットワーク › DSM 設定に、DSM が待ち受けている HTTP と HTTPS のポートが表示されます。変更していなければ、5000 と 5001 です。

ブラウザから

DSM にアクセスするために入力しているものが、そのままアプリに必要な情報です。https://192.168.1.20:5001 では、ホストは 192.168.1.20、ポートは 5001、HTTPS はオンです。

ルーターから

ほとんどのルーターは、接続中のデバイスを名前で一覧表示します。NAS は、コントロールパネル › 情報センターで設定したサーバー名で表示されます。

固定のアドレスを割り当ててください。ルーターが再起動後に NAS に別の IP を割り当てると、アプリは NAS を見つけられなくなります。ルーターでの DHCP 予約か、NAS での固定アドレスの設定で防げます。ホスト名やカスタムドメインなら、IP が何であっても問題ありません。
NAS を追加

フォームのすべての入力欄

デバイス一覧で + NAS を追加をタップします。フォームは短く、既定値のない入力欄は3つだけです。

項目入力する内容
NAS のニックネームお好きな名前で構いません。表示されるのはあなたにだけです。複数台になったときに便利です。
接続タイプ入力したアドレスを使う場合は直接 IP、QuickConnect ID を使う場合は QuickConnect を選びます。下記をご覧ください。
ホスト / IP アドレスNAS のローカル IP、ホスト名、またはそれを指すカスタムドメインです。
ポートHTTPS オンなら 5001、オフなら 5000 です。DSM が別のポートに変更されている場合は、そのポートを使ってください。
HTTPS既定でオンになっており、オンのままにしておくことをおすすめします。パスワードを含め、スマートフォンと NAS の間のすべての通信が暗号化されます。
SSL 証明書を検証既定ではオフです。ほとんどの DiskStation は、公的な認証局に対して検証できない自己署名証明書を提示するためです。どちらの設定でも、接続は暗号化されます。正規の証明書をインストールしている場合にのみ、オンにしてください。
ユーザー名DSM のアカウント名です。スペースを含むユーザー名にも対応しています。アプリは正しく引用符で囲んで処理しますが、ほかのクライアントが失敗する原因としてよくあることです。
パスワードDSM のパスワードです。目のアイコンで、入力中に表示できます。プラットフォームのキーチェーンまたはキーストアに保存され、平文で保存されることはありません。
2段階認証DSM アカウントで認証アプリを使っている場合はオンにします。下記をご覧ください。
カメラのライブビューを DSM ポート経由でトンネリング既定ではオフです。オフの場合、カメラのライブビューはポート 554 の RTSP に直接接続します。自宅のネットワークでは高速ですが、どこにいてもそのポートに到達できる必要があります。オンの場合、すでに使用している DSM の HTTPS ポートを通じてストリームをトンネリングするため、554 を公開しなくても、外出先からライブビューが使えます。Surveillance Station をご覧ください。
アドレスを入力する必要はありません

QuickConnect

接続タイプを QuickConnect に切り替えて、ホストとポートの代わりに QuickConnect ID を入力します。Synology のリレーが、NAS がどこにあっても見つけてくれるため、ルーターの設定は不要です。

  • ID の場所。DSM のコントロールパネル › 外部アクセス › QuickConnect にあります。先にそこで有効にしておく必要があります。
  • 代償。リレーを経由するため遅延が増え、サムネイルやライブビューの読み込みは、自宅のネットワークより遅くなります。それでもすべて動作します。
  • 得られるもの。ポート転送も、最新に保つ必要のあるダイナミック DNS も不要で、こちら側でインターネットに公開するものもありません。
両方を使うこともできます。同じ NAS をローカル IP と QuickConnect の2通りで追加すると、自宅用の高速なエントリと、外出先用の確実なエントリが手に入ります。別々のエントリで、レイアウトも別々なので、今いる場所に近いほうを選んでください。
2FA

2段階認証

DSM アカウントが認証アプリで保護されている場合は、保存する前に2段階認証(2FA)をオンにしてください。パスワードが受け付けられた直後に、アプリが6桁のコードを求めます。

  1. NAS の追加フォームでトグルをオンにします。
  2. 保存 & 接続をタップします。アプリがサインインし、DSM が第2要素を求めます。
  3. 認証アプリのコードを入力します。
  4. このデバイスを記憶するかどうかを選びます。記憶すると、DSM がデバイストークンを発行し、このスマートフォンではコードを再度求められません。トークンは、パスワードと同じようにプラットフォームのキーチェーンに保存されます。
コードが拒否される場合は、時計を確認してください。認証コードは現在時刻から生成されるため、スマートフォンまたは NAS の時計がずれていると、誤った数字が生成または要求されます。NAS の時刻ソースは、ホーム画面のクイック統計行に表示されます。
確定する前に

接続をテストして、保存

接続をテストは、何も保存せずに、アドレス、ポート、認証情報を試して結果をお伝えします。「NAS に到達できない」のか、「到達したがパスワードが違う」のかを区別できるため、入力ミスを見つける最速の方法です。

表示される内容意味
接続タイムアウト何も応答がありませんでした。原因は、アドレス、ポート、またはスマートフォンのネットワークです。認証情報はまだ試されていません。
認証情報が無効NAS が応答し、サインインを拒否しました。アドレスとポートは正しく、ユーザー名またはパスワードが誤っています。
証明書エラーHTTPS がオンで、自己署名証明書に対してSSL 証明書を検証もオンになっています。検証をオフにしてください。
2FA が必要アカウントが2段階認証を使っていますが、トグルがオフです。オンにして、もう一度お試しください。

保存 & 接続は、エントリを保存してサインインします。ホーム画面に移動し、NAS の読み込みがすでに始まっています。

接続完了

初回接続時に起こること

  • アプリが NAS にできることを問い合わせます。DSM の API カタログを照会し、その一覧を保持します。これが、Surveillance Station のない NAS にカメラのタブが表示されない理由であり、パッケージをインストールするとその画面が現れる理由です。
  • 対応するすべてのカードがオンになります。新しいカードは非表示ではなく表示された状態で追加されるため、NAS が対応する機能は目に見えます。カスタマイズは何かをオフにする場所であり、探す場所ではありません。
  • NAS の MAC アドレスを取得します。これにより、あとで調べなくてもWake-on-LAN が使えます。
  • 短いウェルカム画面が1回だけ表示されます。アプリの機能と設定を変更できる場所を説明します。次回から表示しないためのチェックボックスもあります。
  • 説明が必要な画面には、ヘルプカードが表示されます。長押しすると閉じられます。設定から、個別に元に戻せます。
接続後にパッケージをインストールしましたか？機能の一覧は接続時に読み取られるため、その後にインストールしたパッケージには、まだタブがありません。プルして更新するか、アプリを開き直すと、新しい画面が表示されます。
接続できないとき

簡単なチェックリスト

  1. スマートフォンのブラウザで DSM を開き、入力したのとまったく同じアドレスとポートにアクセスします。ブラウザでも到達できない場合、問題はアプリではなく、ネットワークまたはアドレスにあります。
  2. HTTPS の設定がポートと一致しているか確認します。HTTPS オフでポート 5001、またはオンでポート 5000 を使うと、タイムアウトします。待ち受けているポートが別だからです。
  3. NAS が出荷時の証明書を使っている場合は、SSL 証明書を検証をオフにします。
  4. スマートフォンのネットワークを確認します。ローカル IP には、モバイルデータ通信からは到達できません。Wi-Fi に接続するか、QuickConnect、ドメイン、VPN を使ってください。
  5. iOS では、ローカルネットワークへのアクセスを許可します。設定 › アプリ › Syno Manager › ローカルネットワーク。これを許可しないと、iOS は同じネットワーク上のアドレスへの接続を黙ってブロックします。
  6. DSM のファイアウォールを確認します。コントロールパネル › セキュリティ › ファイアウォール。特定のアドレスだけを許可するルールがあると、それに該当しないスマートフォンはブロックされます。
  7. 自動ブロックを確認します。コントロールパネル › セキュリティ › アカウント。サインインの失敗が繰り返されると、スマートフォンのアドレスがブロックされることがあります。そこに一覧表示されており、削除できます。

セットアップ FAQ

Syno Manager を使うには何が必要ですか？
DSM 7.0 以降を実行している Synology NAS と、その DSM アカウント、そして Android 7+、iOS 16+、macOS 11+、または Windows が動作するデバイスです。NAS には何もインストールする必要はありません。アプリは、すでに存在する DSM 自身の APIs を使用します。
どのアドレスとポートを入力すればよいですか？
自宅のネットワーク内では、NAS のローカル IP アドレスと DSM のポート（HTTPS オンなら 5001、オフなら 5000）を入力します。ホスト名やカスタムドメインも使えます。アドレスを扱いたくない場合は、接続タイプを QuickConnect に切り替えて、QuickConnect ID を入力してください。
「SSL 証明書を検証」が既定でオフなのはなぜですか？
ほとんどの DiskStation は自己署名証明書を提示します。これは公的な認証局による署名がないため、接続自体は暗号化されていても検証に失敗します。検証をオフにしておくと、その証明書を受け入れます。Let's Encrypt などの正規の証明書をインストールしている場合は、検証をオンにしてください。
ルーターのポートを開放する必要はありますか？
いいえ。自宅のネットワーク内では、転送の設定は不要です。外部からは、QuickConnect が接続を中継するほか、VPN も利用できます。ポート転送が必要なのは、インターネットからの直接経路が特に必要な場合や、ネットワーク外から RTSP でカメラのライブビューを見たい場合だけです。
「接続タイムアウト」と表示されます。どうすればよいですか？
このメッセージは、アプリが応答を得られなかったことを意味し、原因はほとんどの場合、アドレス、ポート、またはスマートフォンが接続しているネットワークです。HTTPS の設定がポートと一致しているか、ローカル IP を使っている場合はスマートフォンが NAS と同じネットワークにあるか、そしてスマートフォンのブラウザで同じアドレスとポートの DSM の Web インターフェースが表示されるかを確認してください。
複数の NAS を追加できますか？
はい、いくつでも追加できます。それぞれが独自の認証情報、ダッシュボードのレイアウト、設定を保持し、デバイス一覧から切り替えられます。複数の NAS デバイスをご覧ください。
