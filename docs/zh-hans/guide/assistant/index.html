助手 · 测试版

向你的 NAS 提问，用日常语言

“我的存储有什么值得担心的吗？”这个问题，原本要打开四个界面才能回答。助手会读取你的 NAS 上报的内容并作答，所用的模型运行在你的手机上，可离线使用，不会向任何地方发送任何数据。

提问

打字或语音皆可

“助手”标签有两个子视图：提问和工作原理。“提问”一开始会给出四条建议，目的是示范好问题的样子，而不是限制你。

  • 在底部的输入框中输入问题，或点按其中一条建议。
  • 如果你愿意，也可以用麦克风说出来。
  • 用右上角的扬声器控件让它朗读答案。
  • 答案边生成边显示，而不是一次性出现，所以你不必等它写完就能开始阅读。
  • 清除会清空对话。
模型在你打开界面时就会加载，而不是等你发出第一个问题时，所以第一个答案不会是最慢的。
范围

没有主题清单

这一点很容易被忽略。助手并不是一套关于存储和备份的固定回答，而是对准你的 NAS 实际公布的一切。

  • 你的 NAS 会公布它能上报的一切，一般有上千项，助手会在这份目录中搜索，并读取与你的问题相关的内容。
  • 安装一个套件后，它也能立刻回答与之相关的问题，无需更新应用。目录中的任何内容都不是写死在应用里的，而是从你的设备上发现的。
  • 用得越多，它越快。如何读取 DSM 的每个部分只需摸索一次并记住，之后再问同样的内容就会更快。
  • “我的 NAS 怎么样？”会以健康结论作答，也就是主屏幕上显示的同一个“健康”“警告”或“严重”结论，并附上原因，而不是脱离上下文的一个温度或单个读数。
好问题就像问题的样子。“我的 NAS 怎么样？”“我的备份健康吗？”“什么占用的空间最多？”“你能看到这台 NAS 的哪些信息？”最后一个值得问一次，因为答案会告诉你它在你的 NAS 上能触及什么。
隐私

任何内容都不会离开手机

模型属于设备。你的问题、你的 NAS 数据和答案都在手机上处理，关闭网络也能使用。

  • 没有云端可作后备。并不是“我们选择不用”，而是只要助手里出现云端主机、云端 SDK 或 API 密钥，应用的构建就会失败。这一承诺由构建来保证，而不是靠谁记着。
  • 由于不传输任何内容，也就没有副本可供存储、分享或用于训练。
  • 免费，无需账户，因为模型已经在你的设备上。
边界

它只读不写

助手无法启动、停止、删除或重启任何东西。并不是因为客客气气地要求它别这么做，而是因为从一开始就没有给它这些工具。

这比听起来重要得多。被要求不做某事的模型，可能被说服去做；而根本没有办法去做的模型，则做不到。如果你想重启容器，Docker 界面只需三下点按，并且会请你确认。

坦诚

它可能出错，界面上会直接说明

这是一个运行在手机上的小模型，而不是数据中心里的大模型。它可能读错数字，也可能说得比实际更笃定。应用会在界面上直接说明，而不是藏在脚注里。

  • 重要的内容请核对，到负责它的界面上确认。每个答案所讲的内容，应用也都会直接展示给你。
  • 标签页标题上标有“测试版”，原因正在于此。

暂时无法回答时，它会说明原因

不是笼统的错误，而是三种明确原因之一，并告知大约需要等多久。

原因含义
用量上限本应用暂时用完了它在设备端模型中的份额。设备上所有使用该模型的应用共用同一个模型，等份额恢复后即可再次回答，通常在一两分钟内。
繁忙设备端模型此刻正在回答另一个请求。请稍后再试。
在后台设备端模型只在 Syno Manager 位于屏幕前台时才会回答。把应用切回前台，再问一次。
出现以上任何情况，都不会丢失任何内容。你的问题会保留在对话中，等原因消除后再问一次即可。
越用越好

它会根据你的评分学习，且仅限于这台设备

每个答案下方都有一个点赞和一个点踩。评分之后，类似的问题就会从该答案的读取位置开始，你用得越多，助手越懂得读你的 NAS，而且不会有任何内容离开手机。

  • 好答案或不是好答案，即答案下方的两个拇指图标，点按一次即可。
  • 按 NAS 分别保存。评分记录在作答的那台 NAS 名下，保存在这台设备上，因此切换到另一台 NAS 时，会从零开始。
  • 绝不发送到任何地方。评分与模型一样都在本地，没有账户，没有同步，没有上传。

“工作原理”标签下的它在这里学到了什么，会统计当前 NAS 上有多少答案被评为好，并用日常语言复述出来。

  • 此 NAS 上还没有答案被评为好，这是首次评分之前它显示的内容，而不是一个零，因为零看上去像是测量结果，而不是空缺。
  • 清除此 NAS 的评分，一键删除这台设备上为当前 NAS 保存的所有评分。

常见问题

助手常见问题

助手在哪里运行？
在你的手机上。Android 上通过 AICore 使用 Gemini Nano，iOS 和 macOS 上使用 Apple Intelligence。没有云端可作后备，只要助手里出现云端主机、云端 SDK 或 API 密钥，应用的构建就会失败。
我的 NAS 数据会被发送到别处吗？
不会。你的问题、你的 NAS 数据和答案都不会离开设备，关闭网络也能使用。由于不传输任何内容，也就没有可供存储、分享或用于训练的副本。
可以问它什么？
没有固定的清单。你的 NAS 会公布它能上报的一切，一般有上千项，助手会在其中搜索。安装一个套件后，它也能回答与之相关的问题，无需更新应用。
它能更改我 NAS 上的任何东西吗？
不能。它只读不写。它无法启动、停止、删除或重启任何东西，因为根本没有给它这些工具。
要花钱吗？
不用。它使用你设备内置的模型，所以无需付费，也无需创建账户。
为什么看不到“助手”标签？
因为该设备没有可用的设备端模型。与其展示一个无法使用的功能，应用选择在无法运行它的硬件上将其完全隐藏。
助手会学习吗？
它会根据你的评分学习，且仅限于这台设备。用答案下方的拇指图标给答案评分，类似的问题就会从该答案的读取位置开始。评分永远不会离开设备，点击“清除此 NAS 的评分”即可清空。
为什么提示模型繁忙或次数已用完？
设备端模型与你手机上的其他应用共用，而且只在 Syno Manager 位于屏幕前台时才运行。助手会说明具体触发了哪一种限制，而不是给出笼统的错误。
