ヘルプ

何かがおかしいとき

ほとんどの問題は、いくつかのパターンに分類できます。以下では、それぞれの症状が実際に何を意味するかを説明します。それが解決への一番の近道であることがほとんどです。

移動先
  • 接続できない
  • サインインが拒否される
  • タブやカードがない
  • 写真タイルが空白
  • 外出先でカメラが使えない
  • ログが読み込まれない
  • ウィジェットが古い
  • アシスタントタブがない
  • それでも解決しない
接続

「接続タイムアウト」

これは何も応答がなかったことを意味します。認証情報は試されていないため、原因はアドレス、ポート、またはネットワークのいずれかで、パスワードではありません。

  1. 入力したアドレスとポートとまったく同じ内容で、スマートフォンのブラウザーからDSMを開いてください。ブラウザーからも到達できないなら、原因はアプリではありません。
  2. HTTPSとポートが合っているか確認します。5001はHTTPSのポート、5000はHTTPのポートです。取り違えるとタイムアウトになります。
  3. スマートフォンのネットワークを確認します。192.168.1.20のようなローカルアドレスは、モバイルデータ通信には存在しません。Wi-Fiに接続するか、QuickConnect、ドメイン、VPNを使ってください。
  4. iOSではローカルネットワークへのアクセスを許可します。設定 › アプリ › Syno Manager › ローカルネットワーク。許可しないと、iOSは自宅ネットワークへの接続を黙ってブロックし、ネットワークの障害に見えるタイムアウトになります。
  5. DSMのファイアウォールを確認します。コントロールパネル › セキュリティ › ファイアウォール。特定のアドレスだけを許可するルールがあると、それ以外のスマートフォンはブロックされます。
  6. NASが起動しているか確認します。スリープ中のNASは応答しません。まず起こしてください。
サインイン

「認証情報が無効」または証明書エラー

メッセージ意味対処
認証情報が無効NASが応答したうえで、サインインを拒否しました。アドレスとポートは正しいです。ユーザー名とパスワードを確認してください。アカウントで2FAを使っていないか確認してください。切り替えがオンである必要があります。失敗した試行でアドレスがブロックされていないか、コントロールパネル › セキュリティ › アカウントのDSMの自動ブロック一覧を確認してください。
証明書エラーHTTPSがオンで、証明書の検証もオンのまま、自己署名証明書に接続しています。SSL証明書を検証をオフにしてください。ほとんどのDiskStationは自己署名証明書を使用しており、どちらの設定でも接続は暗号化されたままです。
2FA が必要アカウントが2段階認証を使っていますが、切り替えがオフです。NASの設定で2段階認証（2FA）をオンにして、再接続してください。
2FAコードが拒否される原因はたいていコードではなく時計です。コードは現在時刻から生成されます。スマートフォンの時計とNASの時計を確認してください。NASの時刻ソースは、ホーム画面のクイック統計の行に表示されます。
以前は動いていたのに、サインインを求められる保存されていた認証情報が読み取れなくなりました。アプリを新しいスマートフォンに復元したあとに起こることがあります。アプリは読み取れないものを消去して、再度サインインを求めます。パスワードを一度入力し直してください。
ユーザー名にスペースが含まれていますか？問題ありません。アプリは正しく引用符で囲んで処理します。John Smithのようなアカウントで、他のクライアントが失敗する原因としてよくあるものです。
見つからないもの

タブ、サブビュー、カードがない

理由はちょうど3つあり、それぞれ対処が異なります。

  1. パッケージがインストールされていない。アプリはNASができることを読み取り、できないものはすべて非表示にします。Download Stationパッケージがなければ、Download Stationタブもありません。パッケージセンターからインストールしてください。
  2. 接続したあとにインストールした。機能の一覧は接続時に読み取られます。下に引っ張って更新するか、アプリを開き直せば表示されます。
  3. 非表示になっている。タブの⋮メニュー › ビューのカスタマイズと、カードについては設定 › ダッシュボードのカテゴリを確認してください。カスタマイズもご覧ください。
ビューが非表示のカードをタップすると、その旨が表示され、カスタマイズボタンが提示されます。NASがそのビューに対応していないと表示された場合は、本当にそのパッケージがありません。
Photos

フォトライブラリのタイルが空白

  • 最近のiPhoneの写真：これらはHEICで、DSM 7.2.2以降ではNASがプレビューを作成しなくなりました。Syno Manager がデバイス上でデコードするので表示されるはずです。表示されない場合は、アプリが最新バージョンかどうか確認してください。
  • 古い写真も空白：NASのサムネイルが本当にない状態です。写真画面の再インデックスで、NASに再作成させてください。大きなライブラリでは時間がかかりますが、処理はNAS上で実行されるので、アプリを閉じても構いません。
  • QuickConnectですべてが空白で遅い：中継は速度が制限されています。もう少し待つか、自宅では直接接続のエントリを使ってください。
カメラ

自宅ではライブビューが動くのに、外出先では動かない

NASの設定にあるDSMポート経由でカメラのライブビューをトンネリングという1つの設定で解決します。

  • オフ - ライブビューはポート554のRTSPに直接接続します。自宅のネットワークでは高速ですが、そのポートが外部から到達可能になることはほとんどありません。
  • オン - ストリームは、すでに接続に使っているDSMのHTTPSポート経由でトンネリングされます。新たに公開するものはなく、DSMに接続できる場所ならどこでも動作します。
  • 「タップして表示」と表示されるカメラは、故障していません。H.265のカメラで、DSMはそれらの静止スナップショットを生成しません。タップするとストリームが開きます。
ログ

システムログが読み込まれない

アプリの他の部分は問題なく動作しているのにログが接続タイムアウトと表示される場合、応答していないのは接続ではなく、NAS上のログセンターサービスです。

  • DSMのパッケージセンターで、ログセンターがインストールされ、実行中か確認します。システムログAPIはその一部です。
  • アカウントの権限を確認します。多くのDSM構成では、システムログの読み取りに管理者権限が必要です。
  • コンテナーとスタックのログは別物でDockerから取得されるため、システムログが読めなくてもそちらは動作することがあります。
ウィジェット

ホーム画面のウィジェットが古い

ウィジェットをいつ更新してよいかを決めるのはAndroidとiOSで、どちらもバッテリー節約のために厳しく制限しています。アプリが強制することはできないため、各ウィジェットは約束の代わりに数値を取得した時刻を表示します。

  • アプリを開きます。最も確実な更新方法です。
  • Android：Syno Managerをバッテリー最適化の対象から除外します。
  • iOS：アプリのバックグラウンド更新がオンになっているか確認します。
  • 到達性を確認します。スマートフォンから到達できないNASは、ウィジェットも読み取れません。ローカルIPだけのエントリでモバイルデータ通信を使っている場合は、帰宅するまで更新されません。
  • 「未更新」は、まだ一度も正常に読み取れていないことを意味します。追加したばかりか、それ以降アプリが起動していません。
アシスタント

アシスタントタブがない

アシスタントにはオンデバイスのモデルが必要で、それがないハードウェアではタブごと非表示になります。動作しない操作部品は、ないほうがましだからです。

  • Androidでは、Gemini Nanoモデルが利用可能なAICoreが必要です。
  • iOSとmacOSでは、Apple Intelligenceに対応し、有効にしている必要があります。
  • お使いのデバイスの状態は、設定 › オンデバイスAIで確認できます。検出された状態が表示されます。

よくある質問

トラブルシューティングに関するよくある質問

「接続タイムアウト」と表示されます。どういう意味ですか？
指定したアドレスとポートで何も応答がなく、認証情報は試されていないということです。HTTPSとポートが合っているか、スマートフォンがNASに到達できるネットワークにあるか、DSM自体のウェブインターフェースがスマートフォンのブラウザーで同じアドレスで開けるかを確認してください。
パスワードが正しいのに「認証情報が無効」と表示されるのはなぜですか？
NASが応答したうえで、サインインを拒否したからです。入力ミスがないか、アカウントで2FAを使っていないか、繰り返しの試行によりスマートフォンのアドレスがブロックされていないかをDSMの自動ブロック一覧で確認してください。
あるはずのタブが表示されないのはなぜですか？
そのタブの元となるパッケージがインストールされていないか、サブビューが非表示になっています。接続したあとにインストールしたパッケージは更新が必要です。下に引っ張って更新するか、アプリを開き直してください。
自宅ではカメラが動くのに、外出先では動きません。
「DSMポート経由でカメラのライブビューをトンネリング」をオンにしてください。オフの場合、ライブビューはポート554のRTSPを必要としますが、通常は外部から到達できません。
写真が空白のタイルで表示されます。
DSM 7.2.2以降ではNASがHEIC写真のプレビューを作成しなくなったため、HEIC写真はデバイス上でデコードされます。古い写真も空白の場合は、写真画面の再インデックスを使ってください。
ウィジェットの数値が古いのはなぜですか？
ウィジェットをいつ更新してよいかを決めるのはOSだからです。まさにこの理由で、各ウィジェットにデータを取得した時刻が表示されます。アプリを開くのが、最も確実な更新方法です。
