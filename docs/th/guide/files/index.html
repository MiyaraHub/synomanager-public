โฟลเดอร์แชร์ของคุณ จากที่ไหนก็ได้

File Station

เรียกดูและดาวน์โหลด

เริ่มที่ Root ซึ่งคือทุกโฟลเดอร์ที่แชร์ที่บัญชีของคุณเห็นได้ แล้วไล่ลงไป เส้นทางด้านบนแสดงว่าคุณอยู่ที่ไหนและพากลับขึ้นไปได้

  • โฟลเดอร์และไฟล์ พร้อมรายละเอียดที่ DSM เก็บไว้ ได้แก่ ขนาด วันที่สร้างและแก้ไข เจ้าของ และสิทธิ์
  • ดาวน์โหลดไฟล์ใดก็ได้ บน Android และ iOS เมนูแชร์จะเปิดขึ้น คุณจึงบันทึก เปิดที่อื่น หรือส่งต่อได้ บน Windows และ macOS จะได้กล่องโต้ตอบ Save As ของระบบ
  • ใช้ได้เมื่ออยู่นอกบ้าน การดาวน์โหลดไปตามเส้นทางใดก็ตามที่เข้าถึง NAS ได้ รวมถึงรีเลย์ของ QuickConnect
  • อัปโหลดไฟล์ไปยัง NASโดยเลือกจากอุปกรณ์ของคุณ
สิ่งที่คุณเห็นคือสิ่งที่ DSM ให้คุณเห็น File Station ที่นี่เคารพสิทธิ์ของบัญชี DSM ของคุณอย่างตรงไปตรงมา โฟลเดอร์ที่บัญชีของคุณอ่านไม่ได้จะไม่ปรากฏ เหมือนกับในเว็บอินเทอร์เฟซ
File Station

คัดลอกและย้าย บน NAS เอง

เลือกไฟล์หรือโฟลเดอร์ เลือก Copy to หรือ Move to แล้ว NAS จะทำการถ่ายโอนให้ ไม่ใช่มือถือของคุณ แม้หลายร้อยกิกะไบต์ก็ไม่ผ่านอุปกรณ์ในมือคุณ

  • กดค้างเพื่อเลือกหนึ่งไฟล์หรือโฟลเดอร์ขึ้นไป แถบด้านบนจะเปลี่ยนเป็น Copy to... และ Move to...
  • เลือกปลายทางแบบเดียวกับที่เรียกดู File Station คือเปิดโฟลเดอร์ที่แชร์หรือโฟลเดอร์แล้วยืนยัน ทุกโฟลเดอร์ที่แชร์ที่ NAS แสดงเป็นปลายทางได้ รวมถึงไดรฟ์ภายนอกที่เสียบกับ NAS โดยปรากฏเหมือนโฟลเดอร์ที่แชร์ทุกประการ เพราะ NAS เมานต์มันเป็นแบบนั้น
  • ชื่อซ้ำจะถามก่อน หากมีรายการอยู่ที่ปลายทางแล้ว คุณเลือกเขียนทับหรือข้ามและเก็บของเดิมก่อนที่อะไรจะเริ่ม
  • การย้ายต้องกดค้างเพื่อยืนยัน การย้ายจะลบต้นฉบับเมื่อสำเนาไปถึง ปุ่มยืนยันจึงต้องกดค้างไม่ใช่แค่แตะ เป็นความฝืดที่ตั้งใจก่อนสิ่งที่ย้อนกลับจากแอปไม่ได้

ตัวเลือกปลายทางคือ File Station อีกครั้ง แต่จำกัดให้เลือกโฟลเดอร์ ไม่ใช่เปิดไฟล์

  • ความคืบหน้าขณะรัน - ไบต์ที่ย้ายแล้วและเปอร์เซ็นต์ อ่านจาก NAS เอง ยอดรวมที่ NAS ยังคำนวณอยู่จะแสดงว่ากำลังวัดขนาด แทนที่จะเป็นตัวเลขที่ยังไม่มีความหมาย และขณะวัดขนาด แบนเนอร์ยังแสดงว่าคัดลอกไปแล้วเท่าไร เช่น "6.82 GB so far" พร้อมแถบที่เคลื่อนไหว ไม่ใช่แถบที่ค้าง
  • ความเร็วแสดงทุกครั้งที่ NAS รายงาน หาก NAS เงียบไปพักหนึ่ง ซึ่งพบบ่อยขณะเขียนลงไดรฟ์ USB ที่ช้า แบนเนอร์จะคงปริมาณที่คัดลอกแล้ว ซ่อนความเร็วจนกว่าจะมีค่าใหม่ และตรวจสอบถี่น้อยลงจนกว่า NAS จะตอบอีกครั้ง การคัดลอกเองยังรันต่อบน NAS ตลอดเวลา
  • Cancel หยุดการทำงานบน NAS กลางการถ่ายโอน สิ่งที่คัดลอกไปแล้วยังอยู่ที่ปลายทาง ไม่มีอะไรถูกย้อนกลับ
  • ปิดแอปแล้วมันยังทำต่อ งานเป็นของ NAS ไม่ใช่หน้าจอที่ต้องเปิดค้างไว้ เปิด File Station อีกครั้งแล้วแอปจะเชื่อมกลับกับงานเดิม ไม่ใช่ทำหาย
ทำไมต้องกดค้างแทนแตะ การคัดลอกทิ้งต้นฉบับไว้ การแตะพลาดจึงไม่เสียอะไร อันนั้นแตะครั้งเดียว ส่วนการย้ายลบต้นฉบับเมื่อสำเนาไปถึง จึงใช้รูปแบบกดค้างเพื่อยืนยันเหมือนปุ่มรีบูตและปิดเครื่องที่อื่นในแอป
โฟลเดอร์ที่แชร์

ตัวโฟลเดอร์ที่แชร์เอง

ไม่ใช่ไฟล์ แต่เป็นโฟลเดอร์ที่แชร์ แต่ละรายการแสดงชื่อ วอลุ่มที่อยู่ คำอธิบาย และชิป ACL เมื่อมีสิทธิ์ควบคุมการเข้าถึง

  • สร้างโฟลเดอร์ที่แชร์ด้วยปุ่มที่มุมขวาล่าง
  • เมนูเพิ่มเติมในแต่ละแถวมีสิ่งที่ทำกับโฟลเดอร์ที่แชร์นั้นได้
  • โฟลเดอร์ที่แชร์ที่เข้ารหัสถูกระบุไว้ คุณจึงรู้ได้ทันทีว่าอันไหนต้องปลดล็อกหลังรีบูต
ตำแหน่งของโฟลเดอร์ที่แชร์สำคัญ วอลุ่มแสดงในทุกแถว ซึ่งเป็นวิธีที่เร็วที่สุดในการตอบว่า "วอลุ่มไหนกำลังเต็ม" เมื่อคุณกำลังดูอันที่เต็มบนหน้าจอพื้นที่จัดเก็บ
Note Station

สมุดบันทึกและบันทึก

สรุปด้านบน คือจำนวนบันทึก สมุดบันทึก และแท็กทั้งหมด จากนั้นเป็น All Notes และแต่ละสมุดบันทึกพร้อมจำนวนของตัวเอง

  • เปิดบันทึกใดก็ได้แล้วอ่านเนื้อหาเต็ม
  • รูปภาพแสดงตรงตำแหน่งในบันทึก ระหว่างย่อหน้า ไม่ถูกตัดออกหรือกองไว้ท้ายสุด
  • รูปที่ NAS ส่งมาไม่ได้จะแสดง Image could not be loaded แทนที่ แทนที่จะหายไปเฉย ๆ รวมถึงรูปที่ web clipper เพิ่มมาจากหน้าเว็บภายนอก ซึ่ง NAS บางครั้งส่งกลับมาไม่ได้
  • สร้างสมุดบันทึกหรือเพิ่มบันทึกด้วยสองปุ่มที่มุมขวาล่าง
  • ลบสมุดบันทึกจากแถวของมัน

ชื่อสมุดบันทึกสามชื่อในภาพหน้าจอนี้ถูกเบลอ เพราะเป็นของ NAS จริง

Synology Office

ติดตั้งแล้ว และรองรับอะไร

หน้าจอสถานะ ไม่ใช่ตัวแก้ไข แสดงเวอร์ชันของ Synology Office ที่ NAS ของคุณรัน และเอกสารประเภทที่รองรับ ได้แก่ Documents, Spreadsheets และ Slides โดยแต่ละอย่างมีเครื่องหมายถูก

ทำไมจึงหยุดแค่นั้น เอกสาร Office ถูกเก็บและเปิดผ่าน Synology Drive แทนที่จะสร้างตัวแก้ไขสเปรดชีตครึ่ง ๆ กลาง ๆ ไว้ในแอปตรวจสอบ NAS แอปบอกว่ามี Office อยู่ และชี้ไปที่ Drive ซึ่งเป็นที่ที่เอกสารอยู่จริง
Contacts

สมุดที่อยู่

ยอดรวมของทุกสมุดที่อยู่ จากนั้นเป็นแต่ละสมุดพร้อมจำนวนของตัวเอง รวมถึงสมุดที่นำเข้าจาก Google ซึ่งปรากฏควบคู่กับสมุดที่สร้างบน NAS

  • ค้นหาข้ามทุกอย่างจากช่องด้านบน
  • ขยายสมุดเพื่อดูผู้ติดต่อในนั้น ส่วนต่าง ๆ ย่อได้ สมุดที่มีสองพันรายการจึงไม่ท่วมสมุดที่มีหกรายการ
  • เพิ่มผู้ติดต่อในสมุดที่ระบุจากแถวของมัน หรือด้วยปุ่มที่มุมขวาล่าง
  • แก้ไขหรือลบผู้ติดต่อที่มีอยู่

ชื่อสมุดที่อยู่หนึ่งชื่อถูกเบลอ เพราะเป็นที่อยู่จริง

คำถามที่พบบ่อย

คำถามที่พบบ่อยเรื่องไฟล์

ดาวน์โหลดไฟล์จาก NAS มายังมือถือได้ไหม
ได้ เปิด File Station หาไฟล์แล้วดาวน์โหลด บนมือถือเมนูแชร์จะเข้ามาแทน บน Windows และ macOS จะได้กล่องโต้ตอบ Save As ของระบบ การดาวน์โหลดใช้ได้ผ่าน QuickConnect ด้วย
คัดลอกหรือย้ายไฟล์ไปยังไดรฟ์ USB ที่เสียบกับ NAS ได้ไหม
ได้ ไดรฟ์ภายนอกปรากฏเป็นปลายทางเหมือนโฟลเดอร์ที่แชร์ เพราะ NAS เมานต์มันเป็นแบบนั้น เลือก Copy to หรือ Move to เปิดไดรฟ์แล้วยืนยัน NAS เขียนลงไดรฟ์โดยตรง
การคัดลอกหรือย้ายผ่านมือถือของฉันไหม
ไม่ NAS ทำงานเอง มือถือของคุณส่งคำขอและดูความคืบหน้า การถ่ายโอนหลายร้อยกิกะไบต์จึงไม่แตะแพ็กเกจข้อมูลของคุณ และยังรันต่อแม้คุณปิดแอป
สร้างโฟลเดอร์ที่แชร์จากแอปได้ไหม
ได้ จากมุมมองย่อย Shared Folders โฟลเดอร์ที่แชร์ที่มีอยู่แสดงชื่อ วอลุ่ม คำอธิบาย และว่ามีสิทธิ์ ACL หรือไม่
อ่านบันทึกใน Note Station ได้ไหม
ได้ มุมมองย่อย Notes แสดงสมุดบันทึกพร้อมจำนวนบันทึกและจำนวนแท็ก และเปิดบันทึกใดก็ได้เพื่ออ่านเต็ม ๆ สร้างสมุดบันทึก หรือเพิ่มบันทึก รูปภาพในบันทึกแสดงตรงตำแหน่งที่อยู่ในบันทึก และรูปที่ NAS ส่งมาไม่ได้จะแสดงตัวแทนว่าโหลดไม่ได้ แทนที่จะหายไป
ทำไม Synology Office จึงแสดงแค่สถานะ
เพราะเอกสาร Office ถูกเก็บและเปิดผ่าน Synology Drive แอปรายงานว่าติดตั้ง Office แล้วและรองรับเอกสารประเภทใด การแก้ไขเอกสารควรทำในแอป Drive ของ Synology
ทำไมฉันจึงไม่เห็นโฟลเดอร์ที่รู้ว่ามีอยู่
File Station ที่นี่เคารพสิทธิ์ของบัญชี DSM ของคุณอย่างตรงไปตรงมา โฟลเดอร์ที่บัญชีของคุณอ่านไม่ได้จะไม่ปรากฏ เหมือนกับในเว็บอินเทอร์เฟซ ลงชื่อเข้าใช้ด้วยบัญชีที่เห็นโฟลเดอร์นั้น
