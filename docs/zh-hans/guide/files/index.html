File Station

浏览与下载

从根目录开始，也就是你的账户能看到的所有共享文件夹，并从那里逐级向下。顶部的面包屑显示你所在的位置，并可返回上级。

  • 文件夹和文件，各附 DSM 保存的详细信息：大小、创建和修改日期、所有者和权限。
  • 下载任意文件。在 Android 和 iOS 上会打开分享面板，你可以保存、在别处打开或转发。在 Windows 和 macOS 上则是原生的另存为对话框。
  • 离家在外也能用。下载会通过 NAS 可达的任何路径进行，包括 QuickConnect 中继。
  • 从设备中选择文件，上传到 NAS。
你能看到的，就是 DSM 允许你看到的。这里的 File Station 严格遵守你的 DSM 账户权限，你的账户无法读取的文件夹不会出现，和网页界面一样。
File Station

在 NAS 上直接复制与移动

选择文件或文件夹，选择复制到或移动到，由 NAS 来执行传输，而不是你的手机。即使是几百 GB，也不会经过你手里的设备。

  • 长按选择一个或多个文件和文件夹。顶部栏会切换为复制到...和移动到...。
  • 选择目标位置的方式与浏览 File Station 相同，打开某个共享或文件夹并确认。NAS 列出的每个共享都可以作为目标位置，包括插在 NAS 上的外接硬盘：它看起来和共享文件夹完全一样，因为 NAS 就是把它当作共享文件夹挂载的。
  • 重名时会先询问。如果目标位置已存在同名项目，在开始之前你可以选择覆盖或跳过并保留现有项目。
  • 移动需要长按确认。移动会在复制完成后删除原件，因此确认按钮需要按住，而不是轻点，这是有意设置的一点阻力，因为这是应用内无法撤销的操作。

目标位置选择器仍是 File Station，只是范围限定为选择文件夹，而不是打开文件。

  • 运行时显示进度，包括已移动的字节数和百分比，均读取自 NAS 本身。NAS 仍在计算的总量会显示为“正在计算大小”，而不是一个毫无意义的数字；在计算期间，横幅仍会显示目前已复制了多少，例如“已复制 6.82 GB”，并带有移动的进度条，而不是停滞不动。
  • 只要 NAS 上报了速度就会显示。如果 NAS 沉默了一阵（写入速度较慢的 USB 硬盘时很常见），横幅会保留已复制的数量，在有新读数之前隐藏速度，并降低查询频率，直到 NAS 重新响应。复制本身全程都在 NAS 上继续运行。
  • 取消会在 NAS 上停止任务，哪怕传输到一半。已经复制的内容会保留在目标位置，不会回滚。
  • 关闭应用，任务也会继续。任务属于 NAS，而不是一个必须一直开着的界面。重新打开 File Station，应用会重新连上同一个任务，而不会丢失。
为什么要长按而不是轻点。复制会保留原件，所以点错了也没损失，因此复制只需轻点一下。移动会在复制完成后删除原件，因此它和应用其他地方的重启、关机控件一样，采用长按确认的方式。
共享文件夹

共享文件夹本身

不是文件，而是共享。每个条目都会显示名称、所在存储空间、描述，以及带有访问控制权限时的 ACL 标签。

  • 用右下角的按钮创建共享文件夹。
  • 每行的溢出菜单包含可对该共享执行的操作。
  • 加密的共享会被标明，让你一眼看出哪些在重启后需要解锁。
共享所在的位置很重要。每行都会显示存储空间，当你在存储界面看到某个空间已满时，这是回答“哪个存储空间快满了”最快的方法。
Note Station

笔记本和笔记

顶部是摘要，显示笔记、笔记本和标签的总数，下面是全部笔记和各个笔记本及其数量。

  • 打开任意笔记，阅读完整内容。
  • 图片显示在它在笔记中所处的位置，位于段落之间，而不是被删掉或堆在末尾。
  • NAS 无法发送的图片会在原位显示无法加载图片，而不是直接消失，包括网页剪藏工具从外部网页添加的图片，NAS 有时无法返回这类图片。
  • 用右下角的两个按钮创建笔记本或添加笔记。
  • 从笔记本所在行删除笔记本。

Synology Office

已安装，以及它支持什么

这是状态界面，而不是编辑器：显示你的 NAS 运行的 Synology Office 版本，以及它支持哪些文档类型，即文档、电子表格和幻灯片，各带一个对勾。

为什么只做到这一步。Office 文档是存储在 Synology Drive 中、并通过它打开的。与其在 NAS 监控应用里做半个电子表格编辑器，应用选择告诉你 Office 已就绪，并把你指向 Drive，文档真正存放的地方。
Contacts

通讯录

先是所有通讯录的总数，然后是各个通讯录及其数量，包括从 Google 导入的通讯录，它们与在 NAS 上创建的并列显示。

  • 用顶部的输入框搜索全部内容。
  • 展开某个通讯录查看其中的联系人，各部分可以折叠，因此有两千个条目的通讯录不会淹没只有六个条目的那个。
  • 从某个通讯录所在行，或用右下角的按钮，向该通讯录添加联系人。
  • 编辑或删除现有联系人。

常见问题

文件常见问题

能把 NAS 上的文件下载到手机吗？
可以。打开 File Station，找到文件并下载。在移动设备上会交给系统分享面板，在 Windows 和 macOS 上则是原生的“另存为”对话框。下载同样适用于 QuickConnect。
能把文件复制或移动到插在 NAS 上的 USB 硬盘吗？
可以。外接硬盘会像共享文件夹一样显示为一个目标位置，因为 NAS 就是把它当作共享文件夹挂载的。选择“复制到”或“移动到”，打开硬盘并确认，NAS 会直接写入。
复制或移动会经过我的手机吗？
不会。NAS 自己完成这项工作。你的手机只发出请求并观察进度，因此几百 GB 的传输不会动用你的流量，关闭应用后它也会继续运行。
能在应用里创建共享文件夹吗？
可以，在“共享文件夹”子视图中创建。已有的共享会显示名称、所在存储空间、描述，以及是否带有 ACL 权限。
能阅读我的 Note Station 笔记吗？
可以。“笔记”子视图会显示你的笔记本，附带笔记数量和标签数量，你可以打开任意笔记完整阅读、创建笔记本或添加笔记。笔记中的图片会显示在它在笔记中所处的位置，NAS 无法发送的图片会显示“无法加载”的占位符，而不是凭空消失。
为什么 Synology Office 只显示状态？
因为 Office 文档是存储在 Synology Drive 中、并通过它打开的。应用会报告 Office 已安装以及它支持哪些文档类型，编辑文档应该用 Synology 自己的 Drive 应用。
为什么看不到一个我明明知道存在的文件夹？
这里的 File Station 严格遵守你的 DSM 账户权限。你的账户无法读取的文件夹不会出现，和网页界面一样。请用能看到它的账户登录。
