Больше, чем DS finder, в одном приложении

DS finder - собственное приложение Synology для настройки NAS и наблюдения за ним. Syno Manager - независимое приложение для дня после настройки: проверять всё, что работает на NAS, и действовать, не переключаясь между приложениями.
