隐私

哪些会离开手机，哪些不会

说得具体，而不是笼统地让你放心。下面是应用实际所做的事，包括唯一会被传输的那一样。

简要概述

你的 NAS 数据始终在你的掌控之中

数据去向
你的 NAS 报告的一切 - 系统读数、存储、网络、容器、套件、日志、用户、任务手机直达 NAS。路径上没有我们的服务器。
你的文件、照片和摄像头视频流手机直达 NAS，经由你配置的任何线路。
你的 DSM 用户名、密码和2FA设备令牌设备的钥匙串或密钥库。除了登录时发送给你的 NAS 之外，绝不传输到任何地方。
你向助手提出的问题及其回答哪里都不去。由设备上的模型处理。
应用设置 - 主题、布局、轮询、单位留在设备上，除非你自己导出。
崩溃报告Firebase Crashlytics。唯一会离开设备的东西。详见下文。
没有中间人

你和你的 NAS 之间没有 MiyaraHub 的服务器

这是架构决定的，而不是一项政策。Syno Manager 是一个使用 DSM 自己 API 的客户端 - 与 DSM 网页界面调用的是同一个 API - 直接从你的手机连到你的 DiskStation。

  • 在你自己的网络中，连接是通过LAN从手机直达 NAS。
  • 通过 QuickConnect 连接时，流量会经过 Synology 的中转服务 - 那是 Synology 的服务，使用的是你的 Synology 账户，而不是我们的。
  • 通过域名或 VPN，是直接连接到你的地址。
  • 以上任何一种情况下，路径上都没有 MiyaraHub 的服务。你的 NAS 数据无处可经过，也无处可存放。
凭据

你的密码存放在哪里

  • 平台的安全存储。iOS 和 macOS 上是钥匙串；Android 上是由 Keystore 支持的加密存储。绝不以明文保存，也绝不放在普通的偏好设置文件中。
  • 不包含在设备备份中。应用明确将其安全存储文件排除在 Android 云备份和设备迁移之外，所以还原或迁移手机时不会带上你的 NAS 密码。你只需重新输入一次。
  • 不包含在应用自身的设置导出中。备份 & 还原文件刻意不包含任何连接、密码或会话 - 一个带有 NAS 密码的便携文件，就是一个带有 NAS 密码的便携文件。
  • 无法读取时会被清除。如果保存的凭据无法解密 - 还原到新硬件上之后可能出现这种情况 - 应用会将其清除并要求你登录，而不是拿着读不了的内容反复重试。
唯一的例外

崩溃报告

应用内置了 Firebase Crashlytics，并且已启用。应用崩溃时会发送一份诊断报告，以便找到并修复崩溃。

崩溃报告包含什么

  • 堆栈跟踪 - 哪段代码出错，以及在哪里。
  • 设备型号和操作系统版本。
  • 应用版本和构建号。

它不包含什么

  • 你 NAS 的地址、名称或配置。
  • 你的 DSM 用户名、密码或令牌。
  • 你的文件、照片、摄像头录像或日志。
  • 你向助手提出的任何内容。
为什么要有它：没人看得到的崩溃，就是不会被修复的崩溃。这是用一份堆栈跟踪换取问题被发现 - 我们在这里明确写出来，而不是藏起来，因为悄悄略去唯一会传输内容的一项的隐私页面，算不上隐私页面。
助手

由构建强制保证，而不是靠承诺

设备端助手使用你手机上已有的模型。你的问题、你的 NAS 数据和回答都不会离开设备，关闭网络也能工作。

值得明说的一点：这不是需要谁去记住的政策。只要助手的代码中任何位置出现云主机、云 SDK 或 API 密钥，应用构建中的检查就会失败。这一保证是结构性的。

权限

应用会请求哪些权限，以及原因

权限原因
本地网络 (iOS)用于访问你自己网络中某个地址上的 NAS。没有它，iOS 会悄悄阻止连接。
照片库仅在你选择要发送到 NAS 的文件时使用。应用在 iOS 和 macOS 上声明了此权限，其他情况下不会触碰照片库。
麦克风仅用于助手中的语音输入，并且只有你使用时才会用到。没有麦克风的设备也完全受支持 - 只是没有该功能。
通知可选，用于应用自身的提醒。

常见问题

隐私 FAQ

Syno Manager 会把我的 NAS 数据发送到别处吗？
不会。你的手机直接连接你的 NAS。这条路径上没有 MiyaraHub 的服务器，所以你的文件、照片、摄像头录像、日志、使用数据和配置都不会到达我们或其他任何人手中。
有任何东西会离开我的手机吗？
只有一样：通过 Firebase Crashlytics 发送的崩溃报告 - 包含堆栈跟踪、设备型号和应用版本。它不包含你 NAS 的数据、你的凭据或你的文件。
我的 NAS 凭据存放在哪里？
存放在平台的安全存储中 - iOS 上是钥匙串，Android 上是由 Keystore 支持的存储 - 绝不以明文保存，并且被明确排除在 Android 云备份和设备迁移之外。
助手会把我的问题发送到服务器吗？
不会。它运行的是设备上已有的模型，断网也能工作。只要助手中任何位置出现云主机、SDK 或 API 密钥，应用的构建就会失败。
有广告或追踪器吗？
应用中没有广告、没有订阅，也没有应用内购买。

对以上内容有疑问？

请到问题追踪器提问 - 它是公开的，所以答案也能帮到下一个人。
